# guard_arms_lower：放下双臂，回战斗架势

> 空手护面规格。原速 300 ms，单次播放。与[抱架](guard_arms.md)共用两端姿势。

## 1. 目的与触发

宿主进入收势时先停止这次守的保持和受击，再播本段。玩家仍在战斗架势里，松开的是抱在脸前的双臂。结束时前拳回到肩前、后拳护在下颌侧，双脚保持原来的错步。

## 2. 关键姿势与支撑

首姿等于抱架循环 0.20 s 的全身姿势。两前臂从额前竖到上胸，只露出一道窄缝；肘尖朝下，躯干基本直立，下颌微收。放下时先松肩，再给前拳让出向前的路线；后手沿自己脸外侧回落。侧面能依次看见前臂之间的空隙打开、拳落过眼线、半侧身架势重新清楚。末姿逐骨等于 [stance_idle 首帧](stance_idle.md)，包括腕、手指和后脚趾。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 躯干、头和支撑 | 双臂与持物 |
| --- | --- | --- |
| 0–60 ms | 后脚前掌仍承重，胯在原处略稳一下。腰先松开，胸口随之打开，头仍朝前。 | 双肩松力，肘从上胸前稍让开。手腕先保住剑柄朝向，让放下动作从肩膀开始。 |
| 60–210 ms | 双膝从守位逐渐伸回架势屈度，胯回到原高度，腰胸带回半侧身，头跟随抬回架势视线。 | 前手向肩前送回，后手下落到下颌侧前方。肘先走，腕随后调整，主手剑沿本侧退开。 |
| 210–300 ms | 胯先稳，胸与头收住余势；前脚全掌和后脚前掌维持原接地点。 | 手腕缓停，手指从抱架时的紧握回到架势握形。到 300 ms 双拳和双脚都已到位。 |

剪辑长 **0.30 s（6 tick）**，`loop: false`。300 ms 是回到架势的时刻。末帧淡出期间底层继续走自己的时钟。收势由宿主计时，剪辑没有 `timeline` 事件。

## 4. 覆盖、视角与衔接

- 建议 `mask: full`、`priority: 16`，淡入 0.05 s、淡出 0.05 s。保持为 15，受击为 16；两者已收到停止，同优先级的放下后起播，短淡入承接当前可见姿势。
- 静止时双腿承接胯的回升，`root` 固定。移动时沿用架势的 `upper`，腰胸头和双臂放下，胯至脚趾继续当前步态。镜像、持物和视角同抱架，`hand: main`、`fpv: false`。全身第一人称应能看见两臂从眼前退开，主手的剑也沿同侧离开视野中心。
- 从任意呼吸相位、或受击后坐途中放下，旧层从停止时的姿势淡出。放下结束露出当前 `stance_idle` 或移动架势。终态清理后再起守，新动作从自己的抬手段开始。

验收重点是两种体型上放下的首尾与共用姿势一致，以及吸气最高处、受击最深处转放下时手腕的轨迹连续。静止看脚是否并拢或滑动，移动看放下时步伐是否被截断。
