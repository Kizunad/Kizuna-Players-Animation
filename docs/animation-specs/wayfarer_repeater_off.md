# wayfarer_repeater_off：连弩（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-11-01），实测与出入见文末「制作实测」。随主手页 [wayfarer_repeater](wayfarer_repeater.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9。本页只写与主手版不同的地方。

## 做法

- **时间轴、事件、窗口**：与主手版相同（5.0 s；`0.70: step_l`、`1.60 / 2.00 / 2.40 / 2.80 / 3.20: release`、`3.90: step_l`；失衡、瞄准、五段 `phases` 都不变），`hand: off`。
- **上身**（镜像主手版，C9）：
  - 躯干世界偏航取反：架弩时胯、腰、胸依次**左转**，胸世界约 −38°（主手版 +38°），右肩前送；头 +18°，正视前方。比架势（胸世界约 +20°）左转约 58°，胯、腰、胸各分约 20°；
  - 弩挂左手（`l_item`），照 `crossbow_hold_off` 抵左颊；右手托在扳机前、推拉；后坐时左上臂后让。
- **腿**：照搬主手版的脚位与脚步（C9：架势左前右后本来就合持弩）：前脚（左）0.45 离地、前移 1 px，0.70 全掌落（`step_l`）；3.60 离地、3.90 落回架势踝位（`step_l`）。IK 按镜像后的躯干重求；胯左转后两脚相对躯干成「交叉」站法（左脚在前、右肩在前）。
- **物品**：`item_states`（`pulling`、`pull`、`charged`）与主手版相同，挂在副手。

## 与主手版不同的约束

- 躯干要从架势反向转约 58°，淡入、收势的上身转动比主手版大；胯左转受两脚限制，主要靠腰、胸（各 ≤ 45 / 60），原型核对。
- 推拉够得着按主手版 C8 镜像估算（右肩前送约 3 px，右手推到弩身前约 3 px），交叉站法下右肩能否送得出去待原型。

## 门禁

适用项同主手页第 9 节；握持查左手握弩、右手推拉；错峰主链换右臂（推拉臂，C12），预备 / 跟随用左臂链。

改主手版后必须用同一原型重新生成本段，不允许只改一边。

## 制作实测（2026-11-01）

与主手版同一原型生成（`d_repeater.py` 的副手分支），索引字段、时间线同主手页第 10 节。门禁全部通过（粗、细臂相同）：关键帧 1,537；最快 692°/s（右前臂 1.72 s），抽搐最大 1.31×10⁶°/s³（左前臂 2.05 s）；最低点 −0.239 px；重心出界 0.53–0.62、3.72–3.80 s（同主手版，都在失衡窗口内）；支撑脚滑动右 0.02、左 0.26 px；手臂穿模 0；预备 / 跟随 4/5 骨（左前臂没过）。错峰门禁只判到第一拉一段（右上臂 1.35 → 右前臂 1.40 → 右手 1.43 s），五连同主手版因上臂整段主轴是 Z 没判到；探针按段内主轴另查，五段都是右上臂 → 右前臂 → 右手各隔一帧。自查：弩托离抵颊点最大 0.016 px，弩口俯仰在后坐外 ≤ 0.42°，后坐上跳 3.25°；推、拉到底托手位置五次差 ≤ 0.02 px。

与主手版不同的地方：
- 偏航不照镜像分配：架势本来偏右（胯 +12°），左转到镜像射位（胸世界偏航约 −32°）胯受双脚限制少转，胯、腰、胸面板 Y 为 −4 / −13 / −15°（主手版 +18 / +10 / +4°），头 +21°；预备腰、胸各反拧 3.5°；
- 交叉站法下右手够得着：2 px 行程同主手版，五次推拉的托手位置一致（见上）；俯仰、侧倾与腿照搬主手版。
