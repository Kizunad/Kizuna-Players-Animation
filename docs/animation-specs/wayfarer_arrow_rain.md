## 1. 动作目的与触发

- **用途**：行矢第八式，看不见目标时的覆盖射击：
  - 站得比别的式都宽，身体后仰，把弓举到仰角 50°，身体压进弓里拉满；
  - 五箭一支接一支抛上天；每撒放一次，双膝一伸、身体往上一送，像把箭往天上扔；
  - 最后仰着头目送箭落下去。
  - 全套唯一仰身、唯一往天上抛的一式（天地同至的前半段借用这个节奏，只抛三箭）。
- **触发**：行矢箭雨起手时，宿主调用 `PlayerAnimationAction.WAYFARER_ARROW_RAIN`（弓在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **7.0 s**（140 tick），`loop: false`。撒放 2.80、3.20、3.60、4.00、4.40 s。
- **承接**：没有承接入口。作后式：没有（服务端 §4.2 里箭雨只作前式；§4.3 弩式换兵只接满月、连珠、弓梢）。作前式：天地同至从 1.20、连弩 / 横风 / 跪射（换兵）各从 0.40 起播。收势从 4.40 起，前半段到 5.70，右脚 5.40 已回架势踝位。
- **打断**：起手 0–2.80 s 被伤害打断时淡出 0.20 s。
- **时间线事件**：`0.85: step_r`、`2.80 / 3.20 / 3.60 / 4.00 / 4.40: release`、`5.40: step_r`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。

### 起点与终点（0.00 s、7.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯 Y +2°（与之后的左转相反），胯位置前送 0.2 px。0.40 s 全身速度为零（同其他式的预备段末停顿；箭雨不作后式，这里不是承接入口）。

### 足踏（0.40–1.10 s）

- **右脚**：0.45 离地（离地前提踵变全掌在空中完成，C2），从左脚右侧绕到右前方，**0.85 全掌落在约 `(−0.7, 1.0, −8.4)`**（`step_r`）：在 B0 的右踝 `(0.2, 1.0, −6.6)` 沿两脚连线再外推 2 px，两踝相距约 6.5 px（B0 约 4.5 px）。行程约 11.6 px，比 B0 长 1.6 px，靠胯同时前移。
- **左脚**：0.50–0.90 绕踝竖线碾，脚跟内转，脚尖左转 40°（C2）。
- **胯**：0.45–1.00 到世界 Y −25°，位置约 `(1.0, −1.4, −2.9)`（比 B0 低约 0.5 px、前约 1 px）；胯、腰、胸 X 回 0。探针：这个高度双膝约右 18° / 左 54°，全身最低点约 −0.1（左小腿）；胯再降 0.3 px 左小腿就到 −0.25 的边。
- **上身**：腰 `(0, −8, 0)`、胸 `(0, −7, 0)`、头 `(0, 40, 0)`，侧身 40°，头的世界朝向回到正前方。

### 仰（1.10–1.80 s）

- **胯**：前送 1 px（到 z 约 −3.9，探针最低点约 −0.15），重心约 55% 在后脚（左）。
- **躯干**：腰 X 0 → +6°、胸 X 0 → +10°（1.10–1.60），胸的世界俯仰约后仰 16°；收着腹，不过度弓背。
- **头**：X 0 → +30°（1.20–1.70），看向落点上空。
- **弓臂**：1.10–1.50 举到仰角 50°：双臂在胸系里绕肩线再转约 34°（胸已后仰 16°），弓把、锚点在胸系里的相对位置照 `bow_draw` 的会（C5）。
- **弦手**：1.40–1.60 伸到弦上，手指 −8° → −62° 勾弦，**1.60 `pulling` 开**；左手同时攥着那把箭（另一只手拿着箭时可见，待决定第 17 条）。

### 第一拉（1.80–2.75 s）

- **躯干**：胸往弓下沉 0.5 px、再后仰 2°（X +12°）、左转 3°（两肩胛往脊柱夹，动作稿 §3.1），肩下沉；峰值约 1.95。
- **弦手**：1.85–2.70 拉到下颌下锚点，弦臂肘约 39° → 65°（C5）；`pull` 0 → 1（2.39 过 0.65 换 `_1`，2.61 过 0.9 换 `_2`）；手指 −62° → −70°。
- **弓臂**：不动。

### 五抛（2.75–4.45 s）

每发（撒放时刻 t = 2.80、3.20、3.60、4.00、4.40）：

- **撒放**：`release` t，`pulling` 关；手指 t → t+0.11 张到 −40°（C7），弦手后走 1 px（t → t+0.08）。
- **一送**：双膝 t → t+0.10 伸 3°、胯升 0.3 px，t+0.10 → t+0.25 回落；胸 t → t+0.06 被顶回前 3°（X −3°），t+0.06 → t+0.15 再后仰回去。
- **搭、拉**（前四发之后）：弦手 t+0.08 → t+0.18 回到弓旁，**t+0.15 `pulling` 开**；手指 t+0.11 → t+0.21 勾回 −62°（与拉弦重叠约 0.03 s）；t+0.18 → t+0.38 拉到八五成（`pull` 0 → 0.85，`_1`），手指到 −68°。
- **最后一发（4.40）**：手指 4.40–4.57 张到 −8°，弦手后走 2 px，`pulling` 保持关。
- 弓臂在 2.75–5.00 一直举在 50°。

### 随（4.45–5.00 s）

- 头 X +30° → +10°（4.50–5.00），目送箭落下去；弓臂留在高处；双膝、胸回到第一拉末的位置。

### 收（5.00–7.00 s）

- **脚**：5.00 重心压到左脚；右脚 5.02 离地，**5.40 以提踵 −35° 落回 `(−1.7, 1.72, 3.2)`**（`step_r`）；左脚 5.05–5.35 绕踝竖线碾回架势朝向；胯 5.00–5.45 回到架势位置。
- **上身**：5.40 起腰、胸 X 回 0、头 X 回 0，再回架势（6.30 到位）；5.50–6.50 长呼气。
- **双臂**：弓 5.00–6.20 从高处放下回持物位；左手 5.40–6.30 回下巴前；6.40–7.00 静止。

## 7. 骨架与门禁带来的约束

1. **宽站的高度**（探针）：两踝相距 6.5 px 时，胯比 B0 再降 0.5 px，左小腿最低点约 −0.1；降到动作稿的 0.8 px 时约 −0.2～−0.3（仰时前送 1 px 再低一点）。所以按 0.5 px 做，「双膝屈 15°」读作「比 B0 再屈约 5–10°」（C4）。
2. **仰射的锚点**：胸后仰 16°、头抬 30°，双臂绕肩线再转 34°；头绕颈枢轴、双臂绕肩线，转轴不同，弦手到下颌的相对位置会变，要原型按 `arm_frame_ik` 核对（PROGRESS 出入表）。
3. **连抛的手指**：每发 0.40 s，手指只张开 30°（0.11 s）、0.10 s 勾回，峰值约 510°/s、抽搐约 1.35×10⁶，贴着上限（C7）；原型实测超了就把勾回放到 0.11 s、拉弦晚 0.01 s。
4. **胸的反作用**：3° / 0.06 s，抽搐约 8.3×10⁵；做成 0.03 s 会超。

## 10. 制作实测（2026-11-01）
