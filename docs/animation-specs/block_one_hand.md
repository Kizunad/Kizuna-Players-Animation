## 1. 动作目的与触发

- **用途**：单手武器（剑、斧、工具）的单手上架：右（主手）前臂竖起挡在右额前，拿剑时剑身从拳的拇指侧斜向左上，成“上架”；左拳收回护下颌。补上 `block_shield` 设计时留下的“通用单手/双手格挡”缺口；持盾仍用 `block_shield`。
- **触发**：调用方给出“格挡中”状态（原版没有通用格挡，按键与判定都在战斗 UI / Human，本轮不接线）；持续到调用方结束格挡。选择：主手单手武器 → `block_one_hand`；双手武器或空手 → `block_two_hand`；副手持盾 → `block_shield_off`。
- **受击反馈**：拆成独立 ID [block_one_hand_hit](block_one_hand_hit.md)（审阅决定 Q10），叠在本保持段之上播一次，回到同一保持姿态。
- **时长**：剪辑 **1.95 s**，`loop: "hold_on_last_frame"`，`loop_region: [0.35, 1.95]`：0.00–0.35 举起（格挡开始后的真实时间），0.35–1.95 保持循环（1.6 s 一次呼吸）。
- **结束**：格挡结束淡出 0.15 s 回当前架势底层。

## 2. 关键姿势

- **保持姿态（0.35 s）**：右上臂 `(89.7, −32.1, 28.9)`、肘屈 21.0°、手 `(−32.0, 12.2, 22.2)`（尺偏 32°），`r_item` 在 `(−2.8, 23.3, −9.2)`：拳在右额前、眉高；左上臂 `(53.8, 3.8, 28.5)`、肘屈 60.6°，`l_item` 在 `(2.2, 21.0, −8.9)`：左拳收在下颌左前。
- **躯干**：胯 `(0.15, −2.0, 0.97)` / `(−7, 9, 0)`：比架势再沉 0.2 px、后坐 0.4 px、左转 3°（右肩迎上去）；腰 `(−3, 0.6, 0)`、胸 `(−0.8, −1.8, 0)`，头 `(−3, −15, 0)`（低头收在臂后）。
- **手指**：比架势再握紧 6°。
- **双腿**：前脚全掌、后脚提踵，锁定在架势踝位；胯下沉后坐由屈膝吸收；后脚脚趾 0.2 s 起再背伸 2°。

## 3. 分阶段全身动作

- **举起 0.00–0.35**：胯 0.06 s 先下沉 0.1 px、前移 0.1 px（预备），0.26 s 到保持位；腰 0.05 s、胸 0.06 s 先前倾 1°～1.8°（反向预备），0.13 / 0.15 s 到 0.8 倍、0.24 / 0.26 s 过冲 1.15 倍；头 0.08 s 先抬 2°，0.30 s 低到保持。
  右臂先外展、略抬蓄（0.08 s：前举 +3°、外展 9°），再经外侧上抬（0.29 s 到位并过冲 4°）；肘不做反向预备（后手肘下沉时再屈会把前臂压进腰），0.31 s 过冲 5°，腕 0.33 s 过冲 4°。
- **保持 0.35–1.95**：呼吸节律从胯 → 腰 → 胸 → 头 → 肩 → 肘依次晚 0.04～0.2 s；手腕不动（保持挡面朝向）。

## 4. 重心与支撑

双脚全程锁定（滑动 ≤ 0.02 px），最低点 -0.125 px；重心在两脚之间偏前脚。

## 5. 衔接

- 进入：架势底层上发起，淡入 0.06 s；移动底层只取上身，腿继续走 `stance_walk_*`。
- 退出：淡出 0.15 s；受击段播放中结束格挡时两者一起淡出。
