# wayfarer_dry_draw_off：拉空弓（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-10-31），实测与出入见文末「制作实测」。随主手页 [wayfarer_dry_draw](wayfarer_dry_draw.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9，射位见 C4 副手版。本页只写与主手版不同的地方。

## 做法

- **时间轴、事件、窗口**：与主手版相同（32.0 s；`0.45: step_r`、`31.70: step_r`；失衡占位、五段 `phases` 都不变；没有 `aim_windows`），`hand: off`。
- **上身**（镜像主手版，C9）：侧身向右 40°（胯 +25°、腰 +8°、胸 +7°），足踏时头 Y −19° → −25°、立弓时到 −40°；左手持弓，右手勾弦、拉开、持满、慢放；每周期胸张开 X +2°、Y +3°。
- **腿**：同 [满月副手版](wayfarer_full_draw_off.md)，时刻照本式：右脚 0.10 离地、**0.45 全掌落在 `(0.2, 1.0, 1.4)`**（`step_r`）；左脚 0.15–0.50 碾到脚尖右转 40°；收步右脚 31.40 离地、**31.70 以提踵落回架势踝位**（`step_r`）。
- **物品**：`item_states`（`arrow` 全程 0、`pulling`、`pull`）与主手版相同，挂在副手。

## 制作实测（2026-10-31）

同主手页第 10 节的做法：胯以上全部镜像主手版，腿按 C4 副手版。索引同主手版（`hand: off`）。

**门禁**：全部通过。关键帧 2,193；全段最快 666°/s（右手手指 31.10 s），抽搐最大 6.4×10⁵°/s³（左小腿 31.33 s）；最低点 −0.186 px；重心出界 0.38 s、31.47–31.58 s（都在失衡窗口内）；持满弦手离锚点最多 0.073 px，周期间导出差最多 0.32°。

**与主手版的出入**（都为预备 / 跟随门禁：持物臂换成左臂后，左臂护颌 ↔ 腹前的上臂行程约为主手版两倍）：
- 弓手放到腹前放慢到 0.03–0.60 s（主手版 0.05–0.50），落弓放慢到 31.00–31.48（主手版 31.05–31.42）；
- 放弓前左前臂 0.00–0.20 s 先屈 6°，给立弓伸肘一个反向；
- 结果持物臂链 5 骨里 3 骨通过（门禁要 60%）。
