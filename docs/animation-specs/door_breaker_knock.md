## 1. 动作目的与触发

- **用途**：破门斩第一式，单手持斧。斧刃朝前，小臂带着斧子短促连敲门板三下：斧子每次只抬到肩高，随即落下。前两下轻，用来找距离和节奏；第三下身体跟着转一点，落得最深。「咚、咚、咚！」一下比一下重，每一下都由双膝轻沉带出。
  - 与破门（`door_breaker_cleave`）的区别：叩门是单手、小臂发力的轻敲，斧子不过肩；破门是双手、全身发力的举过头重劈（用户 2026-10-29）。
- **触发**：功法 `meridian_door_breaker:knock` 起手时，宿主（Human）调用 `PlayerAnimationAction.DOOR_BREAKER_KNOCK`，按真实时间播放，用 `start_tick` 同步起点。出手的手是副手时播 `door_breaker_knock_off`（第 7 节）。
- **时长**：剪辑 **3.0 s**（60 tick），`loop: false`。起手 0–1.70 s，`hit` 1.70 s（服务端在这一刻结算）；收势 1.70–3.0 s。服务端数值和钝击语义不变：画面上是斧刃敲，结算仍按钝击（用户 2026-10-29）。
- **承接入口 0.30 s**：撞门之后接叩门时，宿主把 `start_tick` 前推 6 tick，从 0.30 s 起播，跳过整段预备。0.30 s 的姿势必须是「预备做完、斧子还没开始放下」，能直接接 0.30 s 淡入。
- **打断**：服务端设计里叩门起手**不能**被伤害打断，所以不设打断路径；播完按 `blend_out` 淡回 `stance_idle`。
- **时间线事件**：只有 `1.70: hit`（客户端通知，不授权伤害）。两下轻叩不发事件；全程不迈步，不发 `step_l` / `step_r`。

## 3. 分阶段全身姿势

数值为面板值或模型空间位置（像素，脚底原点，右侧 −X、前方 −Z）。「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量。
斧子几何同渲染器 `AXE_*` 常数（挂点局部）：柄线方向 `AXE_ALONG`，刃口朝向 `AXE_EDGE`（第 8 节）；「斧头中心」取柄上 4.8 px、刃口方向 0.75 px，「刃口点」取柄上 4.8 px、刃口方向 4.2 px。

### 起点与终点（0.00 s、3.00 s）

与 `stance_idle` 首帧完全一致（胯 `(0.15, −1.8, 0.6)` / `(−6, 12, 0)`，腰 `(−3, 4, 0)`，胸 `(−2, 4, 0)`，头 `(3, −19, 0)`，右拳 `r_item` 在 `(−4.4, 22.6, −7.7)`，左拳 `l_item` 在 `(4.3, 23.6, −10.2)`（2026-10-29 改后的护手位），握拳手指同架势）。首尾速度为零。
架势里斧子竖在头右侧：柄朝上偏右（世界方向约 `(−0.43, 0.90, 0.08)`），斧头中心约 `(−7.8, 28.4, −6.2)`，斧刃朝前（约 `(0.38, 0.26, −0.89)`）；右腕弯折 14°、扭转 8.5°。

### 预备（0.00–0.30 s）

- **胯**：位移到相对架势 `(0, −0.1, −0.2)`（0.22 s），旋转 Y −2°（0.20 s）。
- **腰 / 胸**：Y 各 −1°，比胯晚 0.02 / 0.04 s。
- **头**：Y 反向 +2°，视线不动。
- **右臂**：拳下沉 1 px、内收 0.3 px（0.27 s 到位），为随后的前伸做反向预备；腕角不变。
- **左臂**：拳前送 0.5 px（0.27 s）。
- **腿**：双脚锁定，由胯求解，膝几乎不变。

### 对门（0.30–0.65 s）

- **胯**：相对架势位移 `(−0.05, −0.25, 0)`、旋转 Y +4°（0.55 s 到位）。
- **腰 / 胸**：Y +1° / +2°（0.58 / 0.60 s）。
- **头**：抵消躯干转动看住门，并低头 1°（看胸口高的落点）。
- **右臂**（0.62 s 到位，上臂 → 肘 → 腕依次晚 0.02 s）：拳 `r_item ≈ (−5.4, 16.6, −5.0)`，在右腹前。上臂约 `(6, −31, 8)`（大臂基本垂下），屈肘约 60°；手腕约 `(27, 8, −4)`：桡偏后翘 27°，弯折 28°，扭转 7°（架势是 8.5°，即**不翻腕**）。
  柄线前倾约 21°、略偏右；斧头中心约 `(−7.3, 23.2, −5.5)`，比架势落下约 5 px，到肩高；斧刃朝前（约 `(0, −0.23, −0.97)`）。斧子离头盒约 1.6 px。
- **左臂**（0.60 s 到位）：掌心朝前，按在身前 `l_item ≈ (3.0, 21.0, −11.5)`，肘微屈约 25°；腕背伸约 40°，使掌心朝前；手指伸开（两组 −78° / −84° → −12° / −15°，拇指 −48° → −15°）。掌离斧子 ≥ 5 px。
- **腿**：胯降 0.15 px 由双膝微屈吸收，脚锁定。

### 第一叩（0.65–1.05 s，接触 0.90 s）

- **举**：0.80 s 保持对门姿势（斧在肩高）。
- **腿**：胯 0.84–0.88 s 下沉 0.35 px（双膝约各多屈 4°），0.95–1.02 s 回升。
- **胯 / 腰 / 胸**：0.83 / 0.85 / 0.86 s 达到角速度峰值，各左转约 3°、1°、3°，1.00 s 后回到对门。
- **头**：Y 反向，0.90 s 低头 2°（看点到处）。
- **右臂**（链：上臂 0.87、肘 0.89、腕 0.90 s 依次到峰值）：
  - 上臂下压前送约 29°，到约 `(35, −27, 10)`；
  - 肘由约 60° 伸到约 32°；
  - 腕由桡偏 27° 甩到约 6°（尺偏甩出 21°），弯折 12°，扭转不变；
  - 拳到 `(−4.8, 15.3, −7.7)`，柄前倾约 37°；刃口点约 `(−6.1, 19.5, −13.5)`，斧刃朝前下约 35°。
  - 0.92–1.05 s 原路回到肩高（回的速度约为出手的一半）。
- **左臂**：掌按住不动，只随胸转动被动小移。
- **手指**：右手 0.90 s 再握紧 2°。

### 第二叩（1.05–1.35 s，接触 1.25 s）

- 与第一叩同链同序（1.15 s 举在肩高），幅度略大：胯降 0.45 px（1.23 s 最低）；胯、腰、胸左转约 4°、1.5°、4°（峰值 1.18 / 1.20 / 1.21 s）；上臂 1.22 s、肘 1.24 s、腕 1.25 s 到峰值。
- 拳到约 `(−4.6, 15.0, −8.0)`，柄前倾约 40°，刃口点约 `(−5.8, 18.9, −14.0)`，比第一下深约 0.5 px。
- 1.28 s 起回弹不回到对门位，而是跟着躯干右转带向后方，转入蓄（见下）。左掌 1.30 s 起收回。

### 蓄（1.35–1.55 s，后带从 1.28 s 开始）

- **腿与重心**：胯位移到相对架势 `(−0.2, −0.15, 0.4)`（1.50 s），重心后移约 0.4 px，仍在两脚之间。后脚保持架势提踵（不落后跟），后膝多屈约 3°。
- **胯 / 腰 / 胸**：胯 `(+1, +10, 0)`（1.50 s）、腰 `(0, +3, 0)`（1.52 s）、胸 `(+1, +7, 0)`（1.54 s），躯干累计右转 20°。这是单手轻敲的量，比柄尾版的 36° 小，留给破门用全身。
- **头**：Y 约 −20°，继续反向转，视线锁在门上。
- **右臂**：1.28–1.52 s 拳随右肩后带到 `(−5.8, 17.0, −3.8)`；上臂约 `(8, −37, 14)`，屈肘约 55°，腕后翘到约 `(25, 6, −12)`（弯折 29°）。斧头中心约 `(−7.6, 23.6, −3.9)`，仍在肩高；斧子离头盒约 1.3 px。手指 1.50 s 握紧 8°。

### 随（1.75–2.20 s）

- **腿与重心**：胯相对架势 `(0.15, −0.45, −0.3)`（1.90 s），重心约 55% 在前脚；前膝 1.75–1.90 s 回弹约 1.5°（膝伸一点再稳住）。
- **躯干**：胸 Y 过转到相对架势 −8°（1.85 s）后减速；胯、腰比胸早 0.03 / 0.015 s 到过转点。
- **右臂**：砸实后反弹：1.72–1.80 s 腕回翘 8°、肘回屈 6°（刃口回弹约 1 px），1.90 s 起放松，斧子停在身前胸口高。手指 1.78 s 放松 3°。
- **左臂**：保持贴肋。

### 收（2.20–3.00 s）

- **后脚**：2.20–2.45 s 脚底俯仰回 −35°、脚趾回 10°（架势提踵位）；胯 2.45 s 回架势位置，此后腿脚静止。
- **躯干**：胯 2.45 s、腰 2.55 s、胸 2.65 s、头 2.75 s 依次回架势（缓入缓出）；2.30–2.90 s 一口长呼气（胸 X 先 −1° 再回 −2° 基准，叠在回位上）。
- **右臂**：2.35 s 起经身前把拳抬回右下颌，2.95 s 到位；斧子随之回到头侧竖直持物位。
- **左臂**：2.40 s 起拳回下巴前，2.90 s 到位。
- 3.00 s 全身等于 `stance_idle` 首帧，速度为零。

### 不动的部位

- `root`：功法锁移动，模型空间里不推 root。
- 前脚（左）：全程全掌锁定，只有踝背屈随膝屈变化。
- `r_item` / `l_item`：挂点，不允许轨道（不换握）。

## 4. 重心与支撑

- 双脚全程着地：前脚全掌；后脚脚趾前缘承重，只在实叩时提踵多 5°、收势回位。没有单脚支撑期，不声明 `unbalanced_windows`。
- 柄尾版的「蓄时后跟落低」去掉了：轻敲不需要大幅后坐。同时也免掉了后小腿前角先触地、后跟只能落到离地 0.5 px 的问题。
- 重心投影（门禁口径：落在两脚踝 ±2 px 内）：架势 z ≈ −0.9；蓄后移到约 −0.5；实叩、随前移到约 −1.5；x 随胯在 −0.2～+0.3 之间。

## 5. 衔接

- `stance_idle` → `door_breaker_knock`：淡入 0.10 s。起点就是 `stance_idle` 首帧。`mask: full`，不属于 `AnimationPlayer` 的架势上层或原版上层规则，任何底层上都整段生效。功法锁移动，只从 `stance_idle` 进入。
- `door_breaker_knock` → `stance_idle`：播完淡出 0.25 s。
- 承接：
  - 撞门 → 叩门：从 0.30 s 起播，前一式淡出 0.30 s。
  - 叩门 → 破门 / 破盾 / 横扫：在叩门收势后半段（2.60–3.00 s）或结束后 0.5 s 内，后一式从它的承接入口起播。
  - 这些边等后续各式交付时再加进切换表。
- 服务端每次打击另调原版挥手：客户端会起 `attack_main`（优先级 20，在架势底层上只取上身）。它低于本段的 24，不接管任何骨，不需要新规则；已有组合回归覆盖。

- `loop` 省略（一次性），时间线 `{"1.7": "hit"}`。叩门只有一段打击时段，沿用单段字段 `impact_window`。
- 没有 `burst_windows`、`unbalanced_windows`、`slide_window`、`reaction`。
- **两下轻叩**不声明打击时段，必须满足窗口外上限 720°/s、1,500,000°/s³。按升余弦估算：上臂约 29° 在 0.12 s 内，峰值约 380°/s；腕约 21° 在 0.10 s 内，约 330°/s。回弹按一半速度。
- **实叩**：上臂约 25° 在 0.08 s 内，峰值约 490°/s；腕约 26° 在 0.06 s 内，约 680°/s；都远低于窗口内上限 1,800°/s。1.75 s 窗口结束时，所有骨角速度必须已降到 720°/s 以下（反弹段放慢）。
- `phases` 先沿用；如果制作时轻叩的回弹段角速度盖过出手段，就按实测收窄（柄尾版就是这样收到点到为止）。

## 8. 打击面：斧刃

### 斧刃朝向

- 原版 `item/handheld` 第三人称右手 display 为 `rotation [0, −90, 55]`。按 `iron_axe.png` 贴图和挂点变换 `Rx(−90)·Ry(180)` 推算，刃口方向在 `r_item` 局部约为 `(0, −0.985, 0.174)`（渲染器 `AXE_EDGE`），几乎沿前臂指向拳外；斧背则指回肘。
- 核对：架势里斧刃朝前；原版垂手持斧时斧刃朝下；第一人称刃口朝前上。三者都与游戏观感一致。
- 所以前臂指向前下、柄竖在拳上方时，斧刃自然朝前。小臂下落加腕尺偏一甩，斧头就沿刃口方向前进，是最顺的单手敲法，不需要翻腕或换握。

### 为什么不用柄尾、斧背

- **柄尾**（2026-10-28 版，已录入）：用户验收时退回，要求回到斧背。
- **斧背**：斧背法线约沿前臂指回肘，斧背朝前就要求肘在拳前或与拳齐平。复核（`~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/probe_back3.py`）发现：
  - 柄尾版第 8 节当时报的「腕各分量限 60° 时偏差 21°～28°」，手腕实际弯折了 113°～172°，拳折回贴着前臂，欧拉分量上限挡不住；
  - 按已交付动画的实际腕限（弯折最大约 75°，扭转约 90°）约束后，斧背只能到胸前约 5 px，偏差 23°～25°，姿势别扭。
  - 对比图：`build/anim-review/door-breaker/knock-rework/axe-back-options.png`。
- 斧面拍门（可行）和翻斧换握（要改挂点接口）也比较过，用户都没选。用户 2026-10-29 定为斧刃。

### 本稿的腕约束

- 弯折 ≤ 40°（实测最大约 29°），扭转保持架势的 8.5° ± 12°，即**不翻腕**。
- 欧拉分量都远在门禁 120° 以内。

## 11. 制作结果

关键帧由原型 `~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/d_knock.py` 求出，`install.py` 写入 `.bbmodel`，再用仓库导出脚本导出。架势基准取第 2 项改后的版本（左护手位腕旋后 31°、拳外移 0.5 px）。

**做法**：
- 躯干（胯位置 / 旋转、腰、胸、头）按相对架势的增量关键帧给出，每根骨自己的时刻。
- **持物臂改在关节空间给出**（上臂、肘、腕三段），手腕关键帧在到位时刻，肘早 `lag`、上臂早 `2·lag`。
- 空手臂按挂点位置或绝对角度给出；按门的掌与回拉的拳按原护手腕角取绝对朝向（同架势的手势规则）。
