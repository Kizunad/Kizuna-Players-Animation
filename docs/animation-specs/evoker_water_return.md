## 1. 动作目的与触发

- **用途**：五脏诀强身第四式，照五禽戏鹿抵。左脚往左前方迈成弓步，腰往左后方拧，两手成鹿角向后划弧，左肘抵住腰，右臂举到头前往后伸，眼睛从左肩上方往后下方看。全书唯一拧腰回望的一式。
- **触发**：五脏诀归水起手时，宿主调用 `PlayerAnimationAction.EVOKER_WATER_RETURN`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。效果 `cast` 2.40。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`0.90: step_l`、`2.40: cast`、`3.30: step_l`。整段在架势的错步上做，不开立；右脚整段不离地，没有 `step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- **腿**：胯 0.00–0.40 由 `(0.15, −1.8, 0.6)` 后移到 `(−0.2, −1.9, 3.2)` 附近，重心压到右踝 `(−1.7, 3.2)` ±2 px 内（重心 Z ≥ 1.2，原型按重心求）；左腿随之伸直到膝约 15°，右膝约 80°。
- **躯干**：胸 X −2° → 0，腰 X −3° → −1°（上身竖直）。
- **双臂**：两拳不动，只随躯干。

### 上步（0.40–1.00 s）

- **腿**：左脚 0.45 离地，先收向右脚内侧（0.65 在 `(0.6, 1.8, 0.4)` 附近，离地 ≤ 1.2 px），再向左前方迈出，0.90 脚跟着地于 `(3.3, 1, −5.6)`，脚尖翘 ≤ 12°（E7）；右脚前掌撑住，踝不动。
- **躯干**：胯 Y 12° → 15°、腰 Y 4° → 6°、胸 Y 4° → 6°（依次晚 0.04 s），这是拧腰的反向预备；头 Y −19° → −15°。
- **双臂**：两拳 0.45–0.95 向右侧摆起到肩高，拳心朝下：右上臂外展到约 80°、肘 30°；左上臂前屈 90°、水平内收约 60°，左拳在胸前右侧；左臂晚 2 帧。

### 拧腰回望（1.00–2.40 s）

- **腿**：
  - 左脚 1.00–1.20 绕脚跟放平（踝降 ≤ 0.4 px），1.20–1.40 绕踝竖线外转 20°；
  - 胯 1.20–2.00 前移到 `(0, −2.0, −2.2)`（探针：右腿伸直、左膝约 46°），转到 Y −30°；
  - 右脚 1.40–2.00 半落跟：踝 1.72 → 1.25，脚底 −35° → −15°；右脚绕踝竖线脚跟外转约 15°。
- **躯干**：胯 Y +15° → −30°（1.20–2.00），腰 Y +6° → −15°（晚 0.05 s），胸 Y +6° → −15°（晚 0.10 s），胸 X +5°（挺胸）。
- **头**：Y −15° → −40°、X 0 → −20°（相对胸），1.60–2.30；世界偏航约 −100°，视线朝左后下方。
- **双臂**（1.00–2.30）：
  - 手型 1.00–1.30 由拳变鹿角（E3：腕背伸 30°、拇指 `(40, 0, 0)`、两组手指 15° / 35°）；
  - 左臂：向上、向左、向后划弧，左上臂后伸约 20°、外展约 25°，肘屈约 90°，肘尖抵在左腰侧（离腰 0.3–0.5 px，不穿）；左手在左腰后上方，鹿角朝后；
  - 右臂：经头前向左上划弧，右上臂前屈约 150°、内收约 40°，肘 30°，右手在头前左上方，鹿角指向左后方；
  - 两臂峰值：右上臂 1.62、右前臂 1.68、右手 1.75；左臂各晚 2 帧。

### 定（2.40–2.80 s）

- 全身不动，屏气。

### 回（2.80–3.40 s）

- **腿**：胯 2.80–3.05 后移、转回，重心压回右踝上方（同预备）；左脚 3.05 离地，3.30 全掌落回 `(2.3, 1, −2.6)`、脚尖外转 10°（`step_l`）。
- **躯干**：胯、腰、胸 Y 2.80–3.30 转回架势角（胯 12°、腰 4°、胸 4°），头回 −19°、X 回 3°。
- **双臂**：两臂 2.85–3.35 落下，鹿角 3.00–3.30 握成拳。

### 收（3.40–5.00 s）

- **腿**：右脚跟 3.40–3.70 提回：踝 1.25 → 1.72，脚底回 −35°；胯 3.40–4.00 前移、降回 `(0.15, −1.8, 0.6)`。
- **上身**：腰、胸 X 回架势；两拳 3.40–4.30 回护身位；呼气 3.40–4.20（胸 −2°）。

## 8. 骨架与门禁带来的约束

1. **弓步可达**（探针）：见页首第 1 条。弓步的形由胯前移、前倾和拧腰撑。
2. **后脚半落跟**（E7）：右脚整段着地，踝 Y 范围 1.25–1.72 = 0.47 px ≤ 0.5。
3. **回望**：头相对胸 Y −40°、X −20°，合成约 45°，叠上视线层头最多约 70°，在颈的上限内。
4. **拧腰分摊**：胯 −30°、腰 −15°、胸 −15°，腰、胸在 45 / 60 上限内；胯相对两脚转 30°，大腿相对胯拧约 30°（左脚外转 20° 分掉一部分）。
5. **左肘抵腰**：分析器只查前臂和手对躯干；肘尖在前臂近端，原型保持前臂离腰 ≥ 0.3 px。

## 11. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/evoker/d_water_return.py` 求解（交接目录，不入库；左脚上步、回步用千里腿 `ped.step`，上步另叠一个经右脚内侧的水平鼓包；右脚整段着地，半落跟用 `ped.planted`），由 `install_ev.py` 装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：`phases` `[[0.40, 1.00], [1.00, 2.40]]`（同第 7 节）；**另声明 `unbalanced_windows` `[[0.73, 0.84], [3.05, 3.27]]`**（第 5、7 节原定不声明，见出入）；时间线 `0.90 step_l`、`2.40 cast`、`3.30 step_l`。分析器 `UNBALANCED_WINDOW_PREFIXES` 已加 `evoker_water_return`。

**门禁**：全部通过。
- 有效运动骨 26 根；关键帧 1,517（目标 1,000–1,300，超出：两腿支撑脚 IK 逐帧出帧）。
- 全段最快 613°/s（左上臂 3.17 s，两臂落下）；抽搐最大 0.83×10⁶°/s³（左小腿 2.98 s，回步离地前）。
- 最低点 −0.211 px（右小腿 1.55 s，半落跟）。支撑脚滑动右 0.492、左 0.471 px：右脚整段是一个着地段，踝 Y 范围就是半落跟、提回过冲的高度差。
- 重心：去掉窗口逐帧量，出界 0.750–0.817 s（左脚跟着地前）与 3.067–3.250 s（左脚回步离地后），两套相同；窗口各放宽约 1 帧。
- 关节最大：头 40.0°、腰 15.1°、胸 15.1°、右手 30.0°、左手 35.0°（架势本身）；右小腿 83.5°（3.27 s，见出入）。
- 手臂穿模 0。
- 预备 / 跟随 4/5 骨：右前臂主通道峰值在 0.78 s，没有反向蓄力，不过。
- 错峰：
  - 上步 `[0.40, 1.00]`：右上臂 X 0.700 → 右前臂 X 0.783 → 右手 Z 0.817；腰、胸本段只转 2°（不到 3°），不计；
  - 拧腰回望 `[1.00, 2.40]`：腰 Y 1.583 → 胸 Y 1.633 → 右上臂 X 1.683 → 右手 Z 1.833；右前臂本段肘角不变（30°），不计。
- 曲线相关 2/253 对。

**自查**：
- 右踝 X 整段范围 0.022 px，Y 范围 0.492 px（规格 ≤ 0.47，见出入）；左脚弓步着地段踝 X 0.027、Y 0.211 px，回步落地后 X、Y ≤ 0.15 px。
