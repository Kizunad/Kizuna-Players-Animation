# piglin_sword_coil · 缠（流金剑下卷第四式）

> 主手 `piglin_sword_coil`，副手 `piglin_sword_coil_off`。文中左右按右主手角色自身计算，时间从施放起点算起。

## 1. 目的与触发

施放者用一只手持剑。剑尖沿目标持械前臂的轮廓盘过一圈，双方牵住一段时间，最后剑沿原来贴住的方向抽回。
以施放者身前的前臂高度作构图参照。三格是双方距离的玩法边界，剪辑中手臂和剑保持模型原长。

下卷要求 `#meridian_piglin_sword:soft_blades`（默认金剑）。目录在起手时发 `meridian_piglin_sword:piglin_sword_coil`，人体按施放快照选持剑手。
符合标签的剑共用同一条相应手别的轨道。普通硬剑由宿主在施放前拒绝。剑身的柔软、弯曲与颜色交给物品效果。

## 2. 目录时刻与时间线标记

时间取自剑仓 P3 的 `shared/src/main/resources/data/meridian_piglin_sword/technique_catalog.txtpb` 中的 `coil`。原速每 tick 50 ms。

| 目录 | 剪辑时间 | 屏幕上看到的动作 |
| --- | --- | --- |
| `presentation` 在 0 ms，`start_millis: 0` | 0.00 s，第 0 tick | 从战斗架势起播 |
| `warmup_millis: 500` | 0.00–0.50 s，第 10 tick 到位 | 盘绕一圈，握剑手停在目标前臂旁。0.50 s 是持段入口 |
| `active_millis: 2500` | 0.50–3.00 s，共 50 tick | 始终保留牵住的轮廓，末段身体先换重心，给抽剑留出预备 |
| `weapon_strike` 在 3000 ms | **3.00 s，第 60 tick，唯一的 `hit`** | 刃口回抽经过贴合处。目录为正前方单目标、距离 3 格、锥角 60°、×1.2、`CUTTING` |
| `recovery_millis: 350`，`UNTIL_RECOVERY_END` | 3.00–3.35 s，第 67 tick 结束 | 抽离后的跟随、归架，收势结束时宿主发 STOP |

设计 §4 的起手、持段、末击与冷却 18 s 和目录一致，目录另给出了 350 ms 收势。§5 的「缠住」记录目标及其出手侧，「持缠」限制施放者选定的手，两人仍可在三格内走动。
P3 这条定义只有起播和一次末击，没有在 500 ms 写入锁手效果。成对状态、超距解除、反拉以及抽完半秒内接「绕」属于 P4。0.50 s 在本片只作为姿势边界。

## 3. 关键姿势

- **架势**。左前脚全掌着地，右后脚以前掌支撑，右拳在右颊侧前，左拳在前。头看向正前的目标。
- **盘上**。三分之四视角下，握柄仍在圈心附近，剑尖从圈心一侧经过上沿、远侧和下沿，最后落回前臂旁。持剑侧肩稍向前，左手退到剑路之外。腕、肘、肩合成道具的圆弧，腕骨在自己的活动范围内转动。
- **持缠**。握柄留在身前，肘保留弯度。胸和前膝先压下，再稍稍让回。隔一会儿，后脚承担更多重量，胸口稳住，握柄仍朝同一处。头部姿态补偿躯干的转动。玩家转头时沿用 PA 的加性视线层，朝向由玩家视线决定。
- **抽离**。侧面看得见握剑腕从身前拉到身侧后方。前膝先屈深、持剑肩压低，后脚跟抬起，胯撤回，肩线随后打开。剑尖横过身前，非持剑拳还向前送，两手在命中后拉开。剑再多走一截，身体稳住才归架。

## 4. 分阶段全身动作

下列分界供制作安排节奏，目录锚点为 0.50、3.00、3.35 s。全程在架势的两个支点之间换重心。

| 剪辑时间 | 腿、脚与胯 | 腰、胸肩与头 | 持剑臂与非持剑手 |
| --- | --- | --- | --- |
| 0.00–0.15 s，预备 | 后膝略屈承重，前掌稳住，胯先后坐 | 腰稍拧、胸稍收，视线先落到目标持械侧 | 右肘收近，握柄离开颊侧。左拳略向前留出两手间距 |
| 0.15–0.50 s，盘上 | 后脚跟略提，前膝弓出，胯移向前脚 | 腰跟胯转，胸再前倾，右肩送到前侧，头反向补偿 | 右上臂送出、肘领腕连续翻转，剑尖完成一圈。左手向后下展开 |
| 0.50–1.35 s，压住 | 前膝多承一点重，后腿仍撑住，前掌位置固定 | 胯先沉，腰随之侧倾，胸口稍晚压住，头保持目标方向 | 右肘吸收下沉，使握柄留在前臂旁。左手外展平衡 |
| 1.35–2.35 s，让回再稳住 | 后膝渐屈接重，前膝略伸，再向前脚还回一部分 | 腰较早回正，肩较晚松开少许，胸口随呼吸起伏，头不随肩摆 | 右臂随肩微屈伸维持接触轮廓。左肘向肋旁靠一点 |
| 2.35–2.85 s，反向压住 | 重心再往前脚送，前膝屈深，后掌留在支点上 | 腰胸向前倾，持剑肩送低，头看向贴合处 | 右腕向内扣，握点继续前压；左手从身体外侧伸到前方 |
| 2.85–3.00 s，抽剑 | 后脚跟提起，脚掌在原处碾转，胯回撤，前膝开始伸展 | 胯先往持剑侧后方转，腰、胸肩随后打开，头最后转 | 上臂带动剑柄横过身侧，非持剑手向前推。**3.00 s 刃口拉过接触处** |
| 3.00–3.17 s，跟随 | 后腿接重，前掌守住支点；胯转过命中姿势才刹住 | 胸肩多走几度，头短暂跟随，再回正 | 持剑腕继续到身侧后方，剑沿大弧摆出；另一手仍在前侧平衡 |
| 3.17–3.35 s，恢复 | 两膝回到架势弯度，后跟落回，胯回位 | 腰胸恢复半侧身，头抬回正前 | 双臂从伸开的位置迅速收回，最后几帧握剑手、脚趾逐骨归架 |

### 持段的播放方式

采用 **3.35 s 单次播放**，把持段的一次压低、一次让回和末尾蓄势写进同一条剪辑。三个动作的幅度、时长各异，能在 2.5 s 里看出双方还在相持。
代价是每个手别都要制作并检查整段持姿。好处是晚收到起播的客户端能按原起点取姿，3.00 s 自然走到同一个抽剑时刻，中途 STOP 也有明确的退出姿势。

PA 的 `loop_region` 可供 scrub 进度回绕。自由播放还要求保持剪辑（`hold_on_last_frame`）及 `free_loop_region: true`。例如 `guard_weapon` 在 0.40–2.00 s 反复呼吸，放下由宿主另播 `guard_weapon_lower`。循环能复用短动作，也适合持时由玩家决定的格挡。播放器到区间终点后持续按区间长度取模，STOP 冻结当时的采样。因此要从循环准时进入抽剑，还需要另一次选片与起播，P3 目录只给本式一次起播。详见[资产契约](../asset-contract.md)、[循环条件](../../src/main/java/dev/kizuna/playeranimation/animation/AnimationEntry.java)和[播放时钟](../../src/main/java/dev/kizuna/playeranimation/animation/AnimationPlayer.java)。

## 5. 覆盖层、手别与持物

- 静止 `stance_idle` 上用 `mask: full`，覆盖胯、腰、胸、头，双侧上臂、前臂、手、拇指、两组手指，以及大腿、小腿、脚和脚趾。`root` 固定，剑随持剑侧的空挂点 `r_item` 或 `l_item`。沿用原版握法，盘绕和抽回由手臂姿态完成。
- `upper_while_moving: true`。移动架势、行走、跑步或潜行时，腰胸头、双臂及手指仍演持缠和抽离，胯及双腿交给移动底层。走动中从停步到再迈步，持剑臂要一直维持牵住的轮廓。
- 持剑侧的 `*_thumb`、`*_fingers_a`、`*_fingers_b` 全程在剪辑内保持握剑。非持剑手配重时维持自然握形，也适用于另一手持物。
- `_off` 用左前手持剑，维持左前右后的脚位。将握柄及剑尖的横向目标换边，按左肩枢轴重解左臂，躯干相对架势的转动增量换向。右后手在胸前留出胸盒厚度。按两种体型校正沉胯和提踵，仍需看得出两腿换重。左主手玩家另由 PA 对所选剪辑整体镜像。
- classic 与 slim 共轨，各验侧面着地、剑到头身的净距、非持剑臂的位置。`fpv: false`，独立第一人称手臂走现有规则，全身第一人称复用第三人称，`fpv_torso` 取默认值。

## 6. 首末帧与衔接

首末逐骨对齐 [stance_idle](stance_idle.md) 首帧，含手指与脚趾，首尾速度平稳归零。从架势、普攻末段、格挡放下或受击恢复进入时淡入 0.10 s。完整抽剑后经跟随、归架，再以 0.25 s 淡出交回当前底层，可接普攻、格挡或受击。

持段中断时，人体按施放 ID 与表现 ID 查到实际播放的主手或副手片段。PA 冻住 STOP 当刻的姿态，按当前权重淡出 0.25 s。分别在压住、让回、抽剑预备三个位置检查交接。下一动作接过尚在身前的手，走路的腿继续走，时间线停在中断点，后续 `hit` 不补发。设计中的缠后接「绕」从回抽向内收的手位衔接，实际承接资格由宿主判定。
