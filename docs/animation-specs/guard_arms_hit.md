# guard_arms_hit：挡中受击，回到抱架

> 空手护面规格。原速 250 ms，单次覆盖在[抱架保持](guard_arms.md)之上。

## 1. 目的与触发

宿主确认这一次攻击被挡住时触发。画面要读成双前臂被压回来一下，身体接住重量，随后仍在守。首姿、末姿都等于抱架 0.20 s 的基准。下层保持从受击前的起点继续计时，多次反馈之间能看见原来的呼吸。

## 2. 关键姿势与支撑

接触从已经举好的两条前臂开始。侧面看，前臂往身前的空隙缩回一小段，肘进一步屈曲，头和原本直立的上身随后向后晃，双拳仍在额头前方。正面两条前臂并排护住脸颈，肘尖朝下收在上胸前，中间保留窄缝。重心从两脚之间略移向后脚，后膝再屈，后脚以前掌压地，前脚全掌留在原位。回弹止于原护面。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 从画面上要能读到的动作 |
| --- | --- |
| 0–50 ms | 来力即起。前臂短促后让，手指扣紧；胸口随即缩回，膝胯开始吃重。第一拍就能读出接触。 |
| 50–100 ms | 胸肩后坐到位，头略晚跟上，下颌仍收。肩、肘、腕先后刹住，胯往后下方沉一点，前踝、后前掌稳住重心。挡面在这里压得最深，拳与额头之间仍有间隙。 |
| 100–200 ms | 腿先撑住，腰胸带肩向前回弹，前臂和腕略晚跟回。拳留在额前，肘维持弯曲，避免回弹看成出拳。 |
| 200–250 ms | 下颌、双腕和手指收住余势，双腿回到守位。以抱架基准缓停，淡出后露出仍在走的呼吸相位。 |

剪辑长 **0.25 s（5 tick）**，`loop: false`。0 ms 表示已收到宿主结果，100 ms 前后是最大压缩的视觉标记。索引声明 `reaction: hit`，按被动受击检查跟随、错峰和回落；全段用常规速度阈值。剪辑没有 `hit` 事件或其他 `timeline` 事件。

## 4. 覆盖、视角与衔接

- 建议 `mask: full`、`priority: 16`（保持为 15），淡入 0.03 s、淡出 0.05 s。受击层给出绝对骨姿。单次结束只淡出这一层，下一次有效受击重播短反馈，底层保持的起播时刻不变。若中途收势，宿主停止这两层，转入[放下](guard_arms_lower.md)。
- 静止时从腰胸头、肩肘腕到双膝与踝都有承力反应，脚趾保住地面接触，`root` 固定。四成速度移动中，受击层也只取 `upper` 的腰、胸、头和双臂，胯和双腿仍由步态驱动。
- `hand: main`，空手两拳始终闭合，持剑手保持握柄并留出后坐行程，左主手镜像整段。沿用 `fpv: false`，全身第一人称能从手和物品的短促回摆看出受击，视野中心仍可见。

验收时从呼吸峰、谷分别触发，再连续触发两下，并在一次后坐途中放下。粗臂、细臂都要看清每一下、两拳与脸的间隙、镜像持剑和走动时脚步的连续性。
