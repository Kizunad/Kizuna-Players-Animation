# equip_helmet：双手捧起头盔，举过头顶扣上，拧正后松手

> 审阅状态：待审阅（2026-10-22，第二批）。轴向、坐标和数值来源见 [共用约定](conventions.md)；整体做法与已通过的 [equip_chestplate](equip_chestplate.md) 相同。
> 数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：头盔槽从空变为有物品时，演出“捧起头盔 → 举过头顶 → 扣到头上 → 左右拧正 → 松手”。
- **触发与驱动**：与胸甲相同，`VanillaAnimationScheduler.playArmorEquip` 检测到头盔槽空 → 非空时播放；原版穿戴是瞬间完成的，没有进度可以 scrub，
  本动作从槽位变化那一 tick 起按世界时钟播放。上一 tick 只有副手拿着盔甲时改播 `equip_helmet_off`（本稿镜像）。
- **结束**：1.28 s 播完淡出。

## 2. 时间轴

剪辑长度 **1.28 s**（26 tick），`loop: false`。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.12 | 低头看头盔，膝微屈，右手先往下沉 |
| 捧起 | 0.12–0.28 | 双手在下巴前捧住头盔两侧，身体略后仰抵住重量 |
| 上举 | 0.28–0.50 | 经肩前举到头两侧上方（0.39 s 过下巴，手在肩前外侧，避开脸），胸后仰 6° |
| 扣上 | 0.50–0.67 | 双手沿头两侧往下压，含胸 6°、低头迎上去，膝再屈；**0.68 s 头盔上身** |
| 拧正 | 0.67–0.82 | 两手一前一后把头盔拧正，头右转 10°，胸、腰反向左转 6° / 4° |
| 松手 | 0.82–1.05 | 双手离开头侧往外放（0.94 s 手在肩高外侧），点一下头确认，再把手放到身侧外 |
| 收势 | 1.05–1.28 | 手回身侧，头微右转后回正，全身回零 |

时间线：`0.68: equip`（等事件白名单加入 `equip` 后补，见「分工」第一批第 3 条）。

## 3. 分阶段全身姿势

右臂在前，左臂所有关键帧晚 0.025 s；腰比关键时刻早 0.01 s，胸晚 0.01 s，头晚 0.02 s。手臂按手腕在胸骨空间的目标点摆放后求肩肘角度，腿由胯的姿态做脚底锁定求得。

- **预备（0.12 s）**：低头 14°，胸、腰前屈 2° / 1°；胯下沉 0.35 px、后坐 1 px、前倾 2°，双膝屈约 30°。右上臂回到前举 6°、外展 6°，肘屈 20°，左臂前伸到前举 8°。
- **捧起（0.28 s）**：右手腕到胸骨空间 `(−5.0, 22.4, −6.6)`，左手对称：双手在下巴前，相距约 9 px。手腕背伸 10°，左手 0.31 s 握紧（38°/62°/68°）。
  腰、胸后仰 3° / 5°，胯后坐 1.6 px，抵住身前的重量；头低 10° 看着头盔。
- **上举（0.39 / 0.50 s）**：0.39 s 手腕到肩前外侧 `(−6.7, 25.4, −5.8)`，路线在脸外侧，不从脸前穿过；0.50 s 到头两侧上方 `(−6.9, 28.6, −2.6)`，上臂上举 156°、肘几乎伸直。
  胸后仰 6°、腰后仰 3°，头低 8° 看着头顶方向。手臂上举角速度峰值 0.43 s（右）/ 0.46 s（左）。
- **扣上（0.67 s）**：手腕沿头两侧下压到 `(−7.1, 27.0, −0.6)`，屈肘 81°，肘向外张开；同时含胸 6°、腰前屈 4°、胯前倾 3°，头微抬 2° 迎上去，
  胯下沉 0.7 px，膝屈 40°。右前臂下压的角速度峰值 0.60 s，胸、腰前屈峰值 0.59 / 0.57 s 与之同步：手往下按、身子往上迎。
- **拧正（0.82 s）**：右手在头右侧偏前 `(−7.4, 27.4, −1.6)`，左手在头左侧偏后 `(7.5, 26.8, 0.6)`，两手一前一后；头右转 10°，胸左转 6°、腰左转 4°，胯右转 3°，
  转动角速度依次在 0.72（腰）、0.73（胯）、0.75（胸）、0.76 s（头）到峰值。
- **松手（0.94 / 1.05 s）**：0.94 s 双手离开头侧到肩高外侧 `(−8.6, 24.2, −0.6)`，手指 0.98 / 1.00 s 松开；头低 8°、左转 5° 点头确认，胸后仰 4°、左倾 2° 舒展。
  1.05 s 手到胸侧外 `(−9.0, 18.5, −2.8)`，屈肘约 65°，头回到右转 4°。
- **收势（1.16 s）**：上臂后伸 3°～4°、外展 10°，肘屈 12°～14°，头右转 6° 后在 1.28 s 回零。
- **不动的部位**：`root`（原地动作）；`r_toe` / `l_toe`（全程全掌着地，只有膝和胯起伏）。

## 11. 待审事项

- 头盔扣上时“含胸迎上去”与“抬头 2°”同时出现：前者让身体去接头盔，后者让脸不被头盔压低。若审阅方希望更像“戴帽子”的轻巧动作，可去掉含胸。
