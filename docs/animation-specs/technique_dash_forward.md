## 1. 动作目的与触发

- **用途**：基础功法“轻步”（`meridian_basic_techniques:light_step`）的表现。真元催动的短距冲刺，和 `dodge_*` 区分：闪避读作一次性起跳（预备步 → 下蹲 → 腾空收腿 → 落地缓冲）；
  轻步读作“压低身子、连续几步冲出去，再一步刹住”。本方向：加速跑：躯干大幅前倾，后脚蹬伸后高抬膝向前驱动。
- **功法时序**：起手 **0.28 s**（领先脚第 1 步 + 蹬地脚蹬伸），功法冲量在 0.28 s 生效，之后两步冲刺、一步制动、一步撤回架势。表现在起手开始播放。
- **位移由调用方负责**：`root` 不平移；着地的脚在模型空间锁定（每段着地内踝不动），实体被功法推动时随之在世界里滑行（`slide_window`）。
  冲刺步是原地步态：脚只在摆动时改变位置，四个着地点都在身体附近。
- **方向选择**：按施放时的移动输入相对身体朝向取 90° 扇区（同 `stance_walk_*`）；无输入时为前。四个方向都不转身（玩家朝向由视角决定）。
- **结束**：按真实时间播完 1.15 s（`PlayerAnimationAction` 23 tick）后淡出 0.15 s 回当前架势底层。

### 冲刺短跑要点与取值（短跑加速段生物力学，按 Minecraft 骨架尺度折算）

- **躯干前倾**：起跑后第 1～2 步身体前倾约 40°～45°，随步数增加逐步抬起；前冲取胸轴相对竖直最大 52°（架势本身 10.6°，净增约 42°），第 2 步着地时 46°，制动时回到约 2°。
  后撤、侧移不需要“向前倒”，只取略前倾 / 侧倾。
- **触地时间与步频**：加速段前几步触地约 0.17～0.20 s、步频约 4 步/s。这里每步摆动 0.18～0.28 s、单脚触地 0.20～0.30 s，比真人略慢：
  一次性动作的角速度上限 720°/s、角加加速度 1.5×10⁶°/s³（窗口外）不允许更快的高抬膝，驱动步（第 2 步）因此取 0.28 s。
- **摆臂**：肩以上臂前摆约 60°～70°、后摆约 30°～40°（相对躯干），屈肘约 90°，与对侧腿同步。这里前冲上臂摆幅 −36°～66°、肘 82°～97°。
- **落脚**：加速段脚落在重心正下方略靠后、前脚掌着地，然后蹬伸。前冲第 2 步落点在胯后约 0.8 px、前脚掌（俯仰 −35°）着地。
- **步幅由小到大**：第 1 步是短步（领先脚 0.6～0.8 px、抬脚 1.2～1.4 px、半幅摆臂），第 2 步是驱动步（抬脚 2.0～3.2 px、膝前驱，满幅摆臂）。
- **总时长 1.15 s 的理由**：起手 0.28 s 固定；第 2 步要高抬膝又不超角速度上限，至少 0.28 s；制动步 0.20 s；之后蹬地脚还要撤回架势位（0.17 s），否则剪辑末帧不是架势基准、
  淡出时脚会滑回去；最后留 0.14 s 让躯干、手臂回到护架。0.9 s 放不下“两步 + 制动 + 撤步”，1.2 s 以内取 1.15 s。

## 2. 时间轴与驱动

剪辑 **1.15 s**，`loop: false`，**按真实时间播放**（`t = 已播放秒数`），不再取竖直速度：

| 段 | 剪辑时间 (s) | 腿 | 上身 |
| --- | --- | --- | --- |
| 起手·压重心 | 0.00–0.12 | 双脚着地；胯先朝反方向回收、下沉 0.6 px，重心压到蹬地脚 r（后脚）；后脚再提踵 0.3 px（踝在着地容差内） | 腰、胸先反向回收（预备）再朝方向倾；上臂 0.10 s 前不动（躯干先动） |
| 第 1 步（短步） | 0.12–0.3 | 领先脚 l（前脚） 离地迈出短步并着地；蹬地脚单撑蹬伸，胯沿方向前移到 1.2 px、最低 −1.1 px | 躯干倾到满；半幅摆臂（领先脚同侧臂后摆、对侧臂前摆） |
| 冲量 | 0.28 | 功法冲量生效；**爆发窗口 0.24–0.32 s**（蹬地脚蹬伸 → 0.31 s 离地） | |
| 第 2 步（驱动步） | 0.31–0.59 | 蹬地脚 r（后脚） 离地，脚跟上收后膝前驱，前脚掌落在身体下方；领先脚单撑 | 满幅摆臂反过来；胸反向扭转 |
| 制动步 | 0.6–0.8 | 领先脚 l（前脚） 再迈一步落回架势位；胯回收、下沉（前冲 1.3 px） | 躯干回正、略反向，刹住 |
| 刹停 / 撤步 | 0.8–1.01 | 胯后坐；0.84 s 蹬地脚离地撤回架势位，1.01 s 着地 | 双臂收回护架 |
| 回架势 | 1.01–1.15 | 双脚架势位 | 回到架势基准 |

- **为什么改成真实时间**：冲刺没有腾空段，竖直速度始终约为 0，按竖直速度取样会卡在一帧不动；按水平速度取样则在功法冲量衰减后（地面摩擦约 0.2 s）把冲刺段压没。
  所以 `PlayerAnimationAction` 按 23 tick 真实时间播放（运行时目录时长，已实现）。施放时已在空中：从 0.28 s 开始播放（跳过起手）。
- **给功法侧的建议**：冲刺段约 0.28–0.80 s，水平速度最好在这段内保持（持续推动或分几次冲量），否则会出现“脚还在跑、人已停下”；数值待基础功法按冲刺重定（不在本仓库改）。

四个方向共用：时间表与驱动、胯的竖直曲线（相对架势：起手 −0.6 → 冲量前 −1.1 → 冲刺段 −0.8～−1.0 → 制动 −1.3（右脚刹时 −1.0）→ 撤步 −0.6 → 0）与沿方向的前移量（−0.3 → 0.4 → 1.2 → 1.9 → 2.3 → 2.1 → 1.2 → 0.4 → 0.2 → 0 px）、单撑时胯向支撑脚侧摆 0.4 px、摆动脚轨迹形状（离地 / 触地附近只做竖直运动，中段水平，后段膝前驱后回扒）、摆臂节奏（与对侧腿同步，第 1 步半幅）与头的稳定。**各自单做**：领先脚 / 蹬地脚、四个着地点、抬脚高度与膝前驱量、躯干倾斜向量、摆臂幅度、制动下沉深度。

## 5. 衔接

- 进入：架势底层（静止或移动）上施放，淡入 0.05 s，首帧即架势基准；空中施放从 0.28 s 开始。
- 退出：1.15 s 播完淡出 0.15 s 回当前架势底层（没有移动输入时回 `stance_idle`）。
- 冷却 3 s，不会在本动画中被自身重触发；被闪避打断时交叉淡入 0.05 s。
