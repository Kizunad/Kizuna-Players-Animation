## 1. 动作目的与触发

- **用途**：基础功法“轻步”（`meridian_basic_techniques:light_step`）的表现。真元催动的跃步，和 `dodge_*` 区分：起跳更干脆（下蹲只有 0.06 s）、收腿更高、腾空姿势更舒展、落地缓冲更深并带滑停。
- **功法时序（占位）**：起手 0.1 s → 冲量（水平 6 m/s 按移动输入方向，上 4 m/s）→ 收势 0.2 s。表现在起手开始播放。
- **高度按 0.35 格设计**（审阅决定 Q17：数值属功法内容，不在本仓库改）。**原版物理（不由动画推动）**：竖直 `vy0 = 4 m/s = 0.2 格/tick`，按原版 `vy = (vy − 0.08) × 0.98` 约 3 tick（0.15 s）到顶、高 0.35 格（5.7 px），约 6 tick（0.30 s）落地，落地 `vy ≈ −0.27`；
  空中水平阻力 0.91/tick，滞空水平约 1.44 格，落地后地面摩擦 0.546/tick 再滑约 0.37 格（3 tick）。
- **位移由调用方负责**：动画 `root` 不动、不做整体平移；离地高度在动画里只靠胯的高度、腿的姿态和躯干表达。
- **方向选择**：按施放时的移动输入相对身体朝向取 90° 扇区（同 `stance_walk_*`）；无输入时为前。
- **结束**：按**实际落地**结束（审阅决定 Q7）：落地后播完滑停与收势（剪辑 0.78 s，`PlayerAnimationAction` 16 tick）淡出 0.15 s 回当前架势底层。

## 2. 时间轴与驱动

剪辑 **0.78 s**，`loop: false`，三段驱动（与 [jump](jump.md) 同一思路，本版不变）：

| 段 | 剪辑时间 (s) | 驱动 | 腿 | 上身配重 |
| --- | --- | --- | --- | --- |
| 蓄力下蹲 | 0.00–0.06 | 起手真实时间：`t = 0.10 × 起手已过 / 起手时长` | 胯下沉 0.9 px、臀后坐 0.8 px，双膝加屈约 13°，后脚提踵 0.2 px | 躯干前压、双臂后摆；**爆发窗口 0.04–0.12 s** |
| 蹬伸起跳 | 0.06–0.14 | 同上；0.10 = 冲量时刻 | 髋、膝、踝三关节伸展，胯回升到架势以上 0.5 px；l（前脚） 0.11 s 离地，r（后脚） 0.14 s 以脚趾最后离地（冲量后蹬伸余势） | 躯干伸展、手臂随蹬伸送出 |
| 空中收腿 | 0.14–0.25 | 竖直速度：`t = 0.10 + 0.15 × clamp(1 − vy / vy0, 0, 2)` | 双膝提起，0.25 s（顶点 `vy = 0`）收腿最高 | 躯干按方向倾到最大 |
| 伸腿迎地 | 0.25–0.40 | 同上；`vy = −vy0` 时 0.40，更长的下落停在 0.40 的“伸腿找地”姿势 | 膝、踝伸开，脚伸向原落点 | 躯干回正 |
| 先落 / 跟上 | 0.40 / 0.45 | 着地沿起的真实时间 | l（前脚） 0.40 s 先触地，r（后脚） 0.45 s 跟上 | 先落时躯干反向回收 |
| 屈膝缓冲·滑停 | 0.45–0.65 | 同上 | 0.55 s 双膝屈到最深（后膝约 105°），胯最低并向反方向后坐 0.3 倍方向，后脚再提踵 0.3 px；双脚在模型里锁定，随实体在世界中同步滑行减速 | 躯干前压并反向回收 |
| 收势 | 0.65–0.78 | 同上 | 回到架势基准 | 回架势 |

- `vy` 取被渲染实体每 tick 的 y 差（带 tickDelta 插值），远端玩家同样可用；`vy0` 取冲量后第一 tick 的 vy（约 0.2）。
- 着地时 t 还没到 0.40（落在高台上）：用 0.05 s 交叉淡入从当前腾空姿态接到 0.40。施放时已在空中：跳过蹬地段，从 0.14 开始。
- **时长与数值变化时的缩放**：起手改为 T 秒时，蹬地段按 `0.10 / T` 的速率播放；T 短于 0.10 s 时下蹲与蹬伸会超出门禁，不宜缩短。起手 0.1 s 也是下蹲只能做 0.9 px 的原因——**若希望下蹲更深、更看得出来，需要功法侧把起手加长**（例如 0.15 s 时可按闪避的 1.6 px 下蹲重做蹬地段，属设计决定，未做）。
  竖直冲量改变时腾空段由竖直速度自动适配（顶点永远在 0.25），水平冲量变大时滑停段 0.45–0.65 按“着地后水平速度降到 0.02 格/tick 以下”的时刻伸缩（`0.20 × 实际滑行时间 / 0.15 s`）。

四个方向与 `dodge_*` 用同一个腿部动作链生成器（`chain.py`），参数更强；四个轻步之间**共用**：时间表与驱动、胯竖直曲线（相对架势：下蹲 −0.9 px 并后坐 0.8 px → 蹬伸 +0.7 → 顶点 +0.6 → 迎地 +0.1 → 缓冲 −1.7 并后坐 1.2 → 0.65 s −0.4 → 0）、胯水平比例（下蹲向反方向 0.3 倍，蹬伸 0.8、顶点 1.2、迎地 0.8，滑停 −0.3、收势 −0.1 倍方向）、空中收腿量（先离地脚 3.8 px、蹬地脚 3.4 px，前脚蹬地时 2.6 px）、一脚先落一脚跟上、落地滑停段、躯干与头的包络。**各自单做**：蹬地脚（前跃后脚正蹬、后跃前脚蹬、左跃后脚侧蹬、右跃前脚侧蹬）、倾斜向量、手臂造型（后掠 / 前送 / 外展领路）、剑指由哪只手做。左右不镜像：左跃后脚蹬、右跃前脚蹬；剑指固定由左（前）手做，右跃时左手在护颊，所以右跃改为右掌张开领路。

## 3. 分阶段全身姿势

起止姿态都是架势基准（[stance_idle](stance_idle.md) 第 3 节）。方向向量 `d = (0, −1)`。

- **蹬地**：后脚正蹬：后膝从约 88° 伸到约 64°、后髋 37° → 19°，脚底跖屈到 −60°（世界俯仰）、脚趾背伸约 31° 贴地，0.14 s 离地；前脚 0.11 s 先离地。
- **胯**：下蹲 `(−0.3dₓ, −0.9, +0.8)`，蹬伸 `(0.8d, +0.7)`，顶点 `(1.2d, +0.6)`，迎地 `(0.8d, +0.1)`，滑停最低 `(−0.3d, −1.7, +1.2)`（0.53 s），收势 `(−0.1d, −0.4, +0.3)`（0.65 s），相对架势基准、C² 样条连成，再与腿一起做 σ = 2 帧平滑。
- **躯干 / 头**：下蹲时胸前压 −5°（腰 0.6 倍）；蹬伸时伸展 +3° 并带出 0.2 倍前倾；0.28 s 胸前倾 −16°（腰 −9.6°），头反向抬起盯住前方；落地后胸回仰 +6.4° 刹住，0.56 s 缓冲时再前压。头在胯、腰、胸的累积增量上反向稳定（俯仰 0.8 倍、侧倾 0.7 倍，滞后 1 帧）。
- **双臂与手**：双臂后掠（“流星”式）：0.05～0.06 s 先后摆蓄力，0.15～0.19 s 随蹬伸甩到身后（右上臂后伸 32°、左 36°，肘伸 34°～55°），0.28～0.32 s 最大；左手 0.18 s 成剑指（食中指伸直、无名小指扣紧），0.36 s 起收回握拳；落地 0.44～0.47 s 双臂回到身前略过冲。

## 5. 衔接

- 进入：架势底层上施放；淡入 0.05 s，首帧即架势基准。
- 退出：0.78 s 播完淡出 0.15 s 回当前架势底层（落地时若已无移动输入回 `stance_idle`）。
- 腾空中进入水或开始滑翔：按 `jump` 规则淡出 0.08 s 交给 `swim` / `elytra`。
- 冷却 3 s，不会在本动画中被自身重触发；被闪避打断时交叉淡入 0.05 s。
