# piglin_sword_molten · 流金（流金剑下卷第五式）

> 主手 `piglin_sword_molten`，副手 `piglin_sword_molten_off`。文中左右按右主手角色自身计算，时间从施放起点算起。

## 1. 目的与触发

运真元暖透剑身。先看见一把剑立在身前，再看见另一只手从护手旁沿剑脊抹向剑尖。身体随这一抹逐渐沉下，手到尖侧时，原先高举的剑尖也垂下。遮去颜色与粒子，仍应当能认出施法完成的那一刻。

下卷功法 ID 是 `meridian_piglin_sword:molten_flow`，起手发出的表现 ID 是 `meridian_piglin_sword:piglin_sword_molten`。
人体按快照选中的手播放。持物门槛为 `#meridian_piglin_sword:soft_blades`，默认只有金剑，另一只手可以持物。
所有合格剑共用同一手别的轨道。非持剑手以手背或指节虚贴，掌内留住原有物品。

## 2. 目录时刻与时间线标记

时间取自剑仓 P3 的 `shared/src/main/resources/data/meridian_piglin_sword/technique_catalog.txtpb` 中的 `molten_flow`。原速每 tick 50 ms。

| 目录 | 剪辑时间 | 屏幕上看到的动作 |
| --- | --- | --- |
| `presentation` 在 0 ms，`start_millis: 0` | 0.00 s，第 0 tick | 从战斗架势起播 |
| `warmup_millis: 800` | 0.00–0.80 s | 立剑、虚贴剑脊、沉身抹向尖端 |
| `active_millis: 0`，`status_benefit` 在 800 ms | **0.80 s，第 16 tick，`cast`** | 指节到尖侧，剑尖落至前下方，重心最低。此时宿主赋予自身 `meridian_piglin_sword:molten` |
| `recovery_millis: 350`，`UNTIL_RECOVERY_END` | 0.80–1.15 s，第 23 tick 结束 | 另一手先离开剑侧，持剑手归架，宿主发 STOP |

设计 §4 的起手 0.8 s、冷却 40 s 和状态 10 s 均与目录一致。目录补足了 350 ms 收势。10 s 从赋予状态起算，角色在这段时间内可以做其他动作。
设计中的兜盾沿、附带烫伤以及 §5 的入水、淋雨或换物清理都归玩法与物品表现。流金接「泼金」以状态仍生效为条件，泼金属于 P5。

## 3. 关键姿势

- **立剑**。从颊侧握位把剑移到胸前偏持剑侧，尖朝上并略偏向前，眼睛露在剑的另一侧。非持剑手的指节到护手外侧。正面要看得到两手之间的空隙。
- **抹过剑脊**。从护手、剑身中段到尖端，非持剑手的指节沿剑的长轴连续前移。剑也随持剑侧肩、肘渐渐放低，使尖端进入另一手可及的范围。两手间距逐渐拉开，剑柄始终留在同一拳里。
- **垂尖定势**。两膝仍弯着，胸肩已沉稳，持剑手托住柄端，剑尖指向身前下方。非持剑手停在尖侧，前臂轮廓与剑脊之间留一线可见空隙。头略低向剑尖。即使用刚性的剑道具，也能从柄、尖的高低关系读出定势。软化弯尖和发红交给物品效果。

## 4. 分阶段全身动作

0.80 s 和 1.15 s 是目录锚点，其他分界用于安排动作节奏。

| 剪辑时间 | 腿、脚与胯 | 腰、胸肩与头 | 持剑臂与非持剑手 |
| --- | --- | --- | --- |
| 0.00–0.20 s，预备立剑 | 后膝接重，前掌稳住。胯先稍回收，再移回两脚之间 | 腰先转向身前，胸随之打开，头从看前方转看护手 | 右肩带上臂前移，肘随后托出剑柄，腕扶稳立剑。左肘抬起，指节向护手靠近 |
| 0.20–0.45 s，从护手起抹 | 前膝开始屈，后膝跟着松，后脚跟以原前掌为支点稍落，胯逐渐下沉 | 腰先略前倾，胸再收，左肩随移重送前，头沿剑脊移视 | 右肘托住柄，腕渐向前放低剑尖。左臂沿剑脊外侧从护手移至中段，伸手的重量由两腿承担 |
| 0.45–0.80 s，抹到尖侧 | 双膝错时屈深，前膝先稳，后腿接住下沉的胯，重心投影仍在两脚间 | 腰先稳住，胸向持剑侧微倾以平衡前伸的左臂，双肩先后落定，头最后低向尖端 | 右上臂渐收、前臂托柄，腕最后放下剑尖。左肘伸出，指节沿中段移至尖侧并减速。**0.80 s 到垂尖定势** |
| 0.80–0.92 s，跟随 | 前脚全掌、后脚前掌仍承重，后膝先吸收余势 | 胯维持低位，胸口继续呼气，肩松下，头在尖端稍留 | 柄与尖保留高低关系，左手从剑侧横向退开，让出持剑手归架的空间 |
| 0.92–1.15 s，恢复 | 两腿分先后伸回架势弯度，后跟回到起始高度，胯回位 | 腰胸解开侧倾和转动，肩回半侧身，头抬回正前 | 右肘收柄回颊侧，腕随肩肘将剑扶回。左前臂回到原前护位，指形收回架势 |

静止时要从侧面看清脚底受力、双膝屈伸、胯沉、腰胸转倾、肩落、手移、剑尖垂下的先后。持剑手托柄与另一只手沿剑脊移动各有自己的起止时刻。走动时腰、肩、双手仍独立完成这个手势。

## 5. 覆盖层、手别与持物

- 静止 `stance_idle` 上用 `mask: full`。胯、腰、胸、头，双侧上臂、前臂、手、三根手指骨以及大腿、小腿、脚和脚趾都属于本片。脚底留在架势支点，`root` 固定，只有胯在支撑面内换重。
- `upper_while_moving: true`。在移动架势、行走、跑步或潜行时只取腰胸头、双臂与手指。底层继续驱动胯和腿。垂尖那一下在上身轮廓中也应可辨。
- 持剑侧 `*_thumb`、`*_fingers_a`、`*_fingers_b` 全程在剪辑里握住剑，剑跟随 `r_item` 或 `l_item` 用原版握法。另一手以指节示意虚贴，按普通剑的刚性轮廓留出间隙。用剑道具检查指节离剑脊的位置和前后顺序。PA 的手与身体接触检查不含剑几何。
- `_off` 用左前手持剑，右后手抹剑。保留左前右后的站姿，将剑和指节的横向目标换边，按两侧肩位分别重解手臂。剑留在左前方，右肩随胸转到够得着护手的位置。回收时先撤右手，再把左手扶回前护位。左主手玩家由 PA 整体镜像。
- classic 与 slim 共用轨道，各自核对握点、抹剑手与剑脊的间隙、剑到脸的距离。`fpv: false`，全身第一人称复用第三人称，`fpv_torso` 取默认值。竖起的剑置于视线一侧，抹过的手在镜头前方可见。

## 6. 首末帧与衔接

首帧和末帧逐骨对齐 [stance_idle](stance_idle.md) 首帧，包含手指、脚趾和后跟高度，速度平稳归零。由普攻收尾、格挡放下或受击恢复进入时，以 0.10 s 淡入抬剑。完成后双手已归各自护位，以 0.25 s 淡出交回底层，可接普攻、格挡及受击。热剑状态继续按自己的时钟运行。

目录允许受伤打断。0.80 s 以前收到 STOP，人体停掉实际起播的手别，冻结当前抹剑姿势淡出，后续 `cast` 不补发。生效后收到 STOP 同样淡出，热剑状态的持续与清理由宿主处理。

## 7. 索引与验收

| 项 | 主手与副手 |
| --- | --- |
| 资源与层级 | `piglin_sword` 组，`hand: main/off`，23 tick，优先级 24，淡入 / 淡出 0.10 / 0.25 s，一次性播放 |
| 时间线 | `cast` 0.80 s，仅作表现通知。本式只有施法定势，无攻击或命中事件 |
| `phases` 与 `swings` | 使用 `phases: []`，两手别均纳入 `SwingWindowsContractTest`。现有流金剑测量规则只取发力段，两种手别实测列表均为空，索引省略 `swings` |
| 全身与握持 | 进入 `FULL_BODY_IDS`、`GRIP_IDS`，按普通一次性上限验收，省略 `impact_window`。无显式阶段时，分析器按 `whole_clip` 检查持剑侧的腰、胸、上臂、前臂和手的错峰 |

20 fps 正面及三分之四视角对照护手、中段、尖侧三处，0.80 s 单独看尖端是否已经下垂。原速看两手相向靠近、再沿剑身分开的过程中有没有一甩而过的假挥击。另从 `stance_idle` 起播，按 60 Hz 记录整个施放期间的剑尖速度，直接用既有切窗口径复核原始曲线。立剑、抹剑、收剑各段都应量得零次挥击。定稿从架势起播，整段剑尖峰速为主手 classic / slim 5.51 / 5.55 格每秒、副手 5.16 / 5.21 格每秒；四条原始曲线均零挥击。侧面慢放看双膝沉下和依次复位，支撑期滑移上限 0.5 px，鞋底最低容差 −0.25 px。两种体型都核对剑与头盒至少相距 1 px，或不小于该手别的架势净距。取骨与判据见[资产契约](../asset-contract.md)和[动画验收](../animation-acceptance.md)。
