## 共用约束

**E1 起止与收势。**
- 首帧、末帧等于 `stance_idle` 首帧，首尾速度为零；不动 `root`。
- **收势前半段内双脚回到架势踝位**，后半段只有上身回位。收势从 `cast` 起算（定那一段算在收势里，同动作稿 §5.1）；炼元从 31.00 起算。

**E2 开立（强身五式、炼元五式共用；附伤不开立，归水也不开立）。**
- **预压**：右脚离地前 0.10 s，胯左移约 0.5 px，把重心压进左脚（架势重心 X 0.11，左脚单撑要 ≥ 0.3）。
- **右脚**：提踵离地，向前上到左脚右侧，全掌落在 `(−3.7, 1.0, −2.6)`，`step_r` 在落脚帧。左右两踝相距 6 px，两脚平行、脚尖朝前；离地 ≤ 1.2 px。Steve 两肩枢轴相距 10 px，照「与肩同宽」字面会叉腿，这里取髋宽 3.8 px 的约 1.6 倍（待决定第 12 条）。
- **左脚**：原地不抬，绕踝竖线碾正，脚尖外转从约 10° 回到 0°（踝不动，同千里腿 C1 的碾法）。
- **胯**：位置 `(0.15, −1.8, 0.6)` → `(−0.7, −0.1, −2.4)`，旋转 `(−6, 12, 0)` → 0。由屈膝的架势站起来，前移 3 px 站到两脚上方，双膝约 10°。探针：胯降 0.15 px 时膝约 17°，降 0.3 px 时 24°，膝角对胯高很敏感。
- **腰、胸、头**：腰 `(−3, 4, 0)`、胸 `(−2, 4, 0)` → 0；头 `(3, −19, 0)` → 0（身体转正，头不用再左转）。
- **两臂**：两拳松开成掌，垂在体侧，上臂约外展 4°、肘 5°；手型「掌」（E3）。
- **收步**反过来：胯先左移把重心压进左脚（重心 X ≥ 0.3）；右脚离地，撤回架势后脚位 `(−1.7, 1.72, 3.2)`，直接以提踵落地（脚底世界俯仰 −35°、趾背伸 10°），`step_r` 在落脚帧；左脚绕踝竖线碾回脚尖外转约 10°；胯再降回架势高度、后坐。右脚离地 0.30 s 左右，离地 ≤ 1.2 px。

**E4 呼吸。**
- 吸气胸 +2°、胯升 0.3 px，呼气回位（同蹲马步）。
- 吸、呼的时刻写在每页时间轴里，五脏诀的音效表按这些时刻对。

**E5 唤（附伤五式共用，0.00–0.70 s）。**
- **脚**：架势脚位不动，双脚锁定。
- **胯**：升 0.5 px（`−1.8 → −1.3`），右转从 12° 减到 6°。
- **躯干、头**：腰 4° → 0；胸 `(−2, 4, 0)` → `(1, 0, 0)`（展 +3°）；头 `(3, −19, 0)` → `(0, −6, 0)`。身体转正、站高一点。
- **预沉**：0.00–0.10 两肘下沉、两上臂内收约 4°，前臂再屈约 4°，作上举的反向预备（预备 / 跟随门禁按每根骨最快的一下判，「唤」的上举可能是全段最快的）。
- **两臂**：0.05–0.25 拳松开成掌。0.10–0.40 两臂向两侧抬起成「唤魔者施法」：上臂水平外展到肩高，肘在肩外约 3 px、同高；前臂竖直，手在肘正上方；掌心朝前。0.40–0.70 两腕各自 ±5° 颤（腕 Z，约 5 Hz），左右反相。
- **门禁**：峰值 0.30 s 左右，上臂约 400°/s；颤腕峰速约 160°/s、加加速度约 1.6×10⁵°/s³，都在上限内。
- 共用段不算各式的独有动作；每一式从 0.70 起接自己的手势。

**E6 单脚支撑先移胯。**
- 门禁的重心口径：着地脚的踝在 X、Z 上 ±2 px 以内；失衡窗口外每帧都查。
- 开立位上右脚独立（金臂）：探针算得胯 X −2.0 时重心离右踝 1.99 px（贴边），−2.5 时 1.53 px。所以**抬脚前胯先右移到约 −2.8**（离开立中心 2.1 px）。
- 左脚单撑（震土、开立、收步）同理，胯左移到重心 X ≥ 0.3。
- 后脚前掌单撑（归水上步、回步）：要把重心压到后踝 Z ±2 px 以内，胯后移约 3 px（同千里腿 C5）。

**E7 滑脚：提踵、落跟只能做半程。**
- 滑脚门禁按每段连续着地里踝的 X、Y 量（同千里腿 C1）。同一次着地里踝升降 > 0.5 px 就超限。
- 所以：
  - 心火、惊雷的提踵只提 ≤ 0.45 px（踝 1.00 → 1.45，脚底约 −15°）；
  - 归水后脚只半落跟（1.72 → 1.25）；
  - 震土跺实后、舒筋落成全掌后回提踵，都要抬脚重放，加 `step_r`；
  - 舒筋虚步脚跟着地时脚尖只翘 ≤ 12°（绕脚跟压平时踝降 ≤ 0.4 px）。
- 碾脚只绕踝竖线转（踝 X、Y 不动）。

**E8 视线层照常叠加，转头按上限分摊。**

- 主剪辑里头的偏航 ≤ 45°，叠上视线层（最多 30°）也不超颈的 75°；不够的转角让胸、腰分。

**E11 炼元共同结构（32.0 s，五段相同）。**
