## 1. 动作目的与触发

- **用途**：千里腿第二式，把人蹬开：
  - 重心移到后脚，前膝提到胸前，脚尖勾起、脚掌对着人；
  - 胯往前一送，整条腿蹬出去，上身后仰配重（不折腰）；
  - 腿伸直后顶住一下，把人蹬远；收腿、落脚。
  - 全套唯一提膝到胸、唯一往前送胯的一式。
- **与其他式的区别**：

  | 式 | 腿 | 打击面 | 发力方式 |
  | --- | --- | --- | --- |
  | 弹腿 | 前 | 脚尖 | 只伸膝，身不动 |
  | **正蹬** | 前 | **脚掌** | **送胯 + 伸膝，上身后仰配重，伸直后顶住** |
  | 飞踹 | 后 | 脚跟、脚刀 | 腾空侧身蹬 |
  | 尥蹶 | 双 | 脚跟 | 撑地向后蹬 |

- **触发**：千里腿正蹬起手时，宿主调用 `PlayerAnimationAction.PEDDLER_PUSH_KICK`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。打击 1.95 s。
- **承接**：不作后式（服务端 §4.2）；作前式时，飞踹从它的 0.40 s 起播。收势前半段 1.95–3.48 s 内双脚回架势踝位（前脚 2.75 落、后脚 3.00 提踵到位）。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`1.95: hit`、`2.75: step_l`。

## 3. 分阶段全身姿势

基准与写法同 [peddler_snap_kick](peddler_snap_kick.md) 第 3 节：架势胯 `(0.15, −1.8, 0.6)` / `(−6, 12, 0)`，右踝 `(−1.7, 1.72, 3.2)`，左踝 `(2.3, 1.0, −2.6)`；大腿角是相对胯的面板值。

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯位置相对架势 `(0, 0, −0.3)`；胸相对架势 X −2°（比胯晚 0.03 s）。双脚锁定。
- 0.40 s 全身速度为零，脚还在架势踝位：承接从这里起播。

### 蓄（0.40–1.10 s）

- **后脚（右）**：0.55–0.70 半落跟，脚掌 −35° → −13°，踝 → `(−1.7, 1.30, 3.2)`（C1）。
- **胯**：位置相对架势 `(−0.75, −0.3, +3.0)`，1.05 s 到位；旋转 X −6° → 0°（为提膝后的后仰预先放平）。探针：提膝姿势下胯后移 3 px 时重心在后踝前 0.7 px，后移 2 px 时 1.6 px（C5）。
- **前脚（左）**：0.80–1.05 脚跟抬起，踝高 ≤ 1.45。
- **胸**：回直（相对架势 0°）；双拳收紧约 1 px、握紧 6°。

### 提膝（1.10–1.60 s）

- **左腿**：1.10 前脚离地；大腿面板约 `(110, −10, 0)`，膝屈 120°（小腿 −120°），脚掌背屈 +20°，脚掌法线朝前方。
- **右腿**：后膝由约 70° 伸到约 20°，胯随之升约 1.3 px（后踝锁定、逐帧 IK 求胯高）。
- **躯干**：胯 X 0° → +3°，腰、胸各 +1.5°，合计后仰 +6°；头 −4°，视线不抬。
- **双臂**：左拳到胸前中线 `(2.5, 19.5, −8.5)` 附近，右拳护下巴不动。

### 定（1.60–1.80 s）

不动；1.70–1.78 胸 ±0.3° 憋气颤（可省）。

### 蹬（1.80–2.00 s，`hit` 1.95）

- **支撑脚**：1.80–1.88 脚跟抬回，踝 1.30 → 1.70（与 0.00 的 1.72 一起，整段踝高范围 0.42）。
- **胯**：1.82–1.92 位置前送 1.5 px（相对架势 z +3.0 → +1.5），X +3° → +8°。
- **左腿**：1.85–2.00 小腿 −120° → −5°（115° / 0.15 s，峰值约 1,440°/s，在打击时段内，C6）；大腿 110° → 105°（1.86–1.94）；1.95–2.00 脚掌 +20° → +10°（踩实，脚的峰值在最后）。探针：胯后仰 +8° 时大腿 105° 踝高约 14.8 px、115° 约 16.5 px，对方胸腹约 14–18 px；动作稿的 85° 只到约 11 px。
- **躯干**：腰、胸各 +1.5° → +3°（合计后仰 +14°），头反向低 8°。
- **双臂**：左前臂 1.85 起下摆到左胯旁（拳约 `(5.5, 13.5, −2.0)`），配重；右拳护下巴。
- 探针：蹬直时重心在后踝前 1.7 px（胯送出后），仍在界内；登记的失衡窗口是占位。

### 撑（2.00–2.15 s）

腿伸直顶住，全身不动（≤ 1°）。

### 收腿（2.15–2.45 s）

- 小腿 −5° → −110°（0.30 s），大腿 105° → 100°；支撑脚跟 2.20–2.40 落回，踝 → 1.35。
- 胯 X → +3°，腰、胸回 +1.5°；左拳回胸前。

### 落（2.45–3.00 s）

- 大腿放下，脚掌回平，2.75 前脚全掌落回 `(2.3, 1.0, −2.6)`（`step_l`）。
- 胯 2.70 起前移回架势位置、X 回 −6°（3.30 到位）；后脚 2.80–3.00 提踵回 `(−1.7, 1.72, 3.2)`。

### 收（3.00–5.00 s）

腰、胸、头 3.00 起回架势（3.80 到位）；3.20–4.20 呼气；双拳 4.00 到架势护位；4.20–5.00 静止。

### 不动的部位

后脚整段不离地、X 不动；右拳 1.10–2.45 s 护下巴不动。

## 7. 骨架与门禁带来的约束

1. **大腿只落到 105°**：Steve 腿长 12 px，大腿 85° 时脚掌只在约 11 px，踢不到胸腹（探针）。
2. **后脚只半落跟**（C1），胯后移 3 px（C5）。
3. **提膝 120° 时膝盖贴胸**：大腿 110°、胯后仰时膝到胸盒前约 1 px，制作时看接触表，必要时大腿 Y 外旋 5–10° 让膝偏到胸侧。

## 10. 制作实测（2026-10-31）

原型 `kpa-door-breaker-proto/peddler/d_push.py` 求解，装进粗、细臂 `.bbmodel` 后导出。下列数值取自导出资源的分析器报告（粗、细臂相同）和原型自查。

**索引实际值**：`impact_window [1.80, 2.10]`；**不登记 `unbalanced_windows`**（实测单撑 1.10–2.75 s 重心始终在后踝 2 px 内）；`phases` 同第 6 节；时间线 `1.95 hit`、`2.75 step_l`。

**与规格的出入**：
- 蹬时后仰加大：腰、胸各 +7.5°（规格 +3°），胯 X 到 +7°（规格 +8°；相对架势 +13°），合计约 22°（规格 14°）；头低 12°（规格 8°）。蓄时胯放平、提膝时胯 +3°、腰胸 +1.5°、头 −4° 同规格。
- 大腿提膝 118°（规格 110°），蹬时落到 112°（规格 105°）。
- 胯位置（相对架势）：蓄 `(−0.75, −0.5, 3.4)`，提膝 `(−0.8, +0.6, 4.3)`，蹬时 `(−0.8, +0.9, 2.8)`；前送量与规格同为 1.5 px，后移比规格多 0.4–1.3 px。
- 后脚半落跟 0.70–0.95（规格 0.55–0.70）；蹬时提踵、收腿再半落、落脚后回提踵同规格。
- 左臂蹬时下摆到左胯前外侧配重，上臂、前臂直接定角（反解会给扭曲解）。
- 关键帧 969（规格目标 1,200–1,500；撞门 5.0 s / 1,470）。

**实测**：
- 门禁全部通过；有效运动 26 骨；打击时段内最大 1,431°/s、1.61×10⁶°/s³（左小腿蹬伸），时段外 650°/s、6.6×10⁵°/s³；
- 错峰 胯 1.88 → 左大腿 1.92 → 左小腿 1.93 → 左脚 1.98 s；膝最大 120°、踝 49°；手臂穿模 0；
- 1.95 s 左脚底中心高 14.56 px、在胯前约 8 px，脚底法线与正前方夹 25°；
- 提膝时左膝在胸盒前外侧，没有贴进胸盒（规格第 7 节第 3 条的担心没有出现，大腿不必外旋）；
- 全身最低点 −0.19 px（0.95 s，右小腿）；后脚整段一次着地，滑动 0.40 px。

**没验证**：游戏内效果。GIF、接触表在 `build/anim-review/2026-10-31/peddler_push_kick/`（不入库）。
