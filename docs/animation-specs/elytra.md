# elytra：鞘翅滑翔（流线型滑翔姿势）

> 审阅状态：**设计稿，待审阅**（2026-10-26）。尚未录入 `.bbmodel`，未跑原型门禁。轴向与坐标见 [共用约定](conventions.md)。

## 1. 动作目的与触发

- **用途**：`isFallFlying()`。`PlayerEntityRenderer.setupTransforms` 按 `k = clamp(roll² / 100, 0, 1)`（`roll` 为滑翔 tick，
  10 tick 达到 1）把身体绕 X 转 `k × (−90° − pitch)`，再按速度与视线的夹角绕 Y 倾斜；模型头 `pitch = −45°`（`getRoll() > 4`），
  四肢摆动除以速度系数后几乎不动。
- **本动作在身体空间制作**：放倒后身体空间的“上方”= 飞行方向，“后方 +Z”= 世界里朝天。
- **触发**：`isFallFlying()` 且 `getRoll() > 4`（与原版头部切换同一阈值）。
- **原版进度来源**：滑翔 tick；本动作在 0–0.5 s 进入段用自由时钟（与 `k` 的 10 tick 放倒同步），之后 1.6 s 循环。
- **结束**：落地或停止滑翔淡出 0.25 s。

## 2. 时间轴

剪辑长度 **2.1 s**，`loop: "hold_on_last_frame"`，`loop_region: [0.5, 2.1]`。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 展开 | 0.00–0.50 | 双臂从身侧后摆张开到滑翔位，双腿并拢伸直、脚尖绷直，头抬起看飞行方向；0.42 s 双臂过冲 4° 后回落 |
| 滑翔 | 0.50–2.10 | 1.6 s 一周期：双臂随气流 ±2° 上下颤动（左右错 0.2 s），腿 ±1.5° 摆动，胸 ±1° |

## 3. 分阶段全身姿势（滑翔基准）

- **头**：(45, 0, 0)：身体空间抬头 45°，与原版滑翔头 pitch −45° 一致，世界里看前方。头部轨道覆盖原版值，视线叠加由
  [head_follow](head_follow.md) 负责（滑翔时只叠偏航，不叠俯仰：原版此时也忽略俯仰）。
- **胸 / 腰 / 胯**：(4, 0, 0) / (3, 0, 0) / (2, 0, 0)：身体空间后仰 = 世界里背部微拱，流线型。
- **双臂**：上臂 (−25, 0, −22) / (−25, 0, 22)：后伸 25°、外展 22°，像收起的翅膀；肘 10°，手 (0, 0, 10) / (0, 0, −10)、
  手掌朝下（身体空间朝前），手指并拢伸直 5°。
- **双腿**：大腿 (−4, 0, 2) / (−4, 0, −2)：微后伸、并拢；膝 −6°；脚 (−45, 0, 0) 绷直；脚趾 −10°。
- **不动的部位**：`root`。

## 5. 重心与支撑

空中，无地面支撑（门禁不适用：鞘翅）。

## 6. 衔接

- 进入：`jump_air` → `elytra`（空中按跳跃键展开），淡入 0.25 s；`jump` 调度在 `isFallFlying()` 时已退出。
- 退出：落地 → `stand` / `walk`，淡出 0.25 s；入水 → `swim`。
- 烟花推进、转弯倾斜由原版矩阵负责；滑翔中使用烟花火箭（`use_item`）不叠加（原版允许，但横向身体上的“举到胸前”方向错误），
  保持原版。

## 7. 索引条目（提议）

`mask: full`、`priority: 4`、`blend_in: 0.25`、`blend_out: 0.25`、`hand: none`、`fpv: false`、`loop_region: [0.5, 2.1]`。

## 8. 接口缺口

1. 调度新增 `scheduleElytra`：状态边沿起播，`t = 已滑翔 tick / 20`，超过 2.1 s 按 `loop_region` 回绕（同 `spyglass`）。
2. 分析器：全身动作、无地面支撑集合加入 `elytra`。
3. 可选：按 `getRotationVec` 与速度夹角给身体加侧倾（原版已整体倾斜，不重复）。

## 9. 规模预估

24 骨、约 150 关键帧。
