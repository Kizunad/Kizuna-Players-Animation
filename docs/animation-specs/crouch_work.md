# crouch_work：潜行静止操作时的错脚承重

本轮按用户要求制作，效果待用户审图与游戏内验收；不替代尚未制作的通用 `sneak`。

- 触发：真实潜行、着地、静止，同时有已制作的攻击、挖掘或使用动作。移动、离地或操作结束后停止。
- 2 秒循环，淡入/淡出 0.18 秒，底层优先级 2，`hand: main`，左主手镜像。工具动作始终只覆盖上半身。
- 右脚稍后、左脚稍前，双脚保持脚底接触；胯偏向右侧支撑腿并后坐，左右膝角度有明显差异。腰胸轻微前倾，头部保持观察方向。
- 呼吸只有小幅胯部起伏与腰胸错峰；双脚用骨架长度求解锁定，不用左右相同的膝部曲线。双臂在独立预览时自然屈肘，实际操作由上层工具动作接管。
- 位置为模型空间像素，旋转为 Blockbench 面板角度，前方为 −Z。动画只改变渲染姿态，不改变玩家位置或碰撞箱。
- 关键帧与左右镜像以 `models/player_skeleton_classic.bbmodel` 为准。验收需同时看独立支撑姿态与 `crouch_work + mine_main/off` 的真实播放器组合。
