# idle_hands_behind · 背手站

> 玩家版 `idle_hands_behind_enter`、`idle_hands_behind`、`idle_hands_behind_exit`，村民骨架版各加 `_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)，日常站位见 [叉腰站](idle_akimbo.md) 第 3 节。

## 1. 目的与触发

双手背在身后站着，腰板直，看远处。给周前辈、陈恪这类长辈和高手。进出与打断同叉腰站。

## 2. 时长与索引

| 段 | 时长 | 索引 |
| --- | --- | --- |
| `idle_hands_behind_enter` | 一次性 0.50 s | `blend_in` 0.15、`blend_out` 0.12、`hand: none`。`timeline` `step_r` 0.30。`hand_contact_windows` `[[0.42, 0.50]]` |
| `idle_hands_behind` | 循环 12.0 s | `blend_in` 0.20、`blend_out` 0.12、`hand: none`。`timeline` `step_l` 2.62、`step_l` 4.22。`hand_contact_windows` `[[0.0, 8.80], [9.70, 12.0]]` |
| `idle_hands_behind_exit` | 一次性 0.30 s | `blend_in` 0.10、`blend_out` 0.15、`hand: none`。`timeline` `step_r` 0.22 |

全部优先级 6、`mask: full`、`fpv: false`。

## 3. 关键姿势：背手基准

| 部位 | 玩家版 | 村民骨架版 |
| --- | --- | --- |
| 脚、重心 | 日常站位，重心在两脚中间稍偏右，两膝几乎伸直（屈 3° / 5°） | 同 |
| 躯干 | 腰板直：胯中立，腰后仰 1°、胸后仰 2°，两肩后张 0.8 px | 同 |
| 头 | 下巴微抬 2°，看远处（正前方偏上） | 同 |
| 双臂 | 两上臂后伸约 25°、稍外展，肘屈约 40°，手在身后腰下 | 同 |
| 双手 | 在后腰下沿、胯块后面相握，大约在 (0, 13.5, 2.8)。**右手握住左手腕**：右手指包在左腕外侧，看得见；左手半握，掌心朝后 | 手在 (0, 13.5, 3.9)，离袍子背面的膨胀面 ≤ 0.5 px |
| 手指 | 右手屈 50° / 55° / 60°，拇指扣在左腕内侧；左手屈 25° / 30° / 35° | 同 |

## 4. 进入段（0.50 s）

| 时段 | 腿、胯 | 躯干、头 | 双臂 |
| --- | --- | --- | --- |
| 0.00–0.12 | 胯回正、上升 1.8 px | 胸、腰的右转解开，头回正 | 拳松开，两臂往下、往后甩，肩先动，比肘早 1 刻 |
| 0.10–0.30 | 右脚前收 2.6 px，0.30 落地（`step_r`） | 腰板挺起来：胸后仰到 2°，肩后张 | 两手在身后靠拢 |
| 0.30–0.42 | 两膝伸直 | 抬下巴，看远处 | 左手先到后腰，右手握上去（0.42 两手相触），手指晚 1 刻包住 |
| 0.42–0.50 | 稳住 | 吸一口气，肩提 0.3 px | 速度归零 |

## 5. 循环（12.0 s）

基础层：

| 层 | 周期 | 内容 |
| --- | --- | --- |
| 呼吸 | 4.0 s × 3 | 胸后仰 1.0°、肩提 0.3 px，背着的手跟着上下 0.2 px。呼吸慢而深，吸的那段 1.9 s |
| 身体摇 | 12 s | 胸偏航 ±1°、胯 ±0.4°，相位差 0.6 s |
| 手 | 6 s | 右手拇指在左腕上慢慢摩挲 ±6°，像在盘东西 |

小动作：

| 段 | 时段 (s) | 内容 |
| --- | --- | --- |
| H1 踱一小步 | 2.00–4.40 | 2.00 重心先移到右脚：胯右移 0.6 px。2.15 左脚提起，往前迈 3 px，2.62 全掌落地（`step_l`）。重心跟上去，躯干不前倾，背着的手不动。2.62–3.60 站在前面看。3.60 重心移回右脚，左脚收回原位，4.22 落地（`step_l`），4.40 前重心回中 |
| H2 抬头看远处 | 5.60–8.00 | 头抬 10°，慢慢左转 18°，6.30–6.70 停住；再转到右 10°，7.20–7.40 停住；然后回中。胸跟着抬 1.5°、转 4°，晚 2 刻 |
| H3 换握 | 8.80–9.70 | 右手松开，两手在身后错开 1 px，左手握住右腕，再换回原样：右手重新握住左腕。从背后看得见两组手指依次张、收 |
| H4 换一下重心 | 10.20–11.20 | 胯左移 0.4 px 再回来，左膝伸、右膝松，再还原 |
| 回到基准 | 11.20–12.00 | 只剩呼吸和摇 |

H1 落回原位后，左踝和第一帧相差 ≤ 0.05 px（循环接缝的门禁）。两次落地的前后滑动按着地分段统计，不算滑步。

## 6. 退出段（0.30 s）

| 时段 | 内容 |
| --- | --- |
| 0.00–0.05 | 两手松开，手指先张。胯开始下沉 |
| 0.04–0.22 | 右脚后撤，0.22 提踵落地（`step_r`）。胯沉 1.8 px、右转 12°，胸、腰右转 20° |
| 0.05–0.30 | 两臂从身后摆到身前护拳。肩由后伸 25° 前屈到约 60°，0.25 s 内要转 85°，平均 340°/s、峰值约 600°/s，在 720°/s 的上限内，第二段实测。左拳 0.25 先到，右拳 0.29 到。0.30 等于 `stance_idle` 首帧 |

## 7. 骨架差异（村民骨架版）

- 袍子背面比玩家后背深 1 px，再加 0.5 px 膨胀，所以两手往后放 1.1 px，两臂后伸多 4°。
- H1 踱步时袍子跟着胯，前脚只从袍底露出脚尖和脚面。步子照样迈，侧视看得出重心跟上。
- H2 抬头时帽沿上扬，不碰东西。

## 8. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 按站立口径查：H1 单脚支撑期间，重心在右脚 ±2 px 内；
  - 相触窗口内两手相握；
  - 循环首尾连续。
- 切入矩阵：每 0.25 s 一档淡入退出段，重点看 H1 左脚在空中时切出去，脚的轨迹不穿地。
