## 1. 动作目的与触发

- **用途**：五脏诀炼元「肾炼」，照六字诀吹字诀。两臂侧平举，内旋划弧，两掌贴到腰眼；屈膝前倾，两掌沿腰骶摩到胯两侧，再屈肘提臂环抱腹前，吐「吹」；伸膝回身，两掌轻抚腹部，沿腰带摩回腰后。一遍 5 s，练 6 遍。
- **触发**：五脏诀肾炼开始时，宿主调用 `PlayerAnimationAction.EVOKER_REFINE_KIDNEY`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **32.0 s**（640 tick），`loop: false`（待决定第 6 条）。没有 `cast`。
- **打断**：淡出 0.20 s 回架势，两脚在淡出里滑回架势位（E11）。
- **时间线事件**：`0.50: step_r`、`31.40: step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、32.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 进式（0.00–1.00 s）

- 腿、胯、腰、胸、头照 E2、E11（同 [肺炼](evoker_refine_lung.md) 第 3 节）。
- 两拳 0.05–0.30 松成掌；两臂 0.05–0.90 落下、后伸、屈肘，0.90 两掌贴在腰后腰眼 `(±2, 15, 2.5)`，掌心朝前（贴腰），指尖朝内下；上臂后伸约 45°，肘屈约 40°。

### 一遍（τ 0.0–5.0）

- **展（0.0–1.0）**：两掌 0.0–0.1 离开腰后 ≥ 0.5 px，两臂向两侧、向上分开，1.0 成侧平举：上臂外展约 90°，肘约 10°，掌心斜朝后（前臂旋前约 45°）。胸 0 → +2°（吸气）。
- **划弧（1.0–2.0）**：两上臂内旋、后伸、下落，两掌由两侧向后划弧，τ 1.90 掌心贴在腰眼 `(±2, 15, 2.5)`，1.90–2.00 贴住不动。
- **下摩（2.0–2.9）**：上身前倾 −8°（胯 X −3、腰 X −3、胸 X −2，2.0–3.0）；双膝 2.0–3.5 屈到 30°（胯 y −0.07 → −0.40）；两掌沿腰骶向下、向外摩：2.9 掌心在胯两侧 `(±4.6, 13.5, 0.5)` 附近，指尖到大腿根（y 12），手臂近垂直。胸 +2° → 0（呼气）；头 X +3°，抵消前倾、保持平视。
- **环抱（2.9–3.5）**：两掌 2.90–2.95 离开胯侧 ≥ 0.5 px，屈肘提臂，3.5 环抱在腹前：掌心 `(±2, 17, −5.5)` 附近，掌心朝内、离腹约 3 px，两手指尖相距约 2 px，上臂略外展、肘屈约 60°。
- **抚腹、摩回（3.5–5.0）**：3.5–3.6 两掌贴到腹前 `(±1.5, 15.5, −2.5)`；3.6–4.8 沿腰带（y 约 15）向两侧、向后摩：4.2 在腰侧 `(±4.6, 15, 0)`，4.8 回到腰眼；4.8–5.0 停。上身 3.5–4.5 回正，头回 0；双膝 3.5–4.5 伸回 5°。
- 左臂每段晚 2 帧（E12）；贴身的两段左右手同时到位、同时离开，左臂只在中段晚 2 帧（原型把手锁在身体方块表面，沿表面插值）。

### 收式（31.00–32.00 s）

- 照 E11：两掌 31.00–31.05 离开腰后，31.00–31.40 落到体侧；31.00–31.10 胯左移；右脚 31.10 离地，31.40 以提踵落回 `(−1.7, 1.72, 3.2)`；左脚碾回外转 10°。
- 31.40–32.00 胯、腰、胸、头回架势；两掌握拳抬回护身位（全段最快，约 250°/s）。
