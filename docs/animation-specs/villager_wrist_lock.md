## 2. 时间轴

| 段 | 时间 (s) | 做什么 |
| --- | --- | --- |
| 预备 | 0.00–0.25 | 前手张开；后手先往下松一下（约 5°） |
| 刁 | 0.25–0.90 | 前脚上步（`step_l` 0.55）；前手伸出刁住对方手腕，后手 0.60 起按到对方肘上。**`grab` 0.90** |
| 引 | 0.90–1.10 | 重心后移，两手把对方的胳膊带直 |
| 一拧 | 1.10–1.40 | 身子往下坐，胯右转；前手把腕往上翻，后手往下压肘。**`hit` 1.40** |
| 压 | 1.40–1.80 | 坐住，两手保持 |
| 再拧 | 1.80–2.10 | 再往下坐，前手再翻，后手把肘压到胯高。**`hit` 2.10** |
| 放 | 2.10–2.50 | 双膝慢慢伸，回正。**`release` 2.50**：两手松开往前一推 |
| 收 | 2.50–5.00 | 前脚回架势踝位（`step_l` 2.80），双拳回架势 |

效果时刻和袖手拳目录一致：擒拿 900 ms 起、持续 1600 ms（到 2500 ms），两下打击在 1400 ms、2100 ms，第二下卸兵器。

## 3. 制作实测（2026-11-17）

- 全段最大角速度 443°/s（右小腿，上步时），最大角加加速度 648,536°/s³，都在一次性动作的上限以内，不声明打击时段。
- 支撑脚滑动右 0.22 / 左 0.21 px，脚底最低 −0.18 px，全程重心在两脚之间；手臂对头、胸、腰、胯的穿入两套几何都是 0。
- `phases` 两段。再拧那段门禁核到了：腰 1.950 → 胸 1.967 → 右前臂 1.983。
  一拧那段右臂链各节的转动不到门禁的起算量，门禁判「不适用」，这一段的先后没有被核到。
- 相对草稿只改了一处，同寸劲：右手伸出去之前加一小下反向预备（右上臂 6.5°、右前臂 5°、右手 5°，开头 0.24 s）。

## 4. 没验证的

- 动作稿要的 `grip_windows` `[0.90, 2.50]`（两手抓着对方的那一段）没声明：本仓门禁没有这个字段。
  两手的位置是照「对方右手腕在身前 14 px、高 16 px」摆的，游戏里对方的胳膊不会跟着动，看上去是对着空处拧。
- 接背摔（动作稿说从收势后半段淡出、手一直抓着）没做，现在两式各播各的。
- 持物：按空手做。
