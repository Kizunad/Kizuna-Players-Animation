## 1. 动作目的与触发

- **用途**：基础功法“蓄力”（`meridian_basic_techniques:charge`）的表现：握拳蓄劲，手臂、胸、肩发力，定劲时由弱到强颤动；收势松劲回架势。
- **时长与驱动**：剪辑 **2.0 s**（`PlayerAnimationAction` 40 tick），`loop: false`。剪辑内 0–1.60 s 是起手（蓄势），1.60 s 为生效时刻，1.60–2.0 s 是收势（松劲）。
  默认按真实时间播放完整 2.0 s。宿主要与功法时序对齐时按分段映射：`t = 1.60 × 起手已过 / 起手时长`；`t = 1.60 + 0.40 × 收势已过 / 收势时长`。
  定劲颤动的角加加速度已用到 1.33×10⁶°/s³，起手不能压缩（最短约 1.54 s）；收势不宜短于 0.24 s。起手长于 1.6 s 时建议在 1.25–1.55 s 之间按真实时间循环强颤，直到起手结束。
  **功法时序目前是占位的起手 0.6 s / 收势 0.2 s，与 2.0 s 表现不一致**：要么功法侧把起手 / 收势改为 1.6 s / 0.4 s，要么表现按真实时间播完——属功法侧的设计决定，本仓库未定。
- **打断**：起手被打断淡出 0.15 s。
- **层次**（审阅决定 Q13）：静止架势上 `full` 整段生效（剪辑里的胯只做 ±3° 前后倾、腿锁在架势踝位，与 `stance_idle` 无缝），底层是 `stance_walk_*` / `stance_run` 或闪避/轻步时只取上身。

## 3. 分阶段全身姿势

- **胯**：位移 −0.08 px（0.42 s）→ −0.1 px（0.60 s）→ −0.22～−0.24 px（0.86–1.55 s）→ 0；旋转 −2.5°（合）→ +3.5°（开、定劲）→ 0。
- **腰 / 胸 / 头**：见上表；开势时腰先、胸后 0.03 s，手臂再晚（主链错峰：腰 0.72 s → 胸 0.75 s → 上臂 0.88 s → 肘 0.93 s → 腕 0.97 s 达到角速度峰值）。
- **双臂**：面板绝对值关键姿势（右 / 左）：合 `(52, −46, −34)` 肘 60° / `(48, 44, 24)` 肘 108°；合住 `(51, −45, −34)` 肘 60° / `(47, 43, 25)` 肘 106°；
  外展过渡 `(24, −32, −32)` 肘 68° / `(6, 22, 30)` 肘 92°；开 `(−30, −4, −10)` 肘 102° / `(−24, 4, 10)` 肘 100°（定劲 `(−31, −4, −10)` / `(−25, 4, 10)`）；松劲过渡 `(20, −34, −6)` 肘 72° / `(20, 2, 18)` 肘 80°。
  上臂 → 肘 → 腕在开势段依次晚 0.05 s、松劲段晚 0.04 s、其余晚 0.02～0.03 s。
- **手**：开势时腕旋后 30°（拳心向上，像“收拳于腰”），掌屈 4°～6°。
- **手指**：合 +8°、开 +14°、定劲 +15° 握紧，松劲 1.74 s 回 +3°。
- **不动的部位**：`root`；腿同 `technique_breath`。

## 4. 重心与支撑

腿不动；脚底最低 -0.133 px，滑动 ≤ 0.01 px。扩胸后仰时重心后移约 0.3 px，仍在两脚之间。

## 5. 衔接

同 `technique_breath`：淡入 0.08 s、淡出 0.15 s；移动底层只取 `upper`；攻击会接管手臂（蓄力生效后的第一次攻击很可能紧接着来，攻击的起始姿态是持物站姿，交叉淡入 0.04 s，不跳）。
