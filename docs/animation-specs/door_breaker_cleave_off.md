# door_breaker_cleave_off：破门（副手持物）

> 状态：**已制作**（2026-10-29），粗臂、细臂门禁全部通过，待用户看 GIF 验收；未进游戏录制。规格第三轮（C′）随 [door_breaker_cleave](door_breaker_cleave.md) 审过，制作结果与出入见第 5 节。
> 副手版 C′ 的举与击中已用原型探针按真实斧子几何核对（`probe_cleave_coff.py`、`probe_cleave_coff2.py`、`probe_cleave_coff3.py`）。举斧那一帧没有姿势能同时满足全部自查，取最接近的一组；用户已确认接受（第 3 节）。A 案的上一版稿备份在 `kpa-door-breaker-proto/out/spec-cleave-off-A-2026-10-29.md`。

## 1. 做法（同一原型，`spec(off=True)`）

- **时间轴、事件、索引**：
  - 与主手版相同：6.0 s，`0.85: step_l`、`3.2: hit`、`4.5: step_l`；
  - 索引字段相同：`impact_window [3.00, 3.25]`、`unbalanced_windows [[0.60, 0.80], [4.22, 4.45]]`（制作后按实测改，见主手页第 6 节）、`phases [[2.95, 3.30]]`；
  - 只把 `hand` 改为 `off`。服务端结算同主手版。
- **为什么不整段镜像**：首末帧必须等于 `stance_idle` 首帧（左脚在前），同叩门副手版。
- **腿**：踝位保持左前右后，与主手版相同：
  - 前脚（左）斜滑半步；
  - 下劈时后脚提踵到 −45°；
  - 收势前脚收回。
- **握法**：
  - 左手持物（`l_item`）握柄尾，右手跨过胸前叠握在左拳正上方、斧头下沿；
  - 右手的虚拟柄线锁到左手柄线上、沿柄偏 4.4 px；
  - 约束与主手版第 8 节相同。
- **C′ 的镜像**：
  - 躯干左拧蓄力，斧竖在左颊旁；
  - 从左往右斜劈过身体中线，腰高劈中；
  - 刃口朝右下。

## 3. 与主手版的出入（已确认）

1. **举斧那一帧斧子离头只有 0.70 px**，低于自查的 1 px。
   - 原因：右手是远端那只手，又在后肩一侧，要跨过胸前握到左颊旁的柄上。
   - 探测共 432 组：
     - 左拧 30°～50°；
     - 头多右转 0°～20°；
     - 左拳 x 2～5、y 18.5～20、z −8～−5.5；
     - 柄线多种朝向。
   - 结果：**没有一组同时做到右手离柄 ≤ 0.5 px 和斧子离头 ≥ 1 px**。
     - 右手握得住时，斧子离头 0.27～0.70 px；
     - 斧子离头 ≥ 1 px 时（左拧 40°、头多转 16°），右手离柄 0.81 px。
   - 本稿取最接近的一组：左拧 45°、头多右转 16°，右手 0.46 px、斧离头 0.70 px。分析器门禁只查手臂与头、躯干，不查斧子；0.70 px 在渲染里不贴脸。
   - 若不接受，可把副手版的举改得不那么偏侧（斧更靠脸前正中），离头能到 1 px，但更像 A 案。
   - 对比图（主手 / 副手的举到最高与击中）：`build/anim-review/door-breaker/cleave-raise/cleave-cprime-main-vs-off.png`。
2. **举到最高时头偏离门约 16°**（看向门偏右），给左颊旁的斧子让出位置。劈下时转回正对门。
3. **躯干回转只有 15°**（主手版是 35°）。
   - 击中时右手要握到柄上远端，躯干得仍左拧 30° 左右：左拧更少时右手离柄 > 0.5 px；左拧 30°～38° 都可行，取 30°，让回转最大。
   - 举时又必须左拧 45° 右手才握得住。
   - 所以副手版靠躯干回转的发力比主手版弱，靠腿、沉胯和前屈补。
4. **左主手玩家**：运行时按 `hand` 把整套资源（含 `stance_idle`）镜像，左主手玩家持主手看到的是主手版的镜像（右拧 35°、回转 35°），不受上面几条影响。副手版只在右主手玩家用副手出手时播放。

## 4. 规模与门禁

- 目标 24 骨，约 900–1,200 个关键帧。
- 门禁适用项与自查项同主手页第 10 节，左右手对调：左手持物，右手按柄线逐帧锁定。
- 本段举斧那一帧斧子到头盒的自查下限按第 3 节第 1 条确认后的口径。
- 击中时刃口朝向的自查目标改为 `(−0.29, −0.93, −0.24)`，刃口点在中线右侧（x ≤ −1）。
- 改主手版后必须用同一原型重新生成本段。
