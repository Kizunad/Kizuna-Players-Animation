## 1. 用途与触发

**做什么**：
- 双手式照常播，另一只手的物品不再叠在斧柄上；
- 宿主同时叠播覆盖层：
  - 主手出手的式叠 `door_breaker_guard`（`mask: l_arm`）；
  - 副手出手的 `_off` 叠 `door_breaker_guard_off`（`mask: r_arm`）。
- 覆盖层 0.40 s 内把持物臂收到体侧（第 3 节），之后保持不动。其余骨照该式播。

**哪几式叠**：
- 只叠「另一只手握柄」的式：破门、连门、万门一斩及副手版；
- 叩门、撞门、破盾、掩门、横扫都是单手式，空手照各自规格动作，不叠（各页第 5 节已写明）。

**左主手玩家**：
- 运行时在 `hand` 为 `main` 或 `off` 时整段镜像，遮罩按源骨判断后再镜像到另一侧；
- 所以 `l_arm` 遮罩自动落到右臂，和式本身的镜像一致，不另做资源。

**宿主怎么播**（宿主行为，本会话不改，写给整合会话）：
1. **起播**：
   - 另一只手非空的判断，只在双手式起手那一刻做；
   - 判为非空就和该式在同一 tick 播覆盖层，`start_tick` 相同。
2. **承接**：
   - 双手式接双手式（破门、连门 → 万门一斩）时，覆盖层继续保持，**不重播**；
   - 重播同 id 会从 0 s 重来，手臂会先回护手位再收一次。
   - 单手式接破门（叩门、撞门承接，破门从 0.40 s 起播）时，在破门起播时播覆盖层，覆盖层照常从自己的 0 s 起（第 5.3 节核过）。
3. **结束**：
   - 动作稿要求整式结束一起淡出；
   - 本稿建议改成该式淡完再停覆盖层（第 5.3 节、第 9 节第 4 条）。
4. **中途换手、物品用完**：
   - 首版不在式中途加或撤覆盖层；
   - 物品用完后手里空握，拳照样收在体侧（动作稿 §9「首版照播，手里空握」）。

**层次**：
- 该式优先级 24，覆盖层 25，后叠；
- 原版挥手（攻击 20）、举盾（`block_shield` 15）都在下面，施放期间本来就被该式压住，覆盖层不改变这一点；
- 起手中按右键举盾也不显示举盾姿势。

**一种姿势通用**：盾、火把、其他物品共用同一个护持姿势，不按物品分资源（第 6 节分别核过，第 9 节第 3 条）。

**手指**：
- 覆盖层带拇指、两节手指轨道，全程等于该式 0 s 的握拳值；
- 这样能盖掉该式叠握手「憋劲再握紧 8°、击中后放松 3°」的变化，手里的东西一直握着。

## 4. 为什么盾面不朝前

- **斧和持斧臂扫过的空间**（四式含横扫逐帧并起来，胸局部）：
  - 胸前、脸前整块都会被扫到：X −10…+9、Y 15–34、Z −11…−2；
  - 更远的前方（Z −24…−11）在 X 3–10、Y 15–32 也会被扫到；
  - 腰以下，前（左）腿迈步时向前；
  - 左侧 X 8–16 基本空着，只有最远前方（Z −14…−9）被扫到；腿只在 Y 3–13 伸进这一带。
- **试转盾面**：
  - 以体侧竖持为基准（上臂 −20, 0, 24，屈肘 60），用上臂内旋把盾面往前转；
  - 斧都会插进盾：

  | 盾面前转 | 斧插进盾 | 另外 |
  | ---: | ---: | --- |
  | 16° | 2.5 px | 最深在万门一斩 1.60 s |
  | 32° | 3.76 px | 连门 |
  | 48° | 4.82 px | — |
  | 62° | 5.6 px | — |
  | 90°（正朝前） | 2.85 px | 持斧臂插进盾 3.49 px |

  - 盾面往外转反而离斧更远：外转 16° 间隙 1.82 px。
- **结论**：
  - 动作稿的「盾面朝前 / 盾收胸前」和三式斧路冲突；
  - 要朝前，就得改三式已验收的斧路。
  - 本稿取体侧竖持、盾面朝外（往后偏 7.8°），见第 9 节第 1 条。
  - 动作稿 §8 的验收句相应改为「另一只手持盾时盾收在体侧，不穿斧柄和持斧臂」。

## 5. 与三式共存

### 5.1 斧柄单手持握

- 覆盖层只改持物臂的 6 根骨，斧仍挂在持斧手 `r_item`（`_off` 为 `l_item`）上；
- 持斧臂和躯干全链与该式单独播放逐帧相同；
- 所以 6 段每一帧都是「主手握柄尾单手持斧」，和单手式一样成立。
- 以下读数原样沿用各式已通过的门禁和已审自查，不受覆盖层影响：
  - 持斧腕弯折 / 扭转；
  - 斧离头盒；
  - 斧不插进躯干、腿；
  - 击中刃口领先；
  - 斧最低点。
- 覆盖层叠着时，下面这些自查不适用（那条手臂不在柄上）：
  - 叠握离柄线（≤ 0.35 px）；
  - 叠握肘不反关节；
  - 叠握沿柄距；
  - 叠握手的柄线过拳心与投影读数；
  - 动作稿 §7「双手式副手 IK 逐帧锁柄线」。
- 各式自己的 GRIP 门禁只看持斧手，单独跑，不受影响。
- 观感：
  - 破门、连门的抡劈，万门一斩的荡、提、竖斧、劈下，都变成单手抡斧；
  - 斧路不变，力量感靠持斧臂和全身；
  - 拄斧段变成单手拄着柄尾。
  - 这些按动作稿 §4「双手式照常播」接受，验收时看 GIF 确认（第 12 节）。

### 5.3 路径（进场、自然结束、打断、承接）

都按运行时实际混合模拟：
- 欧拉角线性混合；
- 淡入、淡出权重线性；
- `stop` 冻结剪辑时刻。

覆盖层在探针里按 0.40 s 三骨同步五次缓动模拟，制作时要用真实关键帧重跑（第 9 节第 10 条）。已重跑，结果和更正见第 13 节第 3 条。

- **进场**（与该式同刻起播，0–0.40 s，叠 0.10 s 淡入）：
  - 主手版：持物、覆盖臂离斧和持斧臂 ≥ 3.75 px，不碰躯干；（制作时更正：这是盾的值。普通物品离持斧臂 2.85 px，起点帧满格贴图插头 1.1 px，见第 13 节第 3 条）
  - 副手版：只有起点那一帧本身的接触，沿路径变浅。这些接触是架势右手持物时自带的：
    - 主手的盾把手插头 1.59 px；
    - 贴图插头 2.58 px；
    - 右前臂擦腰 / 胸约 1 px；
  - 中途只有 0.20 s 前后盾把手擦胸 0.28 px，比该式单独播放的 0.26 px 深 0.02 px。
- **叩门、撞门承接破门**（破门从 0.40 s 起播，覆盖层在那一刻从 0 s 起）：
  - 破门 0.40 s 时持物臂已离开 0 s 约 12°（主手上臂 (70.6, −12.5, 29.3)）；
  - 0.10 s 淡入里逐通道最大 460 / 476°/s；
  - 接触都比该式单独播放浅；
  - 只有副手版前 0.15 s 有三处短暂比单独播放深：贴图 +0.35 px、细臂前臂 +0.17 px、盾把手 +0.07 px；
  - 0.25 s 起全部离开。
  - 叩门、撞门自己的淡出没算进去。
- **自然结束**（该式末帧 = 架势首帧，两层同时 0.25 s 淡出）：
  - 主手版离斧、持斧臂 ≥ 3.59 px；
  - 副手版只剩架势帧本身的接触。
- **起手被打断**（破门 0–3.20 s、连门 0–1.55 s、万门一斩 1.50–4.05 s，每 0.1 s 取一个打断时刻）：
  - 斧、持斧臂和持物、覆盖臂始终不碰：
    - 同刻停时最小间隙：持物对斧 1.11 px、对持斧臂 0.93 px（破门 2.7 s 打断，普通物品）；
    - 晚停时：1.98 / 1.88 px。
  - 但**同刻停**时，万门一斩 1.7–2.1 s（荡的前迈）被打断，淡出中途约 0.15 s 处：
    - 盾下沿扫进前腿胫：主手 2.0 px，副手 2.7 px；副手同时插大腿 2.0 px，把手插腰 1.1 px；
    - 副手右前臂擦腰最深 1.76 px（架势帧本身 1.1 px）；
    - 持续约 0.1 s。
  - 原因：
    - 两层同时淡出时，手臂 = (1 − w)² 架势 + w(1 − w) 该式 + w 覆盖层；
    - 中途有约四分之一回到该式握柄的手臂，盾被带向前下；
    - 这时腿还在前迈位。
  - **晚停**（该式淡完后覆盖层再淡 0.25 s）：
    - 该式淡出时手臂不动，回架势时腿已经在架势位；
    - 只剩架势帧本身的接触；
    - 代价是手臂比身体晚 0.25 s 回位。
- **承接交叉淡化**（破门恢复段 4.60–6.00 s、连门 6.50–8.00 s 交给万门一斩 1.50 s，覆盖层保持）：
  - 前式冻结、淡出 0.25 s，万门一斩淡入 0.10 s；
  - 持物离斧 ≥ 1.78 px（主手）/ 2.88 px（副手），离持斧臂 ≥ 2.17 / 3.54 px，不碰躯干。
- **架势帧本身的接触**（不属覆盖层，有没有覆盖层都一样）：
  - 主手版，左手拿 16×16 满格贴图时擦头 0.97 px；
  - 副手版，右手（架势持物位）：
    - 盾把手插头 1.57–1.59 px；
    - 贴图插头 2.45–2.58 px；
    - 右前臂擦胸 0.96 px、擦腰约 1.1 px（盒心不进躯干，门禁不算）；
  - 主手版副手持盾时，盾在脸前但不插头。
  - 写进第 9 节第 7 条给审阅方，本稿不处理。
