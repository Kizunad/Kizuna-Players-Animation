# sneak_walk：潜行行走（低姿态错步循环）

> 状态：设计稿已审阅通过；2026-10-26 已录入 classic `.bbmodel` 并导出，调度已接入。双体型门禁通过（实测见第 9/8 节）；离线 GIF 在 `build/anim-review/2026-10-26/`，游戏内视觉验收尚未执行。
> 数值来自设计期原型轨道并经仓库门禁同算法核对。基准躯干姿态与 [sneak](sneak.md) 相同。

## 1. 动作目的与触发

- **用途**：替换原版潜行移动（原版只把行走摆腿幅度乘上较小的 `limbDistance`，上身保持折叠前倾）。
- **触发**：`isInSneakingPose()`、着地、水平移动（相邻 tick 水平位移平方 > `0.0004`），且没有工具动作需要 `crouch_work`
  （潜行移动时 `crouch_work` 本来就会退出）。
- **原版进度来源**：原版潜行速度为行走的 0.3 倍（约 1.3 m/s），`LimbAnimator` 目标速度 `min(位移×4, 1)` ≈ 0.26/tick，
  原版摆腿一周期 `2π / 0.6662 / 0.26 ≈ 36 tick`（1.8 s）。本动作取 **1.6 s 一周期（两步）**，与原版节奏接近；和 `walk` / `run`
  一样按自由时钟循环，不追踪地面速度（现有 `walk` 1.2 s 周期同样不与实际速度同步）。
- **结束**：停步换 `sneak`（0.20 s 交叉淡入），松开潜行淡出 0.20 s 回 `walk` / `stand`。

## 2. 时间轴

剪辑长度 **1.6 s**，`loop: true`。建议时间线事件 `step_r` @ 0.0 s、`step_l` @ 0.8 s（白名单已有，供脚步声/粒子接入；
不触发即无副作用）。

| 相位 | 右腿 | 左腿 | 上身 |
| --- | --- | --- | --- |
| 0.00 | 前脚落地（踝 z −4.0 px），膝屈 21° | 支撑末段，膝屈 75° | 胯右转 0°、向左侧屈过零 |
| 0.00–1.02 | 支撑：踝沿 +z 匀速后移 5.0 px（约 4.9 px/s） | 0.18 s 起离地摆动 | 胯 Y ±4.5°、Z ±2.2° 随支撑腿转换 |
| 0.20 | 支撑中 | 摆动最高（抬脚 1.4 px） | 胸腰反向扭转 2.5°，抵消胯的转动 |
| 0.80 | 支撑末段 | 前脚落地 | 镜像 |
| 1.02–1.60 | 摆动（抬脚 1.4 px，脚尖先背屈再放平） | 支撑 | |

支撑占比 64%（双支撑约 14%），比 `walk` 更“粘地”；支撑行程中心前移 1.5 px，避免后脚踝背屈过大（见第 3 节）。

## 3. 分阶段全身姿势

- **胯**：下沉 2.6 px、后坐 3.0 px、前屈 22°；每步下沉 0.25 px（2 倍频）、左右移 0.35 px 跟随支撑腿；
  Y 旋转 ±4.5°（迈步侧胯前送）、Z ±2.2°（摆动侧胯下沉）。
- **腰 / 胸**：前屈 10° / 8°，Y 反向 −2.5° / −2.6°（晚 0.06 / 0.12 s）抵消胯转，Z 反向 1.0°～1.2°；每步 0.6°～0.7° 前屈起伏。
- **头**：抬头 36°，每步 0.9° 点头、0.8° 反向转头，保持视线稳定。
- **双臂**：与对侧腿反向摆 ±11°（相位晚胯 0.52 s，即 1/3 周期），肘屈 30° ± 7°，手腕 2°～4° 跟随；手指半握。
  潜行时摆臂幅度只有 `walk` 的一半左右，表现“压低、收着走”。
- **双腿**：踝枢轴轨迹按支撑/摆动分段，腿由胯姿态做脚底锁定求解：支撑期脚底全掌着地；摆动期抬脚 1.4 px（前送在摆动 85% 处完成，最后 15% 竖直落脚，避免贴地前滑被判为支撑），
  脚尖先 −18° 跖屈离地、中段 +10° 背屈过障再放平落地。支撑末 30% 脚趾背伸到 18° 表现蹬地。
- **不动的部位**：`root` 无轨道。

## 4. 关键帧

见附表。腿部每 0.1 s 一个锁定关键帧（17 帧/骨），保证 Catmull-Rom 插值时脚底不穿地（原型最低 −0.148 px）。

## 5. 重心与支撑

重心 x −0.28～+0.28 px、z −0.66～−0.20 px；单脚支撑段重心投影在支撑脚 ±2 px 内。支撑脚相对 `root` 后移速度约
4.9 px/s（`walk` 9.14 px/s）。原型 60 Hz：脚底最低 −0.148 px，踝 x 漂移 0.01 px。

## 6. 衔接

- `walk` → `sneak_walk`：按下潜行时 0.20 s 交叉淡入（优先级 2 高于 `walk` 的 1，不必停止宿主的 `walk`）。
- `sneak_walk` ↔ `sneak`：0.20 s；`sneak_walk` → `jump`：跳跃接管。
- 上层叠加：同 [sneak](sneak.md) 第 6 节；吃喝/格挡/拉弓等走 `upper`。

## 7. 索引条目（提议）

`mask: full`、`priority: 2`、`blend_in: 0.20`、`blend_out: 0.20`、`hand: none`、`fpv: false`、`loop: true`。
