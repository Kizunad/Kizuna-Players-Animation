# ride：骑乘（跨坐、握缰、随坐骑起伏）

> 状态：2026-10-26 已录入 classic `.bbmodel` 并接入调度（服务端 `hasVehicle()`；`shouldRiderSit` 仅客户端存在，原版坐骑均为坐姿）：2.4 s 起伏循环，22 骨 184 帧。双体型门禁通过，GIF 在 `build/anim-review/2026-10-26/`，游戏内视觉验收尚未执行；下文为设计记录，数值以 `.bbmodel` 为准。

## 1. 动作目的与触发

- **用途**：替换原版骑乘姿势（`BipedEntityModel.riding`：大腿 `pitch −1.414 rad`（屈髋 81°）、`yaw ±0.314`（外旋 18°）、
  `roll ±0.0785`，双臂额外前举 36°）。原版膝不弯，小腿直直伸向前方。
- **触发**：`LivingEntityRenderer` 的 `riding = hasVehicle() && vehicle.shouldRiderSit()`（马、驴、猪、炽足兽、骆驼、船、矿车）。
  服务端调度用同一条件。
- **原版进度来源**：骑乘是状态姿势，无进度。坐骑移动时原版骑手没有起伏；本动作是 2.4 s 自由时钟循环，表现呼吸和轻微随动，
  不推断坐骑步态（见第 8 节可选项）。
- **结束**：下坐骑淡出 0.25 s。

## 2. 时间轴

剪辑长度 **2.4 s**，`loop: true`。

| 时间 | 内容 |
| --- | --- |
| 0.0–1.2 | 吸气：胸后仰 1°、腰 0.6°，双手随胸上移 0.3 px，头补偿 −1° |
| 0.6–1.8 | 胯前后摆 ±1°（坐骨在鞍上滚动，晚 0.3 s），小腿随惯性摆 ±2° |
| 1.2–2.4 | 呼气回落 |

## 3. 分阶段全身姿势（基准）

- **胯**：位置不变（鞍点就是原版胯枢轴，乘坐高度由坐骑的 `getMountedHeightOffset` 决定，不能移动 `pelvis` Y）；后仰 4°（坐在鞍上微后靠）。
- **双腿（跨坐）**：大腿 (78, 16, −10) / (78, −16, 10)：屈髋 78°、外旋 16°、外展 10° 骑在马腹两侧；膝屈 70°，小腿沿马腹向下；
  脚背屈 10°（脚跟下压踩镫），脚趾 0°。与原版相比膝弯下来，脚不再伸到马头前。
- **腰 / 胸**：(2, 0, 0) / (−2, 0, 0)，上身挺直略前倾，肩放松。
- **双臂（握缰）**：上臂 (38, −8, −6) / (38, 8, 6)、肘 62°，双手在腹前 4 px、相距 4 px；手腕 (−10, 0, 15) / (−10, 0, −15) 掌心相对，
  手指握拳（拇指 45°、手指 75°～82°）。
- **头**：(3, 0, 0)，看前方；视线由 [head_follow](head_follow.md) 叠加。
- **不动的部位**：`root`、胯位置。

### 船与矿车

原版对所有坐骑用同一姿势。船中跨坐外展会穿出船舷？船宽 1.375 格，跨坐外展 10° 时膝宽约 12 px（0.7 格），在船内。
矿车宽 0.98 格，膝宽同样在内。保持同一资源，不按坐骑分支（YAGNI）；若审阅要求船中双腿并拢前伸，再加 `ride_boat`。

## 5. 重心与支撑

坐姿，无站立地面支撑（门禁写明不适用：骑乘）。左右对称，重心 x = 0。

## 6. 衔接

- 进入：`stand` / `walk` / `jump_air` → `ride`，淡入 0.25 s（上马瞬间原版即切骑乘姿势）。`jump` 调度在 `hasVehicle()` 时已退出。
- 退出：→ `stand`，淡出 0.25 s。
- 上层叠加：攻击、挖掘、放置、吃喝、拉弓、格挡、三叉戟均以 `upper` 叠加；`lowerBase` 需加入 `ride`，使骑乘时上层动作不改腿。

## 7. 索引条目（提议）

`mask: full`、`priority: 3`、`blend_in: 0.25`、`blend_out: 0.25`、`hand: none`、`fpv: false`、`loop: true`。

## 8. 接口缺口与可选项

1. 调度新增 `scheduleRide`（状态边沿 play/stop）；目录 `RIDE`；`lowerBase` 加入 `ride`。
2. 分析器：`ride` 加入全身动作与无地面支撑集合；多轴门禁适用（大腿三轴、上臂两轴）。
3. 可选：按坐骑水平速度把剪辑速率提高到 1.5 倍表现马小跑起伏（需要 `PlayRequest` 携带播放速率，协议没有该字段，本稿不做）。
4. 坐骑操控（骑马时左右手拉缰转向）：没有原版信号，不做。

## 9. 规模预估

24 骨、约 140 关键帧。
