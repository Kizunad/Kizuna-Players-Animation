## 1. 动作目的与触发

- **用途**：五脏诀附伤「锐金」。起手「唤」后，右前臂横在胸前，左手并成剑指，从右手腕往外一抹，抹过右手以后一弹，甩向左外侧。手里有兵器时，正好顺着抹过手边。
- **触发**：五脏诀锐金起手时，宿主调用 `PlayerAnimationAction.EVOKER_METAL_EDGE`，按真实时间播放，`start_tick` 同步起点。附伤在战斗中放，不开立。
- **时长**：剪辑 **3.5 s**（70 tick），`loop: false`。效果 `cast` 2.00。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`2.00: cast`。两脚整段锁定，没有 `step_*`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、3.50 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 唤（0.00–0.70 s）

见 E5。0.70 时：胯 `(0.15, −1.3, 0.6)`、旋转 `(−6, 6, 0)`；腰 0、胸 `(1, 0, 0)`、头 `(0, −6, 0)`；两上臂水平外展，前臂竖直，两手在头两侧，掌心朝前。

### 横臂（0.70–1.10 s）

- **躯干**：胯 Y 6° → 14°，腰 Y 0 → 2°（晚 0.04 s）。胸、头不动。
- **右臂**：上臂由外展 90° 收到前屈约 65°、内收约 20°，肘屈约 95°；前臂水平、横在胸前指向左方，右腕在 `(−1, 19.5, −7.5)` 附近，掌心朝下，腕平（手 0）。手型保持掌。
- **左臂**：由唤位下落、内收，左手 0.75–1.00 并成剑指（E3：拇指 `(10, 0, −60)`、`fingers_a` 0、`fingers_b` −90），1.05 指尖落到右腕上方约 0.3 px；左腕平，剑指指向右前方，指腹朝下。

### 抹锋（1.10–1.90 s）

- **左手**：剑指指腹贴着右手手背，沿右手长度方向（向左）匀速抹：1.10 在右腕，1.45 越过右手指尖（3 px），1.90 再到指尖外 4 px。整段左手高度跟着右手背走，接触段间隙 ≤ 0.5 px、不穿入。原型用「手贴前臂滑动」求解：把左手指尖锁在右手背上沿直线插值，左臂 IK 求肩、肘。
- **躯干**：胯 Z 位置前移 0.2 px（1.10–1.40）；头 X −10°（1.10–1.40），看右臂。
- **右臂**：不动（相对胸）。

### 弹（1.90–2.10 s）

- **左臂**：左腕 1.90–1.98 一弹（腕背伸约 30°），左上臂 1.92–2.10 外展到约 45°，左手甩到左外侧 `(9, 17, −4)` 附近；剑指不变。
- **头**：X 回 0（1.90–2.10）。右臂仍不动。

### 收（2.10–3.50 s）

- 胯 2.10–2.70 降回 `(0.15, −1.8, 0.6)`、旋转回 `(−6, 12, 0)`；腰、胸、头 2.10–2.80 回架势。
- 两臂 2.15–3.00 回护身位；剑指、掌 2.30–2.60 握拳。2.20–3.00 呼气（胸 −2°）。

## 8. 骨架与门禁带来的约束

1. **够得着**：页首第 1 条（估算，没用探针核对）。原型按「左手指尖在右手背上 ≤ 0.5 px」逐帧 IK，够不到就把右前臂再往左挪。

## 11. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/evoker/d_metal_edge.py` 求解（交接目录，不入库；共用的「唤」「收」在 `ev.py`），由 `install_ev.py` 装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（除相触一项外两套相同）和原型自查。

**索引实际值**：`hand_contact_windows` 为 `[[1.10, 1.52]]`（第 7 节估 `[1.10, 1.45]`）；`phases`、时间线没改。

**门禁**：全部通过。
- 关键帧 838（目标 700–900）。
- 全段最快 680°/s（右手 `fingers_b` 0.15 s，唤段松拳）；抽搐最大 1.22×10⁶°/s³（左手 0.95 s，左手落向右手背）。
- 最低点 −0.135 px（右脚趾 2.18 s）；重心没出界；支撑脚滑动右 0.018、左 0.015 px。
- 手臂穿模 0（门禁按方块中心判）。
- 预备 / 跟随 3/5 骨：腰、胸全段最快的一下是唤的转正，前面没有反向。
- 错峰：横臂段右上臂 0.95 → 右前臂 0.983 → 右手 1.00。抹锋段右臂不动，链上不到 3 根骨，门禁不判（第 10 节已写「抹锋段跳过」）。曲线相关 0/231 对。
- 两手相触：窗口 26 帧。最大间隙粗臂 0.165 px（1.517 s 右拇指对左拇指），细臂 0.136 px。最大穿入 0.015 px（粗臂 1.117 s，左手对头：左手落位时擦到下巴），细臂 0。
- 关节角度：头 20.1°（规格估颈 ≤ 19°）、左手 54°（剑指贴右手背的腕偏加上弹腕，规格估腕 ≤ 30°），都在门禁上限内。

**自查**：
- 两踝整段不动（漂移 ≤ 0.02 px）。
- 右臂横臂落点 IK 误差 0.72 px（1.06 s）：掌心朝下后偏 25° 加指向，在臂长边上取最小二乘解。
- 两手间隙（原型探针，手对手和左手对右前臂）：1.10–1.50 约 0.1 px，1.55 为 0.41 px，1.60 起 ≥ 0.73 px。规格自查要「1.45 之后 ≥ 0.6 px」，实际从 1.60 起满足：左手过了右手指尖以后，左手手指还在右手手指上方，要到 1.52 才离开。
- 会话探针按门禁的同一峰值算法查了左臂链（门禁只查右臂链）：
  - 横臂 0.70–1.10：左前臂 0.883 → 左上臂 0.983 → 左手 1.00，前臂先于上臂（左手经途经点落下时先伸肘）；
  - 弹、甩 1.90–2.16：左上臂、左前臂同在 2.05 达峰。弹腕在腕 Z 上 1.90–2.02，按设计先于甩臂；按整段主轴取的左手通道（Y）在这段不到阈值。
- 实体探针 `ev.clip_clash`（内层方块分离轴穿入，标准见 PROGRESS「制作实测」）：
  - 手、前臂对头不超过 `stance_idle` 本身：左前臂 0.90 px（1.13 s，1.00–1.30 有交叠），右拇指 1.01 px（架势本身）；
  - 上臂肩角对头：右 1.40 px（1.65 s）、左 1.22 px（1.12 s）；
  - 前臂压进躯干前角：右前臂对腰 1.29 px（1.57 s，横臂到收势 1.00–2.52）；对胸 1.49 px（2.42 s，回护身位途中；架势本身约 0.9）；左前臂对胸 0.96 px（1.12 s）。

**与规格的出入**：
- **右前臂不横在胸前，改为斜向左前下方**：右腕 `(−1.5, 17.8, −5.0)`（胸系），前臂方向从 +X（左方）向前偏 30°，掌心朝下再向后偏 25°，肘极向量 `(−5.5, 18.8, −1.6)`。原因：
  - 规格的右腕 `(−1, 19.5, −7.5)` 离肩 8.9 px，手臂只有 7.1 px，够不到；
  - 前臂真横在胸前时会压进胸口（上臂只有 3.16 px）；
  - 左手叠在右手背上要 4 px 厚，左前臂正好在下巴高度（模型没有脖子），右腕放低、掌面后偏，左前臂才不从下巴里穿过。
- 右臂由唤位先到肩前途经点（掌心 `(−7.0, 21.5, −6.5)`，0.70–0.90，途经段手腕不动）再到横臂位（0.82–1.06）：直走时右手横扫过脸。
- 左手由唤位先到左胸前途经点（掌心 `(4.5, 24.0, −7.0)`，0.72–0.98），再落到抹锋首帧的位置（0.86–1.10）：直走时左手贴着下巴左角扫下来。剑指 0.75–1.00 并成。
- 抹锋：
  - 逐帧求解，左指腹尖对右手背的间隙迭代到 0.1 px；
  - 起点离右腕 0.5 px（贴腕起抹时左手碰下巴）；约 1.43 s 越过右手指尖，1.90 到指尖外 4 px；
  - 两端各用全程的 20% 加减速，中段匀速；
  - 过指尖后左手平滑抬起 1 px：不抬时左拇指（垂在掌面下约 0.7 px）会刮到右拇指。
- **头**：低头 6°（规格 10°），并随剑指左转。偏航由唤的 −6° 转到 −16°（0.85–1.10）、−20°（1.10–1.60），1.90–2.10 回到 `(0, −6, 0)`。不左转时左前臂穿下巴约 2 px。叠视线层后偏航最多 50°，在颈 75° 内（E8）。
- 弹腕 1.90–2.02（0.12 s；规格 0.08 s，加加速度超限）。甩臂 1.92–2.16（规格到 2.10；0.18 s 甩完上臂 750°/s，超限），落到 `(9, 17.5, −5)`（规格 `(9, 17, −4)`，取臂长内略前）。解支用种子和肘极向量固定：不固定时最小二乘会落到上臂 Y 135° 的另一支。
