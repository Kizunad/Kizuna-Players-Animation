## 1. 动作目的与触发

- **用途**：五脏诀炼元「肝炼」，照六字诀嘘字诀。两掌收在腰间、掌心朝上；身体向左转 90°，右掌由腰间向左穿出、约与肩平，头微抬，吐「嘘」；转回正面，右掌收回腰间，吸气。下一遍向右转、穿左掌。一遍 5 s，练 6 遍（左右各 3 遍）。
- **触发**：五脏诀肝炼开始时，宿主调用 `PlayerAnimationAction.EVOKER_REFINE_LIVER`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **32.0 s**（640 tick），`loop: false`（待决定第 6 条）。没有 `cast`。
- **打断**：淡出 0.20 s 回架势，两脚在淡出里滑回架势位（E11）。
- **时间线事件**：`0.50: step_r`、`31.40: step_r`。转身时两脚不动，不加脚步事件。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、32.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 进式（0.00–1.00 s）

- 腿、胯、腰、胸、头照 E2、E11（同 [肺炼](evoker_refine_lung.md) 第 3 节）。
- 两拳 0.05–0.30 松成掌；两臂 0.05–0.90 落下、屈肘后收，0.90 两掌在腰侧 `(±5, 14.5, −2.5)` 附近：掌心朝上（前臂旋后），指尖朝前，肘屈约 50°、贴在体侧后方。

### 一遍（τ 0.0–5.0，单数遍向左）

- **停（0.0–0.5）**：两掌在腰侧不动。
- **转身穿掌（0.5–2.5）**：
  - 胯 Y 0 → −30°（0.5–2.3）、腰 Y 0 → −30°（0.55–2.4）、胸 Y 0 → −30°（0.60–2.5），起动依次晚 3 帧；胯缓起缓停，胸后段收得快一点。头 Y 不另转（随胸），头 X 0.8–2.2 抬到 +5°。
  - 两脚不动：两大腿相对胯被拧约 30°（左外旋、右内旋），膝维持约 5°。
  - 右掌由腰侧经腹前向左上穿出，2.4 到胸系 `(−1.5, 21.5, −7)` 附近（随胸转后朝世界左方）：上臂前屈约 70°、内收约 30°，肘屈约 50°，掌心斜朝上（前臂旋后约 45°）。左掌留在腰侧不动。
  - 呼气：胸 X −1°（0.5–2.5）。
- **转回（2.5–4.5）**：胯、腰、胸照原路转回 0（胯先起、胸后起，各晚 3 帧）；头 X 回 0；右掌沿原路 2.6–4.4 收回腰侧，掌心朝上。胸 X +1°（吸气）。
- **停（4.5–5.0）**：不动。
- 双数遍左右镜像：向右转（胯、腰、胸各 +30°），穿左掌，右掌留在腰侧。

### 收式（31.00–32.00 s）

- 照 E11：两掌 31.00–31.40 由腰侧落到体侧；31.00–31.10 胯左移；右脚 31.10 离地，31.40 以提踵落回 `(−1.7, 1.72, 3.2)`；左脚碾回外转 10°。
- 31.40–32.00 胯、腰、胸、头回架势；两掌握拳抬回护身位（全段最快，约 250°/s）。

## 8. 骨架与门禁带来的约束

1. **转身分配**：页首第 1 条（待决定第 15 条）。腰 30° ≤ 45°、胸 30° ≤ 60°。
2. **曲线相关性**：胯、腰、胸三条 Y 曲线同幅同形会算三对高相关（|r| > 0.98、峰值差 < 1 帧）。起动依次晚 3 帧，曲线形状也不同（胯缓起缓停，胸后段快收），原型实测 |r| 或峰值差，不行再加大错开。
3. **两脚不动、只拧大腿**：胯转 30° 时两大腿 Y 相对胯约 ±30°；原型逐帧查两踝 X、Y、Z 不动、全身最低点 ≥ −0.25 px。
4. **周期生成**：周期 10 s（左右两遍），τ = 0 与 τ = 5.0 姿势相同、速度为零（前后各停 0.5 s），左右两遍首尾相接。
5. **转速**：转身各骨约 30° / 1.8 s，峰值约 26°/s；穿掌上臂约 100° / 1.9 s，峰值约 85°/s。
