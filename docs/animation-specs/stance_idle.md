## 1. 动作目的与触发

- **用途**：战斗架势内、着地、水平静止时的底层姿态。左脚在前全掌、右脚在后提踵（右手为主手），重心明显下沉、双膝都屈，双拳护身；有呼吸起伏和脚下的轻微重心游移。
- **触发**：玩家处于“战斗架势”状态且着地、静止、未潜行/骑乘/游泳/攀爬/滑翔/睡觉。按审阅决定按“其他玩家也能看到架势”设计；“架势中”标志的同步不在本仓库，是接线前提（总览 Q1）。
- **时长**：剪辑 **2.0 s**，`loop: true`，自由时钟。一次呼吸 2.0 s（每分钟 30 次，比放松站立更急）。
- **进入 / 退出**：由 [stance_enter](stance_enter.md) / [stance_exit](stance_exit.md) 完成并步 ↔ 错步的换脚（0.45 s），不靠淡入淡出滑脚。开始移动换 `stance_walk_*` / `stance_run`；离地由 `jump` 接管。

## 3. 架势基准（所有架势动作共用）

数值为面板值；手臂由拳的挂点目标求解（带“肘下沉”的正则），腿由踝 / 前脚掌接地点锁定求解。

- **胯**：位移 `(0.15, −1.8, 0.6)`，旋转 `(−6, 12, 0)`：**下沉 1.8 px**（审阅要求 ≥ 1.5 px）、后坐 0.6 px、前倾 6°、右转 12°（半侧身）。
- **腰 / 胸**：`(−3, 4, 0)` / `(−2, 4, 0)`；躯干累计右转 20°、前倾约 11°。
- **头**：`(3, −19, 0)`：左转 19° 正对前方；比上一版少抬 2°，即**收下巴**。
- **前手（左）**：上臂 `(66.3, −25.2, 19.8)`、肘屈 52.7°、手 `(6, −4, −18)`（腕背伸 18°，拳峰朝前）；`l_item` 在 `(3.8, 23.6, −10.2)`：拳在左肩前方 10 px、**下巴高**，前臂由肘向前上斜。
- **后手（右）**：上臂 `(62.0, −34.2, 15.1)`、肘屈 47.2°、手 `(4, 8, 14)`；`r_item` 在 `(−4.4, 22.6, −7.7)`：拳护在**右下颌侧前方**，肘点 `(−4.8, 18.5, −1.7)` 下沉贴肋。
  两拳左右相距 8.2 px、前后错开 2.5 px，正视、侧视都不重叠（接触表见总览第 4 节）。后拳比下颌前出 1 px 是细臂骨架的间隙要求：再贴近，后手一收紧（肘屈多 10°）细臂的拳就会进头盒。
- **手指**：握拳。右拇指 `(10, 0, 50)`、两组手指 80° / 86°；左 `(8, 0, −48)`、−78° / −84°（与持物握姿一致，空手或持武器都成立）。
- **前脚（左）**：踝 `(2.3, 1, −2.6)`，全掌着地；大腿 `(48.7, −10, 1.5)`、膝屈 58.2°、踝背屈 15.1°。

  这正是解除小腿穿地限制的办法：本骨架小腿 cube 下沿与踝同高，踝在全掌时只有 1 px 高，后小腿前倾超过约 28° 就穿地；提踵后踝抬高 0.7 px，后腿可以屈到 75°、胯下沉到 1.8 px。

- **不动的部位**：`root` 无轨道。
