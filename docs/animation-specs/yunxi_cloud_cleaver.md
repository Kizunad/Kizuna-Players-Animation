# yunxi_cloud_cleaver · 裁云斜劈

拟用表现 ID `meridian_story:yunxi_cloud_cleaver`，PA 主手 `yunxi_cloud_cleaver`、副手 `yunxi_cloud_cleaver_off`。以下左右按右主手模型，原速每刻 50 ms。

## 目的与触发

下卷 `meridian_story:cloud_cleaver` 受理，所选手持合用的剑，普通铁剑与养父的旧剑共用轨道。按 P1 选定的「A 展臂斜落」，从持剑侧高处往对侧前方落一道斜线。命中瞬间肘已展开，剑和手都留在身前，正面看得见高低落差，侧面看得见重心越过两脚中点。目录在身前 2.4 格、总角 55° 内取一人，普通与还击共用一个落点。

| --- | --- | --- | --- |
| 0–200 ms · 单发引剑 | 左脚在前，右后膝承重，两膝向外开、胯下降到格剑的支撑高度。 | 腰胸随胯转向额前架位，持剑肩上提，头仍朝前。 | 肘先将柄送离身体，再抬至持剑侧额角外，转腕横剑，另手落到对侧身旁。**200 ms 全身逐骨取同手格剑 400 ms 横格基准**，包括剑挂点、另手、鞋底。 |
| 200–300 ms · 展臂 | 后脚前掌压地，后膝先伸，前膝留有承重余量，胯从横格向斜线打开。 | 腰随后转，持剑侧肩向上外侧展开，头稳住正前方。 | 从横剑位置将肘向本侧略打开，腕把剑引向同侧高处，另手护向胸外。短版从这里直接展臂，起手不再绕回身后。 |
| 300–450 ms · 斜落 | 后脚前掌碾转，胯先前送，重量由两脚间交给前膝，后跟随之提起。 | 腰随胯解开蓄转，胸带持剑肩切向斜下，头稍迟补转看落点。 | 上臂带肘展开，前臂、腕、剑尖依次追上。另手向本侧胸旁回收，避开斜线。**450 ms** 剑在身前斜线上，双手轮廓分明。 |

拟定 `cut` 发力段 0.30–0.45 s。用胯、腰、胸、本手上臂、前臂、手检查角速度峰依次传递，剑尖最后走完斜线。按 60 Hz 只在该段且淡入结束后量本手剑尖的 `swings`，目标一次；实测定起止与轻重。短版换算为受理后 100–250 ms，入画抬剑及回摆均不计。

## 主副手、覆盖与衔接

主手右后手自右高向左前下斩，副手左前手自左高向右前下斩。副手按左肩和本侧横格基准重解肘腕，胯胸转动增量换向，两版都保留左前右后的脚位。另手收回本侧，给斜线留出空间。持剑拇指与两组指骨全程握剑，挂点用物品原握法，左惯用手由 PA 镜像整套姿势。

两版均为一次性，优先级 24，淡入 0.10 s、淡出 0.25 s。`mask: full`、`hand: main/off`、`upper_while_moving: true`。静止时下盘有换重，走动时胯腿保留步态，上身仍画出斜线。`fpv: false`，全身第一人称沿用第三人称姿态与默认躯干。classic、slim 各核握点、异手持物间隙、支撑脚滑移 ≤0.5 px 和鞋底最低 ≥−0.25 px。[资产契约](../asset-contract.md) · [动画验收](../animation-acceptance.md)

**格剑接斜劈。** 设 R 为格剑正常实挡后开始收势的时刻。合法还击窗口是 **[R+300, R+800) ms**。要求本人实际防住、正常完成收势；守空、破防、本人用盾挡住或自己的剑打在对方盾上均走普通入口。立即受理时，从格剑回震后收稳的同手额前横格接剪辑 200 ms；若在窗口后部才受理，此时角色已开始回架或走动，从当下可见姿势淡入短版，服务端命中仍在受理后第 5 刻。普通版从战斗站姿起播，两个入口都可在收势后接普攻、格挡或受击。中断从当前帧淡出。[额前横格与两个出口](yunxi_flash_parry.md) · [战斗站姿](stance_idle.md)

逐帧对照同手格剑 400 ms、回震收稳末帧与斜劈 200 ms 的剑柄、剑尖、肩肘、膝胯。连播时分别在窗口首刻、最后一刻起还击，检查实际淡入的前两刻与第 5 刻落剑。另查窗口截止时起普通版，第 9 刻才落剑。静止和走动都要看，侧面检查脚底和肩位，正面检查剑尖连续。
