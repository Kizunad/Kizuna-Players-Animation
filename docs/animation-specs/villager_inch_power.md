## 2. 时间轴

| 段 | 时间 (s) | 做什么 |
| --- | --- | --- |
| 预备 | 0.00–0.30 | 前手松开；后手先往下松一下（约 5°），再抬起来 |
| 贴 | 0.30–0.90 | 前脚上半步（`step_l` 0.60），后脚跟踩实；前拳伸出停在身前，肘留着不伸直；后手护在胸前 |
| 定 | 0.90–1.30 | 双膝微屈，全身不动 |
| 抖 | 1.30–1.45 | 后脚蹬地，胯前送左转，腰、胸、肩依次一抖，肘伸直，拳面只往前 1 px。**`hit` 1.45** |
| 余震 | 1.45–1.70 | 全身回弹一下，拳停在原处不收 |
| 收 | 1.70–4.00 | 前脚回架势踝位（`step_l` 2.00），前拳慢慢收回 |

效果时刻和袖手拳目录一致：寸劲起手 1450 ms，打击在 1450 ms。

## 3. 制作实测（2026-11-17）

- 全段最大角速度 461°/s（右小腿，上半步时），那一抖里最快的是左前臂 350°/s，都在一次性动作的 720°/s 以内。
  所以动作稿里的打击时段 `[1.36, 1.50]`、爆发窗口 `[1.30, 1.38]` 都没声明，按最严的上限过。
- 最大角加加速度 763,622°/s³（上限 1,500,000）。支撑脚滑动右 0.30 / 左 0.21 px，脚底最低 −0.18 px，全程重心在两脚之间。
- `phases` 的主链写左臂：出拳的是前手（左），门禁缺省查右臂链，右手这一式只是护在胸前。
  实测峰值：胯 1.333 → 腰 1.367 → 左前臂、左手 1.367，近端先于远端（同帧在门禁的两帧容差内）。
- 相对草稿只改了一处：右手从架势抬到胸前之前，右上臂、右前臂、右手各加一小下反向预备（6.5°、5°、5°，开头 0.24 s）。
  门禁的「预备与随势」查右臂链，要主动作前有 3° 以上的反向；草稿里右手是直接抬的，五节里一节都不过，加了以后右臂三节过（要求六成）。
  腰和胸在那一抖之前没有反向预备，这是动作稿要的「前面越静越好」，没改。

## 4. 没验证的

- 持物：按空手做。
- 拳面离对方胸口的距离是按动作稿身前 18 px 摆的，游戏里对方站多远由袖手拳的起手距离定，贴不贴得上要看录像。
