# campfire_stand_up · 起身

> 玩家版 `campfire_stand_up`，村民骨架版 `campfire_stand_up_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)，坐姿见 [坐下](campfire_sit_down.md) 和 [抱袖坐](campfire_hands_in_sleeves.md)。

## 1. 目的与触发

从火边坐姿站起来，回到战斗站姿：手从袖里抽出，一手撑地，身体前倾，蹬起，拍两下衣摆，回到站姿。

- 用于：宿主让 NPC 离开火边、天亮动身，以及坐姿被打断。被打断时要不要整段播，见总览待审决定 5。
- 首帧是抱袖坐，即抱袖循环 0 s。
- 从烤火循环也能直接起播：`blend_in` 0.30 s，从当前姿势淡入，两手在淡入里由朝火位置移到抽袖的位置。这条路由切入矩阵检查。

## 2. 时长与标记

- 一次性 **1.00 s**（20 tick）。`blend_in` 0.30、`blend_out` 0.25、`hand: main`（拍衣摆用右手，左撇子整段镜像）、优先级 6。
- `timeline`：`step_r` 0.80、`step_l` 0.88，脚步声。
- 末帧逐骨等于 `stance_idle` 首帧，速度归零。宿主在第 20 tick STOP，露出底下的站姿。

## 5. 骨架差异（村民骨架版）

- **胯角跟胯高倒着走**：胯先升、再回正。任何时刻胯高都 ≥ 袍子在当前胯角下伸到的深度 − 0.2 px，对应关系见总览第 2 节的实测表。远看是起身时袍子从腿上滑下来、垂回原位。
- 腰的反向前屈和胯角同步解除，躯干朝向两版相同。
- 村民的肩更靠后，撑地的右掌往后放 1 px，在 (−6.5, 0, −0.5)。
- 拍衣摆拍在袍子后侧，手离袍子 ≤ 0.5 px、不穿入。

## 6. 衔接

- 从抱袖循环接本段，首帧逐骨相同。从烤火循环接本段，淡入 0.30 s。
- 末帧是战斗站姿，可以直接接战斗动作。被打时宿主 STOP，按 0.25 s 淡出，受击片段盖上去。

## 7. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 全身最低点 ≥ −0.25 px；
  - 0.48–1.00 s 按站立口径查：支撑脚滑动 ≤ 0.5 px，重心在支撑脚 ±2 px 内；
  - 0.00–0.48 s 坐着或手撑地，按总览待审决定 2 的口径查。
- 60 Hz 峰值时刻表看蹬起顺序：胯前移 → 膝伸 → 胯升 → 腰 → 胸 → 头，右臂推地在膝伸之前。
