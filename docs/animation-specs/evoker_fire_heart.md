## 1. 动作目的与触发

- **用途**：五脏诀强身第三式，照五禽戏猿提。两手撮成猿钩往上一提，同时耸肩、收腹、脚跟提起，头猛地转向左侧，像猴子受惊张望；然后一下松下来。全书唯一提踵耸肩的一式，也是强身里最快的一式。
- **触发**：五脏诀心火起手时，宿主调用 `PlayerAnimationAction.EVOKER_FIRE_HEART`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **4.0 s**（80 tick），`loop: false`。效果 `cast` 1.80。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`0.35: step_r`、`1.80: cast`、`2.80: step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、4.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 开立（0.00–0.40 s）

- 照 E2，时间压缩：胯 0.00–0.08 左移；右脚 0.08 离地，0.35 全掌落开立位；胯 0.35–0.40 到 `(−0.7, −0.1, −2.4)`、旋转 0；腰、胸、头回 0。
- 两拳 0.05–0.25 松成掌；两臂屈肘，两掌 0.40 到腹前 `(±1.5, 13.5, −3.5)` 附近，掌心朝下。

### 成钩（0.40–0.80 s）

- **手**：0.40–0.70 五指撮拢成猿钩（E3：拇指 `(0, 0, 45)`、两组手指 50° / 55°），腕 0.45–0.80 掌屈到 60°，钩尖朝下。三片手指错开 1–2 帧。
- **头**：X −5°，看手。其余不动。

### 提（0.80–1.30 s）

- **脚**：两脚跟 0.80–1.15 提起：踝 y 1.00 → 1.45、脚底约 −15°、趾背伸约 15°，前脚掌着地（E7：只做半程）。双膝伸到约 5°，胯升约 0.45 px。
- **躯干**：两上臂枢轴（位置 Y）0.85–1.15 上移 0.5 px 表现耸肩；胯 Z 位置后移 0.3 px、胸 X −4°（收腹含胸）；头 X 回 0。
- **双臂**：上臂前屈 20° → 50°、肘 30° → 100°，两钩 1.20 到胸前 `(±1.5, 19, −4)` 附近；腕再屈到 75°（「提腕」）。上臂、前臂、手的峰值依次晚 0.05 s。

### 转头（1.30–1.80 s）

- **头**：Y 1.30–1.55 到 −45°；**胸** Y −15°（1.30–1.50）、**腰** Y −10°（1.30–1.48）；腰、胸先到，头最后到。1.55–1.80 定住。
- 两臂随胸一起转（局部不动），提踵、耸肩保持。

### 松（1.80–2.30 s）

- **脚**：脚跟 1.85–2.00 落地（踝回 y 1.00）；胯降回 y −0.1。
- **躯干**：头、胸、腰 1.80–2.10 转回 0；肩 1.80–2.00 落下；胯、胸回 0。
- **双臂**：钩 1.85–2.05 松成掌，掌心朝下；两掌 1.90–2.30 沿体前下按到体侧（上臂回 5°、肘回 5°）。

### 收（2.30–4.00 s）

- 照 E2 收步：胯 2.30–2.40 左移；右脚 2.45 离地，2.80 以提踵落回 `(−1.7, 1.72, 3.2)`；左脚碾回；胯 2.80–3.30 降回架势、旋转回 `(−6, 12, 0)`。
- 腰、胸、头 2.45–3.30 回架势。两掌 2.40–2.70 握拳，两拳 2.60–3.40 回护身位。呼气 2.40–3.40（胸 −2°）。

## 11. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/evoker/d_fire_heart.py` 求解（交接目录，不入库；开立、收步用 `ev.py` 的 `open_feet`，支撑脚与提踵沿用千里腿 `ped.py`），由 `install_ev.py` 装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：同第 7 节，`phases` `[[0.80, 1.30], [1.30, 1.80]]`，时间线 `0.35 step_r`、`1.80 cast`、`2.80 step_r`。

**门禁**：全部通过。
- 有效运动骨 26 根；关键帧 1,521（目标 700–900，超出：两臂掌心 IK、两腿支撑脚 IK 都逐帧出帧）。
- 全段最快 704°/s（右小腿 0.32 s，开立落脚前）；抽搐最大 1.08×10⁶°/s³（右小腿 0.35 s，落脚）。
- 最低点 −0.209 px；重心没出界。支撑脚滑动右 0.428、左 0.433 px（就是半提踵的踝升，≤ 0.5）。
- 关节最大：头 45.0°、胸 15.0°、腰 10.1°、前臂 75.4°、腕 75.0°。
- 手臂穿模 0（门禁按方块中心判）。
- 预备 / 跟随 5/5 骨。
- 错峰：
  - 提 `[0.80, 1.30]`：右上臂 1.017（Z）→ 右前臂 1.083（X）→ 右手 1.117（Z）；腰、胸本段不动，不计；
  - 转头 `[1.30, 1.80]`：两臂不动，有效骨不到 3 根，分析器跳过（同第 4 节）。
- 曲线相关 1/253 对。

**自查**：
- 0.35–2.45 两踝 X 范围右 0.019、左 0.022 px，Y 范围右 0.428、左 0.430 px（≤ 0.45）；Z 范围约 0.34 px，是提踵时脚趾前缘不动、踝绕它前移。
- 1.55 头世界偏航 −70.0°。
- 0.30（右脚离地中）重心离左踝 X 1.91 px（±2 内）。
- 掌心 IK 残差最大 0.29 px（腹前钩）。
- 实体探针 `ev.clip_clash`（标准见 PROGRESS「制作实测」）：
  - 手、前臂对头不超过 `stance_idle` 本身：右拇指 1.01 px（架势本身）；
  - **上臂肩角对头超过固有范围**：左 2.15 px（1.50 s）、右 2.07 px（1.67 s），固有范围约 1.2–1.6。头转 45° 时头盒的角正好伸到两肩上方，钩上提时上臂外展约 71°、又耸肩 0.5 px，肩块上角顶进去。列进 PROGRESS「留给验收决定」；
  - 前臂压进躯干前角：右前臂对腰 1.41 px（3.07 s，回护身位途中）、对胸 1.22 px（0.25 s，开立）；左前臂对腰 0.92 px。

**与规格的出入**：
- **腹前手位抬高**：规格腹前 `(±1.5, 13.5, −3.5)` 离肩 9.8 px，超过掌心臂长 8.6 px（E11）。平掌掌心点改到 `(∓3.4, 17.0, −5.5)`、腹前钩 `(∓3.4, 17.5, −5.5)`（胸系，右手负 X）；两手块各宽 4 px，取 ±3.4 不叠。
- **掌心朝下靠手 Y 拧 −62°**：Steve 前臂不能旋前、上臂只有 3 px。再拧，手的主通道就从 Z 变成 Y，提段错峰不计手。
- **钩手**：腕固定掌屈（腹前 60°、胸前 75°），指尖朝下偏内，肘点拉向体侧外（猿钩提肘）；直接按掌心朝下求腹前钩时 IK 落到另一支解，转速 1,050°/s、前臂压进腰 2.6 px。
- **胸前钩在 `(∓3.4, 20.5, −5.5)`**（规格 `(±1.5, 19, −4)`），1.20 时上臂约 `(51, −18, −71)`、肘 75°（规格上臂前屈 50°、肘 100°）。肘点放到 `(∓9.5, 21.5, −3.0)`：肘不往外拉时提段上臂 Z 只动 3.3°，有效骨不到 3 根，提段错峰也被跳过。
- **提踵时胯升 0.35 px（到 y 0.25）、后移 0.25 px，膝约 14.5°**（规格胯升 0.45、后移 0.3，膝伸到约 5°）。两踝升 0.42 px 并前移约 0.3 px 后，胯升到 y 0.40 右腿就够不着（探针）；膝在 14.5° 到伸直之间腿长只差约 0.1 px。开立时膝约 10°，所以提的时候膝反而多屈约 4.5°。
- 提踵：踝升 0.42 px（规格 0.45，膝随动再多约 0.01，留出 E7 的 0.45），脚底俯仰 −15°，脚趾前缘不动。两踝左晚 1 帧。
- 开立胯：右脚摆动中胯到 `(0.75, −0.4, −2.0)`，0.31–0.49 到开立位（规格 0.35–0.40）。摆动胯再往右，0.30 时重心出左踝 ±2 px；再往左，右小腿超过 720°/s。
- 松：腰 1.80–1.94、胸 1.80–1.95 转回（规格 1.80–2.10），比转过去还快，作为腰、胸全段最快的一下，转头本身就是它的反向预备（按规格时序，腰、胸的预备 / 跟随不过）。头 1.82–2.12 转回。
