# campfire_warm_loop · 烤火循环

> 玩家版 `campfire_warm_loop`，村民骨架版 `campfire_warm_loop_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)，坐定的「烤火基准」见 [坐下](campfire_sit_down.md) 第 3 节。

## 1. 目的与触发

盘坐在火边烤火。底下是一层基础姿态加呼吸，上面依次叠六段小动作，时机错开，互相交叠，不整齐划一。宿主在 [坐下](campfire_sit_down.md) 末 tick 起播，一直放到收手入袖、起身或被打断。

## 2. 时长与索引

- **12.0 s**，`loop: true`，自由时钟。
- `blend_in` 0.20、`blend_out` 0.12、`hand: main`（拨火用右手，左撇子整段镜像）、优先级 6、`fpv: false`。
- `hand_contact_windows`：`[[0.65, 2.05], [4.30, 5.05]]`，分别是搓手和呵气时两手相贴。
- `item_states`：`{"open": [[0, 0], [6.18, 0], [6.22, 1], [7.73, 1], [7.77, 0]]}`。拨火那 1.5 s 显示手里的枯枝，见总览待审决定 6。没给物品时这条轨道不起作用。

## 3. 基础层（全程）

**姿态**：烤火基准，两版目标见坐下第 3 节。
- 微驼背，躯干世界前倾 14°；
- 缩肩：上提 0.4 px、前收 0.5 px；
- 双手掌心朝火，停在膝前、离火面 2.5 px；
- 低头看火，俯视 18°。

**叠在上面的周期层**，每层周期都整除 12 s，相位互不相同：

| 层 | 周期 | 内容 | 相位 |
| --- | --- | --- | --- |
| 呼吸 | 4.0 s × 3 | 吸 1.7 s、呼 2.3 s。肩提 0.4 px（比胸晚 0.15 s），胸后仰 0.8°（腰早 0.1 s），头反向 0.4°，两手随肩上移 0.25 px | 吸气峰在 1.7 s、5.7 s、9.7 s。第二周期被呵气替换，见 E2 |
| 坐姿摇晃 | 12 s | 胯侧倾 ±0.6°，胸反向 ±0.4°，晚 0.4 s；重心左右游移 0.25 px | 胯在 3.0 s 向右最大 |
| 头的漂移 | 6 s | 偏航 ±3°、歪头 ±1.5° | 偏航峰在 1.2 s、7.2 s |
| 手的微动 | 4 s | 两手各自前后飘 0.2 px，左手晚 0.6 s；三片手指屈伸 ±3°，从拇指到 b 依次晚 2 刻 | 跟呼吸错开 0.9 s |
| 脚 | 12 s | 左脚踝内外转 ±4°，右脚趾在 3.0 s 和 10.0 s 各屈一下 6° | — |

## 5. 各段细节

### E1 搓手翻手（0.30–3.60 s）

| 时段 | 动作 |
| --- | --- |
| 0.30–0.65 预备 | 肩先提 0.2 px，两手往中间合，掌心相对贴在身前 (0, 8.5, −6.5)，手指并拢伸直。两肘向内收 |
| 0.65–2.05 搓四下 | 每下 0.35 s：右掌前推 1.2 px、左掌后拉，下一下反过来。第四下幅度减半，像搓到尾。肘反向走，躯干跟着反向偏航 ±1.5°，晚 1 刻。每下到头时手指收紧 10°，挤一下 |
| 2.05–2.55 翻手背 | 两手分开回到基准宽度，前臂旋前、手翻转，**手背朝火**，掌心朝向自己。手指放松，屈 20° / 25° / 30°。头低 2°，看手背 |
| 2.55–3.25 烤手背 | 手停住。2.80–3.10 手指慢慢张开再松回（开合一次）。肩随呼吸 |
| 3.25–3.60 翻回 | 手翻回掌心朝火，比腕晚 1 刻手指重新张开，回到基准 |

### E2 呵气（4.00–5.55 s）

这一段替换呼吸层的第二个周期。

| 时段 | 动作 |
| --- | --- |
| 4.00–4.45 合手到嘴前 | 两手抬起相合，**拱成碗形**：手指屈 35° / 40° / 45°，拇指内收，两手外缘相贴。手停在嘴前 2 px。头低 8°，迎上去。深吸：胸后仰 2.5°，肩提 0.8 px |
| 4.45–5.05 呵 | **4.55 s 肩一耸**，峰值 +1.0 px，比胸晚 1 刻，然后落下。胸前屈 1.5°，头随呼气前点 2°。手指再收 5°，像把热气捂住 |
| 5.05–5.55 放回 | 两手分开，顺势搓一下（单次，幅度 0.6 px），回到朝火位置，头抬回俯视 18° |

### E3 拨火（5.90–8.10 s，右手）

| 时段 | 动作 |
| --- | --- |
| 5.90–6.25 拿枝 | 头先往右下瞥 15°（早 2 刻）。躯干右倾 6°、右转 8°。右手伸到右侧地面 (−7.5, 0.5, −2)，掌心朝下，6.20 手指收拢握住。6.22 枯枝出现 |
| 6.25–6.65 前伸 | 躯干在基准上再前倾 12°，到 26°。重心前移，左手按到左膝上撑着（6.55 着膝）。右臂前伸，枝尖指向火堆近侧的柴，大约 (0, 3, −13)。头回到看火 |
| 6.65–6.95 第一下 | 前送 2 px，腕往下压 15°，再收回。肩比肘早 1 刻，头晚 1 刻轻点 |
| 7.05–7.40 第二下 | 小一点的撬拨：腕先下压再上挑，前臂不动，肩随之起伏 0.3 px |
| 7.40–7.85 放下 | 右手收回，把枝搁回右侧地面，7.75 手指张开、枝消失。躯干回到前倾 14°，左手离开膝头（7.85） |
| 7.85–8.10 回位 | 右手抬回朝火位置。比左手晚 0.15 s 到，两手不同时 |

### E4 换坐姿（7.70–9.30 s）

| 时段 | 动作 |
| --- | --- |
| 7.70–8.10 挪重心 | 胯右倾 4°、右移 0.6 px，坐到右侧坐骨上。胸反向左倾 2°，晚 1 刻 |
| 8.10–8.60 收腿 | 左脚跟贴地后拉，从 z −8.5 收到 −4.5，左膝立起，从 4.6 px 抬到 8.0 px |
| 8.60–8.95 停 | 立膝停住，左脚全掌踩地，脚趾屈伸一下 |
| 8.95–9.30 再伸出 | 左脚滑回斜伸位置，胯回正，9.35 向左过冲 0.8°，9.60 前收稳。腿最后逐骨归位 |

### E5 抬头看天（9.40–10.70 s）

| 时段 | 动作 |
| --- | --- |
| 9.40–9.75 抬头 | 头从俯视 18° 抬到仰 12°，胸跟着伸 3°，晚 1 刻。两手因为分心下垂 0.5 px |
| 9.75–10.25 四顾 | 头慢慢左转 25°，10.00–10.20 停住（看远处），再往回转 |
| 10.25–10.70 回到火 | 头低回俯视，10.65 过冲到 20°，再回到 18°。胸和手跟着回位 |

### E6 小哈欠、缩脖子（10.55–11.55 s）

| 时段 | 动作 |
| --- | --- |
| 10.55–11.00 小哈欠 | 头后仰 5°，胸扩 2°，肩提 0.6 px。左手离开火，抬到嘴前一掌远，手背朝外，不碰脸 |
| 11.00–11.25 冷得一缩 | 左手放回。两肩快速上耸 1.2 px，头下沉 3°（缩脖子），躯干小幅抖两下：偏航 ±1°，约 8 Hz |
| 11.25–11.55 放松 | 肩慢慢落回缩肩基准，手回到朝火位置 |

## 6. 接缝

- 0 s 和 12 s 只有周期层，六段小动作都在 11.55 s 前完全收住。门禁按首尾位置差 ≤ 0.05 px 查。
- 呼吸层三个周期首尾相接，第二周期被呵气替换，但起点和终点的相位不变。

## 7. 骨架差异（村民骨架版）

- **基准**：胯后仰 85°、袍子盖在腿上、躯干从胯后 4 px 立起，见坐下第 3 节。肩更靠后，手要到同一个离火距离，所以肘更直。
- **E2 呵气**：手停在鼻子前面，离鼻尖 ≥ 0.5 px，不碰鼻子。头只低 5°。
- **E3 拿枝**：右手绕过袍子右侧，袍宽 ±4 px，手到 x −7.5 不碰袍子。
- **E4 收腿**：左膝立起时从袍子左边露出来。袍子是刚体，不跟膝走；膝 x 在 4–5 px，基本在袍外。
- **E6**：抬到嘴前的手离鼻子 ≥ 1 px。

## 8. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 全身最低点 ≥ −0.25 px；
  - 首尾接缝连续；
  - 两段 `hand_contact_windows` 内两手相贴、不穿；
  - 坐姿支撑按总览待审决定 2。
- **切入矩阵**：从 0.00、0.25、…、11.75 s 每一档淡入收手入袖（0.30 s）和起身（0.30 s），查淡入期间最低点、手臂互穿、两手间隙。重点是 E3 前倾拨火和 E4 立膝这两段。
