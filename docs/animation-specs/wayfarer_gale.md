## 1. 动作目的与触发

- **用途**：行矢第五式，照连弩的用法把弩托顶在右胯上，整个身体像炮塔一样从右 45° 匀速转到左 45°，边转边推拉，六发散成一个扇面。全套唯一抵腰、唯一边转边射的一式。
- **与其他弩式的区别**：连弩抵颊、原地前后摇；跪射跪着、膝上装填；**横风抵腰、整个身体转 90°**。
- **触发**：行矢横风起手时，宿主调用 `PlayerAnimationAction.WAYFARER_GALE`（弩在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **6.0 s**（120 tick），`loop: false`。撒放 2.20、2.55、2.90、3.25、3.60、3.95 s。
- **承接**：承接入口 0.40。作后式：连弩承接、五个弓式（天地同至除外）换兵，都从 0.40 起播。作前式：满月 0.40、连珠 0.40、弓梢 0.30（换兵）。收势从 3.95 起，前半段到 4.98，后脚 4.90 已回架势踝位。
- **打断**：起手 0–2.20 s 被伤害打断时淡出 0.20 s。
- **时间线事件**：`0.75: step_r`、`2.20 / 2.55 / 2.90 / 3.25 / 3.60 / 3.95: release`、`4.90: step_r`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。推拉行程与物品状态见 C8。

### 起点与终点（0.00 s、6.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯位置相对架势 `(+0.3, 0, 0)`、Y −2°；重心 X 进左踝 ±2 px（同 C4 的预压）。0.40 s 全身速度为零（承接入口）。

### 调整（0.40–1.00 s）

- 右脚 0.45 离地，0.75 以提踵 −35° 落在 `(−2.8, 1.72, 4.3)`（向右后 1.5 px）；左脚不动。
- 双膝 0.50–1.00 屈到 30°，胯下沉 1.2 px、右移回中。
- C3：前脚全掌、膝 30° 时小腿前倾约 18°、侧倾约 10°，最低点约 −0.05 px；后脚提踵，余量大。

### 抵腰（1.00–1.40 s）

- **躯干**：胯 X −6° → −10°、腰 X −3°、胸 X −2°，合计前倾约 15°；胸相对胯右扭约 20°（腰 +8°、胸 +12°），左肩前送。
- **右臂**：弩由持物位落到腹高：弩托末端贴右胯侧（约 `(−4.5, 10.5, 0.5)`），右手约 `(−3.5, 11, −4.5)`，弩身水平、弩口偏左约 15°（斜过腹前）。右上臂前屈约 15°、肘约 45°。
- **左臂**：几乎伸直，托在扳机前约 3 px（推位），左肘外张；手指 −40°。
- **头**：Y 随胸转回正前，X +10°（前倾时仍平视）。

### 转到右（1.40–1.85 s）

- 胯 Y +20°、腰、胸依次跟上，弩口世界偏航 1.85 到 +45°（以胯的初始朝向即视线为 0）；胸相对胯的右扭保持 20°。
- 重心移到后脚约 60%（胯后移约 1 px）；两脚绕踝竖线碾，前脚脚尖右转约 15°，后脚跟内转约 15°。
- 头 Y 跟弩口，头世界偏航 = 弩口偏航。

### 第一拉（1.85–2.15 s）

- 左手 1.85–2.12 沿弩身拉回扳机旁（3 px）；物品：1.85 `pulling` 开，`pull` 1.85 → 2.12 由 0 到 1；2.16 `pulling` 关、`charged` 开。
- 后脚保持提踵（动作稿「后脚脚跟抬起」）：架势的后脚本来就是前脚掌着地，调整时也以提踵落地，所以这里不再变化。

### 回扫（2.15–3.95 s）

- **转身**：弩口世界偏航由 +45° 转到 −45°，2.20 / 2.55 / 2.90 / 3.25 / 3.60 / 3.95 正好 +45 / +27 / +9 / −9 / −27 / −45°。平均 51°/s，每循环脉动约 ±15°/s：发后 0.10 s 慢（后坐）、推拉时快，腰的角速度峰值在 t + 0.10、胸在 t + 0.12（胯领先、腰晚 0.03 s、胸晚 0.05 s），看起来仍是匀速转。
- **脚**：后脚绕踝竖线碾（看起来是前脚掌为轴、脚跟外转），前脚绕踝竖线碾、脚尖内转，踝 X、Y 都不动（C2）；双膝始终 30°；重心由后脚 60% 移到前脚 60%（胯前移约 2 px）。
- **每发 t**：`release`；弩口上跳 2°（0.05 s 上、0.05 s 回）；右胯被顶，胯后移 0.2 px，0.15 s 回；`charged` 关。
- **推**（t + 0.03 → t + 0.15，前五发）：左手前推 3 px，`pulling` 关。
- **拉**（t + 0.15 → t + 0.28）：拉回扳机旁；t + 0.15 `pulling` 开、`pull` 0，t + 0.27 到 1（`_2` 显示 0.03 s）；t + 0.30 `pulling` 关、`charged` 开，挂上的箭显示到 t + 0.35 发。
- 第六发（3.95）后不再推拉。

### 随（3.95–4.40 s）

- 余势再转 7°，4.20 到 −52° 停住（最小抽搐减速）；前脚撑住；4.00–4.40 呼气。左手停在扳机旁。

### 收（4.40–6.00 s）

- **上身**：4.40–4.90 由 −52° 转回正前，前倾回架势屈度。
- **脚**：4.45–4.50 重心移到左脚；右脚 4.50 离地，4.90 以提踵落回 `(−1.7, 1.72, 3.2)`；左脚 4.50–4.90 碾回；双膝 4.90–5.40 回架势屈度，胯升回。
- **双臂**：弩 4.70–5.40 举回持物位，左手 5.50 回下巴前；5.60–6.00 静止。

## 7. 骨架与门禁带来的约束

1. **抵腰够不着**（估算，未用探针核对）：动作稿「右上臂前屈 20°、外展 10°，屈肘 90°」的手在胸高，弩托顶不到胯。弩托顶胯时右手约在 y 11，左手要伸到腹前的弩身：躯干直立时左肩到弩身约 11.9 px，超过手臂 10.2 px；前倾 15°、胸相对胯右扭 20° 后约 9.6 px，刚够。原型按「弩托末端贴右胯 ≤ 0.5 px、弩身水平 ±5°、左手在弩身上」逐帧 IK，够不到就把弩抬高 1–2 px（弩托改顶在右腰侧）。
2. **推拉行程**（C8）：3–4 px，同连弩。
3. **拉弦提前**：动作稿 0.34 挂上、0.35 发，挂上的箭只显示 0.01 s（不到一帧）；拉 0.15–0.28、0.30 挂上，箭显示 0.05 s。推 0.12 s、拉 0.13 s，左肘约 30°，峰值约 470 / 430°/s。
4. **回扫脉动**：见第 6 节 `phases`。
5. **碾脚**：两脚绕踝竖线转（C2），看起来是动作稿的「以前脚掌为轴」；后脚提踵时绕前脚掌转踝会走 0.7 px，超过 0.5。
