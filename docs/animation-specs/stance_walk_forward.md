## 1. 动作目的与触发

- **用途**：战斗架势内的移动，面朝前保持架势，脚下垫步前进。
- **触发**：架势中、着地、在移动，移动方向（实体水平速度相对身体朝向）落在本方向的 90° 扇区：前 `|角| ≤ 45°`、左 `45°～135°`、后 `≥ 135°`、右 `−135°～−45°`；斜向取最近扇区、不单做（Q9），边界 10° 迟滞。疾跑时改为 `stance_run`。
- **时长**：剪辑 **0.8 s**（两步），`loop: true`，自由时钟（与 `walk` 一样不随实际速度变速；原型支撑脚移动约 5 px/s，游戏内仍有全库原地步态共有的脚下滑动）。
- **结束**：停步换 `stance_idle`（0.15 s），换方向在 `stance_walk_*` 之间交叉淡入 0.12 s；退出架势时先停步再播 `stance_exit`（移动中退出见 [切换表](transitions.md)）。

## 2. 时间轴

四个方向用同一个步态生成器（`gait.py`），**共用**：周期 0.8 s、摆动 28%、第二只脚相位落后 0.42、步态踝位中心、抬脚曲线（水平三次 Hermite，离地和触地瞬间水平速度等于支撑期后移速度；竖直 `sin^1.15`）、上身对落脚的反应模板、手指节奏。**各自单做**：先动的脚、步幅向量、摆动脚俯仰、躯干倾斜方向、手臂分工。左右**不能镜像**：架势左前右后，向左前脚领步、向右后脚领步；镜像会变成右前左后的架势、脚序也反了。前进和后退的脚序互为时间反演，但不能倒放：倒放会让蹬地变成落地、预备变成跟随。

## 3. 分阶段全身姿势

基准同 [stance_idle](stance_idle.md) 第 3 节；步态中胯抬到 `(0.15, −1.5, 0.5)`（比站姿高 0.3 px，给步幅留腿长），两脚踝位中心为左 `(2.3, 1, −2.2)`、右 `(−1.7, 1.72, 2.5)`，与站姿差 0.4～0.7 px，由 0.15 s 淡入完成。

- **脚序**：前（左）脚先向前迈 2.8 px，后（右）脚随后跟进 2.8 px，两脚不交叉、不并拢。步幅向量 `(0, 0, −2.8)` px。
- **脚**：前脚摆动先提脚跟（俯仰 −8°）、贴地前送、全掌落地；后脚全程提踵，以前脚掌着地、前脚掌离地，摆动时多抬 0.8 px（脚尖朝下，抬得少会被当成着地拖行）。支撑期脚底锁定、匀速反向后移；摆动水平轨迹在离地和触地瞬间与支撑速度连续，最后约 15% 竖直落脚。
- **胯**：起步前重心先向后脚压 0.35 px（反向预备），前脚落地后移入前脚；落地下沉 0.18 / 0.12 px；随行进方向侧屈或前倾 1.0°～1.6°；Y 随先动脚 ±1.5°。
- **腰 / 胸 / 头**：前脚落地后 0.06 s 胯前倾多 1°、腰胸再前倾 1.2° / 1.0°；头反向抬 2° 保持平视。胸另有 0.6° 的整周期呼吸。
- **双臂**：前（左）拳在前脚落地后 0.13 s 前探：上臂多前举 4°、肘伸 5°；后（右）拳在后脚落地后上提 2.5°，前脚落地时肘外展 1°（不向下压到腰）。上臂 → 前臂 → 手腕依次晚 0.04 相位（32 ms）。
- **手指**：握拳，各自脚落地后紧握 3°～4°。
- **不动的部位**：`root`。
