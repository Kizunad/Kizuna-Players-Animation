## 1. 动作目的与触发

- **用途**：五脏诀附伤「震土」。起手「唤」后，右膝慢慢提到胯高，两掌举到头前；然后一脚跺下，两掌同时往下按，像把力送进地里。全书唯一跺脚的一式。
- **触发**：五脏诀震土起手时，宿主调用 `PlayerAnimationAction.EVOKER_EARTH_QUAKE`，按真实时间播放，`start_tick` 同步起点。不开立。
- **时长**：剪辑 **3.5 s**（70 tick），`loop: false`。效果 `cast` 2.00。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`1.95: step_r`、`2.00: cast`、`2.55: step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、3.50 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 唤（0.00–0.70 s）

见 E5。0.70 时胯 `(0.15, −1.3, 0.6)`、旋转 `(−6, 6, 0)`。

### 提膝（0.70–1.70 s）

- **腿**：
  - 胯 0.70–0.80 左移、前移到约 `(1.3, −1.0, 0.0)`，重心压进左踝 ±2 px（E6；右腿提起后重心再往右前偏，原型按重心求）；
  - 右脚 0.80 离地，右大腿 0.80–1.40 前屈到 80°（胯高），膝屈约 90°，小腿近竖直，脚背伸 0、脚尖自然下垂；
  - 左膝 0.80–1.20 伸到约 35°，1.40–1.70 定住。
- **躯干**：胯 X −6° → 0（上身竖直），胸 X +1° → +4°（吸气，0.80–1.30）。头 X 0、Y −6°。
- **双臂**：两掌 0.75–1.35 由肩旁举到头前上方：上臂前屈约 140°、外展约 10°，肘 20°，两手在额前上方 `(±2.5, 29, −5)` 附近，掌心朝下（前臂旋前），腕平。左臂晚 2 帧。

### 震脚按掌（1.70–2.00 s）

- **腿**：右脚 1.75–1.95 竖直跺下，1.95 全掌落在 `(−1.5, 1.0, 0.5)` 附近（`step_r`）；落地前 0.03 s 减速收尾，落地帧踝不弹；胯 1.80–2.00 沉到 y −2.3（比唤低 1 px），双膝各再屈约 20°。
- **躯干**：胸 X +4° → −5°、腰 X 0 → −3°（含胸、呼气），1.70–1.95。
- **双臂**：两掌 1.70–2.00 同时向下按（右臂先、左臂晚 2 帧）：上臂前屈 140° → 20°，肘 20° → 30°，两掌到胯前 `(±2.5, 11, −4)` 附近，掌心朝地，腕背伸 20°（按的手型）。2.00 到位（`cast`）。

### 定（2.00–2.30 s）

- 全身不动。

### 收（2.30–3.50 s）

- **右脚**：胯 2.30–2.35 左移压左脚；右脚 2.35 离地，2.55 以提踵落回 `(−1.7, 1.72, 3.2)`（`step_r`）。
- **胯**：2.55–3.00 回 `(0.15, −1.8, 0.6)`、旋转 `(−6, 12, 0)`，双膝回架势屈度。
- **上身、两臂**：腰、胸、头 2.30–3.00 回架势；两掌 2.40–2.70 握拳，两拳 2.40–3.10 回护身位。

**与规格的出入**：
- **跺点移到髋前下、与左脚并排**：右踝世界位 `(−2.1, 1.0, −1.0)`（规格 `(−1.5, 1, 0.5)`）。规格的跺点全掌着地时小腿前倾约 38°，后下沿压地约 0.4 px（前倾超过约 26° 就压地）；前移后外移 0.6 px，让开左脚和左小腿。跺前先到跺点上方 0.4 px 的悬停解（1.75–1.90），再竖直落（1.86–1.95）。
- 提膝：0.80–1.00 先屈膝到 105°、1.00–1.40 回 90°，大腿 0.80–1.40 前屈到 80°；先起大腿时提踵的脚尖贴地前拖。脚面 1.00–1.35 才绷（−15°）：先绷脚尖会往下扎，脚掌离地更慢。
- 胯（位置）：
  - 0.70–0.80 压左脚到 `(1.5, −1.0, −0.4)`（规格 `(1.3, −1.0, 0.0)`）：右脚刚离地时腿还在后面，胯要多前移 0.4 px，细臂模型重心前后余量才过 0.5 px；
  - 0.82–1.20 升到 y −0.75，定左膝 35°；
  - 跺时 1.80–2.00 沉到 `(0.7, −1.65, 0.0)`：由提膝高度沉 0.9 px，双膝各屈约 20°。规格的 y −2.3 是按提膝时胯不升算的；
  - 收步 2.29–2.35 再压左脚 `(1.1, −1.65, 0.0)`，2.38–2.58 升 0.25 px 到 `(1.1, −1.4, −0.1)`：后脚提踵落回时胯还在前、在低，后小腿前倾过大，下沿压地约 0.3 px；胯不后移、不右移，单撑时重心要留在左踝 ±2 px 内。2.58–3.00 回架势（规格 2.55–3.00）。
