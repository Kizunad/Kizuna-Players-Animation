## 1. 动作目的与触发

- **用途**：千里腿的训练功法，不打人：
  - 从架势横开一步成马步；
  - 蹲 30 s，每 4 s 一次深呼吸；
  - 再收回架势。
  - 整段慢，没有爆发、没有打击；全套唯一的训练段、唯一双脚平行站的一段。
- **与其他式的区别**：

  | 段 | 脚位 | 时长 | 打击 |
  | --- | --- | --- | --- |
  | 九式 | 架势错步 | 3–9 s | 有 |
  | **蹲马步** | **两脚平行、横开** | **32 s** | **无** |
  | [technique_breath](technique_breath.md)（调息） | 架势错步，只取上身 | — | 无 |

- **触发**：千里腿蹲马步开始时，宿主调用 `PlayerAnimationAction.PEDDLER_HORSE_STANCE`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **32.0 s**（640 tick），`loop: false`。
- **承接**：不作后式，不作前式。
- **打断**：被伤害打断或宿主提前结束训练时淡出 0.20 s 回架势；两脚会在淡出里从马步滑回架势踝位，和其他式被打断时一样（动作稿 §5.10 已接受）。
- **时间线事件**：`0.50: step_l`、`0.70: step_r`、`31.60: step_l`、`31.85: step_r`。

## 3. 分阶段全身姿势

基准同 [peddler_snap_kick](peddler_snap_kick.md) 第 3 节（架势胯 `(0.15, −1.8, 0.6)` / `(−6, 12, 0)`，右踝 `(−1.7, 1.72, 3.2)`，左踝 `(2.3, 1.0, −2.6)`）。

### 马步姿势（探针）

| 部位 | 面板值 | 说明 |
| --- | --- | --- |
| 胯 | 位置约 `(0, −5.8, +3.0)`，旋转 `(−25, 0, 0)` | 胯降 4 px（胯高 10.2 → 6.2 px），坐到两踝连线后方 |
| 腰 | `(0, 0, 0)` | — |
| 胸 | `(10, 0, 0)` | 胸世界前倾约 −15°，看起来接近竖直 |
| 头 | `(15, 0, 0)` | 头世界朝向水平，平视 |
| 右 / 左大腿 | 约 `(107, +30, 0)` / `(107, −30, 0)` | 世界屈髋约 82°；外旋 30°，膝对脚尖 |
| 右 / 左小腿 | 约 −102° | 屈膝约 102°，小腿前倾约 20°（全掌限 38°，C2） |
| 右 / 左脚 | 约 `(19, −30, +3)` / `(19, +30, −3)` | 全掌，脚尖朝正前 |
| 右 / 左踝 | 约 `(−5.0, 1.0, −0.5)` / `(5.0, 1.0, −0.5)` | 两踝相距 10 px，平行 |

- 探针结果：全身最低点 0.0 px，重心 z 约 +0.15（在两踝连线后 0.65 px，前后余量各约 1.3 px），两腿 IK 误差 0。
- 动作稿的「两脚中心相距约 12 px、屈髋约 70°、屈膝约 90°、躯干竖直」：躯干竖直时胯降 4 px 要么小腿前倾超 38° 插地，要么重心落到脚跟后面出界；两踝放宽到 12 px 时大腿要外展，膝更难对脚尖。所以改成胯前倾、坐向后方、两踝 10 px（PROGRESS 待决定第 11 条）。
- **双拳**（抱拳于腰）：拳在腰两侧约 `(±5.0, 9.0, +1.5)`，拳心朝上；上臂后伸约 40°，肘约 100°（原型手臂 IK 求解）。

### 起点与终点（0.00 s、32.00 s）

与 `stance_idle` 首帧完全一致。

### 预备（0.00–0.20 s）

- 胯位置相对架势 → 约 `(−0.5, −0.3, +3.0)`，重心移到后脚（右踝前约 1.5 px）；胯 X −6° → −2°。
- 双拳不动。

### 开步（0.20–0.70 s）

- **左脚**：0.22 离地约 1 px，往左后横开，**0.50 全掌落在 `(5.0, 1.0, −0.5)`**（相对架势 `(+2.7, 0, +2.1)`），脚尖朝正前；落地前 0.08 s 只做竖直运动（`step_l`）。这一段是右脚单撑，重心靠预备的后移压在右踝 ±2 px 内。
- 0.50–0.58 胯往两脚中间、偏左移（约 `(+1.5, −0.5, +2.0)`），重心往左脚挪。
- **右脚**：0.58 离地约 1 px（提踵 −35° 的脚这时变成全掌，脚掌 0°、脚尖朝前），**0.70 落在 `(−5.0, 1.0, −0.5)`**（相对架势 `(−3.3, −0.72, −3.7)`；`step_r`）。这一段是左脚单撑，0.58 时重心在左踝内侧约 2–3 px，0.12 s 内移不完的帧登记失衡窗口（占位 `[0.56, 0.72]`）。
- 胯 Y +12° → 0°（0.20–0.70），双拳 0.40–0.70 从护身位往腰间收一半。

### 下蹲（0.70–1.00 s）

- 胯从约 `(0, −2.0, +1.5)` 降到马步位 `(0, −5.8, +3.0)`、X −2° → −25°；两腿逐帧 IK，大腿 Y、脚 Y 按上表。
- 腰 0.72、胸 0.75、右上臂 0.78、右前臂 0.81、右手 0.84 依次起动（默认链错峰）：胸回 +10°、头回 +15°，双拳收到腰间、拳心翻上。
- 0.66–0.70 腰、胸先微后仰 1°（预备，与下蹲时的前倾相反）。

### 站桩（1.00–31.00 s）

- **呼吸周期**（4 s，共 7.5 个；1.00 起吸气）：
  - 吸 2 s：胯升 0.3 px（两腿随 IK 微伸）、胸 X +2°、头 X +1°（头比胸晚 0.2 s，胯比胸早 0.1 s）、肩微抬（上臂外展 +1°）；
  - 呼 2 s：回位；
  - 最后半个周期 29.00–31.00 是吸气，31.00 起身时顺势呼出。
- 原型脚本按周期生成关键帧，不手录；每个周期的幅度加 ±5%、相位加 ±0.1 s 的小变化，避免完全复制（也照顾曲线相关性门禁）。
- 两脚、双拳在世界里不动；视线层照常叠加（拳在腰间，不是接触）。

### 起身（31.00–31.40 s）

- 胯升回站高、X −25° → −6°，往右脚移（相对架势约 `(−1.5, −0.5, +1.0)`）；胸、头回架势；31.40 重心压在右踝 ±2 px 内。
- 双拳从腰间回到身前护位；起身后胸越过 1° 再回（跟随）。

### 收步（31.40–32.00 s）

- **左脚** 31.42 离地，**31.60 全掌落回 `(2.3, 1.0, −2.6)`**（`step_l`）。
- 31.60–31.66 胯往左脚移；**右脚** 31.66 离地，**31.85 提踵落回 `(−1.7, 1.72, 3.2)`**，脚掌 −35°、脚趾 +10°（`step_r`）；单撑出界的帧登记失衡窗口（占位 `[31.64, 31.86]`）。
- 胯 Y 0° → +12°；31.85–32.00 胯、双拳回架势，32.00 全身速度为零。

### 不动的部位

站桩段两脚、双拳不动；腰全段保持 0°。

## 7. 骨架与门禁带来的约束

1. **后脚要迈步**（C1）：踝从 1.72 落到 1.00、再横移 3.3 px，不是碾转能做的。
2. **马步几何**（C2、C5）：胯前倾 −25°、坐向后方、两踝 10 px，见第 3 节「马步姿势」。
3. **32 s 一次性**（PROGRESS 待决定第 3 条）：不改播放器；关键帧量靠周期脚本控制。
4. **一次性动作的躯干、头门禁**靠开步、下蹲、起身满足；站桩段只有呼吸的小起伏。
5. **重复周期**：7.5 个周期加小变化，避免曲线相关性门禁把它当复制（门禁实际怎么判，制作时看结果）。
