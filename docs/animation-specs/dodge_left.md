## 1. 动作目的与触发

- **用途**：不带功法的普通闪避。上身向左让开中线，后脚向左侧蹬，左脚先落、右脚跟上。发力前先迈一小步定位（运动生物力学里的“倒数第二步 / 预备步”：降低重心、刹住原动量、上身提前朝新方向转），再爆发蹬出。
- **触发**：由调用方（战斗 UI / Human 宿主，本轮不接线）在架势中发起一次闪避，并给出方向；方向按移动输入相对身体朝向取 90° 扇区（同 `stance_walk_*`）。
  **位移由调用方负责**（审阅决定 Q8），动画原地制作、`root` 不动、不做整体平移；迈出去的是脚相对身体的位置，离地高度只靠胯的高度、腿的姿态和躯干表达。动画空中段 0.29～0.56 s（双脚同时离地 0.32～0.52 s），调用方若让实体真正离地，宜在 0.29 s 前后起跳、离地约 0.2 s。
- **时长**：剪辑 **0.80 s**（`PlayerAnimationAction` 16 tick），`loop: false`，真实时间播放。预备步占 0.03–0.14 s，迈步落地到胯最低约 0.08 s（下蹲关键帧 0.25 s），之后的链与第 3 版的 0.70 s 剪辑一致。
- **结束**：播完淡出 0.15 s 回当前架势底层；中途被新的闪避打断时交叉淡入 0.05 s 重新开始。

## 3. 分阶段全身姿势

起止姿态都是 [stance_idle](stance_idle.md) 第 3 节的架势基准。方向向量 `d = (+1, 0)`（模型 XZ，+X 为角色左、−Z 为前）。

- **预备步**：左脚 l 向左迈 3 px（实测踝位移见下表“迈步落地”行前后），空中脚尖略勾、全掌或脚跟先落；后脚迈步时落地踝比架势高 0.3 px（前脚掌着地），下蹲时再多提踵 0.15 px，免得后膝压到地面。
- **蹬地**：后脚侧蹬：迈步后胯随重心向左移到左脚上方（0.35 倍步幅），右腿斜撑；蹬伸时胯向左送出 0.7 px，右腿斜向伸展（后膝约 100° → 65°、后髋 46° → 22°），脚底跖屈到 −58°、脚趾背伸约 30°，0.32 s 离地。
- **胯**：迈步落地 `(0.7f, −0.5, +0.3)`（`f` = 朝迈步方向 0.35 倍步幅），下蹲 `(f, −1.6, +1.3)`，蹬伸 `(0.7d, +0.9)`，收腿 `(0.8d, +0.6)`，迎地 `(0.5d, +0.2)`，缓冲 `(0.2d, −1.45, +1.2)`，相对架势基准、C² 样条连成，再与腿一起做 σ = 2 帧平滑。迈步落地时胯旋转取空中姿态的 0.6 倍加下蹲姿态的 0.3 倍（提前预倾）。
- **腰 / 胸 / 头**：迈步落地时胸已朝左倾（空中倾斜的 0.4 倍）；下蹲时胸前压 −5°、反向右侧屈 +4.5° 回到蹬地脚上蓄力；蹬伸时向左侧屈 −4°；空中左侧屈 −7°、右转 3°；先落脚触地后反向回 +3° 刹住侧移，缓冲 +2°。胯旋转：下蹲 (−6, −3, 4)、蹬伸 (2, 2, −6)、缓冲 (−7, −2, 4)。头自身在迈步落地时提前转向目标方向（侧闪偏航 5°），并在胯、腰、胸的累积增量上反向稳定（俯仰 0.8 倍、侧倾 0.7 倍，滞后 1 帧），视线基本水平。

## 5. 衔接

- 进入：`stance_idle` / `stance_walk_*` / `stance_run` 上发起，淡入 0.05 s（首帧即架势基准，不跳）。
- 退出：淡出 0.15 s 回当前架势底层；闪避是全身动作，期间底层的步态不显示，结束后步态相位从当前时间继续。
- 打断：闪避中再次闪避，交叉淡入 0.05 s 重新开始；闪避中攻击、调息、蓄力只取上身。
