## 怎么做出来的

- 关键帧来自 MotionBricks 管线（`~/Code/MotionBricks-Intergrate-Test`）的草稿合集 `artifacts/technique-collection-v1/impact-v2/`：
  手和身体的目标姿势是数据，逐体型解 IK，过渡由 MotionBricks 模型生成，再把速度峰值重排到击中前。崩拳是用户 11-08 认可过的样片。
- 进 PA 之前用本仓的完整门禁（粗臂、细臂两套几何）量过草稿，只对没过的地方做定点修正，别的姿势不动。
  修正写在 MotionBricks 目录的 `scripts/author_villager_pa.py`，产物在 `artifacts/villager-pa-a3/generated/`；
  追加进模型文件用 `scripts/import_villager_pa.py`（先确认原文件照本仓写法重写出来一字不差，再按名追加，然后跑本仓的导出器和 `--check`）。
- 复查用 `scripts/audit_villager_pa.py`（调本仓的 `analyze_animation.report`，两套几何各跑一遍）。

## 和动作稿不一样的地方

- **背摔的转身不是原地碾脚，是小垫步。** 动作稿要右脚以前脚掌为轴碾转；本仓门禁按踝点位移算滑动，没有碾脚窗口。
  现在转身、回身时两脚有约 0.4 秒同时离地（右脚离地 0.55 px，约 3 厘米），看起来是小跳转身。要改回原地碾脚得先加碾脚的门禁口径。
- 撩天没声明动作稿里的打击时段、爆发窗口、失衡窗口：实测都在一次性动作的上限以内，用不着。
- 崩拳的 `slide_window`（进半步时随冲量滑行）没声明：那是游戏内验收口径，等袖手拳那边定了冲量再加。
- 背摔摔不动时改播「一靠」（动作稿 §5.3）没做，宿主现在整段照播。
