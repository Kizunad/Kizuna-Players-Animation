# block_shield：持盾格挡（5 tick 举盾到位）

> 审阅状态：**设计稿，待审阅**（2026-10-26）。尚未录入 `.bbmodel`。轴向与坐标见 [共用约定](conventions.md)，
> 数值来自设计期原型轨道并经仓库门禁同算法核对。动作 ID 用 `block_shield`，与将来的通用单手/双手格挡区分。

## 1. 动作目的与触发

- **用途**：`UseAction.BLOCK`（盾牌）持续使用。原版 `ArmPose.BLOCK`：持盾臂 `pitch × 0.5 − 0.942 rad`（前举 54°）、
  `yaw −0.524 rad`（内收 30°），身体和腿不动。
- **触发**：`armPoseAction` 的 `BLOCK` 分支；盾在主手 `block_shield`，副手 [block_shield_off](block_shield_off.md)。
- **原版进度来源**：盾牌最大使用时间 72000 tick；`LivingEntity.isBlocking()` 要求**已使用 ≥ 5 tick** 才真正格挡。
  本动作 0.25 s（5 tick）举盾到位，和格挡生效同一刻。
- **驱动**：`t = 已使用 tick / 20`；`t ≥ 1.95` 后在 `loop_region [0.35, 1.95]` 回绕（保持段呼吸）。
- **结束**：松手淡出 0.15 s。盾牌被斧击破（冷却 100 tick）时原版会中止使用，同样走淡出。

## 2. 时间轴

剪辑长度 **1.95 s**，`loop: "hold_on_last_frame"`，`loop_region: [0.35, 1.95]`，无事件。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.06 | 胯下沉 0.5 px、屈膝，胸腰后仰 1.2°～1.4° 并左转 1.5°～2°，右臂下沉后撤 7°，右肘屈到 18° |
| 举盾 | 0.06–0.25 | 胸腰前屈、右肩前送 6°～7°；右上臂经外侧上抬再内收，肘 0.19 s 时先伸开 20° 再收回，盾从身侧画弧到身前；0.25 s 到位 |
| 稳住 | 0.25–0.35 | 上臂过冲 3°、肘过冲 4° 后回落；头 0.26 s 到位，从盾上沿看出 |
| 保持 | 0.35–1.95 | 1.6 s 一次呼吸：胯 0.15 px、胸腰 0.6°～0.8°，持盾臂 1.2° 微沉、左拳护腰随动 |

## 3. 分阶段全身姿势

- **持盾手朝向对齐原版**：保持段右手的世界朝向与原版 BLOCK 右臂 `(54, −30, 0)` 完全一致（误差 0.001），所以盾牌
  使用 `shield_blocking` 显示变换时朝向与原版相同；`r_item` 在 (−1.23, 17.9, −9.1)，比原版位置前移 0.6 px、高 0.2 px，
  盾面挡在胸前偏左。为此右臂改为屈肘持盾：上臂 (28.7, −26.7, −30.4)、肘 83.1°、腕 (−40.7, 20.4, −17.4)；握持手指。
- **躯干**：胯下沉 1.2 px、后坐 0.6 px，前屈 3°、Y −3°；腰 (−4, −4, 0)、胸 (−3, −6, 0)：身体压低、右肩（持盾侧）前送，
  重心前移。
- **头**：(4, 9, 0)，抬头 4° 从盾上沿观察、右转 9° 抵消躯干左转，面部朝前。
- **左臂**：握拳护在左腰前：上臂 (−2, 19.6, 18.7)、肘 69.5°，`l_item` (5.6, 15.4, −5.2)；拳握紧（−40°～−84°）。
- **双腿**：踝锁定在零姿态位置；胯右转 3° 时大腿 Y 反向 3° 保持脚尖朝前；膝屈约 57°，踝背屈约 28°。左脚趾背伸 4°。
- **不动的部位**：`root`；双脚不移步（一次性/保持动作淡出时腿角插值，若移步会滑脚）。

## 4. 关键帧

全部 Catmull-Rom。见附表。

## 5. 重心与支撑

重心 x 0.05～0.15 px、z −0.61～−0.09 px，压低后仍在两脚之间。原型脚底最低 −0.090 px，支撑脚滑动 0.11 px。

## 6. 衔接

- 进入：站立/步态/潜行/`crouch_work`/骑乘/腾空 → `block_shield`，淡入 0.06 s（预备只有 0.06 s，不能更慢）；移动/潜行底层时只取 `upper`。
- 退出：松手淡出 0.15 s。原版格挡时移动速度降为潜行速度，步态仍由底层播放。
- 不做受击反应段：原版盾牌受击只有音效和攻击者击退，没有持盾者动作；需要时另立 `block_shield_hit` 设计。

## 7. 索引条目（提议）

`mask: full`、`priority: 15`、`blend_in: 0.06`、`blend_out: 0.15`、`hand: main`、`fpv: false`、`loop_region: [0.35, 1.95]`。

## 8. 接口缺口

1. `armPoseAction` 的 `BLOCK` → `block_shield` / `block_shield_off`；`armPoseProgress` → `loopedSecondsProgress(used, 1.95, 0.35, 1.95)`。
2. 目录 `BLOCK_SHIELD`、`BLOCK_SHIELD_OFF`；`upperOverlay` 加入 `block_shield`；`GRIP_IDS` 加入两者。
3. 盾牌渲染：确认 `PlayerHeldItemFeatureRenderer.renderItem` 对使用中的盾仍走 `shield_blocking` 模型（原版由物品
   `blocking` 谓词决定，与姿态无关），需 `calib_item` 游戏内核对盾面朝向。
