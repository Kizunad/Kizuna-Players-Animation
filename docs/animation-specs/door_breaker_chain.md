## 1. 动作目的与触发

- **用途**：破门斩第七式，双手连环三刀，一路往前压：
  - 正手斜劈：斧由右肩前劈向左下；
  - 反手斜劈：斧余势落到左下不停，绕身体左侧翻到左胸前，再由左上劈向右下；
  - 弓步横斩：斧余势落到右下不停，提回右肩前，躯干拧到最紧，前脚跨出一大步，斧由右向左斩到腰高；
  - 每刀的余势不停，绕 ∞ 字变成下一刀的蓄。每刀一次冲量，前两刀前脚原地垫一步，第三刀弓步跨出。
  - 全套唯一连环三刀、唯一三次冲量。
- **与前六式的区别**（交接的区分原则）：

  | 式 | 单手 / 双手 | 轻 / 重 | 发力方式 |
  | --- | --- | --- | --- |
  | 叩门 | 单手 | 轻 | 小臂向前短促连敲 |
  | 破门 | 双手 | 重 | 站定全身向下劈 |
  | 撞门 | 单手 | 重 | 身体向前冲撞，再回身横撩 |
  | 破盾 | 单手 | 先轻后重 | 向后：撤步、后坐、躯干回转把盾拽回来 |
  | 横扫 | 单手持斧，空手张开配重 | 重、长 | 旋转离心：单脚为轴转一整圈 |
  | 掩门 | 单手；空手张开成掌，先推后按 | 先轻后重 | 向上：深蹲后坐、后腿蹬伸、沿前臂上顶 |
  | **连门** | **双手**（目录 `can_two_hand: true`），两手叠握、全程不松（第 8 节第 6 条） | **一刀比一刀重**：前两刀 ×1.2、前脚原地垫步、膝只多屈 20° 左右；第三刀 ×2、弓步跨出 6 px、后腿蹬直 | **左右来回拧**：躯干相对 root 右 45° → 右 16°（击一）→ 左 20°（蓄二）→ 右 26°（击二）→ 右 58°（蓄三）→ 左 2°（击三）→ 左 25°（随）；每刀余势不停、绕 ∞ 字变下一刀的蓄 |

  - 破门也是双手、由右往左下斜劈，但破门站定、只劈一刀，蓄要右拧 35°（相对架势），胯下沉 1.8 px。连门第一刀轻：蓄只右拧 25°，击中时胯降 1.0 px，靠冲量和前脚垫步往前压。
  - 三刀的分量体现在躯干转幅（29° → 46° → 60°）、胯下沉（1.0 → 1.2 px → 弓步前移 5.6 px）和斧头行程（约 15.5 → 11.4 → 21.1 px）上。粗算的斧头最快速度是 101 / 83 / 153 px/s，第二刀行程短，比第一刀略慢（第 3 节）。
  - 横扫也是由右向左横着扫，但横扫单手、单脚为轴转一整圈；连门第三刀双手、弓步向前跨，躯干只转 60°。
  - 撞门也往前冲，但撞门是一次冲刺两步加肩撞；连门是每刀一次冲量、一刀一步。
  - 不举过头：预备和三次蓄的拳最高 y 16.8（右肩约 y 20.4），斧头最高 y 23.5（头盒底 y 24），竖在头侧；关键姿势斧离头盒 ≥ 2.08 px（第 3 节）。
- **触发**：功法 `meridian_door_breaker:chain` 起手时，宿主（Human）调用 `PlayerAnimationAction.DOOR_BREAKER_CHAIN`，按真实时间播放，用 `start_tick` 同步起点。持物手是副手时播 `door_breaker_chain_off`（第 7 节）。
- **时长**：剪辑 **8.0 s**（160 tick），`loop: false`。
  - 起手 0–1.55 s：冲量一 1.55 s；
  - 生效 1.55–5.00 s：击一 1.70 s，冲量二 3.05 s，击二 3.20 s，冲量三 4.85 s，击三 5.00 s；
  - 收势 5.00–8.00 s。
- **承接**：
  - 目录里没有以连门为后式的前式，连门总是从剪辑起点播。动作稿写的「承接入口 0.50」不设。
  - 连门 → 万门一斩：万门一斩以连门为前式，收势过半（5.00 + 0.5 × 3.00 = **6.50 s**）起可接，万门一斩从它自己的 1.50 s 起播。按通则，收势前半段（5.00–6.50 s）里脚回位：前脚 6.35 s 收回架势踝位；6.50 s 以后只有上身和斧回位，万门一斩从这里接走。
- **打断**：起手（0–1.55 s）可以被伤害打断（目录 `interruptible_by_damage: true`）：宿主停止播放，淡出 0.20 s 回 `stance_idle`（动作稿 §4），资源不另做打断段。
- **时间线事件**：
  - `1.68: step_l`、`3.18: step_l`：前脚原地垫步落地；
  - `4.95: step_l`：弓步落地；
  - `5.0: hit`：客户端通知，不授权伤害。按叩门、横扫的先例只标末击，1.70、3.20 两刀不标；
  - `6.35: step_l`：前脚收回架势踝位。

## 11. 制作结果

关键帧由原型 `~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/d_chain.py` 求出（主手、副手同一原型，`build(cid, off)` 切换参数），`install_chain.py` 写入 `.bbmodel`，再用仓库导出脚本导出并登记索引；`quick_chain.py` 跑门禁与自查，`com_chain.py` 实测重心出界帧，`keys_chain.py main|off` 读打包资源的关键姿势。

**做法**（同破盾、横扫、掩门第 11 节，下面只写连门新加的）：
- 躯干、持斧臂按探针的关键姿势（`out/chain_keys_<main|off>.json`）逐骨插值（五次 Hermite，节点加速度为零）：停顿两端速度为零；击中、低点是经过点，速度取相邻两点差商，斧经过击中不停。
- 叠握手 0.45–7.00 s 逐帧（60 Hz）锁柄：把叠握手的虚拟柄线锁到持斧手柄线上、沿柄前移 4.4 px。之前由护手位经 0.28 s 中途姿势伸过来，之后经 7.25 s 中途姿势回护手位；握上、离柄那一帧按锁柄段的速度补 0.08 s 渐入。
- 双脚逐帧 IK：后脚脚趾前缘锁在架势接地点，提踵按时刻变化；前脚两次原地垫步（抬 0.6 px）、弓步跨出、收脚。不用 `root`。
- 胸的叠加：定三颤（胸 Y 7 Hz ±0.3°，持斧肘 8 Hz ±0.6°，叠握手随锁柄跟着颤）；随的喘气（胸 X 前倾 1.5° 再回，5.42–6.02 s）；收势长呼气（胸 X 前倾 2° 再回，6.40–7.40 s）。
- 每个通道 60 Hz 采样后删减关键帧（导出插值离设计曲线：旋转 ≤ 0.15°、位置 ≤ 0.005 px、腿 ≤ 0.10°）。

**与上文设计值的出入**（设计值没改，以这里为准）：
1. **垫步离地提前 0.01 s**：1.55 / 3.05 s 离地（设计 1.56 / 3.06 s），落地 1.68 / 3.18 s 不变。摆动 0.12 s 时前小腿落地三阶导 1.55×10⁶°/s³（限 1.5×10⁶），0.13 s 降到 1.24×10⁶。
2. **三刀躯干提前起**：胯 1.44 / 2.94 / 4.75 s 起（设计 1.52 / 3.02 / 4.83 s），腰、胸依次再晚 0.02 / 0.03 s。
   - 原因：按设计时刻起，腰、胸的速度峰比主手上臂晚 2–3 帧，主链峰值门禁不过；
