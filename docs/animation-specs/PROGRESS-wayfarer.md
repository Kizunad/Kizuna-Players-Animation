## 共用约束

规格里用「C1」…「C12」引用。

**C1 起止、架势与持物。**
- 架势基准（[stance_idle](stance_idle.md) 第 3 节）：胯位置 `(0.15, −1.8, 0.6)`、旋转 `(−6, 12, 0)`；腰 `(−3, 4, 0)`；胸 `(−2, 4, 0)`；头 `(3, −19, 0)`；左踝 `(2.3, 1.0, −2.6)` 全掌；右踝 `(−1.7, 1.72, 3.2)` 提踵 −35°、脚趾 +10°；重心约 `(0.11, 12.32, −1.3)`。
- 主手（右）拳 `r_item` 约 `(−4.4, 22.6, −7.7)` 护右下颌，弓、弩就挂在这里（`r_item` 不能有轨道）；左拳 `l_item` 约 `(4.3, 23.6, −10.2)` 在下巴前。副手版反过来：左手持武器（`l_item`），右手是拉弦 / 推拉手，首末帧仍是架势首帧（架势本身不分主副手）。
- 首帧、末帧等于架势首帧，首尾速度为零；收势前半段内双脚回到架势踝位，后半段只有上身回位（动作稿 §3.5）。

**C2 滑脚口径（同千里腿 C1）。**
- 分析器把一次连续着地（脚最低点 ≤ 0.25 px）当一段，段内踝（`*_foot` 枢轴）的 X、Y 范围各 ≤ 0.5 px，Z 不查。
- 脚尖着地时转脚掌会让踝走动；架势后脚（右）从提踵 −35° 落成全掌，踝高 1.72 → 1.00，同一次着地里超限。所以凡是右脚要从提踵变全掌（弓的射位）或反过来（收势回架势），**都抬脚再落**（离地 ≥ 0.3 px，新的着地段，补 `step_r`）。动作稿写的「滑到」一律做成迈步。
- **碾脚绕踝竖线转**：踝的 X、Y 不动，门禁过。弓射位的「左脚以前脚掌为轴，脚跟内转」、横风的「以前脚掌为轴、脚跟外转」都这样做（这副骨架的脚趾枢轴就在踝正下方 1 px，看起来就是碾）。

**C3 小腿穿地（同千里腿 C2）。** 小腿方块底面在踝高，前后左右各 2 px。全掌（踝高 1.0）时小腿前倾 θ、侧倾 φ 的最低点约 `1.0 − 2 sin θ − 2 sin φ`，要 ≥ −0.25，所以**全掌脚的小腿只能倾约 38°**。影响：
- 天地同至的深弓步后腿（探针，[该页](wayfarer_convergence.md)第 7 节第 1 条）：后脚全掌够不着或穿地 −0.4～−1.0；后脚要抬起、脚尖转向前（朝向 0°，腿的平面与小腿方块的边对齐）、脚跟抬起（脚底俯仰 −30°，踝 1.92）重新落下，后小腿约 −0.05。踝高变化 0.9 px 超同一次着地的 0.5 px（C2），所以是新的着地段，多一个 `step_l`。早先写的「同一次着地里后脚跟半抬、踝 1.0 → 1.45」被探针否定。
- 横风宽站屈膝 30°（侧倾）、跪射（C10）。

**C7 撒放的手指。** 动作稿「手指 0.03 s 内张开到 −8°」要 2,000°/s 以上，打击时段的 1,800 也不够。本稿：
- **整段只撒一次的式**（满月、弓梢、回马、天地同至平射）：手指 0.17 s 由 −70° 张开到 −8°（最小抽搐峰值约 680°/s、抽搐 7.6×10⁵）；
- **连射**（连珠、箭雨、天地同至仰射）：每发只张开一部分再勾回，最后一发才张到 −8°。抽搐上限决定最短时长（峰值抽搐 = 60Δ/T³）：
  - 连珠（每发 0.55 s）：−70° → −30°（40°）0.12 s，再 0.11 s 勾回 −62°；
  - 箭雨、天地同至仰射（每发 0.40 s）：−70° → −40°（30°）0.11 s，再 0.10 s 勾回 −62°，勾回的末尾和下一次拉弦重叠约 0.03 s；
- 「离」的那一下由三样同帧给出：`item_states` 的 `pulling` 在撒放帧阶跃关掉（弓上的箭立刻消失、弦回直）、弦手开始后走、`release` 事件。手指 1 px 宽，0.17 s 和 0.03 s 在 20 fps 接触表上差三帧。
- 另一种做法见待决定第 7 条。

**C8 弩的推拉够不着前端，行程缩短。**

4. **回马的转身方向与整圈口径**（动作稿 §5.7、§7「胯整圈转，需审阅方确认」）。
   - 动作稿的文字前后不一：「以左脚前脚掌为轴**向右**转身，胯向右转 180°」+「头**留在后面**」+「头、胸、腰都向右扭，从**右肩**上方回头看着目标」。向右转身时头留在目标上，是从**左肩**回看；要从右肩回看，头得抢在胯前面向右甩一整圈（世界 360°），不是「留在后面」。
   - **建议甲：转身改为向左**（胯 0 → −160°，左脚前脚掌为轴，右脚绕到身后），头一直对着目标，腰、胸、颈相对胯向右扭到 +40 / +52 / +68（合 +160°，在 45 / 60 / 75 上限内），从右肩上方回看；空中「顺着回头的方向继续右转」就是解开这股扭转：胯 −160° → −25°（射位），头先到、胸、腰、胯依次跟上。
     - 动作稿其余文字（头留在后面、右肩回看、空中右转、扭转在空中解开、落成射位）全都对得上；胯始终在 ±180° 内，**不转整圈**，不用 `root`、不用 2.60 的 pre/post，打断时也没有倒转问题；
     - 服务端冲量只「按移动方向，默认向后」，与转身方向无关。
   - 乙：保留整圈（向右 180° 再右转 155°）。那么头要在 0.35–0.75 s 向右甩一整圈（领先胯），口径**建议用 `root` Y**，同千里腿审定第 1 条与横扫：`root` 0 → +180 → +335，胯相对 `root` 保留射位的 −25°，2.50 前后静止处 pre/post 由 +360 换回 0；打断倒转同横扫，记为已知缺陷。
   - 丙：乙的转法、照动作稿用胯 Y 转整圈。分析器对所有骨都折回角度差，离线可行，但本仓没有先例，且和 `root` 两种口径并存。不建议。
5. **跪射的膝着地判定**（动作稿 §7 `kneel_windows`）。
   - **建议甲：不加字段。** 探针（C10）：右脚尖点地、左脚全掌就是门禁认的两个着地点；重心在两踝盒内；右小腿最低点 0.04 px，不穿地；下跪时右踝固定，滑脚门禁照常过。膝「贴地」由原型自查保证：1.20–5.10 s 右小腿最低点在 `[−0.1, 0.25]`，不进门禁。
   - 乙：照动作稿加 `kneel_windows`（时段内着地判定改为右膝 + 左脚、重心按这两点查、小腿贴地容差 0.1）。分析器多一个只有跪射用的字段；甲的探针已过，不需要。
6. **副手版的腿**（C9）：建议照 C9——弓式左脚碾、右脚短步；弩式照搬主手版脚步；回马、弓梢的步伐按副手页重写。另一种是整段镜像、首末各加一段换脚，起止要多走两步，和叩门、破门副手版的做法不一致，不建议。
7. **撒放手指的速度**（C7）。
   - **建议甲：手指不放宽门禁**，单发 0.17 s 张到 −8°，连射张开 30–40°（0.11–0.12 s）再勾回；「一瞬」靠 `pulling` 阶跃关掉、弦手后走和事件同帧给出。

8. **爆发窗口**。
