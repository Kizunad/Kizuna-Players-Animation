## 1. 动作目的与触发

- **用途**：行矢第二式，速射：
  - 弦手先从左胯后抓一把箭，拿到胸前攥成扇形；
  - 搭、半拉（八成）、撒放；手被弦带回来时顺势绕一个小圈，正好落到弓旁搭下一支；
  - 三发「哒、哒、哒」，节奏均匀（每发 0.55 s）。
  - 全套唯一抓箭、唯一绕圈连射的一式。
- **与其他弓式的区别**：满月一次满弓、会 0.5 s；**连珠不满弓、不停**，看点是弦手的小圈和均匀的节奏；箭雨虽然也连射，但是仰身、每发八五成、身体往上送。
- **触发**：行矢连珠起手时，宿主调用 `PlayerAnimationAction.WAYFARER_PEARLS`（弓在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。撒放 2.00、2.55、3.10 s。
- **承接**：承接入口 0.40。作后式：弓梢承接、连弩 / 横风 / 跪射换兵，都从 0.40 起播。作前式：回马从 0.35、连弩 / 横风 / 跪射从 0.40 起播。收势从 3.10 起，前半段到 4.05，右脚 3.95 已回架势踝位。
- **打断**：起手 0–2.00 s 被伤害打断时淡出 0.20 s。
- **时间线事件**：`0.75: step_r`、`2.00: release`、`2.55: release`、`3.10: release`、`3.95: step_r`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。射位 B0 见 C4，满弓基准见 C5。

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯位置相对架势 `(+0.3, 0, −0.2)`、Y +2°；双脚锁定，腿逐帧 IK。0.40 s 全身速度为零（承接入口）。

### 足踏（0.40–0.90 s）

- 同 [满月](wayfarer_full_draw.md) 第 3 节足踏，快 0.1 s：右脚 0.45 离地、0.75 全掌落在 `(0.2, 1.0, −6.6)`；左脚 0.50–0.85 绕踝竖线碾到脚尖左转 40°；双膝到 B0（约右 18° / 左 44°，胯升约 0.9 px，C4 探针）。
- 躯干一步到射位（不另做胴造）：胯世界 Y −25°、X 0，0.90 前移 2.5 px 到位；腰 `(0, −8, 0)`、胸 `(0, −7, 0)`、头 `(0, 40, 0)`，胯 0.45、腰 0.48、胸 0.51 起依次到位。

### 攥箭（0.90–1.40 s）

- **左手**：0.90–1.15 沿身体左侧向后下方伸到左胯后约 `(5.5, 12, 2.5)`（左肩在后，胸再左转 5° 后伸臂即到，不用弯腰）；1.15 手指 −8° → −62° 握拢；1.15–1.40 拿到胸前约 `(1.0, 20, −5)`，手指松到约 −40°，腕旋后约 60°，扇面箭尾朝上。
- **弓手**：0.90–1.40 由垂在身前举到 `bow_draw` 会位的弓把位置（胸系照搬，C5），臂伸直、弓身竖直。
- **腿**：双膝 10° → 15°（0.90–1.20），胯随之降约 0.3 px。

### 第一发（1.40–2.00 s）

- 胸 1.40–1.60 回 −7°；头 1.60 起锁定，不再有可见变化。
- **搭**（1.60–1.70）：左手到弓旁弦上（`bow_draw` 起拉位，弦手 z 约 −4.6），转腕 30° 把扇面最前面一支压到弦上；1.65 `pulling` 开，弓换 `bow_pulling_0`，箭出现。手指 −40° → −62°。
- **半拉**（1.70–1.95）：弦臂肘 39° → 58°，弦手到脸颊旁（锚点前约 0.4 px）；`pull` 0 → 0.8（1.89 过 0.65 换 `_1`；0.8 不到 0.9，整式不出现 `_2`）。手指 −62° → −66°。
- **撒放**（2.00）：手指 2.00–2.12 −66° → −30°；`pulling` 关。

### 轮手（2.00–2.55 s）

- **弦手小圈**：2.00–2.15 被弦带回 2 px（沿下颌向后），随即向下、朝弓的方向绕一个半径约 1.5 px 的小圈（腕带动，肘 58° → 45°）；2.15 回到弓旁。
- **手指**：2.13–2.24 −30° → −62° 勾回（C7）。
- **搭**（2.15–2.25，2.20 `pulling` 开）、**半拉**（2.25–2.50，`pull` 0 → 0.8）、**撒放** 2.55。
- **身体**：每发撒放后双膝一沉 2° 再起（0.25 s）、胸 Y −2° 再回（0.20 s），像被弦的反作用推了一下。

### 第三发（2.55–3.10 s）

- 同轮手：2.55–2.70 回带、小圈，2.70–2.80 搭（2.75 `pulling` 开），2.80–3.05 半拉，**`release` 3.10**。

### 随（3.10–3.60 s）

- 弦手带回 2 px 后停在脸颊后；手指 3.10–3.27 由 −66° 张到 −8°（最后一发全张开）。弓臂伸着不动，头盯靶。

### 收（3.60–5.00 s）

- **脚**：3.60–3.65 胯后移、右移，重心压回左脚；3.65 右脚离地，3.95 以提踵落回架势踝位；左脚 3.70–3.95 碾回。
- **上身**：3.95 起胯、腰、胸、头依次回架势（4.60 到位），4.10–4.80 呼气。
- **双臂**：左手 3.70–4.50 手指合拢、回下巴前；弓 3.70–4.40 回持物位；4.60–5.00 静止。

## 7. 骨架与门禁带来的约束

1. **撒放手指**（C7）：每发 0.55 s，张开 40° 要 0.12 s、勾回 32° 要 0.11 s（都按抽搐上限），正好落在「回 0.15 + 搭 0.10」里。
2. **攥着的箭**：只有左手（副手）真拿着箭时才看得到那叠箭；空手时是半张的手势（待决定第 17 条）。扇面朝向靠左腕旋后，原版箭的物品模型在 `l_item` 上是斜放的，游戏里用 `calib_item` 看箭尾是不是朝上。
3. **足踏迈步**（C2）：同满月。

## 10. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/wayfarer/d_pearls.py` 求解（交接目录，不入库），装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：同第 6 节，`unbalanced_windows`、`aim_windows`、`phases`、`item_states`、时间线都没改。

**门禁**：全部通过。关键帧 1,554（目标 1,100–1,400：弦手 1.65–3.35 s 逐帧 IK 跟弓，手指每发五段开合）。全段最快 666°/s（左手指 1.20 s，抓箭握拢），抽搐最大 0.99×10⁶°/s³（右小腿 3.82 s，收步）；不登记打击时段、爆发窗口。最低点 −0.227 px；重心出界 0.52–0.57 s（右脚迈步，在失衡窗口内）；支撑脚滑动右 0.33、左 0.03 px。预备 / 跟随 3/5 骨（右上臂、右手举弓前没有反向预备）；错峰三段都是左上臂、左前臂（同帧）→ 左手，半拉时腰、胸不动。

**自查**：1.95、2.50、3.05 s 弦手在锚点前 0.46 px（八成满），弓把与 `bow_draw` 会位差 ≤ 0.01 px；第一、二发撒放后的小圈轨迹差 0.01 px；左踝整段着地，X、Y 变化 0.03 px。右脚 0.45–0.75、3.65–3.95 两次迈步（分析器按 0.25 px 容差判着地，0.72、3.90 起已算着地）。

**与规格的出入**：
- 足踏时胯、腰、胸、头 0.45 / 0.48 / 0.51 / 0.50 起依次转到射位，一步到位；弓手 0.05–0.38 先随身体把弓放低 1 px；
- 攥箭：弦手 0.78 起就向左胯侧后伸（规格 0.90），护颌 → 胯侧后（0.78–1.15）→ 腹前 4 px（1.17–1.32）→ 胸前 4.5 px 攥扇（1.27–1.42）按关节空间过路点走，手不擦腰、各关节单调；弓手 0.90–1.40 由护颌直接举到 `bow_draw` 满弓位（C5）；胯再降 0.3 px；
- 每发弦臂肘的抬起放在拉弦后半段（撒放前 0.16 → 0.02 s），小圈时肘最低只落回松弦位与满弓位的一半：早抬时上臂在拉弦前半段反向，落满时前臂贴进胸腰；
