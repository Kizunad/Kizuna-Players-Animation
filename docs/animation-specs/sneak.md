# sneak：静止潜行（低重心呼吸循环）

> 状态：设计稿已审阅通过；2026-10-26 已录入 classic `.bbmodel` 并导出，调度已接入。双体型门禁通过（实测见第 9/8 节）；离线 GIF 在 `build/anim-review/2026-10-26/`，游戏内视觉验收尚未执行。
> 轴向、坐标和数值来源见 [共用约定](conventions.md)。表中数值来自设计期原型轨道：用仓库 `scripts/analyze_animation.py`
> 同一套正向运动学与门禁计算核对过；录入 `.bbmodel` 后以导出 JSON 的实测门禁和 GIF 为准。

## 1. 动作目的与触发

- **用途**：替换原版六部件潜行姿势（`BipedEntityModel.setAngles` 中 `sneaking` 分支：身体前倾 `0.5 rad ≈ 28.6°`、
  双臂 `+0.4 rad`、腿枢轴后移 4 px、头/身体下移 4.2 / 3.2 px）。原版双腿笔直，上身像折叠一样前倾；本动作改为屈膝下蹲、
  胯后坐、脊柱分段前屈、头抬起看前方。
- **触发**：`player.isInSneakingPose()`、着地、非骑乘/游泳/攀爬/睡眠/鞘翅，且水平静止（沿用 `crouch_work` 的
  `STATIONARY_SPEED_SQUARED = 0.0004` 方块²/tick²）。移动时换 [sneak_walk](sneak_walk.md)；有已制作的工具/使用动作时
  由 `crouch_work` 接管下身（见第 6 节互斥规则）。
- **原版进度来源**：潜行没有进度值，是状态姿势；本动作是自由时钟循环（3.0 s，约 20 次/分呼吸），不需要 scrub。
- **结束**：松开潜行、开始移动或离地即淡出（0.20 s）。

### 原版下沉 2.13 px 的处理（需审阅确认）

`PlayerEntityRenderer.getPositionOffset` 在潜行时把整个模型下移 `0.125` 格；模型再按 `0.9375` 缩放，所以在模型像素里是
`0.125 × 16 / 0.9375 = 2.13 px`。原版潜行腿枢轴还多下移 0.2 px，脚底实际穿进方块约 2.3 px，但头顶恰好落在 1.5 格碰撞箱
（28 px 高的模型 × 0.0586 格/px − 0.137 格 ≈ 1.504 格）。

本稿**沿用原版与 `crouch_work` 的约定：脚底锁在模型地面 y = 0，游戏里同样随原版偏移下沉约 2.1 px**。理由：若在 `root`
上补 +2.13 px 抵消偏移，头顶会高出 1.5 格碰撞箱约 2.1 px，在 1.5 格高的通道里潜行时头会穿进天花板。本稿头顶最高
27.78–28.18 px（原版 27.8 px），与碰撞箱一致。若审阅方更在意“脚不入地”，替代方案是 `root` +2.13 px 并把下蹲加深到
膝屈约 110°，但会触到第 3 节踝背屈与小腿方块穿地的限制，本稿不推荐。

## 2. 时间轴

剪辑长度 **3.0 s**，`loop: true`，无时间线事件。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 吸气 | 0.0–1.5 | 胯微升 0.15 px，胸、腰后仰回正 1°～1.3°，头随之低 1.6°（保持视线），双臂外展略增 |
| 呼气 | 1.5–3.0 | 胯回沉，胸腰前屈到最低，重心在两脚之间缓慢左右换 ±0.15 px |

各骨关键帧步长不同（胯/胸 0.5 s、腰/头 0.6 s、上臂/前臂 0.375 s、手 0.75 s、手指 1.0 s），相位按
胯 → 腰 → 胸 → 头 → 上臂 → 前臂 → 手 → 手指依次后移 0.1–0.2 s，避免整身同相起伏。

## 3. 分阶段全身姿势（基准姿态 t = 0）

- **胯**：下沉 2.5 px、后坐 3.0 px、前屈 22°。
- **腰 / 胸**：前屈 10° / 8°；躯干总前倾 40°（原版 28.6°），用屈膝代替原版的“腿直身子折”。
- **头**：抬头 36°，抵消躯干前倾后面部略低 4°，视线向前下方。头部轨道会覆盖原版视线，需要 [head_follow](head_follow.md)
  在运行时叠加视线（见第 8 节接口缺口）。
- **双腿**：右脚稍后（踝枢轴 z +0.8 px）、左脚稍前（z −0.4 px），两脚各外开 0.4 px；腿由胯姿态做脚底锁定求得：
  右大腿 (71.5, 0, −3.2)、右膝 −77.2°、右踝 28.3°；左大腿 (76.2, 0, 3.7)、左膝 −70.7°、左踝 17.1°。
  后脚脚趾背伸 6°（重心压前脚掌）。
- **双臂**：上臂前屈 14° / 12°、外展 7° / 8°，肘屈 26° / 30°，手腕轻微背伸；随胸前倾，手在身体前下方自然下垂，
  不贴身也不前伸。手指半松握（拇指 12°、两组手指 20°～27°），不是张开的默认手。
- **不动的部位**：`root` 无轨道（原地循环，不推动实体）。

### 为什么膝只屈到约 77°

小腿方块是刚体，踝背屈超过约 30° 时其前下角会低于脚底（原型 −0.45 px）。本稿把下蹲深度与躯干前倾组合到
踝背屈 ≤ 28.3°，最低点 −0.057 px，在 0.25 px 地面容差内；头顶高度仍与原版一致。

## 4. 关键帧（面板值，度；胯位移为像素）

全部 Catmull-Rom，首尾帧相同。由原型谐波轨道按各骨步长取样后取两位小数；录入 `.bbmodel` 后可在 Blockbench 中直接调整。

见附表 [sneak 关键帧](#附表sneak-关键帧)。

## 5. 重心与支撑

双脚全程全掌着地。质量加权重心 x −0.15～+0.15 px、z −0.36～−0.19 px，落在两踝 z ∈ [−0.4, 0.8] 支撑范围内；
原型 60 Hz 采样踝枢轴漂移 0.00 px，脚底最低 −0.057 px。

## 6. 与其他状态的衔接

- 进入：`stand` / `walk` / `run` → `sneak`，淡入 0.20 s；原版潜行眼高变化约 0.1 s，本动作略慢但没有跳变。
- `sneak` ↔ `sneak_walk`：0.20 s 交叉淡入，两者基准胯高与躯干前倾相同（2.5 / 2.6 px），只有腿与摆臂不同。
- `sneak` ↔ `crouch_work`：调度三选一（`sneak`、`sneak_walk`、`crouch_work` 同一时刻只播一个）；静止潜行时开始工具动作，
  淡出 `sneak`、淡入 `crouch_work`（0.18 s），工具动作结束后反向。
- 上层叠加：攻击、挖掘、吃喝、使用等只取 `upper`（`AnimationPlayer.lowerBase` 需加入 `sneak` / `sneak_walk`）。
- 跳跃离地：`jump` 接管（优先级 16），落地后回到当时的潜行底层。

## 7. 索引条目（提议）

`mask: full`、`priority: 2`、`blend_in: 0.20`、`blend_out: 0.20`、`hand: none`、`fpv: false`、`loop: true`。
优先级 2 高于 Human 宿主播放的 `walk` / `run`（1），所以宿主即使在潜行移动时仍播 `walk`，也会被 `sneak_walk` 覆盖。

## 8. 接口缺口（阶段 2 需要改的代码与文档）

1. `PlayerAnimationAction` 增加 `SNEAK`、`SNEAK_WALK`（无自然时长）；`syncScrub` 目前对目录外 ID 会空指针，新动作必须先入目录。
2. `VanillaAnimationScheduler` 新增 `scheduleSneak`：按着地、静止/移动、是否有工具动作在三者间选择，播放/停止循环。
3. `AnimationPlayer.lowerBase` 加入 `sneak`、`sneak_walk`；`upperOverlay` 不变。
4. 分析器：`sneak` 是站立循环，应启用脚底锁定与重心检查（当前循环动作一律跳过站立检查）；`sneak_walk` 应像
   `walk` 一样启用循环支撑检查。需要在 `analyze_animation.py` 增加对应 ID 集合并在 `animation-acceptance.md` 记录。
5. 头部轨道覆盖原版视线：所有带 `head` 轨道的资源都会丢失原版转头/俯仰。本稿依赖 [head_follow](head_follow.md) 的运行时视线叠加。
