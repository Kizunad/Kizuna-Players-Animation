## 1. 目的与触发

- **用意**：目录描述「腕骨轻颤，剑尖连点三处，不给厚甲留整块的受力面」，设计稿 §7 写「三点」。腕子抖三下，剑尖依次点**头、躯干、腿**三处。三下要有三个分得开的峰，腰和重心跟着三下小推。
- **触发**：宿主收到表现 `meridian_piglin_sword:quiver` 的 `START` 时起播，`start_millis 0`。单手持剑，主手或副手都可以。
- **一眼要读出的**：三个点**一个比一个低**（头 → 躯干 → 腿），每一点都是往前一啄再缩回，不是一次往下划。手臂基本不收回，靠前臂和腕出点。

## 3. 关键姿势

幅度是相对 [stance_idle](stance_idle.md) 首帧的增量；实际关键帧以 MotionBricks 试验仓 `scripts/author_piglin_sword_pa.py` 的 `QUIVER` 为准。躯干各骨的转角是各自局部的，逐节叠加。2026-11-24 用户看过 GIF 后要求「加一点身体的协调以及腿部的动作」，本节是返工后的姿势。

- **起姿 P0（0.00）**：逐骨等于 `stance_idle` 首帧。剑竖在右颊旁，左拳在左肩前。
- **端平 P1（0.08–0.22）**：
  - **躯干**：胯先右拧 2.5°（0.08），腰、胸各 3.5° 依次跟上，作反向预备；再左转：胯 7°（0.17）、腰 4°、胸 4°，右肩半送出。头先反向左转 6°（0.10），再转回来看着目标（0.20 右转 15°）。
  - **腿和胯**：胯往前脚送 0.5 px（0.18）。
  - **右臂**：剑从竖着落到前指，剑尖对着对方头部一线，肘约 40°。剑身与前臂对线的做法同 [绕](piglin_sword_wind_around.md) 第 5 节（腕 ≤ 40° 加 `item_rotation`）。
  - **左臂**：拳收到左腮前护着（0.20）。
- **三点（0.30 头、0.40 躯干、0.50 腿），每一点都是先沉后送**：
  - **膝先一沉**：点前 0.045 s（0.225 / 0.325 / 0.425）胯先沉、略往回收：沉 0.18 / 0.35 / 0.55 px。
  - **再把重心送出去**：胯往前送 0.65 px 左右，再沉一点（到 0.23 / 0.43 / 0.75 px），后脚跟跟着蹬一下（抬 2° / 3° / 4.5°）。一点比一点低，第三点（打腿）压得最深。
  - **胯先转，腰、胸依次跟上**：每点胯再左转 3.5–4.5°（0.255 / 0.355 / 0.455），腰晚 15 ms、胸再晚 15 ms；前倾一点比一点深，第三点胸累计前倾约 10°。
  - **肩再送臂**：前臂前推、腕往前啄，剑尖依次到头、躯干、腿的高度。两点之间剑尖缩回、肩下压，手骨的前后速度要换向，三个峰就靠这次换向分开。
  - **头跟着剑尖往下看**：每点低头 1° / 3° / 6°，同时右转到 20° / 27° / 35°，抵消躯干的拧转。
  - **空手配重**：左拳从护腮逐渐往后下展开，第二点时肘 35°、第三点时肘 25°。
- **跟随 P5（0.50–0.60）**：剑尖沿第三点方向再走一点后停住；胯、腰、胸再左转一点，重心停在最低处（实测前小腿最多多屈 20.9°、胯沉 0.8 px、前送 2.2 px）。
- **收回 P6（0.80–0.85）**：后脚跟 0.80 落回，胯和躯干 0.82–0.84 回到半侧身，右臂、头 0.85 回架势。末帧逐骨等于首帧。

`phases`：三段，每段查一次近端先于远端，链从胯算起：

```json
[{"id": "head", "start": 0.22, "end": 0.32, "chain": ["pelvis", "waist", "chest", "r_upper_arm", "r_forearm", "r_hand"]},
 {"id": "body", "start": 0.34, "end": 0.42, "chain": ["pelvis", "waist", "chest", "r_upper_arm", "r_forearm", "r_hand"]},

```

- 第一段从胯开始转的 0.22 算起。后两段从回缩之后算起：回缩带着压肩，上臂在那里也快，但那是收不是出。
- 某根骨在门禁选中的轴上段内不到 3°，门禁就跳过它，剩下的骨里只要还有 ≥ 3 根就照查。每段 4–6 帧，峰值次序靠 2 帧容差。
- 实测峰值（classic、slim 相同）：
  - 主手：第一段腰 0.267 → 胸 0.283 → 前臂 0.300（手 0.283）；第二段胸 0.383 → 前臂 0.400（手 0.383）；第三段腰 0.467 → 胸、上臂 0.483 → 前臂 0.500（手 0.483）。
  - 副手：第一段腰 0.267 → 胸、上臂 0.283 → 前臂 0.300（手 0.283）；第二段胸、上臂 0.383 → 前臂 0.400（手 0.383）；第三段同主手。
  - 胯每点在上一段的回缩里就开始转（近端先动），到段内第一个 60 Hz 取样时已转过大半，段里只剩 0.4–2.8°（副手 0.2–1.4°），不到 3°，按规则不计；前两段的腰或上臂同理。段的起点不往前挪：挪到回缩里，上臂往回带的那一下就进段了。

## 5. 遮罩、覆盖骨与持物

- `mask: full`、优先级 24、淡入 0.10、淡出 0.25；进 `FULL_BODY_IDS` 和 `GRIP_IDS`。两腿靠送胯、沉胯、前膝和后脚跟过有效运动阈值；左臂靠护腮和往后展开。
- **脚**：两脚原地不挪，接地点不动。胯沉得再深，后小腿盒就低于地面（盒子模型的膝弯有限），后脚跟也只能蹬一点。门禁实测鞋底最低 −0.197 px（主手）/ −0.237 px（副手），支撑脚滑移 0.047 px。
- 走动中施放：`upper_while_moving: true`，规则同 [绕](piglin_sword_wind_around.md) 第 5 节。
- 握持同绕：右手全程握住，三点时手指可以收紧，不张开。
- **运动学：这一式必须声明 `impact_window`**。目录定的点距 100 ms，相当于 10 Hz 的往复：
  - 每一点出去约 50 ms。按最小加加速度曲线算，峰值角加加速度 ≈ 60·A/T³。普通限值 1.5e6°/s³ 只容许每点 **≈ 3°**，剑尖动不到 1 px，三个峰看不出来。
  - 腕 6–10°、肘 8–12° 的点，算出来约 3–6e6°/s³，在冲击段限值 7e6 以内；角速度约 300–400°/s，不是瓶颈。
  - 声明 `impact_window: [0.24, 0.54]`，一段盖住三点。本 id 和副手版照破门斩、千里腿、袖手拳的先例进 `AnimationEntry.validateImpactAction` 和 `analyze_animation.py` 的白名单，阈值不动。
  - 实测冲击段内最大角速度主手 777°/s、副手 905°/s（都是空手的上臂往后展开，0.30–0.32 s），最大角加加速度 2.5e6 / 3.2e6°/s³；段外主手 540°/s、5.9e5°/s³，副手 540°/s、6.1e5°/s³。
- 剑与身体的净距按剑的实际几何逐帧算，判据同绕（≥ 1 px，或不比架势更近）。点腿那一下剑尖最低，要看剑离前膝、前脚的间隙。
  - 实测：主手 classic 最近处就是架势（0.774 px）；slim 在 0.017 s 是 0.431 px，比架势的 0.435 近 0.004 px，是开头第一帧的小偏移。副手全程不比架势近（2.688 / 2.311 px）。
- **剑身对线**：`item_rotation` 审定只在刺出段用：`[[0.0, [0,0,0]], [0.04, [0,0,0]], [0.20, [58,0,0]], [0.60, [58,0,0]], [0.78, [0,0,0]]]`。三点时剑身与前臂夹角主手 5.8° / 5.9° / 7.9°、副手 7.3° / 6.5° / 7.6°；腕弯折最大主手 30.6°、副手 36.9°。
- 三点剑尖高度（classic，px）：主手 26.3 / 19.6 / 12.4，副手 26.3 / 19.7 / 12.6，依次是头、躯干、腿。

## 6. 首末帧与衔接

- 首帧、末帧逐骨等于 `stance_idle` 首帧。从非架势底层起播时，两脚在淡入、淡出里滑动，同功法先例。
- **接「弹」**：目录允许抖收势过半后接「弹」，按审定的 350 ms 收势是 0.675 s。此时剑正从低位抬回，弹的回弹把剑往身上带、腕翻到另一侧，方向顺。
- **被打断**：发 `STOP`，0.25 s 淡出回底层，受击反应盖上来。
- **接普攻**：同绕。

## 7. 副手、左主手、体型、第一人称、剑的种类

- **副手版 `_off`**：剑在左手（前手），做法同 [绕](piglin_sword_wind_around.md) 第 7 节：
  - 持剑臂目标 x 取反重解，腿保持架势；
  - 躯干转动增量取反，右拧让左肩送出；
  - 右拳（空手、后手）先护在下颌前 `(−4.5, 19.3, −5.3)`（0.20），不照搬主手版前手的护点（后手够不到），再随三点往后下展开配重。
  - 前手出点像刺拳，距离近、幅度可以比主手版小一点，但三点的高差要一样清楚。
  - 时间、`hit`、`phases` 同主手版，主链改查左臂。
  - 实做时多了三处（都写在生成脚本里）：
    - 前手离肩近，压肩的八成五放进点与点之间的回缩，前推里上臂才有自己的峰；
    - 前两点点到后停 15 ms 再回缩，回缩的峰落到下一个主动作段之前；
    - 副手版躯干往右拧，沉胯时前小腿盒的后下角会低于地面（照主手版的幅度是 −0.40 px），所以胯转 ×0.5、沉胯 ×0.5、前送 ×0.7（`OFF_QUIVER_TURN`、`OFF_QUIVER_SINK`、`OFF_QUIVER_SHIFT`）。副手版因此沉得浅：前小腿最多多屈 14.4°、胯沉 0.4 px、前送 1.6 px。
- **左主手玩家**：运行时整套镜像，不另做。
- **粗臂 / 细臂**：同一轨道，各自过门禁、出 GIF。细臂看端剑时后手离头盒的间隙。
- **第一人称**：`fpv: false`；全身第一人称复用第三人称姿态，`fpv_torso` 用缺省。游戏内录像时截图看三点的剑尖能不能在画面下半部分出来，点腿那下剑会不会出画（待 Human 接线后做）。
- **金剑与别的剑**：一套轨道。剑身颤、弯是剑仓特效，关键帧不做剑身形变。

## 9. 审片要点

- 侧面：三点一个比一个低，每点前啄后缩分得开。0.30、0.40、0.50 三帧各截一张，剑尖依次在头、躯干、腿的高度。
