## 4. 规模与门禁

- 目标 24 骨（不用 `root`），约 2,300–2,700 个关键帧。
- 门禁适用项与自查项同主手页第 10 节，左右手对调；`phases` 主链同主手版（腰 → 胸 → 左上臂 → 左前臂 → 左手）。
- 自查目标同主手页：
  - 击中刃口领先 ≤ 45°（本页粗算 12.0°）；
  - 斧离头盒 ≥ 1 px（本页关键姿势定 0.90 px，第 3 节第 4 条）；
  - 右拳离柄线 ≤ 0.35 px（本页蹬伸、触地 0.36 / 0.37）；
  - 压低斧最低 ≤ 1.5 px（本页 1.5）。
- 改主手版后必须用同一原型重新生成本段。
