## 1. 动作目的与触发

- **用途**：千里腿第八式，直腿高举、脚跟劈下：
  - 后腿伸直，从右外侧往上画弧，举到头前上方，支撑脚提踵把人拔高，停一下；
  - 然后像斧子一样用脚跟笔直劈下来，上身跟着往下卷，两臂一起往下压；
  - 劈完右脚落在身前，再撤回后脚位；
  - 全套唯一直腿举高的一式。
- **与其他式的区别**：

  | 式 | 腿 | 方向 | 膝 |
  | --- | --- | --- | --- |
  | 正蹬 | 前 | 往前推 | 先屈后伸 |
  | 鞭腿 | 后 | 横抽 | 先屈后甩 |
  | **下劈** | **后** | **从上往下** | **始终伸直** |

- **触发**：千里腿下劈起手时，宿主调用 `PlayerAnimationAction.PEDDLER_AXE_KICK`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **6.0 s**（120 tick），`loop: false`。打击 2.45 s。
- **承接**：入口 **0.40 s**（接在扫堂之后）。不作前式。收势前半段 2.45–4.23 s 内双脚回架势踝位（右脚 3.30 撤回）。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势；悬段被打断，举起的腿 0.20 s 混回地面，可接受。
- **时间线事件**：`2.45: hit`、`2.85: step_r`、`3.30: step_r`。

## 3. 分阶段全身姿势

基准同 [peddler_snap_kick](peddler_snap_kick.md) 第 3 节（架势胯 `(0.15, −1.8, 0.6)` / `(−6, 12, 0)`，右踝 `(−1.7, 1.72, 3.2)`，左踝 `(2.3, 1.0, −2.6)`）。

- **世界屈髋**：大腿面板 X 加胯 X（胯后仰为正，会把腿往前带）；下文「世界屈髋」指大腿相对竖直向下的前摆角。

### 起点与终点（0.00 s、6.00 s）

与 `stance_idle` 首帧完全一致。

### 预备（0.00–0.40 s，承接入口 0.40）

胯位置相对架势 `(0, −0.3, 0)`，双膝随 IK 微屈；脚不动。0.40 s 全身速度为零。

### 移（0.40–1.00 s）

- 胯位置相对架势 → 约 `(+0.8, −0.3, −1.8)`：重心移到前脚约 80%，落在左踝后约 0.7 px。
- 后脚：踝 1.72 → 约 2.15（同一次着地 0.43 px，C1），脚掌约 −45°、脚趾 +25°，脚尖点地。

### 蓄（1.00–1.60 s）

- 前膝屈 20°（胯降约 0.4 px），胯 X −6° → 0°。
- 胯 Y +12° → +20°（再右转 8°，打开右髋，为从右外侧起腿蓄劲；动作稿的「+8°」按相对架势读）。
- 胸 Y 再 +3°；双拳由架势收到脸前。
- 1.40 起胯再往左脚上方移 0.5 px，1.60 后脚离地时重心在左踝 ±2 px 内（单撑）。

### 举（1.60–2.15 s）

- **右腿**画弧（膝始终 ≤ 5°）：
  - 1.60–1.85 外展加屈髋：大腿面板约 `(45, 0, −40)`，脚在身体右外侧、离地约 6 px；
  - 1.85–2.15 继续屈髋并内收回中线：面板约 `(141, 0, −5)`，加上胯后仰 +14°，世界屈髋约 155°，脚跟在头前上方、约到自己的下巴高（约 25 px）；
  - 脚 1.70–2.00 背屈到 +20°（勾脚尖、脚跟领先）。
- **胯**：1.60–2.10 Y +20° → 0°（腿由外往里画弧，胯跟着往左回到正对前方），X 0° → **+14°**（后仰，收腹不弓背：腰 X 保持 0° 到 −2°）。探针：后仰 +8° 时直腿离脸约 0.2 px，+15° 时约 1.6 px。
- **支撑脚**：1.95–2.10 半提踵，踝 1.00 → 1.45（C1）；前膝 20° → 5°（伸直）；两项合计人拔高约 1 px。
- 头：X +5°（微仰），看脚跟后面的目标；颈保持在 ±20° 内。
- 两臂 1.70–2.10 向两侧略张开（上臂外展约 35°），配重。

### 悬（2.15–2.30 s）

全身不动，屏气；2.20–2.28 举起的腿 ±0.5° 颤（可省）。

### 劈（2.30–2.50 s，`hit` 2.45）

- 2.30–2.36 支撑脚跟落回全掌（踝 1.45 → 1.00），前膝屈回 15°，胯下沉约 1 px。
- **2.32–2.50 髋伸**：直腿由世界屈髋约 155° 劈到约 40°（115° / 0.18 s，峰值约 1,200°/s，在打击时段内），脚跟领先；2.50 急停（抽搐 ≤ 7×10⁶°/s³）。
- 胯 2.32–2.46 后仰 +14° → −4°；**腰 2.38、胸 2.41** 起由后仰卷到前屈（腰 X −6°、胸 X −6°，合计 −12°），腹肌带动；头随低 −8°。
- 两臂 2.38–2.48 一起往下压（上臂由外展 35° 收到身前下方，肘 30°）。

### 落（2.50–2.90 s）

- 右腿顺势下落，2.85 全掌落在身前约 `(−1.2, 1.0, −6.5)`（`step_r`），变成右前左后；落地前 0.1 s 只做竖直运动。
- 胯 2.50–2.85 回到两脚之间，躯干回直。

### 换回（2.90–3.40 s）

- 2.90–3.05 重心回到左脚（胯回到左踝上方）；3.05 右脚离地，3.30 提踵落回架势后踝 `(−1.7, 1.72, 3.2)`，脚掌 −35°、脚趾 +10°（`step_r`）。
- 3.30–3.40 胯回架势位置和朝向。

### 收（3.40–6.00 s）

腰、胸、头 3.80 回架势；3.50–4.50 呼气；双拳 4.00 回架势；4.50–6.00 静止。

### 不动的部位

悬段（2.15–2.30）全身静止；左脚整段不离地。

## 7. 骨架与门禁带来的约束

1. **腿离脸太近**：Steve 的腿伸直举到世界屈髋 155° 时，胯后仰 +8° 只留约 0.2 px（探针），改为 +14°。再高（160°）要后仰 +15° 以上，上身看起来往后倒。
2. **支撑脚半提踵**（C1）：踝 1.00 → 1.45；整程提踵（约 2.1）要抬脚，单撑时做不了。
3. **后脚尖点地**（C1）：同一次着地只能再抬 0.45 px，脚掌约 −45°。
4. **小腿伸直不进传力链**：链里只剩胯、大腿、脚三骨，正好够分析器的最少三骨。
5. **劈到底急停**：峰值约 1,200°/s 在打击时段内；急停的抽搐按 7×10⁶°/s³ 查。

## 10. 制作实测（2026-10-31）

原型 `kpa-door-breaker-proto/peddler/d_axe_kick.py` 求解，装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：`impact_window [2.30, 2.60]` 同第 6 节；**不登记 `unbalanced_windows`**：1.60–2.85 s 单撑段重心实测一直在左踝 ±2 px 内（原型自查 1.60–2.30 s 重心减左踝 x −1.66 到 −0.50、z −0.12 到 +1.34），劈下时也没出界，第 6 节的 `[1.60, 2.87]` 是占位；**`raise` 段从 1.70 s 起**（规格 1.60）：1.60 s 右脚离地那一下脚的角速度先到峰，会排在大腿前面，「举」的传力从 1.70 起才算。时间线 `{"2.45": "hit", "2.85": "step_r", "3.4": "step_r"}`：**撤步落地 3.40 s**（规格 3.30），`hit` 2.45、入口 0.40 与设计稿 16 一致（设计稿只用前摇 2.45、后摇 3.55，不依赖撤步时刻）。

**与规格的出入**：
