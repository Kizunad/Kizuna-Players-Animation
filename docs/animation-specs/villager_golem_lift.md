## 2. 时间轴

| 段 | 时间 (s) | 做什么 |
| --- | --- | --- |
| 预备、开步 | 0.00–0.95 | 左脚往左外开（`step_l` 0.60），右脚落成全掌、脚尖转正（`step_r` 0.95）：两脚平行、与肩同宽 |
| 垂臂沉身 | 0.70–1.55 | 下蹲，上身前倾，两臂伸直垂到膝前再往后摆，蹲住 |
| 抡起 | 1.55–2.05 | 两脚蹬地，胯、腰、胸依次从前倾转到后仰，两臂伸直从后下方往前上方抡。**`hit` 1.90**，两掌在胸腹高处掀到对方 |
| 余势 | 2.05–2.45 | 两臂举过头顶停一下 |
| 收 | 2.45–5.00 | 左脚收回（`step_l` 2.80），右脚回架势，两臂放下握拳 |

## 3. 制作实测（2026-11-16）

- 抡起段主链取 `胯 → 腰 → 胸 → 上臂`：两臂是伸直着抡的，肘和腕不领先，按整条手臂查峰值顺序没有意义。
- 草稿里胯、腰、胸和上臂都在 1.867 s 同一帧最快（做发力节奏精修时整段一起重排的结果），门禁判「没有先后」。
  进 PA 时把胯、腰、胸的转动依次提前到 1.817、1.833、1.850 s，上臂留在 1.850 s，击中帧的手位不变；两脚照原位重新摆。
- 右脚落步后脚跟落平、抡起时前滚到脚尖，踝点在着地期间上下 0.73 px；门禁按踝点位移算滑动（上限 0.5）。把右脚相对蹲稳时的起伏收到四成，实测 0.46 px。
- 最大角速度 596°/s、角加加速度 858,210°/s³，都在一次性动作上限以内，所以动作稿里的打击时段、爆发窗口都不声明；全程重心在两脚之间，失衡窗口也不声明。
