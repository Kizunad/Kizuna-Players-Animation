- **为什么不整段镜像**：首末帧必须等于 `stance_idle` 首帧（左脚在前），同前四式副手版。
- **腿**：踝位保持左前右后。外撤步、蹬地、右脚离地、左脚前掌为轴、落脚的时刻和做法与主手版完全相同，转轴仍是左脚。

- **手臂与躯干镜像**：
  - 左手持斧，斧在身体**左侧**前后荡、拉到**左后方**，转起来向右扫；右拳横胸、张开配重；
  - 躯干转向取反：预摆、蓄**左转**，发**右转**；
  - 躯干按**绝对角**镜像，不按相对架势的增量镜像（第 3 节第 2 条）；
  - 胯位置不镜像，仍压向左脚（转轴脚）；
  - 拳位和空手挂点按探针重新求，不直接镜像世界坐标（两肩在架势里前后不同）。

## 3. 与主手版的出入（待审）

1. **向右转、仍以左脚为轴**。
   - 左手持斧要向右扫，`root` 向右转。转轴不换成右脚：腿和迈步与主手版完全一样（同前四式副手版，腿不镜像），右脚 3.00 离地、4.30 落回的做法不用另做。
   - 左脚在前、向右转、以前脚为轴，是转身鞭拳的转法，不别扭。
2. **躯干按绝对角镜像，胯不镜像**。
   - 先按主手版增量直接镜像（相对架势的增量取反）：架势本身右转 20°，镜像增量后躯干仍偏右转，左手够不到左前方的击中线，各姿势都不成立。
   - 改为绝对角取反（换算见第 2 节）以后，蓄、击中、随都可行。
   - 胯位置也镜像过：胯会往右移、离开转轴的左脚。所以胯位置与主手版相同，仍压向左脚。
3. **击中时躯干落后 16°**（主手版正对前方）。
   - 躯干正对（绝对角 0°）时，刃口切向误差 8.1°（探针求解代价 0.585，不过 0.3 的门限）。躯干相对 root 左转 16°（向右转时算落后）时误差 0°。
   - 所以起转只回转 49°，比主手版的 65° 少。
4. **空手横胸的位置另求**。
   - 右拳直接镜像主手版的 `(−1.5, 18.0, −8.0)` 到 `(1.5, 18.0, −8.0)` 时，右肘 150°、右前臂插进胸 2.85 px。改到 `(3.0, 18.0, −10.0)`：右肘 108°，穿模 0。

5. **预摆躯干不来回荡**：
   - 架势本来右转 20°，副手版预摆（左转到 −16°）和蓄（再左转到 −65°）同一方向；
   - 主手版是预摆左转、蓄右转，躯干有一次来回。副手版的「前荡、回拉」只体现在斧和手臂上（下垂 → 左前方 → 左后方）。
6. **重心**：斧在转轴（左脚）一侧，重心会比主手版更靠左。目标同主手版（root 坐标系里离左踝 ≤ 1.8 px）；超出时制作时把胯的 x 收小，按实测登记失衡窗口。
7. **左主手玩家**：运行时按 `hand` 把整套资源（含 `stance_idle`）镜像，`root` 的 Y 旋转和平移 X 一起取反。左主手玩家持主手看到的是主手版的镜像：绕右脚向右转，不受上面几条影响。副手版只在右主手玩家用副手出手时播放。
