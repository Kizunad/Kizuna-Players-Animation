# idle_arms_crossed · 抱臂站

> 玩家版 `idle_arms_crossed_enter`、`idle_arms_crossed`、`idle_arms_crossed_exit`，村民骨架版各加 `_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)，日常站位见 [叉腰站](idle_akimbo.md) 第 3 节。

## 1. 目的与触发

双臂交叉抱在胸前站着。用在：
- 走火入魔的同门、路人：宿主随机挑选；
- 陈恪到冢、等你应约时：陈恪是玩家模型，用玩家版。

进出与打断同叉腰站。

## 3. 关键姿势：抱臂基准

| 部位 | 玩家版 | 村民骨架版 |
| --- | --- | --- |
| 脚、重心 | 日常站位，重心在左腿：胯左移 0.5 px，右膝放松屈 8° | 同 |
| 躯干 | 直立，胸后仰 1°（不挺），两肩微前收 0.3 px | 同 |
| 头 | 平视，往右歪 2°，显得不耐烦 | 同 |
| 双臂 | 两前臂在胸前交叉，大致水平，交叉点在 (0, 17.0, −4.4)。**右前臂在外上**，左前臂在内下 | 交叉点外移到 z −5.6，离胸前的膨胀面 ≥ 0.5 px |
| 右手 | 塞在左上臂下面，掌心贴左前臂靠肘处的内侧，从正面只露出手指的一角 | 同 |
| 左手 | 搭在右前臂靠肘处的外侧，四指包在右臂外面、看得见，拇指从下面勾住 | 同 |
| 手指 | 左手三片屈 35° / 40° / 45°；右手屈 20° / 25° / 30°，压在臂下 | 同 |
| 肘 | 两肘贴近肋侧，左肘比右肘低 0.8 px（左臂在下） | 同。肘离袍侧 ≥ 0.5 px |

## 4. 进入段（0.50 s）

| 时段 | 腿、胯 | 躯干、头 | 双臂 |
| --- | --- | --- | --- |
| 0.00–0.12 | 胯回正、上升 1.8 px | 胸、腰的右转跟着胯解开，各晚 1 刻 | 拳松开，两前臂先往外打开 1 px，作为抱上去的预备 |
| 0.10–0.30 | 右脚前收 2.6 px，0.30 落地（`step_r`）。重心先在右腿上，0.40 移到左腿 | 胸稍微往后靠 1°。头回正，再往右歪 | 左前臂先往里收，贴到胸前（0.30），右前臂从外上方压过来（0.38） |
| 0.30–0.44 | 右膝放松 | 肩前收 | 右手塞进左上臂下面，左手包住右肘，0.44 两手都贴上 |
| 0.44–0.50 | 稳住 | 呼一口气，肩落 0.3 px | 两臂一起往胸前一抱：肘内收 0.4 px 再松回 |

## 5. 循环（12.0 s）

基础层：

| 层 | 周期 | 内容 |
| --- | --- | --- |
| 呼吸 | 4.0 s × 3 | 胸后仰 1.0°、肩提 0.3 px，交叉的两臂整体随胸起伏 0.25 px。第二周期被 B4 叹气替换 |
| 重心游移 | 12 s | 胯在支撑腿上方晃 ±0.25 px |
| 头 | 6 s | 偏航 ±2°，歪头在 ±1° 之间慢慢变 |

小动作：

| 段 | 时段 (s) | 内容 |
| --- | --- | --- |
| B1 指敲 | 0.90–2.60 | 左手手指在右臂上轻敲三下：1.15、1.55、2.05 s。每下 fingers_a 先抬 25°、落下，b 晚 1 刻跟着敲，拇指不动。敲的时候左腕跟着抬 3° |
| B2 换到右腿 | 3.20–4.20 | 胯右移 1.0 px，左膝放松。胸反向侧倾 1°，晚 2 刻。两臂抱着不动，随胸转 |
| B3 歪头 | 5.00–6.20 | 头往左歪 8°、右转 6°，像在想事。5.40–5.80 停住，再回到右歪 2° |
| B4 叹气 | 7.00–8.60 | 7.00–7.60 深吸：胸后仰 3°，肩提 1.0 px，两臂被抬起 0.6 px。7.60–8.40 **叹出来**：肩一沉，落到基准下 0.8 px，头低 4°，胸前屈 1.5°。8.40–8.60 回到基准 |
| B5 换回左腿 | 9.20–10.20 | B2 的反向，略慢 |
| B6 指敲 | 10.80–11.40 | 左手指再敲两下（11.00、11.25 s），比 B1 轻，抬 15° |
| 回到基准 | 11.40–12.00 | 只剩呼吸和游移 |

两次指敲次数不同（三下、两下），力度也不同。

## 6. 退出段（0.30 s）

| 时段 | 内容 |
| --- | --- |
| 0.00–0.06 | 左手先松开，右手从臂下抽出，手指先张后收。胯开始下沉 |
| 0.04–0.22 | 右脚后撤，0.22 提踵落地（`step_r`）。胯沉 1.8 px、右转 12°，胸、腰右转 20° |
| 0.06–0.30 | 两臂解开，右臂先从外上方移开。左拳 0.24 到下巴前，右拳 0.28 到右下颌侧前方。手指握拳。0.30 等于 `stance_idle` 首帧 |

## 7. 骨架差异（村民骨架版）

- 交叉点外移 1.2 px。原版村民的抱臂在更低的位置（腹前）。这里抱在胸前，显得像在等人，和原版站姿区分开。
- B3 歪头、B4 低头时，鼻子离交叉的前臂 ≥ 2 px。
- 两肘离袍侧 ≥ 0.5 px，两只手和前臂贴着膨胀面的外侧。

## 8. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 按站立口径查；
  - 循环全程两手贴着对侧前臂，两条前臂互相不穿；
  - 循环首尾连续。
- 切入矩阵：每 0.25 s 一档淡入退出段。
