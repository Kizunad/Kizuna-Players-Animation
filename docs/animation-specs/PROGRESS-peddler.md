## 共用约束（探针结论）

规格里用「C1」…「C10」引用。

**C1 滑脚门禁按踝的 X、Y 量，提踵 / 落跟只能做半程。**
- 分析器把一次连续着地（脚最低点 ≤ 0.25 px）当一段，段内踝（`*_foot` 枢轴）的 X、Y 范围各 ≤ 0.5 px（`vec_range[:2]`，验收文档也写「脚踝 X/Y 范围」）。Z 不查。
- 脚尖着地时转脚掌，踝的高度跟着变。探针（脚趾 0°）：脚掌 0° → 踝高 1.00 px，−12° → 1.25，−14° → 1.34，−18° → 1.52，−25° → 1.80，−35° → 2.14；架势后脚（−35°、脚趾 +10°）1.72。
- 所以动作稿里「后脚由提踵落成全掌」（1.72 → 1.00）、「支撑脚提踵」（1.00 → 约 2.1）在同一次着地里都超限。本稿统一改为：
  - **后脚半落跟**：踝 1.72 → 约 1.30（脚掌约 −13°），重量照样交给后脚；
  - **全掌脚半提踵**：踝 1.00 → ≤ 1.45（脚掌约 −15°）；
  - 要整程换（例如蹲马步、扫堂的后脚）就**抬脚再落**（离地 ≥ 0.3 px，成为新的着地段，补 `step_*`）。
- **碾脚绕踝竖线转**：踝的 X、Y 不动，门禁过；前脚掌（踝正下方 1 px 处，提踵时偏前约 0.6–0.9 px）跟着画一段半径 ≤ 1 px 的弧，GIF 上看是「以前脚掌碾」。绕前脚掌转会让踝走 1.5 px 以上，门禁不过。因此**不加 `pivot_windows`**（待决定第 7 条）。

**C2 小腿方块会穿地。** 小腿方块底面就在踝高，前后左右各 2 px。小腿前倾 θ、侧倾 φ 时最低点约为「踝高 − 2 sin θ − 2 sin φ」，要 ≥ −0.25 px：
- 全掌（踝 1.00）：只前倾时 θ ≤ 约 38°；
- 架势后脚提踵（踝 1.72）：只前倾时 θ ≤ 约 80°；膝外展带来的侧倾要一起算。
- 深蹲（扫堂后腿、尥蹶、不留行的蓄与落、蹲马步）要么小腿接近竖直，要么脚跟抬高。

**C3 胯偏航接近 ±90° 时不能在同一根骨上写侧倾（ZYX 万向锁）。**
- 面板欧拉按 ZYX：Z 在父坐标里最后施加，X 绕骨自己的横轴最先施加。Y = ±90° 时 X 与 Z 绕同一根世界轴：探针 `(0, −90, −35)` 与 `(−35, −90, 0)` 是同一个朝向，都是「转过去的身体向它的前方俯 35°」，**不是动作稿要的「向远离目标一侧倾 35°」**。
- 分析器按欧拉三分量的差算角速度，硬把这个朝向分解成面板值（约 `(90, −55, −90)`）会让速度门禁虚高，Blockbench 的欧拉插值也会走怪路径。
- 规则：**某根骨 |Y| ≥ 约 45° 时，这根骨只写 Y（和绕自身横轴的 X 俯仰）**；侧倾写在子骨（腰、胸的 Z，在转过去的胯坐标里就是身体自己的侧倾），腿的高度靠大腿外展补。探针：胯 `(0, −90, 0)` 时腰 Z −20° 让头枢轴向 +Z（远离前方目标）移 2.74 px，方向对。
- 头要盯目标：胯转 90° 时腰、胸 Y 各回 10–15°，头相对胸再回约 65°（颈 ≤ 75°）。
- 用在鞭腿、连环第三下、飞踹（待决定第 2 条）。

**C4 整圈转身用 `root` Y**（扫堂、不留行；待决定第 1 条）：同横扫，只转 Y，绕转轴竖线平移补偿；只在除转轴脚以外的脚都离地时转，起止角速度、角加速度为零；转满后在静止段用 pre / post 把 ±360° 换回 0°；末帧为 0。被伤害打断时淡出按欧拉线性混合，已转的角度会倒转回去。

**C5 单腿站要把重心压到支撑踝 ±2 px 里，胯要移 3 px 上下。** 重心按躯干 50、头 8、每腿 16、每臂 5 加权（同分析器），支撑范围是着地脚的踝 ±2 px（X、Z）。
- 架势重心 z −0.9，后踝 z 3.2：后腿单站要把重心往后移约 3 px。探针（弹腿，后脚半落跟，前腿提膝 / 伸直）：胯相对架势后移 2.5 px 时重心在后踝前 2.2–2.5 px（出界），后移 3.5 px 时在 1.3–1.6 px（界内）。动作稿写的「胯后坐 0.5 px」不够。
- 前腿单站（鞭腿）：胯 `(0, −90, 0)`、相对架势左移 1.5 px，提膝和击中两帧重心都在左踝 1.3 px 内。
- 出腿、收腿那几帧仍可能出界，按实测登记 `unbalanced_windows`，各放宽约 1 帧（同动作稿 §6）。

**C6 动作稿的角速度是平均值，峰值约是它的 1.9 倍。** 最小抽搐曲线峰值 = 1.875 × 平均。
- 打击时段上限 1,800°/s：伸膝 100° 至少 0.105 s，115° 至少 0.12 s。鞭腿「110° → 10° 用 0.06 s」峰值约 3,100°/s，飞踹「120° → 5° 用 0.07 s」约 3,100°/s，连环每下 0.10 s 约 1,900°/s，都超；本稿把起点前移，见各页。
- 一次性上限 720°/s：尥蹶两腿蹬直（膝 110°，动作稿约 0.2 s）峰值约 1,000°/s，**也要打击时段**，动作稿说不需要（待决定第 8 条）。
- 下劈、正蹬、弹腿在动作稿的打击时段内够用。

**C7 腾空照万门一斩的口径**：跳的高度不在模型里，由实体冲量给（原版起跳 8.4 m/s 约 12 tick 滞空）；模型里胯约在架势高度，两脚收起离模型地面 2–3 px；起跳、落地都屈膝缓冲；腾空段没有着地脚，不查重心。

**C8 视线层是叠加的，会动腰、胸、上臂。** `head_follow`：偏航 ±50° 对应头 ±30°、胸 ±12°、腰 ±8°、上臂 ±4°；`head_follow_pitch`：俯仰 ±90° 对应头 ±62°、胸 ±16°、腰 ±12°、上臂 4° / −6°。只有 `PlayerMeshRenderer.lookPitchWeight` 里的望远镜、号角、弩、弓把俯仰权重设 0，偏航总叠。所以玩家一转头，两拳撑地（尥蹶）、两手扶膝（不留行）的接触点就会走开（待决定第 4 条）。

**C9 手**：两拳全程握拳（架势的 `FIST_R` / `FIST_L`），手里的东西跟着手走；不做 `l_item` IK、`calib_item` 校准。

**C10 时间线事件**：照动作稿，每一下的打击帧都标 `hit`，落脚帧标 `step_l` / `step_r`（都只是客户端通知）。破门斩的先例是「多击只标末击」（Door-Breaker 的 `DoorBreakerAnimationTimingTest` 按这个核对），千里腿服务端那边的测试口径没看到（待决定第 12 条）。
