# place_block：主手放置方块（胸前持块，前推按到目标面上）

> 审阅状态：待审阅（2026-10-22，第三批）。轴向、坐标和数值来源见 [共用约定](conventions.md)；驱动方式与 [attack_main](attack_main.md)、[mine_main](mine_main.md) 相同。
> 数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：手持方块（`BlockItem`）右键放置成功时挥手的动作：把胸前的方块往前下方推出去、按在目标面上，再收回。
- **触发与驱动**：`VanillaAnimationScheduler.scheduleHandSwing` 判定挥动物品是 `BlockItem` 时选 `place_block`（副手放置选 `place_block_off`）。与 attack 同一条 scrub 路径：挥动中 `u = 0.60 × handSwingProgress`（剪辑 `t = 0.30 × handSwingProgress`），挥动结束后 0.30–0.50 s 按原版挥手速率自走收势。
- **连续放置**：按住右键时原版每 4 tick（`itemUseCooldown = 4`）放一块并挥手，上一次挥动已过半，`swingHand` 重开，所以与连续挖掘一样每 4 tick 回到进度 0。本剪辑 **0–0.20 s 是一次完整的“蓄力 → 前推 → 收回”，0.20 s 与 0 s 姿态相同**，搭桥、砌墙时连续前推不跳变。
- **单次放置**：6 tick 挥动播 0–0.30 s，随后 0.30–0.50 s 收回持物站姿。

## 2. 时间轴

剪辑长度 **0.50 s**（10 tick），`loop: false`。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 接缝 / 蓄力 | 0.00–0.04 | 方块端在胸前偏右；胯、腰、胸先后仰 3° 左右、右转，肩、肘把方块往回收到下巴前下方，腕桡偏把方块立起 |
| 前推 | 0.04–0.12 | 胯先前倾下沉，腰、胸前屈并左转，肩把手送到身前 64°、肘伸到 10°，腕最后尺偏 + 掌屈把方块“按”下去（0.12 s） |
| 跟随 | 0.12–0.15 | 腕再压 1°，手指收紧 6°，身体停在最前 |
| 收回 | 0.15–0.20 | 回到 0 s 的胸前持块姿态 |
| 连续放置回绕 | 0.20 → 0.00 | 每 4 tick 重开挥动 |
| 收势（单次放置） | 0.20–0.50 | 手放回身侧持物姿态，身体回零 |

时间线：无事件。

## 3. 分阶段全身姿势

近端先动：胯前倾峰值 0.054 s、腰 0.067 s、胸 0.083 s、肩 0.083 s、肘 0.083 s、腕 0.100 s。腿由胯的姿态做脚底锁定求得，双脚全程全掌着地。

- **接缝（0.00 / 0.20 s）**：右上臂前举 46°、内收 6°、外展 6°，肘屈 28°，腕掌屈 3°：方块在胸前偏右、略低于下巴。头低 8° 看向放置处；左臂自然在身侧略后（−4°），肘屈 18°。
  胯后坐 0.4 px、下沉 0.2 px，膝屈约 21°，腰、胸前屈 2° / 3°。
- **蓄力（0.03–0.06 s）**：腰后仰到 +1.2°、胸 +0.5°，并右转 2°～2.5°；右上臂回收到 40°、肘屈到 34°，腕桡偏 10°、掌屈回 −2°，方块竖起来贴近胸口；头抬到 −6°。
- **前推（0.10–0.12 s）**：胯前倾 2°、左转 2°、后坐到 0.9 px，下沉 0.45 px，膝屈到 32°；腰前屈 5°→7°、胸 7°→8°，左转 2°～3.5°；
  右上臂 64°、内收 12°，肘伸到 10°；腕尺偏 −12°、掌屈 10°，把方块往前下方按出去，`r_item` 到身前 10 px。头低到 −11°、左转 3°，看着方块落点。左臂往后摆到 −12°、肘屈 24°，平衡右臂前推。
- **收回 / 收势**：0.20 s 回接缝；单次放置时 0.30 s 肩 34°、肘 20°，0.50 s 回到持物站姿（与 attack_main 起止姿态相同）。

## 8. 索引条目与叠加

`mask: full`、`priority: 20`、`blend_in: 0.04`、`blend_out: 0.14`、`hand: main`、`fpv: false`；不声明 `impact_window`。
底层是 walk / run / sneak / jump_air / ride 时只取 `upper`（运行时动态遮罩）。动作目录时长 10 tick（现为 9，需同步）。

## 9. 与其他状态的衔接

- 进入：`stand`、`walk`、`run`、`sneak`（潜行搭桥最常见）、`jump_air`（跳起垫方块）、`ride`；`sleep`、`elytra` 中不播放。
- 连续放置：同一 ID 重复 scrub，0.15 s → 0.20 s ≡ 0 s 回绕，要求同 mine_main（见「分工」）。
- 放置后紧接挖掘/攻击：调度换 ID，旧实例从当前姿态淡出 0.14 s。

## 11. 待审事项

- 原版放置只在成功放下方块时挥手；放置失败（目标不可放）不挥手，也就不播放本动作。
- 预备/跟随门禁的“恢复”以 0° 为准，持物站姿本身肩 15°、肘 12°，所以肩、肘两根骨在这一项上不可能通过；本动作靠躯干与手腕满足 3/5。建议门禁改为“回到首帧或末帧附近”，已写入「分工」。
