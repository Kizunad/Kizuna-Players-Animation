# piglin_sword_gold_splash · 泼金

## 目的与触发

流金生效期间，施放下卷泼金。角色先把金剑往身后低处带，前脚跟上，再把手中分量甩向前方。P5 的 `gold_splash` 在 0 ms 发出 `meridian_piglin_sword:piglin_sword_gold_splash`，600 ms 消耗施放手整把剑，作用区域为身前 4 格、60° 扇面，950 ms 收势结束。PA 描述人体和持物挂点。消耗与金粒掉落由剑仓实现。

## 关键姿势和全身节奏

| 时刻 | 脚、膝、胯 | 腰、肩、头 | 两手与道具 |
| --- | --- | --- | --- |
| 0–0.43 s，蓄势 | 从左前右后的战斗架势压向后腿，后膝屈，前脚松重 | 胯、腰、持剑肩先后向持剑侧反拧，头仍朝扇面中线 | 肘向后引，剑随腕下沉至体侧后方，另一手前伸配重 |
| 约 0.45–0.60 s，泼出 | 前脚跟进小半步接重，后脚掌碾地抬跟，胯先从蓄势方向甩回，根骨定在原处 | 腰跟胯打开，胸肩再带臂向前，头稍迟跟向落点 | 上臂带肘，前臂展开，腕最后把剑尖甩过身前。另一手回收以保持平衡 |
| **0.60 s，第 12 tick** | 前膝承重 | 持剑肩已送出 | 唯一 `release` 标记，物品从选定手消失。实机以服务器施放 tick 为准 |
| 0.60–0.77 s，空手跟随 | 前腿接住前冲，后跟暂留高位 | 胯先停，胸肩仍向前，视线随抛出的方向 | 三片手指展开，腕与空掌冲过放手点，张掌轮廓在镜头内可辨 |
| 0.77–0.95 s，归架 | 前脚在泼出时已落回支点，后脚跟放下，两膝和胯回到架势 | 腰、肩依次回转，头回正 | 空掌随肘归护位，手指收回战斗架势的自然拳形 |

## 手别、覆盖与衔接

主手 `piglin_sword_gold_splash` 用右后手，副手 `piglin_sword_gold_splash_off` 用左前手。副手重解肩、肘、腕的位置，两版都保留左脚在前的步型。另一手保留原握形。粗臂、细臂共用轨道。静止时全身播放，`upper_while_moving` 使走动时的胯和腿继续跟随步态。第一人称沿用 `fpv: false`。原版剑握法一直用到放手。

首末帧逐骨取 `stance_idle` 首帧，全长 19 tick，优先级 24，淡入 0.10 s、淡出 0.25 s。普攻、格挡、受击以及流金都经既有架势和淡入淡出衔接。受伤打断时从当前姿势淡出，技能时钟负责决定剑是否已被消耗。

## 握持、挥击与审片

现有 `GRIP_IDS` 统计整段各指的最大转角，无法判别提前松手。泼金沿用时间线已有的 `release` 事件，门禁对这两个 ID 加检：在 0.60 s 前逐个 60 Hz 样本检查施放手拇指和两组指骨沿本侧合拳方向屈曲（拇指至少 30°，两组手指至少 55°）。放手后检查三片指骨在跟随期同时张开，再核对末帧回架。门禁由动作 ID 强制启用，同时核对事件与第 12 tick，对其他握持动作沿用原判据。预览道具用既有 `until` 在 0.60 s 隐去。

索引只声明一次 `splash` 发力段 0.45–0.60 s，按 PA 播放器的 60 Hz 剑尖世界速度测 `swings`，空手跟随不计。正面、侧面、三分之四视角交叉检查蓄势方向、放手点与越程；慢放看后脚、胯、腰胸和投掷臂的错峰。固定侧面实拍从有剑拍到空手、金粒落地。
