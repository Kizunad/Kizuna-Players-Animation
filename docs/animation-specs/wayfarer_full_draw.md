## 1. 动作目的与触发

- **用途**：行矢第一式，照弓道射法八节一节一节做足：
  - 足踏换成弓的射位，胴造立直；
  - 弓构勾弦，「打起」两手把弓举到前上方，「引分」一边分开一边落到满弓，身体压进弓里；
  - 「会」定住，「离」撒放；
  - 「残心」：弦手顺势向后打开，两臂连成一条直线停一会儿。
  - 全套唯一举弓过顶、唯一停在「一」字残心的一式。
- **与其他弓式的区别**：

  | 式 | 开弓方式 | 拉满 | 撒放后 |
  | --- | --- | --- | --- |
  | **满月** | **举过顶，落下分开** | 满弓，会 0.5 s | **左臂打开成「一」字，停 0.8 s** |
  | 连珠 | 攥箭，弓手直接到瞄准位 | 八成，三发 | 手绕小圈搭下一支 |
  | 箭雨 | 仰身 50° | 满弓一次，之后八五成 | 双膝一伸往上送 |
  | 天地同至 | 先仰后沉 | 深弓步满弓、强颤 | 弓垂到地 |

- **触发**：行矢满月起手时，宿主（Human）调用 `PlayerAnimationAction.WAYFARER_FULL_DRAW`（弓在副手时调 `_OFF`），按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **6.0 s**（120 tick），`loop: false`。撒放 3.60 s。
- **承接**：承接入口 0.40（足踏开始，预备不动脚）：连弩、横风、跪射换兵接满月时从 0.40 起播。作前式：天地同至从 1.20 起播；换兵接连弩、横风、跪射从各自 0.40 起播。收势从 3.60 起，前半段到 4.80，双脚 4.75 已回架势踝位。
- **打断**：起手 0–3.60 s 被伤害打断时淡出 0.20 s 回架势，资源不另做打断段。
- **时间线事件**：`0.80: step_r`、`3.60: release`、`4.75: step_r`。

## 3. 分阶段全身姿势

数值为面板值或模型空间位置（像素，脚底原点，右侧 −X、前方 −Z）。「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。射位 B0 见 C4，满弓基准见 C5。

### 起点与终点（0.00 s、6.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯位置相对架势 `(+0.3, 0, −0.2)`，旋转 Y +2°（0.35 s 到位）；双脚锁定，腿逐帧 IK。
- 胯左移 0.3 px 让重心 X 进左踝 ±2 px（架势重心 X 0.11，左踝盒下沿 0.3）；实测进了，足踏的失衡窗口就删。
- 右拳（持弓）降 1 px。0.40 s 全身速度为零（承接入口）。

### 足踏（0.40–1.00 s）

- **右脚**：0.50 离地（先抬脚跟、再离地，离地 ≥ 0.3 px），从左脚右侧绕到右前方，0.80 全掌落在 `(0.2, 1.0, −6.6)`，世界朝向 Y −40°；落地前后只做竖直运动。
- **左脚**：0.55–0.95 绕踝竖线碾，踝 `(2.3, 1.0, −2.6)` 不动，脚尖左转 40°（看起来是以前脚掌为轴、脚跟内转，C2）。
- **双膝**：到 B0 的约右 18° / 左 44°（0.95 到位）。动作稿「双膝微屈 10°」做不到（C4 探针）。
- **胯**：0.50 起左转，0.95 到世界 Y −25°（相对架势 −37°）；位置 0.60–1.00 前移 2.5 px、升约 0.9 px，到 B0 约 `(1.0, −0.9, −1.9)`，重心落到两脚之间。
- **弓**：右臂松垂，弓竖着在身前随身体转；左手不动。

### 胴造（1.00–1.30 s）

- 胯 X −6° → 0°，腰 `(−3, 4, 0)` → `(0, −8, 0)`，胸 `(−2, 4, 0)` → `(0, −7, 0)`；胯 1.00、腰 1.03、胸 1.06 起依次到位。侧身合计 −40°。
- 头 `(3, −19, 0)` → `(0, 40, 0)`：世界朝向回到正前方（−25 − 8 − 7 + 40 = 0）。
- 两臂随胸转，自然垂在身前；弓把在右胯前，弓身竖直。

### 弓构（1.30–1.70 s）

- 弓手把弓移到腹前中线（弓把约 `(−0.5, 15, −6)`），弓身竖直。
- 左手 1.40 到弦上（弓把后约 1.5 px），1.45–1.55 手指 −8° → −62° 勾弦；`pulling` 1.55 开、`pull` 0：弓换成 `bow_pulling_0`，箭出现在弦上（搭箭）。
- 胸 1.35–1.65 一次吸气（X −1° → +1° → 0°）。

### 打起（1.70–2.30 s）

- 两上臂由垂在腹前抬到前上方：世界前屈约 130°（弓道的「前上方约 45°」），两肘屈 15°。手臂长 10.2 px，肩高约 y 20.4，前屈 130° 时弓把约 `(−0.5, 27, −8)`，在额前；弓上梢约 y 36，高过头顶（约 y 30）。
- 弓身保持竖直，两手相对位置不变（左手仍在弦上）；1.70 右臂、1.73 左臂起，2.25 到顶。
- 头不动（盯靶），躯干竖直；胸 1.80–2.20 吸气 X +1°。

### 引分（2.30–3.10 s）

- **胸张开**（2.30–2.60）：胸 X +2°、Y −3°（两肩胛往脊柱夹）。
- **压进弓里**（2.60–3.10）：腰 X −1°、胸 Z 向弓侧（右）倾 1°，肩线下沉约 0.5 px；弓臂不跟着动。
- **弓手**：由额前沿弧线向靶推出、落下，3.05 到 `bow_draw` 会位（胸坐标系照搬弓把 `(−1.0, 23.8, −13.5)` 的位置和弓的世界朝向 `(90, −5.7, 0)`，C5），臂伸直。
- **弦手**：由额前沿弧线落到下颌下锚点（胸系照搬 `bow_draw` 的 z −3.2 锚点），肘 39° → 65°、上臂抬肘后收；手指 2.90–3.10 由 −62° 屈到 −70°。
- **物品**：`pull` 2.30 → 3.10 线性 0 → 1（约 2.82 过 0.65 换 `bow_pulling_1`，3.02 过 0.9 换 `_2`）。

### 会（3.10–3.60 s）

- 胸 Y 再 −0.5°（继续扩张），弱颤 ±0.3°（沿用 [technique_charge](technique_charge.md) 定劲段弱颤的做法：振幅两端渐入渐出、各骨相位错开）；弦手再后移 0.3 px；弓臂不动。

### 离（3.60 s，`release`）

- 手指 3.60–3.77 由 −70° 张开到 −8°（最小抽搐，峰值约 680°/s，C7）。
- `pulling` 3.60 阶跃关：弓回空弓模型，弦上的箭消失（「离」的一瞬由它给出）。

### 残心（3.60–4.40 s）

- **左臂**：3.62–3.92 弦手沿锚线向后上方走，前臂、上臂顺势打开，到 3.92 整条左臂伸直、和弓臂在世界水平面上连成一条线（「一」字）。侧身只有 40°，左臂要在胸平面后再展约 50°（第 7 节第 3 条）。
- **弓手**：3.65–3.85 手腕放松，弓在手里前倾 10°（弓梢向靶倒）。
- 头、躯干、腿不动，保持到 4.40。

### 收（4.40–6.00 s）

- **脚**：4.40–4.45 胯后移、右移，重心压回左脚；4.45 右脚离地，4.75 以提踵 −35° 落回架势踝位 `(−1.7, 1.72, 3.2)`（脚尖先着地，落地即终姿）；左脚 4.50–4.80 碾回架势朝向。
- **上身**：4.75 起胯、腰、胸依次回架势（5.40 到位），头 5.50 回 `(3, −19, 0)`；5.00–5.80 一次长呼气（胸 X −1° 再回）。
- **双臂**：4.40 起落下；弓 5.30 回持物位 `r_item` 约 `(−4.4, 22.6, −7.7)`，左手 5.40 回下巴前 `(4.3, 23.6, −10.2)`、握拳；5.50–6.00 静止。

## 5. 衔接

- 起止等于 `stance_idle` 首帧：`stance_idle → wayfarer_full_draw` 0.10 / 0.25，播完淡回 0.25 / 0.25。
- 作后式：连弩、横风、跪射换兵接满月，从 0.40 s 起播（预备段跳过），前一式淡出 0.30 s，物品在淡出期间由原版换成弓。

## 7. 骨架与门禁带来的约束

1. **打起的高度**：手臂 10.2 px，「举过头顶」做不到手在头顶上方；两手到额前、弓的上梢过顶，接触表看是「举起」。再高要肩上耸，Steve 没有肩骨。
2. **足踏迈步**（C2、C4）：右脚提踵 −35° 落成全掌，同一次着地踝高变 0.72 px，滑脚门禁不过，所以抬脚再落；收势同理以提踵落回。
3. **残心「一」字**：侧身 40°（C5，再侧够不到锚点），左臂要在胸平面后再展约 50° 才和弓臂成一线。Steve 的肩是球形枢轴、没有角度门禁，能摆；看着别扭就退成「左臂伸到胸平面，与弓臂成约 140°」，在接触表上定。
4. **速度**：残心左上臂约 90° / 0.30 s，最小抽搐峰值约 560°/s；动作稿 0.25 s 是 675°/s，离 720 太近，放到 0.30 s（C6）。
