## 1. 动作目的与触发

- **用途**：行矢第四式，弩托贴着脸瞄准，左手沿弩身推拉五次，每拉一次射一发；身体随推拉前后摇，每发后坐一顿，像在压一台机器。全套唯一抵颊连发的一式。
- **与其他弩式的区别**：

  | 式 | 持弩 | 推拉 | 身体 |
  | --- | --- | --- | --- |
  | **连弩** | **抵颊**（`crossbow_hold`） | 五次，0.40 s 一循环 | 原地前后摇 |
  | 横风 | 抵右胯 | 六次，0.35 s 一循环 | 整个身体从右 45° 扫到左 45° |
  | 跪射 | 跪地，膝上装填后举到颊边 | 三次，`crossbow_charge` 的长行程 | 跪着 |

- **触发**：行矢连弩起手时，宿主调用 `PlayerAnimationAction.WAYFARER_REPEATER`（弩在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。撒放 1.60、2.00、2.40、2.80、3.20 s。
- **承接**：承接入口 0.40。作后式：满月、连珠、弓梢、回马、箭雨换兵接连弩，从 0.40 起播。作前式：横风 0.40（承接）、满月 0.40 / 连珠 0.40 / 弓梢 0.30（换兵）。收势从 3.20 起，前半段到 4.10，前脚 3.90 已回架势踝位。
- **打断**：起手不能打断。
- **时间线事件**：`0.70: step_l`、`1.60 / 2.00 / 2.40 / 2.80 / 3.20: release`、`3.90: step_l`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。弩的抵颊姿势见 [crossbow_hold](crossbow_hold.md)，推拉行程见 C8。

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胯位置相对架势 `(0, 0, +0.2)`；胸 Y −1.5°（和之后的右转相反）；右拳降 0.5 px。0.40 s 全身速度为零（承接入口）。

### 调整（0.40–0.80 s）

- 左脚 0.45 离地（离地 0.3 px），0.70 全掌落在 `(2.3, 1.0, −3.6)`（前移 1 px）；右脚不动（架势提踵）。
- 双膝屈到 15°（0.45–0.80）；胯位置前送 0.8 px、降约 0.4 px，重心约 55% 在前脚。

### 架（0.80–1.20 s）

- **躯干**：胯 Y +6°（0.80）、腰 +6°（0.83）、胸 +6°（0.86）依次右转，0.90 / 0.93 / 0.96 起到位：胸世界朝向约 +38°，左肩前送。头 Y −18°（世界朝向回到正前方）。
- **右臂**：照 `crossbow_hold` 把弩举到右颊前：弩托贴右颊、弩身水平指前（世界 −Z）。`crossbow_hold` 的胸世界朝向是 +12°，这里是 +38°，所以不照搬胸系数值，由原型按「弩托贴右颊、弩口指前」逐帧 IK。
- **左臂**：托到扳机前约 3 px（推位，C8）；手指托着，−40°。

### 第一拉（1.20–1.55 s）

- 左手 1.20–1.50 沿弩身拉回扳机旁（行程 3 px，左肘约 +25°）；胸 X +1.5°（后靠），右肩顶住弩托。
- 物品：1.20 `pulling` 开、`pull` 0；1.20–1.50 `pull` 0 → 1（1.37 过 0.58 换 `crossbow_pulling_1`，1.50 到 1.0 换 `_2`）；1.56 `pulling` 关、`charged` 开（`crossbow_arrow`）。

### 五连（1.55–3.25 s）

每发撒放 t（1.60、2.00、2.40、2.80、3.20）：

- **发**（t）：`release`；`charged` 关（`crossbow_standby`，弦松）。
- **后坐**（t → t + 0.10）：弩口上跳 3°（右腕、右前臂 X），右上臂后让 2°，t + 0.05 到顶、t + 0.10 回位（C6：上跳不能短于 0.05 s）；胸 X +1°；前膝再屈 2°，t + 0.20 回。
- **推**（t + 0.03 → t + 0.15，前四发）：左手沿弩身前推 3 px，左肘伸约 25°（峰值约 470°/s）；胸 X −1°（前送）；重心前移 0.2 px。物品：`pulling` 关。
- **拉**（t + 0.15 → t + 0.33）：左手拉回扳机旁；胸 X 后靠 1.5°；重心后移 0.2 px。物品：t + 0.15 `pulling` 开、`pull` 0，t + 0.32 到 1（`_2` 显示到 t + 0.36）。
- **挂上**（t + 0.36）：`pulling` 关、`charged` 开。
- 第五发（3.20）后不再推拉。

### 随（3.25–3.60 s）

- 左手停在扳机旁，弩仍贴着脸；3.30–3.60 呼气（胸 X −1°）。

### 收（3.60–5.00 s）

- **脚**：3.55–3.60 重心后移到右脚；左脚 3.60 离地，3.90 落回 `(2.3, 1.0, −2.6)`；双膝回架势屈度。
- **上身**：3.90 起胯、腰、胸、头回架势（4.60 到位）。
- **双臂**：3.70 起照 `crossbow_hold` 反着放下弩，4.50 回持物位；左手 4.60 回下巴前、握拳；4.70–5.00 静止。

## 7. 骨架与门禁带来的约束

1. **推拉行程**（C8）：抵颊时左手只够到扳机前 3–4 px，动作稿「推到弩前端（7.5 px）」做不到；行程按够得着的做，弦的位置由弩的拉弦模型三档给出。
2. **胸的朝向**：比 `crossbow_hold` 多右转 26°，抵颊的右臂、托弩的左臂不能照搬胸系数值，逐帧 IK。
3. **后坐的抽搐**：弩口 3° 在 0.03 s 内上跳是 6.7×10⁶°/s³，超过 1.5×10⁶；上跳 0.05 s、回落 0.05 s（C6）。

## 10. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/wayfarer/d_repeater.py` 求解（交接目录，不入库），装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：`unbalanced_windows`、`aim_windows`、`phases`、时间线同第 6 节。`item_states` 第一拉同第 6 节；之后每发跟着推拉晚 0–0.03 s：t + 0.16 `pulling` 开、`pull` 0，t + 0.35 到 1，t + 0.36 `pulling` 关、`charged` 开，挂上的箭显示 0.04 s（同规格）。

**门禁**：全部通过。关键帧 1,407（目标 1,300–1,600）。全段最快 675°/s（左前臂 2.12 s，推），抽搐最大 1.30×10⁶°/s³（右前臂 2.05 s，后坐回落）；不登记打击时段、爆发窗口。最低点 −0.200 px；重心出界 0.53–0.62、3.72–3.80 s（左脚两次迈步，都在失衡窗口内）；支撑脚滑动右 0.02、左 0.25 px；手臂穿模 0；预备 / 跟随 4/4 骨（腰、右上臂、右前臂、右手）。
错峰门禁**实际一段也没判到**：它按整段的主轴选通道，左上臂的整段主轴是 Z（举弩时外展，整段 31°），每个推拉循环在 Z 上动不到 1°，五段都凑不齐 3 根骨，报告记为不适用、照常通过。推拉时左上臂其实在 X 上每循环动约 20°、Y 约 10°；用探针按段内主轴、同一峰值算法另查：第一拉左上臂 1.35 → 左前臂 1.40 → 左手 1.43 s，五连每段都是左上臂 → 左前臂 → 左手各隔一帧（如 1.70 / 1.72 / 1.73 s）。探针不入门禁，以后改这段要重查。

**自查**：1.20–3.25 s 弩托离抵颊点最大 0.016 px，弩口俯仰在后坐外 ≤ 0.44°，后坐上跳 3.24°；推到底、拉到底时托手在弩上的位置五次差 ≤ 0.02 px；右踝整段 X、Y 变化 0.02 px。
