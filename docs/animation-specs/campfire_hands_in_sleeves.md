# campfire_hands_in_sleeves · 收手入袖，campfire_sleeves_loop · 抱袖坐

> 玩家版 `campfire_hands_in_sleeves`、`campfire_sleeves_loop`，村民骨架版各加 `_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)，烤火基准见 [坐下](campfire_sit_down.md) 第 3 节。

## 1. 目的与触发

天煞孤星第 5 包，盲眼算命人开场的那句：「树底下有人在烤手……把烤到一半的手收进袖里」。

宿主在 [烤火循环](campfire_warm_loop.md) 的任意时刻起播收手入袖。两手交叉缩进对侧袖口，抱在胸前，肩一缩。收尾停在可以循环的「抱袖坐」，接着播抱袖循环，带呼吸，直到 [起身](campfire_stand_up.md) 或被打断。

## 2. 时长与索引

| 段 | 时长 | 索引 |
| --- | --- | --- |
| `campfire_hands_in_sleeves` | 一次性 **0.80 s**（16 tick） | `blend_in` **0.30**（从循环任意时刻淡入）、`blend_out` 0.20、`hand: none`、优先级 6。`hand_contact_windows` `[[0.50, 0.80]]` |
| `campfire_sleeves_loop` | 循环 **8.0 s** | `blend_in` 0.20、`blend_out` 0.20、`hand: none`、优先级 6。`hand_contact_windows` `[[0.0, 8.0]]` |

收手入袖的首帧是烤火基准，即烤火循环 0 s；末帧逐骨等于抱袖循环 0 s。

## 3. 关键姿势：抱袖坐

下半身、胯和坐高与烤火基准完全相同，两只腿不动。上半身如下。

| 部位 | 玩家版 | 村民骨架版 |
| --- | --- | --- |
| 双臂 | 两前臂在胸腹前交叉成 X，大致水平、稍向内下倾。**右前臂在外**，左前臂贴身在内。交叉点在 (0, 10.5, −5.0) | 交叉点外移到 z −6.0，因为躯干厚 6 px。形状接近原版村民的抱臂 |
| 右手 | 贴在左前臂靠肘一端的外上方，腕屈 30°，手指包住左臂，屈 45° / 55° / 60° | 同 |
| 左手 | 从右前臂下面钻过去，贴在右肘内侧，腕屈 25°，手指屈 40° / 50° / 55° | 同 |
| 从正面看 | 两只手大半被对侧前臂挡住，读作手缩进了对侧袖口 | 同 |
| 肩 | 缩肩加重：上提 1.0 px、前收 0.8 px | 同 |
| 躯干 | 前倾从 14° 减到 10°，微微往后靠 | 同 |
| 头 | 俯视 15°，下巴缩进 1° | 同。鼻子离交叉的前臂 ≥ 2 px |

手是 4 px 见方的方块，不能真的伸进另一条前臂。所以两只手都贴在对侧前臂表面：间隙 ≤ 0.5 px，穿入 ≤ 0.25 px，由 `hand_contact_windows` 把关。

## 4. 收手入袖（0.80 s）

| 时段 | 躯干与头 | 双臂与手指 |
| --- | --- | --- |
| 0.00–0.12 停 | 胸先往后收 1°，像听见了什么。头晚 1 刻停住 | 两手先在火前停一下，往火的方向多飘 0.3 px（预备），手指往回收 10° |
| 0.12–0.45 收 | 躯干前倾由 14° 回到 10°，比肘早 1 刻 | 肘往下往后沉。前臂内旋、往身前交叉：右臂走外道，左臂走内道，两条前臂错开 1 px 擦过，不穿。腕在前臂之后转向对侧肘 |
| 0.45–0.62 入袖 | 胸回落，呼一口气 | 右手顺左前臂外上方滑向左肘，左手从右前臂下面钻到右肘内侧，0.55 s 两手都贴上。手指最后包上去，比腕晚 2 刻 |
| 0.55–0.70 肩一缩 | **0.60 s 两肩一耸，峰 +1.4 px**，然后落到 +1.0 px。头低 3°，晚 1 刻 | 两臂随肩一起抬一下，又抱紧，肘内收 0.5 px |
| 0.70–0.80 稳住 | 回到抱袖坐，速度归零 | 不动，只剩呼吸起伏 |

**切入**：宿主在烤火循环的任意时刻起播。淡入 0.30 s 里，姿势从当前采样往本段前 0.30 s 混。门禁的切入矩阵按 0.25 s 一档逐一合成检查。

两个重点时刻：
- **E3 拨火**：手里还握着枝时切入，`open` 轨道归零，枝随之消失；
- **E4 立膝**：左腿淡入期间滑回斜伸位置，不穿地。

## 5. 抱袖循环（8.0 s）

基础层：

| 层 | 周期 | 内容 |
| --- | --- | --- |
| 呼吸 | 4.0 s × 2 | 吸 1.7 s、呼 2.3 s。吸气时两肩连同抱着的两臂上提 0.4 px，胸后仰 0.6°，头反向 0.3° |
| 前后摇 | 8 s | 躯干前后 ±1°，胯晚 0.3 s 跟着 ±0.4°，像老人坐着微微晃。前摇最大在 2.0 s |
| 头的漂移 | 4 s | 偏航 ±2°，和摇错开 0.7 s |

小动作：

| 段 | 时段 (s) | 内容 |
| --- | --- | --- |
| S1 抱紧 | 1.40–2.30 | 两肘内收 0.6 px、肩提 0.3 px，抱紧一下再松开。手指在袖里捏一下：拇指先动，两组手指晚 1 刻 |
| S2 侧耳 | 3.10–4.40 | 头慢慢右转 15°、往右歪 4°，像在听人走近。3.60–3.95 停住，再转回。胸跟着右转 3°，晚 2 刻 |
| S3 冷一抖 | 5.10–5.65 | 两肩快速上耸 0.8 px，躯干抖两下（偏航 ±0.8°），臂抱得更紧，然后慢慢放松 |
| S4 挪一下 | 6.20–7.30 | 胯左倾 2° 再回正，重心在两侧坐骨间挪一下。左脚踝外转 6° 再回来，右脚趾屈一下 |
| 回到基准 | 7.30–8.00 | 只剩呼吸和摇，接缝处所有小动作都已收住 |

间隔 0.8 / 0.7 / 0.55 s，起点不在呼吸节拍上。

## 6. 骨架差异（村民骨架版）

- 交叉点外移 1 px 到 z −6.0，前臂离胸 ≥ 0.5 px。村民躯干厚 6 px，袍子在胸前还要再膨胀 0.5 px。
- 抱袖的轮廓本来就接近原版村民的抱臂站姿，只是换成了坐姿、肩缩得更高。
- 头更大，鼻子在前。低头 15° 时，鼻子离交叉的前臂 ≥ 2 px。
- S2 侧耳时帽沿跟着头转，不碰别的东西。

## 7. 衔接

- 收手入袖从烤火循环任意时刻淡入，见第 4 节。
- 抱袖循环接 [起身](campfire_stand_up.md)：起身首帧就是抱袖坐，手先从袖里抽出来再撑地。
- 想回到烤火时，宿主用 `blend_in` 0.6 s 直接淡回烤火循环 0 s。这条资源不单做，两手的移动由切入矩阵覆盖。

## 8. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 收手入袖 0.50–0.80 s 和抱袖循环全程，两手贴在对侧前臂上，间隙 ≤ 0.5 px、穿入 ≤ 0.25 px；
  - 前臂互不穿入；
  - 循环首尾连续。
- 60 Hz 峰值时刻表看收手顺序：胸 → 肩 → 肘 → 腕 → 手指。

  - 侧视看肩一缩和前后摇；
  - 四分之三视角看侧耳。
