## 1. 动作目的与触发

- **用途**：弓·上卷附带的训练功法（行矢 §4.4），不射箭：
  - 侧身立弓、不搭箭，拉满，停住 3 s，再慢慢放回去，一共 5 次；
  - 空弓不能撒放，所以没有 `release`，每次都稳稳收回来；
  - 全程弓拉开但弦上没有箭（`item_states` 的 `arrow` 关，动作稿 §3.3）。
- **触发**：施放拉空弓时，宿主调用 `PlayerAnimationAction.WAYFARER_DRY_DRAW`（弓在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。生物不练（行矢 §7），只给玩家。
- **时长**：剪辑 **32.0 s**（640 tick），`loop: false`（待决定第 11 条）。
- **承接**：没有。不作前式、后式，不换兵。
- **打断**：起手 0–31.00 s 被伤害打断时淡出 0.20 s。
- **时间线事件**：`0.45: step_r`、`31.70: step_r`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。射位 B0 见 C4，满弓基准见 C5。

### 起点与终点（0.00 s、32.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 足踏（0.00–0.60 s）

- 同 [满月](wayfarer_full_draw.md) 第 3 节足踏，没有预备段：0.00–0.10 胯左移 0.3 px、前送 0.2 px（重心压向左脚）；**右脚** 0.10 离地，从左脚右侧绕到右前方，**0.45 全掌落在 `(0.2, 1.0, −6.6)`**（`step_r`）；**左脚** 0.15–0.50 绕踝竖线碾到脚尖左转 40°（C2）。
- **胯**：0.10–0.55 到世界 Y −25°、位置到 B0（约 `(1.0, −0.9, −1.9)`）；胯、腰、胸 X 回 0。
- **上身**：腰 `(0, −8, 0)`、胸 `(0, −7, 0)`；头 Y −19° → +25°（世界朝向约 −15°，先看向弓的一侧）。
- **弓手（右）**：0.05–0.50 从护颌位放下，弓竖着垂在身前。这一下与立弓的抬臂方向相反，是持物臂的预备（C12）。左拳留在下巴前。

### 立弓（0.60–1.00 s）

- **头**：Y +25° → +40°（0.60–0.90），世界朝向回到正前方。
- **弓臂**：0.60–1.00 抬到水平、伸向前方，弓把到 C5 的胸系位置，弓身竖直。
- **弦手**：0.80–1.00 从下巴前伸到弦上，手指张开再勾到 −62°。
- 1.00 `pulling` 开（`pull` 0，`arrow` 关：拉弓模型不带箭）。

### 拉满（每个周期，T = 1.00、7.00、13.00、19.00、25.00 s）

- **拉开**（T → T+1.50）：
  - 弦手沿弧线拉到下颌下锚点，弦臂肘 39° → 65°，上臂抬肘后收（C5）；`pull` 0 → 1（T+0.975 过 0.65 换 `_1`，T+1.35 过 0.9 换 `_2`）；手指 −62° → −70°；
  - T → T+0.90 胸张开（X +2°、Y −3°），同时吸气；T+0.90 → T+1.50 **压进弓里**：腰前屈 1°、胸向弓侧倾 1°，肩线下沉约 0.5 px（同满月「引分」，放慢到 1.5 s）。
- **持满**（T+1.50 → T+4.50）：
  - 屏气，胸 X 不再起伏；弦手贴着下颌不动；
  - 微颤：胸 6 Hz ±0.3°、弦臂前臂 7 Hz ±0.5°、弓臂前臂 5 Hz ±0.3°，各自相位错开；两端各 0.30 s 渐入渐出。抽搐最大约 4.3×10⁴，在限内；
  - 弓臂不动。
- **慢放**（T+4.50 → T+6.00）：
  - 弦手沿拉开的弧线慢慢送回弓旁，肘 65° → 39°；`pull` 1 → 0（线性），**T+5.95 `pulling` 关**；手指留在 −62°，仍勾着弦；
  - 胸、腰回到拉开前的值，同时长呼气（胸 X +2° → 0）；
  - T+6.00 全身回到周期起点的姿势、速度为零，接下一个周期（k = 4 时是落弓）。

### 落弓（31.00–31.40 s）

- 左手 31.00–31.15 离弦，手指张开再握拳，回到胸前；弓臂 31.05–31.40 从水平垂下，弓竖着垂在身前。
- 躯干保持侧身，头不动。

### 收步（31.40–32.00 s）

- **脚**：31.40 胯后移、右移，重心回左脚；右脚 31.40 离地，**31.70 以提踵 −35°、脚趾 +10° 落回 `(−1.7, 1.72, 3.2)`**（`step_r`）；左脚 31.45–31.75 绕踝竖线碾回架势朝向。
- **胯**：31.40–31.80 回架势位置与 Y +12°。
- **上身**：腰、胸、头 31.45–31.90 依次回架势值。
- **双臂**：弓 31.40–31.95 提回护颌持物位；左拳 31.50–31.90 回下巴前。
- 31.95–32.00 静止。

## 7. 骨架与门禁带来的约束

1. **32 s 一次性**（待决定第 11 条）：不用 `loop_region`，和服务端 31 + 1 s 一一对应；中间四个周期由脚本复制，首周期的起点姿势就是立弓末帧，周期首尾速度为零，接缝不进门禁（不是循环）。
2. **微颤**比满月「会」的弱颤还小，只为了「持着」不是死帧；用 6–7 Hz、幅度 ≤ 0.5°，速度不过 25°/s。
3. **收步 0.60 s 挤**：右脚 31.70 落地，晚于收势前半段（31.50），本段没有承接时窗，不影响；弓从垂着提回护颌（肘约 125°）用 0.55 s，峰值约 430°/s。

## 9. 门禁适用项

| 门禁 | 适用 | 说明 |
| --- | --- | --- |
| 有效运动骨骼 | 适用 | 目标 24 骨 |
| 躯干链 / 头 | 适用 | 侧身 −40°、每周期胸张开 |
| 双臂双腿（全身动作） | 适用 | 加入 `FULL_BODY_IDS` |
| 握持手指 | 适用 | 加入 `GRIP_IDS`；勾弦、满弦、慢放仍勾着 |
| 预备 / 跟随 | 适用 | 持物臂链：足踏放下弓与立弓抬臂相反 |
| 主链峰值错开 | 适用 | 拉弦臂链五段，每次拉开一段 |
| 曲线相关性 | 适用 | 每骨独立时刻；腿逐帧 IK |
| 多轴 | 适用 | 胯（位置 + Y）、胸（X、Y）、头（Y）、双上臂 |
| 关节角度 | 适用 | 肘 ≤ 70°，在限内 |
| 角速度 / 抽搐 | 适用 | 720°/s、1.5×10⁶°/s³；全段最快是收步的提弓（约 430°/s） |
| 手臂穿模 | 适用 | 满弓时弦臂与头、胸（同 `bow_draw`） |
| 着地 / 滑动 / 重心 | 适用 | 站立口径：两脚不滑、不穿地；右脚两次着地（0.45、31.70），左脚整段一次（碾） |
| 循环接缝 | 不适用 | 一次性动作 |

**自查（原型每次跑，不入门禁）**：
- 每个周期 T+1.50 → T+4.50 弦手在胸系里位于锚点 ≤ 0.2 px；
- 五个周期的同相时刻全身姿势差 ≤ 0.01（脚本复制无漂移）；
- 0.50–31.40 s 两踝 X、Y 不动。

**规模目标**：24 骨，约 5,000–6,500 个关键帧（32 s；五个周期复制，持满段逐帧给颤）。

**接触表**：19 个时刻：
- 足踏、立弓：0、0.30、0.45（落步）、0.80、1.00（搭弦）；
- 第一周期：1.75、2.50（满）、4.00（持满）、5.50（开始放）、6.25、6.95（放到底、松弦）；
- 第二、五周期：8.50（满）、26.50（满）、29.50、31.00（放到底）；

## 10. 制作实测（2026-10-31）

原型 `kpa-door-breaker-proto/wayfarer/d_dry_draw.py` 求解（交接目录，不入库），装进 `player_skeleton_classic.bbmodel` 后导出。弦手逐帧解只求第一周期（拉开由满弓解倒推、持满与慢放顺推），后四周期由脚本按 6 s 周期照抄。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：同第 6 节。

**门禁**：全部通过。关键帧 2,230（规格估 5,000–6,500：删减容差同其他段，持满 0.3–0.5° 的微颤只留峰谷附近的键）。全段最快 666°/s（左手手指 31.10 s，落弓松手），抽搐最大 1.04×10⁶°/s³（右小腿 31.57 s，收步）；最低点 −0.235 px；重心出界 0.18 s（迈步，在失衡窗口内）；预备 / 跟随 4/5 骨通过。

**自查**：持满段弦手离锚点最多 0.072 px；五个周期同相时刻的姿势在设计里完全相同，导出后（删键）相差最多 0.27°；右脚 0.17 抬起、0.40 落到射位（`step_r` 0.45），31.45 抬起、31.65 落回（`step_r` 31.70）；左踝整段不动。

**与规格的出入**：
- 足踏时弓手放到腹前用满月弓构的姿势（弓把 y 17、弓竖着）：手垂下时弓身是横的，要竖着只能屈肘；
- 拉距：弦手从 `bow_pulling_0` 的搭箭点拉到锚点，约 2.25 px（规格 1.5 px），弦臂肘 10° → 66°（规格 39° → 65°）；
- 胸在 T → T+0.6 张开（规格 0.9 s）、T+0.25–0.85 弦手肘由肩前下方抬到 `bow_draw` 满弓的肩前位：否则前臂比上臂先到峰，拉弦臂链错峰不过；
- 手指 0.55–0.78 张开、0.80–0.96 勾弦（规格 0.80–1.00 一起做，手指超速）；
- 落弓时弦手离弦直接回护颌（31.00–31.45），不在胸前停（停的话弦手与身体穿模）；
- GIF 出整段 32 s（渲染器没有分段选项），接触表按第 9 节 19 个时刻。
