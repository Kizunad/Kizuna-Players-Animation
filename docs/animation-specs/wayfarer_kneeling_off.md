# wayfarer_kneeling_off：跪射（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-11-01），实测与出入见文末「制作实测」。随主手页 [wayfarer_kneeling](wayfarer_kneeling.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9、跪姿见 C10。本页只写与主手版不同的地方。

## 做法

- **时间轴、事件、窗口**：与主手版相同（7.0 s；`0.70: step_r`、`2.60 / 3.70 / 4.80: release`、`5.85: step_r`；失衡、瞄准、三段 `phases` 都不变），`hand: off`。
- **腿**：照搬主手版（C9、C10）：右膝跪地、右脚竖直脚尖点地，左膝立起约 70°、左脚全掌不动；下跪、起身的时刻与路径不变。
- **上身**（镜像主手版，C9）：
  - 举、瞄时胸**左**转 12°、右肩前送，头右转正视前方；弩挂左手（`l_item`），照 `crossbow_hold_off` 举到左颊前，右手托弩身、右肘尽量压低；
  - **膝上装填不能镜像**：镜像会把弩架到右大腿上，可右膝跪着、右大腿近乎竖直，搭不住。所以仍架在立起的**左大腿**上：前端搭在左大腿中段偏内侧，弩托抬向**左**胸（左手握着），右手从前端把弦拉回扳机；躯干在装填时左转约 10°、前倾同主手版，让右手够到左大腿上的前端。
- **物品**：`item_states`（`pulling`、`pull`、`charged`）与主手版相同，挂在副手。

## 与主手版不同的约束

- **右手够不够得着左大腿上的前端是估算**：右肩枢轴到左大腿中段约 10.5–11 px，手臂约 10.2 px，靠躯干左转、前倾补；原型核对。够不着就把前端放到左膝内侧更靠身体处（弩身更竖），拉弦路径相应缩短，三档模型照常由 `pull` 给。
- 装填时弩托在左胸、举瞄时在左颊，弩每次从左腿举到脸旁的路径比主手版短（同侧），落、举的时刻不变。

## 门禁

适用项同主手页第 9 节；握持查左手握弩、右手推拉；错峰主链换右臂（推拉臂，C12），预备 / 跟随用左臂链；跪姿的着地、穿地口径同主手版（C10）。

改主手版后必须用同一原型重新生成本段，不允许只改一边。

## 制作实测（2026-11-01）

与主手版同一原型生成（`d_kneeling.py` 的副手分支），索引字段、时间线同主手页第 10 节。门禁全部通过（粗、细臂相同）：关键帧 1,903；最快 700°/s（左手 2.73 s，落弩），抽搐最大 1.32×10⁶°/s³（右手手指 4.30 s）；最低点 −0.147 px；重心出界 0.48–0.65、5.63–5.78 s（同主手版，都在失衡窗口内）；支撑脚滑动右 0.42、左 0.04 px；手臂穿模 0；预备 / 跟随 5/5 骨。错峰三段都判到：右上臂 → 右前臂 → 右手各隔一帧（时刻同主手版）。自查：右小腿最低点、右脚尖、右踝漂移同主手版（右踝漂移同样是 0.059 px，比要求多 0.009）；拉弦到底时右手离扳机点 0.006 / 0.022 / 0.005 px，弩托离抵颊点 0.006 / 0.005 / 0.009 px，装填时弩口离搭点 ≤ 0.041 px。

与主手版不同的地方：
- **右手够得着左大腿上的前端**（上文「与主手版不同的约束」第一条原是估算）：弩口搭点比主手版靠内 1.4 px；装填时腰、胸各左转 5°（胸世界比主手版左转 10°，同规格）；右手勾弦的朝向放松、腕角压得更重（照勾弦朝向右腕要绕前臂扭约 90°，超速），手停在近中立的腕位；
- **落弩 0.26 s、撒放即落**（2.60–2.86、3.70–3.96 s）：整条左臂从左颊回左腿、腕绕前臂扭约 96°，0.20 s 时左腕约 920°/s；弩晚 0.04 s 落定，右手晚两帧才起拉；
- **举、瞄偏航**：跪姿同主手版，胯世界 +12° 不镜像；腰、胸面板 Y 都是 −10°（架势 +4°），胸世界约 −8°，比架势左转 28°（上文「做法」写左转 12°；左颊抵弩、右手托弩要转到这里）；头世界偏航约 −11°（主手版 +11° 的相反数）；
- 举弩时右手离开弩，在关节空间移到瞄准起点的托弩位，瞄准段再逐帧跟（逐帧跟着举弩会横扫过胸前，肘 11° → 110° → 41°，超速）；
- 起身：弩 5.20 起回胯边（比主手版晚 0.1 s，等腰先转开，不然穿腰）；**右手够不到左膝（差约 3 px），不按膝**，5.10–5.80 直接回体侧。
