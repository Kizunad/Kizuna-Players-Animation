## 1. 动作目的与触发

- **用途**：中了魅惑药水、判成「良好」时身子一顿，愣在原地：胸后仰、头歪、两臂松下来，脚不动。不属于哪一式，玩家和生物共用（生物的映射归附属）。
- **触发**：宿主在僵直开始时调用 `PlayerAnimationAction.STATUS_STAGGER` 播放，醒时显式停止。播放器不按时长自动结束（`hold_on_last_frame`，不带 tick）。
- **时长**：剪辑 **0.8 s**，`loop: "hold_on_last_frame"`；僵直 0.8–1.6 s，0.8 s 以后停在末帧。
- **层次**：`mask: full`、`priority: 26`，压住功法（24）、握持覆盖层（25）和攻击（20）。
- **时间线事件**：无（僵直声由服务端播）。

## 2. 时间轴

| 段 | 剪辑时间 (s) | 腿脚与重心 | 躯干与头 | 双臂与手 |
| --- | --- | --- | --- | --- |
| **一顿** | 0.00–0.15 | 双膝微屈，胯降 0.4 | 胸后仰 +4°，头绕 Z 轴歪向右肩 10° | 两臂先被带得往上一提 0.5 px（惯性） |
| **松下** | 0.15–0.50 | 不动 | 胸回弹 1°，头歪住 | 两臂从护身位松下 3 px，前臂下垂约 15°，拳还握着 |
| **愣住** | 0.50–0.80 | 不动 | 头再歪 1° 停住 | 两臂晃一下停住 |
| 保持 | 0.80– | 末帧 | 末帧 | 末帧 |

- 0.80 时全身速度为零（`hold_on_last_frame` 末帧必须静止）。
- 醒时淡出 0.20 s 回下层（静止回 `stance_idle` 或 `stand`）。

## 3. 姿势

- **胯**：0.00–0.12 位置 y −1.8 → −2.2（膝多屈约 4–6°）；旋转不变。
- **腰、胸**：胸 X 0.02–0.12 后仰 +4°（腰 +1°），0.15–0.35 回弹到 +3°。
- **头**：Z 0.03–0.15 歪向右肩 10°，0.50–0.70 再歪 1°；X 随胸后仰补约 −2°，眼睛还是平视。
- **右臂**（主链）：上臂 0.10–0.30 前屈减约 12°，前臂 0.14–0.36 伸肘约 15°，手 0.18–0.40 腕下垂约 8°；拳握着（手指常数）。
- **左臂**：同右臂，晚 1 帧、幅度小一成（曲线相关性）。
- **腿**：两脚锁定在架势踝位，膝角由腿 IK 随胯降。

## 5. 重心与支撑

两脚锁定，胯只降不移，重心不动。

## 6. 衔接

- `stance_idle` / `stand` → `status_stagger` 0.05 / 0.20：僵直开始时快速盖上。
- `status_stagger` → `stance_idle` / `stand` 0.20 / 0.20：醒时宿主停止，淡回下层。
- 僵直打断功法起手时，功法剪辑照它自己的打断淡出 0.20 s，僵直同时以 0.05 s 盖上。其余来源（走、跑、攻击中）随调用方接线时补边。
- 移动底层上只取上身（`stanceOverlay`），腿继续走。

## 8. 骨架与门禁带来的约束

1. **保持动作的预备门禁**：保持剪辑末段收敛即通过，所以「一顿」前不加反向预备（被定住是突然的）。
2. **静止在 `stand` 上**：原版站姿两脚并拢，整段生效时腿锁到架势踝位，0.05 s 淡入里两脚会滑一下（第 6 节、待决定第 13 条）。
3. **头歪方向**：左主手镜像时头 Z 反号，向左歪；不影响观感。

## 10. 门禁适用项

| 门禁 | 适用 | 说明 |
| --- | --- | --- |
| 有效运动骨骼 | 适用 | 目标 22 骨（手指常数不算） |
| 躯干链 / 头 | 适用 | 胯降、胸后仰、头歪 |
| 双臂双腿（全身动作） | 适用 | 加入 `FULL_BODY_IDS`；膝随胯降 |
| 握持手指 | 不适用 | 不进 `GRIP_IDS`；手指常数握拳 |
| 预备 / 跟随 | 适用 | 保持剪辑，末段收敛即过 |
| 主链峰值错开 | 适用 | 整段（第 4 节） |
| 曲线相关性 | 适用 | 左臂晚 1 帧、幅度小一成 |
| 多轴 | 适用 | 胯（位置）、胸、头 |
| 关节角度 | 适用 | — |
| 角速度 / 抽搐 | 适用 | 「一顿」约 300°/s |
| 手臂穿模 | 适用 | 两臂下垂对胯、大腿 |
| 着地 / 滑动 / 重心 | 适用 | 两脚锁定 |
| 两手相触 | 不适用 | — |
| 循环接缝 | 不适用 | 保持动作 |

**规模目标**：22 骨，约 250–400 个关键帧（参照轻身跃步 0.40 s 保持剪辑 379 个）。

**接触表**：0、0.06、0.12、0.20、0.30、0.40、0.50、0.65、0.80，另加 1.60（保持中）共 10 个时刻；与架势并排。
