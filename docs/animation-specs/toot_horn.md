# toot_horn：号角举到嘴边，吸气后长吹

> 审阅状态：待审阅（2026-10-22，第三批，由 use_item 按原版 ArmPose 拆分）。轴向、坐标和数值来源见 [共用约定](conventions.md)。
> 数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：原版 `ArmPose.TOOT_HORN`（`UseAction.TOOT_HORN`）：使用山羊角期间。号角声在开始使用时播放一次。
- **触发**：`armPoseAction` 的 `TOOT_HORN` 分支；副手使用应选 `toot_horn_off`。
- **驱动**：山羊角使用时长由乐器决定（原版 140 tick），按 `1 − 剩余/最大使用时间` 会把 0.33 s 的举号拉成近 1 s。剪辑时间应取**已使用时长**：`t = min(已使用 tick / 20, 2.60)`，之后保持末帧。
- **视线俯仰**：原版手臂俯仰 = 头俯仰 − 80°。本剪辑按平视制作，运行时需把视线俯仰加到头 X 和右上臂 X 上。
- **结束**：停止使用淡出 0.15 s。

## 2. 时间轴

剪辑长度 **2.60 s**，`loop: "hold_on_last_frame"`。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.06 | 右手下沉 7°，腰胸前屈 1°，头低 3° |
| 举号 | 0.06–0.33 | 腰、胸先后仰，右上臂上举到 88°（过冲 3°），肘先屈到 46° 再伸到 24°，腕把吹口送到嘴上、喇叭口朝前上 |
| 吸气 | 0.33–0.60 | 胸后仰 1° → 4°、腰 0.5° → 2°（胸廓扩张），胯上提 0.1 px，左臂外展到 23° 打开 |
| 长吹 | 0.60–2.40 | 胸慢慢回收到前屈 2°、腰到 −1.5°，胯下沉 0.35 px；头从 3° 上扬到 9°，号角随之抬高；左臂慢慢放回 16° |
| 保持 | 2.40–2.60 | 气吹尽的姿态，保持到停止使用 |

时间线：无事件。

## 3. 分阶段全身姿势

腰、胸后仰峰值 0.083 / 0.117 s，右上臂 0.133 s，右前臂与手 0.25 s。双脚全程全掌着地。

- **吹口位置**：山羊角使用中显示 `tooting_goat_horn` 模型，换算到 `r_item` 局部后吹口约在 (2.72, 4.46, −1.75)、喇叭口约在 (−0.15, 0.36, −3.0)。每个关键姿势都按“吹口在嘴前 (0, 25.6, −4.3)（头局部）、号身朝前上 15° + 头俯仰”求右臂：
  举号到位 (84.8, −18.0, −20.4) / 肘 23.8 / 腕 (−16.2, 4.5, −1.3)；吸气 (85.7, −17.3, −21.5) / 23.9 / (−16.8, 5.0, −0.7)；吹尽 (90.4, −9.4, −31.1) / 26.9 / (−19.8, 9.9, 0.3)。全程吹口离嘴最远 0.51 px（1.0 s）。
- **胸廓起伏**：吸气时胸、腰后仰合计 +6°，长吹时 1.8 s 内回收到 −3.5°；头反向上扬，脸和号角越吹越抬高。
- **左臂**：吸气时外展到 23°、肘屈 34°，像吹奏时张开的另一只手；长吹中慢慢收回。
