# equip_boots：弯腰抬膝，双手把靴子套到抬起的脚上按实，落脚；左右脚各一次

> 审阅状态：待审阅（2026-10-22，第二批退回后重做）。轴向、坐标和数值来源见 [共用约定](conventions.md)。
> 数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：靴子槽从空变为有物品时，演出“双手捧靴弯腰 → 抬右膝把右脚送到手边 → 双手把靴子套上、往上按实 → 落脚踩稳 → 换左脚同样一遍 → 直起身低头看”。
- **触发与驱动**：`playArmorEquip` 检测到靴子槽空 → 非空时按世界时钟播放；原版没有穿戴进度。副手持盔甲时播 `equip_boots_off`（本稿镜像）。
- **Minecraft 体型的限制**：Steve 手臂短，肩枢轴到腕枢轴伸直也只有 7 px，站着弯腰摸不到地上的脚。所以这里是把脚抬起来、斜送到身前中线附近（右脚抬到左膝前方），
  上身前屈约 87°（腰 40° + 胸 47°），双手才能握住靴筒口。各关节都在门禁上限内，单脚支撑时按节段质量加权的重心始终在支撑脚范围内。

## 3. 分阶段全身姿势

腰比关键时刻早 0.01 s，胸晚 0.01 s，头晚 0.02 s；手臂在握靴的帧按靴筒口两侧的目标点求解，并加了“前臂、手不得进入头/胸/腰/胯包围盒”的约束；
悬在身前的帧直接手摆（上臂前屈约 100°、外展、肘近直）。着地腿由胯的姿态做脚底锁定，相邻胯关键帧之间补锁定帧；抬起的腿手摆，离地和落地各加一帧“脚底水平、垂直抬高”的 IK 帧。
