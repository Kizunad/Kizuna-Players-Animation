# use_item：通用使用物品（举到胸前看着它）

> 审阅状态：待审阅（2026-10-22，第三批）。只作为**没有专属 ArmPose 的普通物品使用兜底**：望远镜、号角、弩和刷子使用各自已交付的动作；吃、喝、拉弓、三叉戟和格挡暂不接入自定义动作，继续使用原版姿态。
> 轴向、坐标和数值来源见 [共用约定](conventions.md)。数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：`UseAction.NONE` 等没有专属姿势的持续使用（模组物品为主）。
- **触发**：`armPoseAction` 的 `default` 分支，主手 `use_item`、副手 `use_item_off`。
- **驱动**：剪辑时间取**已使用时长**：`t = min(已使用 tick / 20, 0.40)`，之后保持末帧；不按最大使用时间归一化（通用物品常为 72000 tick）。
- **结束**：停止使用淡出 0.15 s。

## 2. 时间轴

剪辑长度 **0.40 s**，`loop: "hold_on_last_frame"`。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.06 | 腰、胸后仰 1.2° / 1.5°，右手下沉 5°，头抬 2° |
| 举起 | 0.06–0.30 | 腰、胸前屈并右转，右臂把物品举到胸前（肘屈到 83°，过冲 3°），腕把物品面转向脸；头低到 −19° 看着物品 |
| 保持 | 0.30–0.40 | 回落到 80°，保持 |

时间线：无事件。

## 3. 分阶段全身姿势

- **保持姿态**：右上臂 (21.2, −34.8, −16.0)、肘 80°、腕 (−30, −12.8, −14.6)：`r_item` 在 (−2.7, 19.1, −7.7)，胸前偏右；原版平面物品（`generated`）换算后物品平面是 `r_item` 局部 XZ，法线（局部 +Y）朝向脸（与“朝上后方”偏差 15°）。
- 头低 18°、左转 3°；胸前屈 3°、右转 2°，腰前屈 2°、右转 1°；胯后坐 0.3 px、右转 1°。左臂自然垂在身侧，肘屈 16°。

## 5. 运动链错峰

腰 0.117 / 胸 0.150 / 右上臂 0.233 / 右前臂 0.233 / 右手 0.267 s。

## 6. 重心与支撑

双脚全掌着地。质量加权重心 x 0～0.03 px，z −0.33～0.06 px；门禁按方块角点平均的重心也在支撑内。

手、前臂与躯干间隙：右前臂上举时擦过胸前 −0.26 px（0.217 s）；分析器的手臂穿模门禁通过。

## 8. 索引条目与叠加

`mask: full`、`priority: 15`、`blend_in: 0.08`、`blend_out: 0.15`、`hand: main`、`fpv: false`。底层为 walk / run / sneak 时只取 `upper`。

## 9. 与其他状态的衔接

见 [transitions](transitions.md)：`use_item` 可叠加在站立、行走、原版潜行姿态和骑乘上；游泳、攀爬默认禁止。
