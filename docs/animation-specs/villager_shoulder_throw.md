## 3. 制作实测（2026-11-16）

- **转身、回身是小垫步，不是原地碾脚。** 草稿照动作稿做的是右脚脚尖点地碾转：踝点在着地中移动 1.7 px，门禁按踝点位移算滑动（上限 0.5），本仓没有碾脚窗口。
  进 PA 时把右脚在 1.27–1.97、2.93–3.66 两段抬离地面 0.55 px，位置和朝向照原动作走；转身那一步在空中就把脚转到位，落地即踩平（原来落地后脚跟还要再落 0.77 px）。
  结果是两次转身各有约 0.4 秒两脚同时离地，看起来是小跳转身。
- 两次转身后各有一段只有左脚着地、重心不在左脚上方，声明失衡窗口 `[1.68, 2.00]`、`[3.40, 3.72]`。动作稿列的弓腰翻摔段 `[2.00, 2.70]` 实测重心在两脚之间，不用声明。
- `phases` 只登扛起翻摔 `[1.70, 2.60]`。动作稿还列了探抓末尾那一拽 `[1.00, 1.20]`：那是两手先拽、腰后跟，登了门禁不过，所以不登。
- 细臂的右前臂在回身收手时（3.70–3.77 s）穿进腰 1.8 px（粗臂没有）：在 3.55–3.90 s 把右臂解开，两套几何实测穿入都是 0。
- 胯绕竖直轴转 180° 再转回，不动 `root`。

## 4. 没验证的

- 摔不动时改播「一靠」没做（见 PROGRESS）。
