# 动作设计稿的共用约定

所有 `docs/animation-specs/<id>.md` 的关键帧数值都是 **Blockbench 动画面板值**（度 / 像素），也就是录入
`models/player_skeleton_classic.bbmodel` 的值；导出 JSON 时由 `scripts/export_bbmodel_animation.py` 统一把
旋转 X/Y、位移 X 反号，设计稿不写导出值。

## 坐标

- 像素单位，脚底原点，Y 向上，前方 −Z；**角色右侧为 −X**（见 [资产契约](../asset-contract.md)）。
- 欧拉顺序 ZYX：矩阵 `R = Rz·Ry·Rx`。读法上等价于“先在父空间绕 X 屈伸，再绕父空间竖直 Y 转，最后绕父空间前后 Z 转”。
  大角度时三个轴会互相影响，设计稿的姿势都经过正向运动学核对，不能按单轴含义随意改其中一个分量。
- Blockbench 空间到游戏是 Y 反射（`Rig.toVanilla`），所以游戏里看到的是 Blockbench 视口的镜像。
  设计稿里的“右手”一律指 `r_*` 骨，即游戏内玩家的右手。

## 各骨轴向含义（面板值正方向）

| 骨 | X 正 | Y 正 | Z 正 |
| --- | --- | --- | --- |
| `pelvis` / `waist` / `chest` | 后仰（负为前屈） | 向右转（右肩后撤） | 向右侧屈 |
| `head` | 抬头 | 向右转头 | 向右歪头 |
| `r_upper_arm` | 前屈上举（负为后伸） | 外旋；手臂前举时为水平外展 | 内收（负为外展） |
| `l_upper_arm` | 同上 | 内旋；手臂前举时为水平内收 | 外展（负为内收） |
| `*_forearm` | 屈肘，单向 0°～150° | 屈肘时会改变屈肘平面，**不是旋前**；仅在近伸直时近似前臂扭转 | 不使用 |
| `r_hand` | 桡偏（手指朝拇指侧/前方） | 旋后（负为旋前） | 掌屈（负为背伸） |
| `l_hand` | 桡偏 | 旋前（负为旋后） | 背伸（负为掌屈） |
| `r_thumb` / `r_fingers_*` | 指尖向前（拇指桡侧外展） | 不使用 | 屈指握拳 |
| `l_thumb` / `l_fingers_*` | 同上 | 不使用 | 负值为屈指握拳 |
| `*_thigh` | 屈髋（腿前摆） | 右腿外旋 / 左腿内旋 | 右腿内收 / 左腿外展 |
| `*_shin` | 负值为屈膝，单向 0°～−150° | 不使用 | 不使用 |
| `*_foot` | 背屈（脚尖上翘） | 随大腿外旋补偿 | 内外翻补偿 |
| `*_toe` | 脚趾背伸（蹬地） | 不使用 | 不使用 |

握剑时剑刃从拇指一侧伸出，与前臂约成 80°（由原版 `handheld` 第三人称 display 推算：刃尖在 `r_item`
局部约 `(0, −1.2, −13.5)` px，剑首约 `(0, 2.2, 5.5)` px，待 `calib_item` 游戏内校准）。手腕 Z 只让剑刃绕
自身转动；改变剑刃与前臂夹角靠手骨 X（桡/尺偏），改变剑刃绕前臂的朝向靠手骨 Y（旋前/旋后）。

## 设计稿怎么来的

- 关键姿势按动作逐段手摆，再用正向运动学核对手、肘、剑尖、脚底和重心位置，并渲染三视角预览确认。
- 站立动作的支撑腿数值由“胯的设计姿势 + 脚底锁定”求出（相当于 Blockbench 的 IK），取一位小数，
  目的是保证脚不滑、不穿地；胯怎么移、移多少、何时移由设计决定。
- 每根骨有自己的关键帧时刻：近端先到、远端后到，不同骨的峰值时刻按运动链错开。不允许把一条曲线乘系数套到多根骨上。
- 插值默认 Catmull-Rom；首尾帧必须是动作的起止姿态，一次性动作首尾的速度为零（首尾相邻帧只做缓入缓出）。
- 设计稿里的门禁数值是用设计期原型轨道跑 `scripts/analyze_animation.py` 的同一套计算得到的；录入
  `.bbmodel` 之后必须重新导出、重跑门禁并以实测值为准。
