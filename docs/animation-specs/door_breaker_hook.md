## 1. 动作目的与触发

- **用途**：破门斩第四式，对付举盾的人：
  - 斧子举到盾沿上方，悬住；
  - 腕、肘一压，斧头越过盾上沿向下一勾，用斧刃下角（胡）挂住盾沿；
  - 后脚撤一大步，全身后坐、躯干回转，像拔河一样把盾拽下来，空手拳同时往前顶。
  - 全套唯一往回拉、唯一撤步后坐的式。
- **与前三式的区别**（交接的区分原则）：

  | 式 | 单手 / 双手 | 轻 / 重 | 发力方式 |
  | --- | --- | --- | --- |
  | 叩门 | 单手 | 轻 | 小臂向前短促连敲 |
  | 破门 | 双手 | 重 | 站定全身向下劈 |
  | 撞门 | 单手 | 重 | 身体向前冲撞，再回身横撩 |
  | **破盾** | **单手** | **先轻后重**：腕、肘一勾要小、要准；拽是全身的重 | **向后**：撤步、后坐、躯干回转把盾拽回来 |

  - 与叩门同为单手。叩门的力向前、只用小臂；破盾的击中是向前下的一勾，主要力量在击中之后的后拽。
  - 不举过肩：「探」的拳在肩下约 1.4 px（第 8 节第 2 条）。
- **触发**：功法 `meridian_door_breaker:hook` 起手时，宿主（Human）调用 `PlayerAnimationAction.DOOR_BREAKER_HOOK`，按真实时间播放，用 `start_tick` 同步起点。持物手是副手时播 `door_breaker_hook_off`（第 7 节）。
- **时长**：剪辑 **4.5 s**（90 tick），`loop: false`。
  - 起手 0–2.05 s；
  - `hit` 2.05 s（服务端此刻结算、破盾）；
  - 收势 2.05–4.50 s。
- **承接**：
  - 叩门 → 破盾：目录里破盾唯一的前式是叩门（叩门收势过半起，`start_millis: 400`）。宿主把 `start_tick` 前推 8 tick，从 **0.40 s** 起播，跳过预备段。0.40 s 的姿势必须是「预备做完、还没撤步」。
  - 目录里没有以破盾为前式的式，收势后半段不需要承接别的式。仍按通则：收势前半段（2.05–3.27 s）里脚回位，3.20 s 落回架势踝位。
- **打断**：起手不能被伤害打断。宿主若因其他原因停止播放，淡出 0.20 s 回架势（资源不另做打断段）。
- **时间线事件**：
  - `0.8: step_r`：后脚外撤落地；
  - `2.05: hit`：客户端通知，不授权伤害；
  - `2.4: step_r`：后脚后撤落地（设计 2.35，制作时推后，第 11 节第 1 条）；
  - `3.2: step_r`：后脚收回架势位。

## 3. 分阶段全身姿势

数值为面板值或模型空间位置（像素，脚底原点，右侧 −X、前方 −Z）。「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量。斧子几何同渲染器 `AXE_*` 常数：原版握法下刃口约沿手的远端方向（顺前臂指向拳外），柄沿拇指方向。「斧刃下角」（胡）取斧刃靠柄的一角，挂点局部 `AXE_GRIP_CENTER + AXE_ALONG·2.4 + AXE_EDGE·4.2`，钩盾沿就用它。

### 起点与终点（0.00 s、4.50 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。架势里斧子竖在头右侧（拳 `(−4.4, 22.6, −7.6)`），左拳在 `(4.3, 23.6, −10.2)` 护下巴；后膝 75°、前膝 58°；重心 z −0.9。

### 预备（0.00–0.40 s）

- **胯**：位移相对架势 `(0, −0.1, −0.2)`（0.30 s），旋转 Y −2°（0.25 s）。

### 收（2.90–4.50 s）

- **重心前移**：2.90–3.00 s 胯前移到相对架势 z +2.0，重心回到两脚间；前脚 2.90–3.00 s 放平。
- **后脚**：2.95 s 离地（离地约 0.5 px），向前上步收回架势踝位 `(−1.7, 1.72, 3.2)`，3.20 s 落地（`step_r`），恢复架势提踵。此后腿脚不再动。
- **胯 / 腰 / 胸 / 头**：3.20 / 3.30 / 3.40 / 3.50 s 起依次回正，3.90 s 回架势。
- **呼气**：3.40–4.20 s，胸 X −1.5° 叠在回位上。
- **主手**：3.00–4.10 s 把斧子由右胯旁经身前收回头侧持物位，4.20 s 到位。
- **左手**：3.20 s 起回下巴前护位，3.80 s 到位。
- 4.20–4.50 s 全身静止，4.50 s 等于 `stance_idle` 首帧，速度为零。

### 不动的部位

- `root`：模型空间不推 root。破盾没有冲量，位移只由玩家 0.4 倍主动移动负责。
- `r_item` / `l_item`：挂点，不允许轨道。

1. **钩靠腕下压加屈肘，用斧刃下角挂**。

## 11. 制作结果

关键帧由原型 `~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/d_hook.py` 求出，`install_hook.py` 写入 `.bbmodel`，再用仓库导出脚本导出并登记索引。

**做法**：
- **每个通道写成「移动」序列**：
  - 每段移动是（起、止、目标），按最小抽搐曲线走，两端速度、加速度为零；重叠的移动按增量叠加。
  - 先按 60 Hz 采样设计曲线，再删减关键帧，删减时导出的 Catmull-Rom 插值要贴合设计曲线（旋转 ≤ 0.15°、位置 ≤ 0.005 px、腿 ≤ 0.10°）。
  - 原因：直接把稀疏的设计关键帧当导出关键帧，均匀参数 Catmull-Rom 在长短段相邻处速度会跳变。钩前后的保持段抽搐超限，拽段峰值顺序也乱。
- 躯干（胯位置 / 旋转、腰、胸、头）按相对架势的增量给出，每根骨有自己的起止时刻。
- **持物臂**：
  - 关键姿势（探、钩、拽）按「拳 + 柄线 + 刃口朝向」求 7 自由度，初值取探针解；
  - 上臂、肘、腕各自起止，近端先起动；
  - 定段微蓄、钩后余势按关节增量叠加。
- **拽段压高修正**：腕角不动，只调上臂和肘，把斧刃下角的高度拉回余势末到拽到位的连线。修正量做成 2.21、2.30、2.39 s 三个鼓包，半宽 0.12 s。
- 空手臂按挂点位置求，腕角保持架势护手拳形。
- **双脚逐帧 IK（1/60 s）**：
  - 后脚三次迈步，摆动脚轨迹同撞门（离地、触地前后只做竖直运动），着地时脚趾前缘锁定；
  - 前脚拽时绕脚跟翘起脚尖。

**与上文设计值的出入**（设计值没改，以这里为准）：

1. **后撤步改为 2.14–2.40 s**（设计 2.10–2.35），时间线 `2.4: step_r`。
   - 后脚落地推后、脚跟放低（第 2 条）以后，后小腿下沿才不压地。
2. **后脚着地时脚跟放低**：
   - 外撤落地、收回起步前，后脚底俯仰 −28°；后撤落地 −18°，2.60 s 再提回架势的 −35°。设计是着地全程保持提踵 −35°。
   - 探时 −36°、钩时蹬到 −32°，同设计。
   - 原因：落地那一刻后膝屈得深，保持 −35° 时后小腿下沿压地，超过 0.25 px 容差。提踵加大反而更压地（同撞门第 2 条：这副骨架脚只有约 1 px 长）。
   - 外撤落地试过 −24°：后脚滑动升到 0.503 px，超过 0.5。
3. **调整段胯升高 0.30 px**（设计回到 0）。不抬时副手版外撤落地后最低点 −0.248 px，贴着容差。
4. **拽段的腰、胸、持物臂都提前**，胯的回转单独提前：
