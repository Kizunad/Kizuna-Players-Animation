# wayfarer_parthian_off：回马（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-11-01），实测与出入见文末「制作实测」。随主手页 [wayfarer_parthian](wayfarer_parthian.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9，射位见 C4 副手版，转身口径见待决定第 4 条。本页只写与主手版不同的地方。

## 做法

- **时间轴、窗口**：与主手版相同（5.0 s；爆发窗口 `[1.36, 1.44]`、失衡、滑行窗口 `[0.80, 2.10]`、瞄准、`phases` 都不变），`hand: off`。落地两脚的先后对调，事件见下。
- **转身方向随上身镜像**（C9；主手版按待决定第 4 条甲向左转）：
  - 预备胯 Y −3°；**转身向右**：胯世界 −15° → +160°（175°，梯形角速度同主手版），仍绕**左踝**竖线转；
  - 头一直对着目标，腰、胸、颈相对胯向**左**扭到 −40 / −52 / −68°，从**左肩**上方回看；
  - 空中**向左**解开扭转：胯 +160° → +25°（副手射位），头先到、胸、腰、胯依次跟上。
  - 同样不转整圈，不用 `root`。
- **腿**：
  - 转身：左脚绕踝竖线碾 175°；右脚 0.37 离地，随身体**从左脚身后**绕过来（主手版从身前），**0.75 以前脚掌落在约 `(6.8, 1.7, −8.0)`**（`step_r`，估算），在身体后方（目标那一侧）；
  - 背身跑、起跳的脚序同主手版：`step_l` 1.00、`step_r` 1.30，右脚 1.36–1.44 蹬地起跳；
  - 落地成副手射位（左前右后，脚尖右转 40°）：**1.85 左脚、1.88 右脚相继全掌落地**（`step_l`、`step_r`），左踝 `(2.3, 1.0, −2.6)`、右踝 `(0.2, 1.0, 1.4)`；
  - 收：2.60–3.00 左脚碾回，右脚抬起，**3.00 以提踵落回架势踝位**（`step_r`）。
- **双臂**：弓在左手、转到身体左侧，弓梢朝下；1.10–1.20 右手横过身前摸到弦上，1.20 搭箭；之后同主手版左右对换。
- **物品**：`item_states` 与主手版相同，挂在副手。

## 与主手版不同的约束

- 右脚 0.37–0.75 绕左踝转 175°（半径约 7 px），弧长与主手版相同，只是从左脚身后绕过、终点偏左约 1.4 px；架势右脚在左脚右后方，向右转时一开始就朝身后摆，不会碰到左脚。
- 0.75 的右脚落点是按「绕左踝向右转 175°」估的，未探针。

## 门禁

适用项同主手页第 9 节；握持查左手握弓、右手勾弦；错峰主链换右臂（C12），预备 / 跟随用左臂链；转身段 `phases` 的腰 → 胸顺序不变。

改主手版后必须用同一原型重新生成本段，不允许只改一边。

## 制作实测（2026-11-01）

与主手版同一原型生成（`d_parthian.py` 的副手分支），索引字段同主手页第 10 节（同样没有 `burst_windows`），时间线同上文。门禁全部通过（粗、细臂相同）：关键帧 1,608；最快 668°/s（右手手指 2.15 s），抽搐最大 1.40×10⁶°/s³（左小腿 1.02 s）；最低点 −0.199 px（右小腿 2.00 s）；重心出界 0.82–0.90、1.35–1.48、1.82–1.83、2.70–2.92 s（都在失衡窗口内）；支撑脚滑动右 0.36、左 0.25 px；手臂穿模 0；预备 / 跟随 3/5 骨（左前臂、左手没过）。错峰：转身段腰 0.567 → 胸 0.600 → 右前臂 0.633 → 右手 0.667 s（右上臂段内主轴不到 3°，没判到）；拉满段同主手版（腰 1.933 → 胸 1.950、右前臂 1.933 s）。自查：头世界偏航 −0.7…+0.9°；转身时左踝漂移 0.023 px；双脚离地 1 px 以上只有 1.53–1.67 s（窗口内最低 0.16 px，同主手版的出入）；1.88 s 两脚朝向 +40.0°、两踝离副手射位 0.0 px；弦手离锚点 0.009 px。

与主手版不同的地方：
- **转身是 151° 不是 175°**：架势胯 +12° 不镜像，预备反向（左）3° 到 +9°，再右转到 +160°（上文写 −15° → +160° 是按镜像绝对值估的，与架势对不上）；腰、胸、颈相对扭 −41 / −51 / −68°，空中胯 +160° → +25°；
- 0.75 s 右脚落在 `(8.61, 1.73, −5.73)`、胯位 `(4.78, −1.8, −4.2)`（上文按转 175° 估 `(6.8, 1.7, −8.0)`）；
- 落地左脚先（1.85）、右脚后（1.88），成副手射位，同上文。
