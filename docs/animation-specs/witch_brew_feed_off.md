# witch_brew_feed_off：熬药副手下料覆盖层（左臂，0.6 s）

> 状态：**规格已审**（2026-11-02，待决定全部按建议），还没有关键帧，等 B1 并入后制作。轴向、坐标和面板值约定见 [共用约定](conventions.md)；主剪辑见 [witch_brew](witch_brew.md)；共用约束 W1–W13 与待决定见 [PROGRESS-witch](PROGRESS-witch.md)。
> 来源：动作稿 `21-Players-Animation-Witch.md` §4.3「副手下料」、§6；服务端 `22-Brewing-Addon.md` §4.10（熬的时候副手右键照常有效：下料、添水、加炭、拨灰）。
>
> **资源 id**：`witch_brew_feed_off`；`mask: l_arm`、`hand: main`（左主手镜像后接管右臂）。
> **与动作稿最大的不同**（待决定第 12 条）：
> - **只做一种**：伸到釜口上方，手腕一翻再收回。动作稿的第二种「往下伸到火那一层（加炭、拨灰）」先不做：宿主要分出这次右键是下料还是加炭就得再加接口；而且火在釜下面一层，覆盖层只管左臂、上身不能跟着弯，从胸高的肩往下伸够不到（没探针，按五脏诀探针的臂长 7–10 px 估）；
> - **手指不松开**：副手拿着料时宿主叠了副手握持覆盖层（同优先级 25，同为握拳），这段手指保持架势左拳。物品是物品渲染，松开手指东西也不会离手，看着反而像没拿住。

## 1. 动作目的与触发

- **用途**：熬药时副手每右键用一次（下料、添水、加炭、拨灰），左手从釜沿抬起伸到釜口上方，手腕一翻，收回釜沿。右手照常搅。
- **触发**：宿主在熬药中副手右键生效的那个 tick 调用 `PlayerAnimationAction.WITCH_BREW_FEED_OFF`，按真实时间播放；连续用时每次重播（同 id 重播从头开始，旧实例淡出）。熬药被打断或播完时宿主一并停止。
- **时长**：剪辑 **0.6 s**（12 tick），`loop: false`。
- **时间线事件**：无。

## 2. 时间轴

| 段 | 剪辑时间 (s) | 左臂与手 |
| --- | --- | --- |
| 抬 | 0.00–0.20 | 由釜沿高度 `(3.5, 20, −8)` 抬起前伸到釜口上方约 `(2.5, 22, −11)`，前臂先微沉 1°（预备） |
| 翻 | 0.20–0.38 | 手腕向内下翻约 40°（前臂旋前加腕屈），像把东西倒进去；0.30 翻到最深 |
| 收 | 0.38–0.60 | 回到釜沿高度，掌心朝下 |

- 首帧、末帧都是主剪辑里左手停在釜沿高度的姿势（[witch_brew](witch_brew.md) 第 3 节）：叠在扇、闻、进式、收式上时，覆盖层的首末帧和主剪辑不同，靠 0.10 / 0.25 淡入淡出过渡。
- 手型：手指保持架势左拳面板值（W2）；拿着东西时副手握持覆盖层同为握拳。

## 3. 姿势

- **左上臂**：0.00–0.20 前屈加约 20°、外展减约 5°；0.20–0.38 不动；0.38–0.60 回。
- **左前臂**：0.00–0.05 微沉 1°（反向），0.05–0.20 伸肘约 15°；0.38–0.60 回。
- **左手**：0.20–0.30 旋前约 25°、腕屈约 15°；0.30–0.38 停；0.38–0.55 回平。
- 错峰：上臂 0.10 → 前臂 0.14 → 手 0.26（只有一条臂，分析器不查错峰，见第 6 节）。

## 6. 门禁适用项

照破门斩握持臂覆盖层（`ARM_OVERLAY_IDS`）的口径：

| 门禁 | 适用 | 说明 |
| --- | --- | --- |
| 覆盖臂三骨 | 适用 | 加入 `ARM_OVERLAY_IDS`，值 `"l"`；左上臂、左前臂、左手都 ≥ 3° |
| 肩 → 肘 → 腕错峰重叠 | 适用 | 见第 3 节 |
| 躯干链 / 头、双腿、预备、主链峰值、握持 | 不适用 | 覆盖层只接管左臂 |
| 角速度 / 抽搐 | 适用 | 翻腕约 250°/s |
| 手臂穿模 | 适用 | 左前臂对胸（叠在闻上时由主剪辑的躯干决定，制作时叠合抽查） |
| 循环接缝 | 不适用 | 一次性 |

**自查**：叠在主剪辑四个时刻（搅、扇、闻、进式末）上合成预览，看淡入淡出有没有跳。

**规模目标**：3 骨（加 3 根手指骨常数），约 30–50 个关键帧。

**接触表**：0、0.10、0.20、0.30、0.45、0.60 六个时刻；另出叠在 `witch_brew` 搅段（t = 2.0）上的合成 GIF。
