# guard_weapon_hit：横架受击回震

> 原速 250 ms，5 tick，单次覆盖在[横架保持](guard_weapon.md)之上。

## 1. 目的与触发

宿主确认这一下由兵器挡住时播放。第一眼应看见胸前横着的兵器猛地往回一震，两手随它后让，头胸稍迟才动。随后回到守位，持续抱架仍按原来的时钟呼吸。

## 2. 关键姿势与支撑

首姿、末姿都逐骨取抱架 0.40 s 的横架基准。最深处保留主手握柄、副手贴住剑根平面或斧柄的轮廓，腕间距离稳定，两肘随兵器向身侧收。侧面能看见兵器明显后移、下颌与胸口仍和它隔开；正面仍能认出横着的剑身或斧柄。重量稍移向后脚，后膝吸收下沉，前脚全掌和后脚前掌留在原位。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 画面 |
| --- | --- |
| 0–50 ms | 兵器和接触它的两手先向后短移，肘跟着屈。胸肩随后让，第一拍能看见剑或斧整体受压，副手仍贴住。 |
| 50–100 ms | 胸口、头和胯依次收到这一下，后膝再沉。至 100 ms 兵器后坐到最深，斧头边缘仍在脸和副手手背之外。 |
| 100–200 ms | 后脚撑稳，腰胸先回，肩肘带两手和兵器向原守位回弹，横向轮廓保持清楚。 |
| 200–250 ms | 双腕、肩和下颌缓停，重量回到两脚之间。250 ms 收回横架基准，露出底层此刻的呼吸姿势。 |

## 4. 播放、覆盖与衔接

`loop: false`、`reaction: hit`、`priority: 16`，淡入 0.03 s、淡出 0.05 s。100 ms 标记最大后让，动画不发命中事件。受击层结束只退这一层；再挡中一次就重播短反馈，两次受击共用底层保持的起点。受击途中收势时两层一起停止，再播[放下](guard_weapon_lower.md)。

`mask: full`。站定时头胸、胯膝、踝与双臂都参与后让和回稳，`root` 固定；移动时取 `upper` 的腰、胸、头和两臂至手指，胯、腿和脚趾继续走。`hand: main`，左主手镜像时托点跟着换侧；`fpv: false`，沿用全身第一人称，兵器的进退应可辨。

## 5. 审片与验收

粗臂、细臂各持铁剑和铁斧，原速能看见每一次回震。接触表并看起点、最深处和回稳，侧面查兵器到下颌、胸的余量，斜面查副手始终贴住且避开刃口，特别查看斧头较宽的一侧。连续从不同呼吸相位触发两次，随后放下，检查受击之间仍在原呼吸相位、每次后让和回弹都可分辨。
