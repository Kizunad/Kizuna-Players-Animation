## 1. 动作目的与触发

- **用途**：双手武器与**空手**（审阅决定 Q11：空手一律用本 ID）的双手上架：两前臂在面前交叉成 X（左腕在外上、右腕在内下），交叉点在下颌右前；持双手武器时武器随 `r_item`，左手托在主手腕外侧。补上 `block_shield` 设计时留下的“通用单手/双手格挡”缺口；持盾仍用 `block_shield`。
- **触发**：调用方给出“格挡中”状态（原版没有通用格挡，按键与判定都在战斗 UI / Human，本轮不接线）；持续到调用方结束格挡。选择：主手单手武器 → `block_one_hand`；双手武器或空手 → `block_two_hand`；副手持盾 → `block_shield_off`。
- **受击反馈**：拆成独立 ID [block_two_hand_hit](block_two_hand_hit.md)（审阅决定 Q10），叠在本保持段之上播一次，回到同一保持姿态。
- **时长**：剪辑 **1.95 s**，`loop: "hold_on_last_frame"`，`loop_region: [0.35, 1.95]`：0.00–0.35 举起（格挡开始后的真实时间），0.35–1.95 保持循环（1.6 s 一次呼吸）。
- **结束**：格挡结束淡出 0.15 s 回当前架势底层。
