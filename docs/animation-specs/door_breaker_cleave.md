## 1. 动作目的与触发

- **用途**：破门斩第二式，双手全身重劈，照劈柴的要领：
  - 先加宽站距；
  - 双手把斧子竖到右颊旁，躯干右拧蓄力；
  - 屏气定住，再由后脚蹬、沉胯屈膝、躯干回转卷腹，从右上往左下斜劈过身体中线，腰高劈进门板；
  - 斧子嵌住拔不出，上下晃两下，后坐一撬才拔出来；
  - 全套唯一「卡住」。
- **与叩门的区别**：叩门是单手、小臂短促轻敲，斧子不过肩、躯干只拧 20°；破门是双手、由腿到斧整条链发力，躯干拧满 35° 再整个折下去（用户 2026-10-29）。
- **触发**：功法 `meridian_door_breaker:cleave` 起手时，宿主（Human）调用 `PlayerAnimationAction.DOOR_BREAKER_CLEAVE`，按真实时间播放，用 `start_tick` 同步起点。持物手是副手时播 `door_breaker_cleave_off`（第 7 节）。
- **时长**：剪辑 **6.0 s**（120 tick），`loop: false`。起手 0–3.20 s，`hit` 3.20 s（服务端此刻结算，同时劈门）；嵌门、晃撬、收势 3.20–6.00 s。
- **承接入口 0.40 s**：叩门、撞门等之后接破门时，宿主把 `start_tick` 前推 8 tick，从 0.40 s 起播，跳过预备段。0.40 s 的姿势必须是「预备做完、还没开始调整」。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势（动作稿 §4），由宿主停止播放实现，资源不另做打断段。
- **时间线事件**：
  - `0.85: step_l`：前脚斜滑半步落地；
  - `3.2: hit`：客户端通知，不授权伤害；
  - `4.5: step_l`：前脚收回落地。
  - 后脚全程不离地，不发 `step_r`。

## 3. 分阶段全身姿势

数值为面板值或模型空间位置（像素，脚底原点，右侧 −X、前方 −Z）。「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量。
斧子几何同渲染器 `AXE_*` 常数（挂点局部）：柄线 `AXE_ALONG`，刃口朝向 `AXE_EDGE`。柄上位置 s 以 `AXE_GRIP_CENTER` 为零点：
- 主手拳占 s −6.5～−2.0（中心 −4.3），握在柄尾；
- 斧头从 s 2.4 起；
- 左手拳中心在 s ≈ +0.1，紧贴主手拳、正在斧头下沿（第 8 节）。

### 起点与终点（0.00 s、6.00 s）

与 `stance_idle` 首帧完全一致。首尾速度为零。
架势里斧子竖在头右侧（斧头中心约 `(−7.8, 28.4, −6.2)`），左拳在 `(4.3, 23.6, −10.2)` 护下巴。

### 预备（0.00–0.40 s）

- **胯**：位移相对架势 `(0, −0.1, −0.2)`（0.30 s），旋转 Y −2°（0.25 s，与随后的右拧相反）。
- **腰 / 胸**：Y 各 −1°，X 各 −0.5°，比胯晚 0.02 / 0.04 s。
- **头**：X −2°，Y 反向 +2°。
- **主手**：拳下沉 1 px（0.30 s），腕角不变。
- **左手**：0.25 s 起手指张开（同叩门按门的张法），拳向中线移约 1 px（0.40 s）。
- **腿**：双脚锁定。

### 调整（0.40–1.00 s）

- **前脚（左）**：
  - 0.55–0.85 s 抬离地面 0.3 px，向左前斜滑半步：踝 `(2.3, 1.0, −2.6)` → `(3.6, 1.0, −4.2)`，脚掌朝向不变，0.85 s 全掌落地（`step_l`）；
  - 两踝左右宽由 4.0 px 加到 5.3 px，前后距由 5.8 px 加到 7.4 px；
  - 0.55–0.85 s 后脚单独承重，声明失衡窗口。
- **后脚（右）**：保持架势提踵（−35°），脚趾前缘锁定。
- **胯**：位移相对架势 `(0.3, −0.5, −0.4)`（0.90 s，随步左前移、下沉 0.5 px）；旋转 Y 回到 0°（0.90 s）。
- **腰 / 胸**：回到架势（0.92 / 0.94 s）。
- **头**：盯住门。
- **主手**：0.40–0.75 s 把斧子从头侧落到右胸前：
  - 拳由右下颌前 `(−4.4, 22.6, −7.7)` 落到约 `(−5.0, 19.5, −6.0)`；
  - 斧子仍竖在身体右侧，斧头中心落到约 y 25.5；
  - 腕弯折 ≤ 40°。
- **左手**：0.60 s 起跨过胸前，0.85 s 握在主手拳正上方：
  - 位置：柄上 s ≈ +0.1，自己的柄线与主手柄线重合，偏差 ≤ 0.5 px；
  - 手指 0.75–0.85 s 合拢成握。

### 蓄 · 右拧（1.00–2.20 s）

- **腿与重心**：
  - 胯位移相对架势 `(−0.2, −0.4, 0.4)`（1.80 s）：比调整后右移 0.5 px、后移 0.8 px，重心约 60% 在后脚；
  - 双膝微屈，后脚保持提踵。
- **胯 / 腰 / 胸**（相对架势）：
  - 胯 `(+1, +15.8, 0)`（1.70 s）、腰 `(+2, +8.8, 0)`（1.80 s）、胸 `(+3, +10.5, 0)`（1.90 s）；
  - 躯干累计右拧 35°（加上架势本身的 20°，面向右前约 55°），右肩后撤、左肩转到前面；
  - 微后仰、收腹（腰 X 只到 +2°，不挺到极限）。
- **头**：`(+2, −35, 0)` 相对架势：反向左转，视线始终在门上。
- **主手**（2.10 s 到位，上臂 → 肘 → 腕依次晚 0.03 s）：
  - 拳约 `(−5.1, 18.9, −4.5)`（右胸前）；
  - 柄线约 `(−0.5, 0.8, 0.3)`：竖起，上端向右后倾；

  - 刃口点不动，斧柄绕它上下晃两下：主手腕 X ±8°、肘 ±6°，拳上下各约 1.2 px；
  - 3.58 s 上、3.66 s 下、3.73 s 上、3.80 s 回中；

- **胯 / 腰 / 胸 / 头**：4.50 / 4.60 / 4.70 / 4.80 s 依次回架势；4.60–5.40 s 一口长呼气（胸 X −1.5° 叠在回位上）。
- **左手**：5.00 s 松开（手指张开 5.00–5.10），5.60 s 拳回下巴前护位。
- **主手**：5.00–5.80 s 把斧子收回头侧持物位，5.90 s 到位。

## 4. 重心与支撑

- **0.55–0.85 s 与 4.15–4.50 s**：前脚离地，后脚（提踵，只有脚趾前缘着地）单独承重，重心在后脚前方约 4 px，超出 ±2 px 支撑范围。声明 `unbalanced_windows`，边界按原型实测出界帧各放宽约 1 帧（同轻步）。
- 其余时间双脚着地：
  - 前脚全掌；
  - 后脚脚趾前缘承重，后跟高度按第 3 节变化（−35° → −45° → −35°），绕脚趾前缘转、脚趾前缘锁定。

## 11. 制作结果

关键帧由原型 `~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/d_cleave.py` 求出，`install_cleave.py` 写入 `.bbmodel`，再用仓库导出脚本导出并登记索引。架势基准是第 2 项改后的版本。

2026-10-29 第一次交付后返修了两处（审阅意见）：
- 嵌住段刃口点逐帧锁定，漂移压到 0.3 px 以内；
- 两拳沿柄叠进 ≤ 0.5 px；左手方向偏差：定段、嵌住段 ≤ 10°，下劈与松手前 ≤ 20°。

**做法**：
- 躯干（胯位置 / 旋转、腰、胸、头）按相对架势的增量关键帧给出，每根骨自己的时刻。
- 持物臂按「拳位置 + 柄线（+ 刃口朝向）」求 7 自由度；腕关键帧在到位时刻，肘早 `lag`、上臂早 `2·lag`。
- **嵌住段（3.20–3.85 s）逐帧（1/60 s）锁刃口点**：
  - 每帧按当时的躯干、腿重解持物臂，刃口点锁在击中位置（位置权重压过其他项，求解残差 ≤ 0.003 px）；
  - 柄线按晃的曲线（三次样条，3.58 上、3.66 下、3.73 上、3.80 回中，±3°）绕刃口点转；
  - 3.20–3.26 s 绕柄轻拧 4°；
  - 斧子不动，手臂和身体去配合斧子。
- 左手在握持段逐帧把自己的虚拟柄线锁到主手柄线上、沿柄前移 4.4 px：
  - 0.05 s 一帧，下劈到嵌住段（2.95–3.85 s）每 1/60 s 一帧；
  - 刚握上（0.25 s 内）和下劈段，沿柄误差的权重加大（宁可方向偏一点，也不让两拳叠进）。
- 双脚逐帧 IK（0.05 s，两次迈步和斜劈段 0.025 s）。
- 求解时手臂与头、胸只罚真实穿入，与腰、胯外扩 0.5 px（细臂肩枢轴内移 0.5 px，前臂贴腰时细臂先穿）。
