# guard_weapon_lower：撤下横架，回战斗架势

> 原速 300 ms，6 tick，单次播放。首姿取[横架基准](guard_weapon.md)，末姿取 `stance_idle` 首帧。

## 1. 目的与触发

宿主进入收势，停止本次抱架和受击，播放下。画面先能看见托点打开，再看见主手把整件兵器带回架势位置。到结束时角色仍握着兵器，下一次起守可以从同一架势接起。

## 2. 关键姿势与支撑

起点逐骨等于抱架 0.20 s 的姿势。主手握柄，副手贴剑根平面或斧头下方的柄。肩先松，副手向下离开托点，兵器在身体前方转回主手一侧。侧面要看见副手离开后，斧头或剑身和手背之间的空隙随之变大。最后前手回到肩前的架势拳位，主手腕、所有手指、胯膝和后脚趾回到架势首姿。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 躯干与脚下 | 双手与兵器 |
| --- | --- | --- |
| 0–60 ms | 双脚保住守位，腰、肩先松，下颌仍收。 | 主手稳住柄，副手掌根脱开托点并向下退。兵器仍横在身前，能读出松托的先后。 |
| 60–210 ms | 胯随双膝伸展回架势高度，腰胸转回半侧身，头稍后跟回。 | 右肩肘撤回，腕带兵器从胸前转向本侧，远端走脸前的外弧。左手在兵器下方让过，回到肩前再合拳。 |
| 210–300 ms | 前脚全掌、后脚前掌留在原处，腰胸与头收住余势。 | 主手腕最后停稳，剑尖或斧头随握柄归位，左手恢复架势指形。300 ms 全身到达架势首姿。 |

## 4. 播放、覆盖与衔接

`loop: false`、`priority: 16`、淡入和淡出各 0.05 s，末帧交回当前架势底层。300 ms 只标记视觉归位，无玩法时间线事件。从呼吸峰谷、受击后让途中转入时，借既有停播淡出与本段淡入接住屏幕上可见的姿势。

`mask: full`。站定时全身放松、`root` 固定。移动时取 `upper`，只覆盖腰、胸、头和两臂至手指，当前步态继续驱动胯、腿和脚趾。`hand: main`，左主手整段镜像；`fpv: false`，全身第一人称下应看见副手退开、兵器退向主手侧。

## 5. 审片与验收

粗臂、细臂各换铁剑和铁斧，慢看离托和远端转回这两处。正面看先松托再撤兵器，侧面看剑尖与斧刃各自经过下颌和胸前时仍有间隙，斜面看手背和斧头分离。核对首末逐骨与共用姿势一致；连续播放再看吸气顶点收势、受击最深时收势两种衔接。
