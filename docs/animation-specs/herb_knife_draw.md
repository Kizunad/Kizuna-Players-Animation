# herb_knife_draw：切到药刀，甩腕开刃（全身，0.6 s）

> 状态：**关键帧已做，classic、slim 门禁通过，用户 2026-11-10 验收通过，关键帧不再改**（派单第八节）。下面的角度是做规格时的设计值，门禁和实测见交接目录 `handoff/herb-knife-anim-20261110/REPORT.md` 第 2 节。轴向、坐标和面板值约定见 [共用约定](conventions.md)；共用约束 K1–K8、刀刃接法、触发和十条决定见 [PROGRESS-herb-knife](PROGRESS-herb-knife.md)；刀刃剪辑见 [herb_knife_blade](herb_knife_blade.md)。
> 来源：派单第四节「切到药刀时播一次，刀刃在甩腕的那一下弹开，和刀的开合对上时刻」；参考 Bong `herb_knife_unfold`（只看节奏）。
>
> **资源 id**：`herb_knife_draw`；`mask: full`（移动中只取上身）、`hand: main`。
> **和 Bong 的不同**：
> - Bong 从右胯摸刀起手、首帧不等于末帧；这里原版换手是瞬间的，切过来那一刻刀已经在手里、手在原版持物位，所以首末帧都是原版持物位，「摸刀」改成往下沉腕蓄力；
> - Bong 的刀没有刃骨，靠腕外翻暗示开刃；这里刃真的转开，开刃由甩腕的惯性带出来，手腕的动作要对得上刃转的方向（第 3 节）。

## 1. 动作目的与触发

- **用途**：主手从别的东西换成药刀时，手腕一甩把折着的刃甩开，落回持物位。之后刀刃保持开着，直到换走。
- **触发**：Brewing 服务端每 tick 检查，主手物品由「不是药刀」变成「药刀」的那一 tick 调用 `ServerPlayerAnimations.play(player, PlayerAnimationAction.HERB_KNIFE_DRAW)`。
  上线、换维度、复活时先记下当前主手，不播；副手拿药刀不播。同一把刀切走再切回来会重播（同 ID 重播从头开始，旧实例淡出）。
- **时长**：**0.60 s**（12 tick），`loop: false`。
- **时间线事件**：无。刀刃时刻写在索引 `item_states` 里（第 5 节）。

## 2. 时间轴

| 段 | 剪辑时间 (s) | 内容 | 刀刃 |
| --- | --- | --- | --- |
| 起 | 0.00 | 原版持物位，刀在手里、刃合着 | 合 |
| 蓄 | 0.00–0.16 | 右肘折深、前臂抬起，腕往桡侧上翘（刀柄前端翻向后上）；胸腰右转一点、右肩后撤，膝微屈下沉；头低一点看刀 | 合 |
| 甩 | 0.16–0.24 | 胸先回转，上臂、前臂接着往前下甩，腕最后猛地尺偏（像锤子砸下去） | 0.20 开始转开 |
| 锁 | 0.24–0.26 | 腕急停 | 0.26 全开、锁住 |
| 过冲 | 0.24–0.34 | 腕、前臂过一点再回，胸回正 | 开 |
| 收 | 0.34–0.60 | 腿和躯干先回位，手臂后到原版持物位 | 开 |

- **刃为什么在甩的时候开**：刃绕 `r_item` 局部 X 正转是由合到开（[PROGRESS](PROGRESS-herb-knife.md) 第 7 节）。
  手腕尺偏（面板 `r_hand` X 往负走）带着刀柄绕局部 X 负转，猛加速时刃跟不上、相对刀柄正转，就是开；腕急停时刃已经到挡位锁住。所以开刃放在尺偏最快那一下（0.20–0.24），0.26 腕停时刃到位。
- **和原版挥手的衔接**：首末帧等于 `use_item` / `attack_main` 首帧，接在原版挥砍、使用前后不跳。
  开刃中左键：`attack_main`（优先级 20）盖住本剪辑（19），本剪辑在下面继续走，刀刃仍按本剪辑的轨道开（挥砍没有 `item_states`，取值时跳过）；挥砍从当前姿势用 0.04 s 淡入。
  开刃中右键切药：`herb_knife_cut`（21）接管，刀刃值在切药权重过 0.5 时直接取 1。
- **移动中**：走、跑、潜行时只取上身（`upperOverlay`），腿归移动底层；第 3 节的下沉和膝屈只在站着时出现。

## 3. 姿势

设计值，制作时由原型求解，以导出资源门禁实测为准。

- **右上臂**：0.00–0.14 前屈加约 12°、外展加约 4°（肘往前外抬，拳到右胸前下方）；0.14–0.22 回到持物位以下约 5°（往前下甩），0.195 最快；0.30 起回持物位。
- **右前臂**：0.00–0.03 先伸 2°（反向）；0.03–0.14 屈肘到约 70°；0.16–0.22 伸到约 25°（0.20 最快）；0.24–0.30 回弹到约 30°；0.60 回 12°。
- **右手**：0.00–0.15 桡偏上翘到 X ≈ +25°；0.18–0.24 尺偏到 X ≈ −25°（0.22 最快，约 650°/s）；0.24–0.28 过冲到 −28° 再回；0.40–0.60 回持物位。旋前旋后、掌屈不动。手指 0.20 收紧 4°，0.40 回。
- **胸**：0.00–0.13 右转 6°、后仰 2°；0.16–0.24 回转到左 3°、前屈 2°（0.19 最快）；0.40 回正。
- **腰**：比胸早约 0.01 s、幅度一半（右转 3° → 左 1.5°）。
- **胯**：0.12 右转 2°、下沉 0.3 px；0.30 回。
- **腿**：脚底锁定，胯下沉由两膝各屈约 3–4° 吃掉；0.30 伸回。
- **头**：0.12 低头 5°、左转 3°（抵消胸右转，眼睛看刀）；0.24 回到低头 2°；0.45 回正。
- **左臂**（平衡）：0.18–0.24 上臂外展加 4°、肘屈加 6°，随胸回转往外摆一点；0.40 回。
- 错峰（主链峰值）：腰 0.18 → 胸 0.19 → 右上臂 0.195 → 右前臂 0.20 → 右手 0.22。

## 5. 索引条目

```json
{
  "id": "herb_knife_draw",
  "file": "animations/herb_knife_draw.animation.json",
  "mask": "full", "priority": 19, "blend_in": 0.08, "blend_out": 0.20,
  "hand": "main", "fpv": false,
  "phases": [[0.16, 0.26]],
  "item_states": {"open": [[0.0, 0], [0.20, 0], [0.26, 1]]}
}
```

- 优先级 19：高于穿戴 18，低于挥砍 20 和切药 21，低于功法 24。
- `open` 线性：0.20 前保持 0，0.26 后保持 1（「首键前取首值，末键后保持」）。剪辑播完、淡出到权重 < 0.5 后不再取这层，交回物品定义的 `idle: 1`，刀刃一直开着，前后值一样，不跳。
- `upperOverlay` 要加 `herb_knife` 前缀，移动中只取上身。

## 6. 门禁适用项

| 门禁 | 适用 | 说明 |
| --- | --- | --- |
| 骨数 ≥ 10、躯干链（胯腰胸头） | 适用 | 第 3 节胯、腰、胸、头、两腿、两臂都在动 |
| 预备 / 过冲 | 适用 | 前臂 0.03 反向 2°；甩之前的蓄（屈肘、腕上翘）是反向；腕过冲 3°、前臂回弹 5° |
| 错峰重叠 | 适用 | `phases` 框 0.16–0.26 |
| 角速度 / 抽搐 | 适用 | 腕约 650°/s，≤ 720°/s |
| 手臂穿模 | 适用 | 蓄的时候右前臂靠近胸右侧，屈肘 70° 时查前臂对胸 |
| 刀对身体 | 自查 | 刀不在骨架里，门禁查不到。按第 7 节探针的刀点逐帧看刃尖不扎进大腿、胸 |
| 循环接缝 | 不适用 | 一次性 |

**自查**：刀刃和手腕的时刻一致——出 GIF 时把刀画上：`scripts/render_animation_gif.py` 已有持物道具（`PROPS`，挂在 `r_item`），行药诀用过 `segments` 类；药刀要加一种刀柄固定、刃按 `open` 轨道绕转轴转的道具，点取 [PROGRESS](PROGRESS-herb-knife.md) 第 7 节。逐帧看 0.18–0.28 刃是不是在腕甩的时候转开。

**规模目标**：全身约 20 根骨在动，约 150–250 个关键帧。

**接触表**：0、0.10、0.16、0.20、0.22、0.24、0.26、0.34、0.60 九个时刻，带刀刃。
