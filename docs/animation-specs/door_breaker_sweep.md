## 1. 动作目的与触发

- **用途**：破门斩第五式，被围时清场：
  - 斧在身体右侧前后荡一次，再向右后拉满，躯干拧紧；
  - 右脚离地，以左脚为轴，整个人原地**向左转一整圈**；
  - 右臂伸长，斧在臂长处、腰高平着领转，斧刃朝前；
  - 斧扫过正前方时打一次，扫过正后方时再打一次；
  - 转完右脚落回原位，余势带过，收回架势。
  - 全套唯一转整圈、唯一动 `root`、唯一前后两侧都打的式。
- **与前四式的区别**（交接的区分原则）：

  | 式 | 单手 / 双手 | 轻 / 重 | 发力方式 |
  | --- | --- | --- | --- |
  | 叩门 | 单手 | 轻 | 小臂向前短促连敲 |
  | 破门 | 双手 | 重 | 站定全身向下劈 |
  | 撞门 | 单手 | 重 | 身体向前冲撞，再回身横撩 |
  | 破盾 | 单手 | 先轻后重 | 向后：撤步、后坐、躯干回转把盾拽回来 |
  | **横扫** | **单手持斧，空手张开配重**（动作稿是双手，第 9 节第 1 条） | **重、长**：起手 3.35 s 是全套最长，斧整整走一圈 | **旋转离心**：右脚离地、单脚为轴、全身转一整圈，斧靠躯干拧紧后的回转与 `root` 的转动甩出去；手臂伸直不发力 |

  - 前四式的斧都只在身前一侧，力向前、向下或向后；横扫的斧绕身体一整圈，力沿圆周的切线。
  - 前四式的手臂都在发力（敲、劈、撩、拽）；横扫的持斧臂伸直锁住，肘、腕不动，力量全靠躯干和转身：离心、平、远。
  - 和单手三式比，空手的用法不同：叩门扶在身前，撞门左肩领撞，破盾左拳前顶；横扫的左臂蓄时横在胸前，转起来向外张开配重（同掷铁饼）。
  - 不举过肩、不过头：下垂到随（0.95–4.30 s）斧在腰到胸高，拳最高 y 16.7（右肩 y 20.2），关键姿势斧离头盒 ≥ 4.8 px（第 3 节）。只有起止的架势持物位在头侧。
- **触发**：功法 `meridian_door_breaker:sweep` 起手时，宿主（Human）调用 `PlayerAnimationAction.DOOR_BREAKER_SWEEP`，按真实时间播放，用 `start_tick` 同步起点。持物手是副手时播 `door_breaker_sweep_off`（第 7 节）。
- **时长**：剪辑 **6.0 s**（120 tick），`loop: false`。
  - 起手 0–3.35 s；
  - 击中一 3.35 s（服务端第一次结算，正前半圈）；
  - 生效 3.35–3.70 s，击中二 3.70 s（第二次结算，正后半圈，`hit`）；
  - 收势 3.70–6.00 s。
- **承接**：
  - 叩门 → 横扫：目录里横扫唯一的前式是叩门（叩门收势过半起，`start_millis: 500`）。宿主把 `start_tick` 前推 10 tick，从 **0.50 s** 起播，跳过预备段。0.50 s 的姿势必须是「预备做完、还没迈步」（同动作稿「承接入口 0.50」）。
  - 目录里没有以横扫为前式的式。仍按通则：收势前半段（3.70–4.85 s）里脚回位，右脚 4.30 s 落回架势踝位。
- **打断**：
  - 起手**可被伤害打断**（目录 `interruptible_by_damage: true`），宿主淡出 0.20 s 回架势，资源不另做打断段。
  - `root` 3.00 s 起转。3.00–3.35 s 之间被打断时，淡出按欧拉角线性混合，会把已转的 0°～57° 在 0.20 s 内倒转回去（第 9 节第 5 条）。3.35 s 以后起手已结束，伤害不再打断。
- **时间线事件**：
  - `0.8: step_r`：后脚外撤落地；
  - `3.7: hit`：客户端通知，不授权伤害。按叩门的先例只标末击（叩门三击只有 `1.7: hit`），Door-Breaker 的 `DoorBreakerAnimationTimingTest` 也按「时间线只有末击」核对；3.35 s 的击中一只体现在姿势上，不发事件（第 9 节第 9 条）；
  - `4.3: step_r`：转完后脚落回架势踝位。

- **节奏**：外撤站位（0.45 s）→ 前荡比一次（0.5 s）→ 慢慢回拉拧紧（1.25 s）→ 定 0.2 s → 起转放开（0.45 s）→ 回旋（0.35 s）→ 减速落脚（0.6 s）→ 缓收。力量感靠「拧得慢、放得快」的对比、单脚整圈的离心和斧走过的大圆。

## 3. 分阶段全身姿势

数值为面板值或模型空间位置（像素，脚底原点，右侧 −X、前方 −Z）。「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量。斧子几何同渲染器 `AXE_*` 常数：原版握法下刃口约沿手的远端方向（顺前臂指向拳外），柄沿拇指方向。

- **斧头点**：斧刃中点，挂点局部 `AXE_GRIP_CENTER + AXE_ALONG·4.8 + AXE_EDGE·0.75`。横扫看它的高度、方位和刃口是否沿切线。
- **方位角**：在 `root` 坐标系里，绕身体中线（x 0.3、z 0 的竖线）量，正前方为 0°，向角色左侧为正。
- **半径**：斧头点离转轴（左踝竖线 x 2.3、z −2.6）的水平距离。
- **刃口切向误差**：刃口朝向与「斧头点绕转轴水平转动的切线方向」的夹角。斧刃要领着转，击中时 ≤ 3°。
- 各姿势的躯干增量记为「胯 / 腰 / 胸 / 头」旋转与胯位移，均相对架势。架势本身胯 Y 12°、腰 4°、胸 4°（躯干相对 root 右转 20°），头 Y −19°。

### 起点与终点（0.00 s、6.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零，`root` 为 0。架势里斧子竖在头右侧（拳 `(−4.4, 22.6, −7.6)`），左拳在 `(4.3, 23.6, −10.2)` 护下巴；后膝 75°、前膝 58°；重心 z −0.9。

### 预备（0.00–0.50 s）

- **胯**：位移相对架势 `(0, −0.1, −0.2)`（0.35 s），旋转 Y −3°（0.30 s）。
- **腰 / 胸**：Y 各 −0.5°，比胯晚 0.02 / 0.04 s。
- **头**：Y 反向 +3°。
- **主手**：拳降 0.8 px（0.35 s），腕角不变。
- **左手、腿**：不动，双脚锁定。
- 0.50 s 全身速度为零，是叩门承接的入口。

### 调整（0.50–0.95 s）

- **后脚（右）**：同破盾的外撤步。
  - 0.55 s 离地（脚底离地约 0.8 px），离地、触地前后只做竖直运动；
  - 接地点相对架势移 `(−1.2, 0, +0.8)`，0.80 s 前脚掌落地（`step_r`）；
  - 踝由 `(−1.7, 1.72, 3.2)` 到约 `(−2.9, 1.71, 4.0)`。
  - 用意：底盘加宽，蓄时重心有地方往左脚移；回旋中右脚悬空，落地时直接落回架势踝位（第 3 节「随」）。
- **胯**：位移相对架势 `(0, −0.3, 0)`，旋转回 0（预备的左转 3° 放回）。**腰 / 胸 / 头**：回架势。
- **主手**（0.55 起，0.95 s 到位）：斧由头侧放下，**垂到右胯前**（探针核对）：
  - 拳约 `(−7.1, 12.5, −0.9)`：右胯旁；
  - 柄线约 `(−0.31, 0.46, −0.83)`：由拳向前上斜出；刃口朝向约 `(0.05, −0.86, −0.50)`：朝下、略朝前；
  - 斧头点约 `(−9.3, 16.6, −6.1)`：右胯前、腰高；
  - 上臂 `(−19.7, 8.9, −7.5)`（略后伸）、肘 42°、腕 `(24.0, −8.0, 23.6)`，腕弯折 35°、扭转 −3°；
  - 手臂穿模 0；斧子离头盒 4.8 px；斧不插进躯干（插入 0.02 px，在 0.25 容差内）。
- **左手**：不动（下巴前护位）。

### 预摆（0.95–1.45 s）

- **主手**（1.00 上臂、1.03 肘、1.06 腕起，1.45 s 到位）：右臂由下垂**向右前方荡出**，伸直平举，即「击中姿势」（下文「发」的击中姿势，探针核对）。

2. **单手、肘伸直、腕顶在上限**。
   - 刃口要沿切线又要斧在臂长处，前臂要偏离径向，靠腕把柄转过来。击中、蓄、随三个姿势腕都在弯折 44°～48°、扭转 43°，贴着设计上限（50 / 45），求解器上限 48 / 43。

## 11. 制作结果

关键帧由原型 `~/Code/Kizuna-remote-session/handoff/kpa-door-breaker-proto/d_sweep.py` 求出（主手、副手同一原型，`spec(off)` 切换参数），`install_sweep.py` 写入 `.bbmodel`，再用仓库导出脚本导出并登记索引。

**做法**（同破盾第 11 节，下面只写横扫新加的）：
- 每个通道写成最小抽搐「移动」序列，60 Hz 采样后删减关键帧（导出插值离设计曲线：旋转 ≤ 0.15°、位置 ≤ 0.005 px、腿 ≤ 0.10°）。

- **`root`**：
  - 旋转按第 3 节曲线 60 Hz 采样，只在 0–4.25 s 内删减。起转前后（2.98–3.05 s）和转满前 0.05 s 逐帧保留：删减后两端相邻帧离端值太远，Catmull-Rom 在 4.25–4.30 s 冲到 −360.04°，右脚落地时 `root` 还在转；
  - 4.30 s 写跳变帧：`.bbmodel` 里两个 `data_point`（pre −360°、post 0°），导出为 `pre` / `post`；
  - 平移按已转角绕左踝竖线补偿，4.30 s 起为 0。
- 双脚逐帧 IK 在 root 坐标系里求；左踝在 root 坐标系里不动，靠 `root` 平移补偿让世界位置也不动。
