# villager_crushing_fist：崩拳

袖手拳 · 崩拳，一次性 3.0 s（60 tick）。半步跟进、立拳直出。设计见动作稿 `handoff/pa-cloud-anim/24-Players-Animation-Villager.md` §5.1，进度和制作办法见 [PROGRESS-villager](PROGRESS-villager.md)。

首帧、末帧等于 [stance_idle](stance_idle.md) 首帧；左主手玩家由运行时整段镜像。

## 2. 时间轴

| 段 | 时间 (s) | 做什么 |
| --- | --- | --- |
| 预备、蓄 | 0.00–0.70 | 重心移到后脚，后拳收到右肋旁，前手压在胸前护中线；胯右转 |
| 进半步 | 0.70–0.90 | 前脚往前蹭半步（`step_l` 0.60 起落），后脚紧跟 |
| 崩 | 0.88–1.00 | 后脚落地踩实（`step_r` 0.98）的同时，立拳从心口直线打出；前手拉回左腰。**`hit` 1.00** |
| 定、收拳 | 1.00–1.45 | 拳停住，再沿原路收回 |
| 收 | 1.45–3.00 | 后脚退回架势踝位（`step_r` 1.80），前脚收回（`step_l` 2.55），双拳回架势 |

## 3. 制作实测（2026-11-16）

- 出拳上臂约 1398°/s，超过一次性动作的 720°/s，所以声明打击时段 `[0.88, 1.15]`；时段内角加加速度 4.2×10⁶°/s³，在打击上限 7×10⁶ 以内。
- `phases` 只登出拳那一下 `[0.88, 1.05]`：腰 0.900 → 胸 0.950 → 上臂、前臂、手 0.967，近端先于远端。
  动作稿把蓄势段 `[0.25, 0.70]` 也列成发力段；蓄势是往回收，不是发力，各节没有近端到远端的先后，登了门禁不过，所以不登。
- 姿势就是 MotionBricks 的崩拳 v2（用户 2026-11-08 认可的样片）再做过发力节奏精修的那一版，进 PA 时没有改。

## 4. 没验证的

- 冲量带人往前时脚会随实体滑行，动作稿要的 `slide_window` `[0.70, 1.00]` 没声明（见 PROGRESS）。
