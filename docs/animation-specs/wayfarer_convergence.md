## 1. 动作目的与触发

- **用途**：行矢第九式，弓卷的收尾：
  - 先照箭雨的抛法仰身往天上抛三箭；
  - 再沉成深弓步，压进弓里拉满，憋到发抖，平射一箭；天上的三箭和这一箭同时射到；
  - 射完弓手撑不住，弓慢慢垂下去，下梢点到地面，人大口喘气，最后一口气把弓提起来。
  - 全套唯一沉成深弓步、唯一虚脱的一式。
- **触发**：满月或箭雨的承接时窗里施放天地同至时，宿主调用 `PlayerAnimationAction.WAYFARER_CONVERGENCE`（弓在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。服务端规定天地同至**只能**这样施放，所以实际总是从 1.20 起播，0–1.20 的「聚」只在单独预览和接触表里看得到。
- **时长**：剪辑 **9.0 s**（180 tick），`loop: false`。撒放 2.50、2.90、3.30（仰射）、5.00（平射）。
- **承接**：承接入口 1.20（跳过「聚」）。作后式：满月、箭雨承接天地同至，前一式淡出 0.30 s，本段从 1.20 起播。作前式：没有（服务端 §4.2、§4.3：天地同至之后不能承接、不能换兵）。收势从 5.00 起，前半段到 7.00；双脚 6.86 已回架势踝位。
- **打断**：起手 0–2.50 s 被伤害打断时淡出 0.20 s。
- **时间线事件**：`1.55: step_r`、`2.50 / 2.90 / 3.30: release`、`3.46: step_l`、`3.70: step_r`、`5.00: release`、`6.60: step_r`、`6.86: step_l`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。射位 B0 见 C4，满弓基准见 C5；仰与三抛照 [箭雨](wayfarer_arrow_rain.md) 第 3 节，下面只写不同的地方。

### 起点与终点（0.00 s、9.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 聚（0.00–1.20 s）

- **腿**：双脚原位锁定，腿逐帧 IK。胯 0.10–1.00 降 0.5 px：探针双膝约右 83° / 左 68°（架势右 75° / 左 58°），全身最低点约 −0.14（右小腿），重心几乎不动。0.60–1.10 胯左移 0.3 px，让重心 X 进左踝 ±2 px（同满月预备，为足踏的单撑做准备）。
- **呼吸**：胸 X −2° → +1°（0.10–1.00），之后屏住。
- **头**：X 3° → −7°（0.15–0.50，低 10°），0.60–1.05 抬回 3°，盯住目标。
- **弓手（右）**：0.15–0.80 从护颌位放下，上臂垂到前屈约 15°、肘屈约 20°，弓竖着垂在右胯前；腕放松。这一下和之后的举弓方向相反，是持物臂的预备（C12）。
- **左拳**：留在下巴前。
- 1.20 s 全身速度为零（承接入口）。

### 足踏（1.20–1.70 s）

- 同 [满月](wayfarer_full_draw.md) 第 3 节足踏，压缩到 0.5 s：右脚 1.25 离地，从左脚右侧绕到右前方，**1.55 全掌落在 `(0.2, 1.0, −6.6)`**（`step_r`）；左脚 1.30–1.65 绕踝竖线碾到脚尖左转 40°（C2）。
- **胯**：1.25–1.65 到世界 Y −25°，位置到 B0（C4，约 `(1.0, −0.9, −1.9)`），即比「聚」升约 1.4 px、前移 2.5 px；胯、腰、胸 X 回 0。
- **上身**：腰 `(0, −8, 0)`、胸 `(0, −7, 0)`、头 `(0, 40, 0)`，胯 1.25、腰 1.28、胸 1.31 起依次到位。
- **弓臂**：1.45 起开始上举（举到 50° 的前半程，见下节），免得仰段 0.3 s 里转 120° 超速。

### 仰（1.70–2.10 s）

- **胯**：后移 0.3 px，重心略偏后脚。
- **躯干**：腰 X 0 → +6°、胸 X 0 → +10°（1.70–2.00），收着腹；头 X 0 → +30°（1.75–2.05）。
- **弓臂**：1.45–2.00 一次举到仰角 50°（从垂着到 50°，肩约转 120°，最小抽搐峰值约 410°/s）；弓把、锚点在胸系里的相对位置照 `bow_draw`（C5），双臂在胸系里绕肩线再转约 34°（同箭雨）。
- **弦手**：1.80–2.00 从下巴前伸到弦上，手指张开再勾到 −62°，**2.00 `pulling` 开**。

### 仰射三箭（2.10–3.30 s）

- **第一拉**（2.10–2.45）：胸后仰 2°、左转 3°，肩下沉（同箭雨第一拉，压缩到 0.35 s）；弦手拉到下颌下锚点前约 0.15 px（九成），`pull` 0 → 0.9（2.35 过 0.65 换 `_1`，2.45 到 0.9 换 `_2`）；手指 −62° → −70°。2.45–2.50 定住。
- **撒放 2.50、2.90**：照箭雨第 3 节「五抛」的每发循环（撒放手指张开 30°、一送、胸被顶回、t+0.15 搭、t+0.18–t+0.38 拉到八五成）。
- **撒放 3.30（第三发）**：手指、胸照抛法；**不做双膝一送**，撒放的同时后脚抬起换步（下一节），身体往前一送就接进「沉」。
- 弓臂 2.10–3.35 一直举在 50°。

### 沉（3.30–4.10 s）

- **后脚（左）换步**：3.30 离地（先抬脚跟、再离地 ≥ 0.3 px）；3.30–3.46 在空中绕踝竖线转到世界朝向 0°（脚尖指向目标）、脚底俯仰到 −30°（脚跟抬起），**3.46 以脚尖着地落回原处**（`step_l`），踝 `(2.3, 1.92, −2.6)`（探针）。转 40° + 俯仰 30° 用 0.16 s，峰值约 570°/s。
- **前脚（右）迈步**：3.48 离地，**3.70 全掌落在 `(0.0, 1.0, −16.0)`**（`step_r`），世界朝向 −40° 不变；行程约 9.4 px。
- **胯**：3.36–3.85 从 B0 到 `(1.0, −3.3, −11.5)`：前移约 9.6 px、下沉约 2.4 px；Y −25° 不变。探针：前膝约 78°、后膝约 32°（后腿几乎伸直），全身最低点约 −0.15（右小腿）。
- **躯干**：腰 X +6° → 0、胸 X +12° → 0（3.35–3.80），回到竖直；侧身 40°（腰 −8°、胸 −7°）不变；头 X +30° → 0（3.40–3.85），平视目标。
- **弓臂**：3.35–3.80 从 50° 落到水平（胸系里绕肩线转回 34°，胸自身回正 16°），弓把、锚点回到 C5 的胸系位置。
- **弦手**：3.30–3.41 手指张到 −40°（同抛法）；3.45–3.80 随弓臂落到弦上，手指 3.65–3.80 勾回 −62°，**3.80 `pulling` 开**。
- 3.85–4.10 全身定住，重心落在两脚之间。

### 满（4.10–4.90 s）

- **拉**：4.10–4.70 弦手沿弧线拉到下颌下锚点（弦臂肘 39° → 65°，上臂抬肘后收，C5）；`pull` 0 → 1（4.49 过 0.65 换 `_1`，4.64 过 0.9 换 `_2`）；手指 −62° → −70°。4.70–4.90 弦手再后移 0.5 px。
- **身体**：4.10–4.40 胸张开（X +2°、Y −3°）；4.40–4.70 **压进弓里**：腰前屈 1°、胸向弓侧倾 1°，肩线下沉约 0.5 px。
- **强颤**（4.70–4.98）：做法照 [technique_charge](technique_charge.md) 的定劲强颤：胸 9 Hz ±0.8°、弦臂前臂 10 Hz ±1.5°、弓臂前臂 11 Hz ±1.0°，两端各 0.06 s 渐入渐出，相位互不相同。最大抽搐约 3.7×10⁵（前臂），在限内。
- **呼吸**：4.40 起屏气，胸 X 不再起伏。
- **腿**：弓步不动；「脚趾抓地」不另做骨骼动作（脚趾骨只有 1 px，看不出来）。

### 平射（5.00 s）

- **`release` 5.00**，`pulling` 关；手指 5.00–5.17 由 −70° 张开到 −8°（C7 单发）；弦手 5.00–5.20 贴着下颌后走 3 px。
- 这一刻落在服务端手臂曲线 ×1.4 的峰顶里（剪辑 4.00–5.20）。

### 余势（5.00–6.00 s）

- 弓臂伸着不动；5.05–5.25 弓手手腕放松，弓在手里前倾 10°。
- 头盯着目标不动，看四支箭到（服务端让三支仰射比平射晚 0.10 s 到）。
- 5.20–6.00 全身静止，只有呼气：胸 X 5.40–6.00 回落 1°。

### 弓垂到地（6.00–7.60 s）

- **重心回后脚**：6.00–6.20 胯后移 3 px、升约 0.5 px（双撑，前腿伸、后腿屈）。
- **前脚收回**：6.20 右脚离地，6.20–6.60 向后摆约 19 px，经过左脚时从外侧绕过（摆动中点 x 约 −2.2，两脚不交叠），**6.60 以提踵 −35°、脚趾 +10° 落回 `(−1.7, 1.72, 3.2)`**（`step_r`）。大腿约转 90°，峰值约 420°/s。
- **胯**：6.20–6.70 回到架势位置再低 0.8 px（`(0.15, −2.6, 0.6)`），Y 回到架势的 +12°。探针：架势脚位胯低 0.7 px 时最低点约 −0.18、1.0 px 约 −0.23（都是右小腿），0.8 px 按插值约 −0.20。
- **后脚放平**：6.64 左脚离地，脚跟放下（俯仰 −30° → 0）、朝向转回架势，**6.86 全掌落回 `(2.3, 1.0, −2.6)`**（`step_l`）。
- **上身**：6.20–6.80 腰、胸 Y 随胯回架势值，同时前塌：腰 X −3° → −6°、胸 X −2° → −8°；头 Y 回 −19°、X 3° → −12°（垂 15°）；两肩下沉 0.5 px。6.10–7.50 大口喘气两次：胸 X ±1.5°，每次约 0.7 s。
- **弓臂**：6.00–6.80 从水平慢慢垂下，到上臂前屈约 10°、外展约 10°、肘几乎伸直，弓竖着垂在右腿外前方；**6.80 下梢点到地面**（估算见第 7 节第 3 条）。6.80–7.60 弱颤：前臂 3 Hz ±2°、上臂 2.5 Hz ±1°，振幅大、频率低、不规则（相位逐周期错开）；弓梢跟着在地面附近轻点。
- **左手**：6.00–6.60 从下颌旁落下，垂在身侧，拳松开到手指 −20°。

### 收（7.60–9.00 s）

- **弓**：7.60–8.00 一口气把弓提起来，回到持物位下方 2 px（`r_item` 约 `(−4.4, 20.6, −7.7)`）；8.00–8.80 慢慢升回护颌持物位（C1）。肩前屈约 100°、肘屈约 125°，最小抽搐峰值约 590°/s，是收势里最快的一下。
- **腿**：7.70–8.50 胯升 0.8 px 回架势高度，双膝回架势屈度。
- **上身**：腰 7.70、胸 7.80、头 7.90 起依次回架势值（8.60 到位），头抬起。
- **左手**：7.80–8.20 回到下巴前、握拳。
- 8.80–9.00 静止。

## 7. 骨架与门禁带来的约束

1. **深弓步**（探针，脚本在会话草稿目录，不入库）：
   - 选定：胯 `(1.0, −3.3, −11.5)`、Y −25°；前脚 `(0.0, 1.0, −16.0)` 全掌、朝向 −40°；后脚 `(2.3, 1.92, −2.6)`，朝向 0°、脚底俯仰 −30°、脚趾 0°。前膝约 78°、后膝约 32°；全身最低点约 −0.15（前小腿）、后小腿约 −0.05；重心 `(1.5, 12.74, −11.49)`。
   - 胯比 B0（胯 y −0.9）降约 2.4 px。再降 0.5 px（动作稿的 3 px）或前脚近 1 px，前小腿到 −0.26～−0.27，超 −0.25；前膝 90° 也就做不到。
   - **后脚不能踩实**：后脚全掌（踝 1.0）、朝向 −40° 时，胯前移到能让前腿够到 −16 的位置，后髋到后踝要 12 px 以上（腿长 11 px），够不着；后腿屈着够得着的胯位，后小腿穿地 −0.4～−1.0（侧倾方向和小腿方块斜着，C3）。
   - 后脚朝向 0°（脚尖指向目标）时腿的平面和小腿方块的边对齐，穿地最轻；朝向 −20° 也能过（踝 2.24，后小腿 −0.21，贴边），−40° 不行。脚底俯仰 −20° 时踝 1.66、后小腿 −0.24，也贴边。
   - 踝高 1.0 → 1.92 超过同一次着地 0.5 px 的限（C2），所以后脚**抬起再落**，多一个 `step_l`；收势时同理放平再落（6.86）。PROGRESS 的 C3 原先写的「同一次着地里后脚跟半抬、踝 1.0 → 1.45」探针否定了，已改。
2. **两次换步挤在 0.40 s 里**：3.30 撒放即抬后脚，3.46 落；3.48 抬前脚，3.70 落。后脚空中转 40°、俯仰 30° 用 0.16 s（峰值约 570°/s）；前脚一步 9.4 px 用 0.22 s（大腿约 60°，峰值约 510°/s）。都在 720 以内，但再压短就超。
3. **弓下梢点地是估算**：架势右肩枢轴 y 约 20.2（探针），胯低 0.8 px、胸前塌后约 19.1；手臂（肩到 `r_item`）约 10.2 px，前屈、外展各 10° 后握把约 y 9.2；弓的下梢在握把下约 9 px（C5），点地误差约 ±0.5 px。原型按渲染器的弓道具线段求，6.80 下梢 y 在 `[−0.2, 0.2]`；不够就多塌 1–2°，不改脚。弓不是骨骼，不进最低点门禁。
4. **前脚收回 19 px**：从深弓步一步收回到架势的后脚位，比别的式都远（0.40 s）。大腿峰值约 420°/s，不超；但重心在前、单撑在后脚尖上，前半段明显失衡（已登记）。分两步收会多一个事件、拖到收势后半段，不建议。
5. **强颤**：照 `technique_charge` 定劲的频率与幅度，最大抽搐约 3.7×10⁵，速度约 95°/s，都远在限内。弱颤 3 Hz ±2° 也在限内。
6. **三抛的手指**同箭雨（C7）：每发张开 30°、0.11 s，0.10 s 勾回，贴着抽搐上限。

## 10. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/wayfarer/d_convergence.py` 求解（交接目录，不入库；仰与三抛复用 `d_arrow_rain.py` 的弓位与抛法），装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（两套相同）和原型自查。

**索引实际值**：同第 6 节（失衡窗口没再放宽，实测出界都在窗口内；第一拉 `pull` 写 0.9）。时间线同第 6 节。

**门禁**：全部通过。关键帧 2,346（目标 2,200–2,600）。全段最快 708°/s（右小腿 6.33 s，前脚收回），抽搐最大 1.35×10⁶°/s³（右小腿 6.42 s，同一步）；不登记打击时段、爆发窗口。最低点 −0.224 px（左小腿 6.30 s，前脚收回时的后腿）；重心出界 1.32–1.35、3.35–3.42、3.50–3.65、6.27–6.42、6.70–6.80 s（都在失衡窗口内）；支撑脚滑动右 0.21、左 0.29 px；手臂穿模 0；预备 / 跟随 4/5 骨（腰没过）。错峰：四段都过，每段左前臂比左上臂早 1 帧（如 2.267 / 2.283 s，在两帧容差内）、左手最晚（2.367、2.817、3.217、4.583 s）；胸在四段的主轴上都动不到 3°，没判到。

- 弦手离锚点：2.45 s 0.22 px（规格约 0.15）、**2.88、3.28 s 0.33 px**（规格约 0.2）、4.70 s 0.02 px；
