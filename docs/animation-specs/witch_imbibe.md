## 1. 动作目的与触发

- **用途**：行药诀上卷「服」：把一瓶饮用巫药慢慢喝下去。左掌先按住胸口，瓶子送到嘴边小口啜三口，每口之间放下来缓一缓；喝完用掌心从胸口往下抚到小腹两遍，像把药往下引。全书最慢、最安静的一段。
- **触发**：宿主（玩家是 Human）在起手时调用 `PlayerAnimationAction.WITCH_IMBIBE`，按真实时间播放，`start_tick` 同步起点；有迟滞时按倍率放慢（W12）。不开立。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。效果 `cast` 3.20。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`0.30: cork`、`0.90 / 1.50 / 2.10: sip`、`2.40 / 2.85: rub`、`3.20: cast`。两脚整段锁定。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 拔塞（0.00–0.50 s）

- **右臂**：0.00–0.25 右拳提到胸前偏右 `r_item ≈ (−2.5, 20, −7)`，腕回正让瓶身竖直、瓶口朝上（瓶口估在拳上方约 4 px，W4）。由下颌侧落到胸前，正好作送瓶到嘴的反向预备（W6）。
- **左手**：0.05–0.20 拳松成「捏塞」（W2），拇指与食中指捏在瓶口；0.28–0.32 向上拔 1.5 px（`cork` 0.30），0.32–0.42 腕向左外一甩（腕 Z 约 30°）；0.42–0.60 手松成「掌」，掌心贴到胸口左侧 `(1.5, 21, −2.3)` 附近。
- **头**：X 低 5°，看瓶口。

### 啜·一（0.50–1.10 s）

- **右臂**：0.50–0.85 送瓶到嘴（W4）：先少屈肘 5° 让瓶离脸，再到「到嘴位」——参照 `drink` 到嘴姿势（上臂约 `(53, −33, −29)`、肘约 102°），按架势的身体朝向与头低 5° 重解；瓶口离嘴约 1 px。0.85–0.95 腕翻 20°（瓶底抬起）小啜，`sip` 0.90；0.95–1.10 腕回 10°。
- **左掌**：0.60 起贴在胸口，整段不离开（W5）。
- **头**：保持低 5°（相对架势），不再看瓶，看前方偏下。

### 啜·二、啜·三（1.10–2.30 s）

- **右臂**：每口 0.6 s：前 0.15 s 瓶离嘴落到下颏高、前移 2 px（腕回正），中间缓一缓，0.20 s 再送回，腕翻 20° 小啜（`sip` 1.50、2.10），之后腕回。两口的关键帧时刻相同、幅度差 1–2°，避免两口完全复制（曲线相关性按骨间算，同一骨的两口相似不受限）。
- **腿**：1.10–1.40 胯降 0.25 px，双膝多屈约 5°，到 2.30 保持。
- **右手落下**：2.15–2.30 瓶离嘴，右拳落到胸前偏右 `r_item ≈ (−3.5, 19, −6.5)`，给左前臂往下抚让出中线。

### 导药下行（2.30–3.20 s）

- **左掌**：贴身滑动（W5，原型逐帧解）：
  - 2.30–2.60 第一遍：胸口 `(1.5, 21)` → 小腹 `(1.5, 15)`，`rub` 2.40；
  - 2.60–2.75 贴着滑回胸口（压得轻，间隙 ≤ 0.3 px）；
  - 2.75–3.05 第二遍，`rub` 2.85；3.05 起停在小腹。
  - 探针：胸含 −3° 时，掌心 y 19 处肘屈约 100–115°，y 15.5 处约 20–60°，y 14.5（x 1–2）肘 10–40° 近伸直；x 0 处 y 14.5 已差 0.47 px。所以小腹取 y 15、x 1.5。
- **躯干**：2.30–2.60 胸 X −3°（含胸），腰 −1°；2.30–3.05 呼气。
- **腿**：2.30–2.60 胯再降 0.25 px（共降 0.5 px），双膝比架势多屈约 10°（膝角由腿 IK 求）。
- **右臂**：右拳在胸前偏右基本不动（±1° 随呼吸），离左前臂 ≥ 0.5 px。

### 定（3.20–3.50 s）

左掌停在小腹；胸 +2° 吸气（3.20–3.50）。

### 收（3.50–5.00 s）

- 左掌 3.50 离腹，3.50–4.40 握拳回护身位；右拳 3.60–4.50 回护身位。右臂各骨最快的一下要么在送瓶到嘴（前有拔塞时的下落作反向），要么在这里（前有落手作反向），制作时按实测核对（W6）。
- 胯 3.50–4.10 回 `(0.15, −1.8, 0.6)`；腰、胸、头 3.50–4.60 回架势。4.60–5.00 只剩缓入。

## 8. 骨架与门禁带来的约束

1. **瓶口到嘴**（W4）：瓶不在骨架里，按「瓶口在拳上方约 4 px」估；右手、右拇指离头盒 ≥ 0.25 px（手臂穿模门禁），原型自查前臂、手对头不超过架势基线约 1.0 px。
2. **左掌贴身滑动**（W5）：窗口内左掌对胸、腰、胯任一方块间隙 ≤ 0.5 px，所有对穿入 ≤ 0.25 px，粗、细两套几何都要满足；原型把两套的间隙一起放进约束，逐帧解左臂。
3. **两臂交叉**：导药时左前臂经过右拳内侧；右拳停在胸前偏右，两臂间隙 ≥ 0.5 px（穿入也算进相触门禁的「所有对」）。
4. **腕翻**：每口腕翻 20°，到嘴位的腕本身约 50°，合计在 120° 内。
