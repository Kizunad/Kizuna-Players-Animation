# attack_main：主手单手剑斜劈（右上 → 左下）

> 审阅状态：**样板已通过**（2026-10-22），已录入 `.bbmodel` 并导出。轴向、坐标和数值来源见 [共用约定](conventions.md)。
> 数值是设计目标：已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查；
> 录入 `.bbmodel` 后以导出 JSON 的实测门禁和 GIF 为准。

## 1. 动作目的与触发

- **用途**：主手持剑、斧或工具做近战挥击，打实体或打空气都用它。挖方块用 `mine_main`，放置和使用用各自动作；
  调度按原版交互类型区分，不靠手持物猜。
- **原版进度来源**：`LivingEntity.handSwingProgress`，即 `handSwingTicks / getHandSwingDuration()`。默认 6 tick；
  急迫 n 级为 `6 − (1 + amplifier)`，挖掘疲劳为 `6 + (1 + amplifier) × 2`。远端玩家由原版
  `EntityAnimationS2CPacket(SWING_MAIN_HAND)` 同步，不需要额外的播放请求。
- **伤害时机**：原版在点击当刻就结算伤害；本动作的 `hit` 时间线事件只是视觉通知，不授权伤害。
- **连点**：原版只在 `handSwingTicks ≥ duration / 2`（默认 3 tick）时重置挥手，所以重触发间隔至少 3～4 tick。

## 2. 时间轴与驱动

剪辑长度 **0.50 s**，`loop: false`。前 0.30 s 对应原版 6 tick 挥手，后 0.20 s 是收势尾段。

| 段 | 剪辑时间 | 原版进度 u | 内容 |
| --- | --- | --- | --- |
| 预备 | 0.000–0.100 | 0.00–0.33 | 胯带头右转、重心移到右脚，剑举到右耳旁、剑刃后指 |
| 主挥 | 0.100–0.185 | 0.33–0.62 | 胯→腰→胸→肩→肘→腕依次发力，剑从右肩后上方过顶劈向左下；`hit` 在 **0.175** |
| 跟随 | 0.185–0.280 | 0.62–0.93 | 剑继续落到左髋外侧，前臂旋前，肘先伸直后回弯，胸过转后减速 |
| 收势 | 0.280–0.500 | 0.93 → 尾段 | 腿和躯干先回正，手臂随后收回原版持物位 |

驱动（运行时需求，详见 `/tmp/players-animation-redo-notes.md` 的「分工」节第 5 条）：

- 挥手进行中：`t = 0.30 × (handSwingTicks + tickDelta) / getHandSwingDuration()`，按 scrub 取样，不自由播放。
- 原版挥手结束后：t 从 0.30 起按同一速率（`0.30 / duration` 剪辑秒每 tick）继续走到 0.50 再淡出。
- 任意时刻出现新的挥手：从当前取样姿态用 0.05 s 交叉淡入，重新从 t = 0 开始。
- 急迫、挖掘疲劳只改变速率，不改变姿势。

## 3. 分阶段全身姿势

### 起始（0.000 s）

原版持物站姿：右上臂前举 15°，屈肘 12°，右手握剑（拇指 50°、两组手指 78°/84°），左手自然半握，双腿伸直。
起始帧与原版持物底层基本一致，淡入 0.04 s 不会跳。

### 预备（0.000–0.100 s）

- **胯**：0.06 s 到顶，右转 8°、右侧略抬 1°，同时向右脚平移 0.5 px、下沉 0.3 px、后坐 0.8 px，重心落到右脚并为手臂前伸预留平衡。
- **腰 / 胸**：比胯晚 0.01 s、0.02 s 到顶，各右转 10° / 12°，后仰 2° / 4°，向右侧屈 3° / 4°。三段累计右转 30°，右肩明显后撤，躯干完成“上紧”。
- **头**：0.08 s 左转 25°、低头 3°、向左歪 5°，抵消躯干转动，视线始终锁在正前方目标上（头相对世界只右偏约 5°）。
- **右臂**：0.10 s 到顶。上臂 `(130, 44, 14)` 把肘抬到右肩外上方，屈肘 61° 让拳停在右太阳穴外侧（离头最近 0.5 px）；
  手骨尺偏 40°、旋后 65°（0.11 s），剑刃向后上方指过右肩，刃尖约在头后 15 px、高 35 px。手指再收紧 6°。
- **左臂**：0.09 s 前伸指向目标：上臂前举 40°、外展 15°、内旋 15°，肘几乎伸直（5°），手掌张开（指屈收到 −8°）。
  它是平衡臂，也是“指向目标”的预备。
- **腿**：膝盖屈 24°～25°，跟着胯的移位吸收下沉；大腿内旋 8° 抵消胯的转动，脚尖保持朝前；脚掌全程贴地。

### 主挥（0.100–0.185 s，`hit` = 0.175 s）

- **胯**：0.06 s 后立即反向左转，0.12 s 到左转 5°（峰值角速度出现在 0.097 s），并向左脚平移到 +0.2 px。
- **腰 / 胸**：0.13 s / 0.14 s 越过中立左转到 −6° / −8°，同时转为前屈 2° / 3°；峰值角速度 0.106 s / 0.114 s，依次晚于胯。
- **头**：0.15 s 右转 12°，继续抵消躯干左转，视线不离目标。
- **右肩**：0.14 s 经过 `(90, 12, 0)`，手在右额前方，剑刃竖直过顶；0.175 s 到接触姿态 `(50, −20, 0)`，峰值角速度 0.122 s。
- **右肘**：先“留后”。0.135 s 仍屈 54°，到 0.165 s 才快速伸到 20°，0.185 s 伸到 7°，峰值角速度 0.147 s，晚于肩。
- **右腕**：最后到位。旋后从 65° 经 0.15 s 的 40° 转到 0.18 s 的 5°，同时保持尺偏 38°～40° 压刃；峰值角速度 0.164 s。
  接触时拳在胸前偏左（约 x = +2.6、y = 14、z = −7.7），剑刃水平前指、略偏左，刃尖约 16 px 高、身前 16 px。
- **左臂**：同步回拉，0.20 s 上臂后伸 25°、外展 18°，肘屈到 60°，拳收在左肋旁（握拳 −40°/−70°/−75°），与右臂形成对拉。
- **腿**：0.12 s 起重心移向左脚，两膝维持约 32° 屈曲，大腿外旋 5°～9° 跟随胯回转，脚不离地。

### 跟随（0.185–0.280 s）

- **胯 / 腰 / 胸**：0.20 / 0.22 / 0.23 s 依次到最大左转 9° / 13° / 16°（累计 38°），前屈 2° / 5° / 3°，向左侧屈 1°～3°，随后减速。
  胸只前屈 3°：再多会把胸前右角送进横过身体的右前臂。
- **头**：0.25 s 右转 25°、低头 8°、右歪 6°，看向剑落点，头相对世界只左偏约 13°。
- **右臂**：上臂 0.21 s 经过 `(48, −28, −16)`、0.25 s 到 `(42, −28, −22)`，横到身体左前方，同时外展让前臂离开胸腹；
  肘 0.205 s 最直（6°），之后保持近直（8°）；前臂与手共同旋前（前臂 Y −35°、手 Y −45°），尺偏回到 24°，手腕掌屈 12°。
  剑刃 0.21 s 指向左前下方，0.25 s 斜指左下、刃尖约在左膝外前方（y ≈ 6）。
- **左臂**：0.26–0.28 s 到最大回拉，上臂后伸 33°、外展 24°，肘屈 72°，拳贴左腰。
- **腿**：左腿承重，两膝屈约 33°，脚底锁定。

### 收势（0.280–0.500 s）

近端先回：胯 0.31 s、腰 0.32 s、胸 0.33 s 回到中立附近（−4° / −6° / −7°），右臂 0.34 s 回到 `(30, −15, −6)`，
前臂和手的旋前在 0.35–0.37 s 逐步解除，左臂 0.35 s 放下，0.50 s 全身回到起始姿态并缓停。

### 不动的部位

- `root`：实体位移和转身由原版物理与朝向负责，动作不推 root。
- `r_toe` / `l_toe`：双脚全掌着地。挥击只在胯和膝上转移重心，没有提踵或碾脚；后脚掌转动留给更重的攻击变体。

## 8. 索引条目与叠加

`player_anim_index.json` 条目：`mask: full`、`priority: 20`、`blend_in: 0.04`、`blend_out: 0.14`、`hand: main`、`fpv: false`
（第一人称继续用原版挥手），并声明 `impact_window: [0.0, 0.2]`（见 [验收规则](../animation-acceptance.md) 第 3 节“打击时段的声明”）。左主手由运行时按资产契约镜像。

叠加规则（需运行时支持，见「分工」第 4 条）：

- 底层是 `stand`：全身生效，下身的屈膝和重心转移照常。
- 底层是 `walk` / `run` / `sneak`：只取 `upper`（腰、胸、头、双臂），胯和腿留给步态。挥击的扭转由腰胸承担，
  胯的 ±9° 不叠加，避免脚相位被打乱。
- 底层是 `jump_air` / `ride`：同样只取 `upper`；`swim` / `climb` 按 [切换表](transitions.md) 默认禁止。

## 9. 与其他状态的衔接

- 进入：`stand`、`walk`、`run`、`sneak`、`jump_air`、`ride` 底层上的原版挥手。起始帧就是持物站姿，淡入 0.04 s。
- 退出：0.50 s 回到起始姿态后用 0.14 s 淡回当前底层；尾段中途被移动打断也不跳回站姿，由叠加规则保留上身动作。
- 连点：新挥手从当前姿态交叉淡入 0.05 s，重新从预备开始。实测最短重触发间隔 3 tick（0.15 s），此时还在主挥段，
  会从接触附近直接接回预备，属于快速连斩的正常观感。
