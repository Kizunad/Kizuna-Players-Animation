## 1. 动作目的与触发

- **用途**：架势中疾跑（原版 `isSprinting()`）。比普通 `run` 更低、更紧凑：短步高频、躯干前倾、双拳收在下颌前只小幅摆动，随时能停下出手。
- **触发**：架势中、着地、`isSprinting()`。原版只允许向前疾跑，所以只有前向；疾跑中按后/侧方向键会结束疾跑，回到 `stance_walk_*`。
- **时长**：剪辑 **0.6 s**（两步），`loop: true`，自由时钟（`run` 0.7 s）。
- **结束**：疾跑结束换 `stance_walk_forward`（0.12 s）或 `stance_idle`（0.15 s）；疾跑中退出架势时直接交叉淡入 `run`（0.12 s）——两者都是双脚交替、没有错步，不需要 `stance_exit` 换脚。审阅决定保留本 ID（Q16）。

## 3. 分阶段全身姿势

- **胯**：高度在 −1.05 px（腾空）与 −1.55 px（触地后 0.06 s 吸收最深）之间按 2 倍频起伏（`run` 用 root 起伏 −0.4～−1.7 px，本动作整体再低约 0.5 px），z 0.6 px，左右随支撑脚 ±0.3 px；旋转前倾 9°～10.2°、Y 以 6° 为中心 ±5°（比架势的 12° 小，跑动时身体转正）、Z ±2°。
- **腰 / 胸**：前倾 5° / 4°，Y 基准 2°、反向扭转 3.5° / 5.0°（抵消胯的转动，胸比腰晚 0.05 相位），Z ±1.0°～1.2°；2 倍频前屈起伏 0.8°～1.0°。
- **头**：抬头 16°（抵消约 18° 的累计前倾），左转 14° 对准前方，Y 反向 6° 稳住视线，2 倍频点头 1.6°。
- **双臂**：在架势护架基础上收得更紧：右上臂 = 架势 + `(18, 4, −2)`、肘再屈 16°；左上臂 = 架势 + `(−18, 8, −2)`、肘再屈 30°（前拳收回到下颌前）；随对侧腿前后摆：右 ±6°、左 ±9°（`run` 为 ±43°），肘 ±8° 反向，腕 ±4° 最后跟随。右臂摆幅更小是细臂骨架的间隙要求：后摆到 9° 时右前臂会擦进腰盒。
- **手指**：握拳，节奏性紧握 3°～4°。
- **双腿**：踝轨迹按支撑/摆动分段求解；摆动期大腿前提、小腿后收（膝最大屈约 105°），脚尖下垂后上翘；支撑期全掌，末 30% 脚趾背伸 22°。
- **不动的部位**：`root` 无轨道（与 `run` 不同，`run` 用 root 做起伏；本稿把起伏放在胯上，便于和 `stance_*` 其他底层淡入淡出）。
