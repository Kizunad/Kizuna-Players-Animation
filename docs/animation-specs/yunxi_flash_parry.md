# yunxi_flash_parry · 瞬息格剑

拟用表现 ID `meridian_story:yunxi_flash_parry`。下文左右按右主手模型，原速每刻 50 ms。格剑的入架、持守、实挡和退出共用本页。

## 目的与触发

上卷 `meridian_story:flash_parry` 受理，按 P1 选定的「B 额前横格」起架。正面应看见一柄直剑横过额前，双眼露在剑下；侧面要看见剑和额头之间留有回震的余量。非持剑手选**护在身侧**，与剑脊分开，另一手持有物品时也能用这套姿势。

普通战斗槽点按起格。目录在 0 ms 发 `UNTIL_ACTIVE_END` 表现，400 ms 开守；`ACTIVE_DURATION_UNTIL_RELEASE` 允许持段随时结束，上限 300 ms。第 8–13 刻可守，守空于第 14 刻（700 ms）转入 300 ms 收势，第 20 刻（1000 ms）归架。实挡即收；若提前结束，以服务端通知为准。格剑的移速倍率为 0.4。

## 关键姿势与入架、持守

**额前横格基准**取同手 400 ms 姿势。剑柄在持剑侧额角外前方，剑尖越过中线指向另一侧，两端近乎等高。肘低于腕，非持剑手在对侧肩下、身体外缘。保留左前右后的落脚顺序，双膝外开、胯沉在两脚之间，形成能看出承重的马步。两手、剑向、头胸、膝胯和支点也作为同手斜劈 200 ms 的取姿依据。

| 入架剪辑时刻 | 双腿、支撑与胯 | 腰胸、肩与头 | 持剑侧与非持剑侧 |
| --- | --- | --- | --- |
| 0–150 ms · 接重 | 从战斗架势屈双膝，前脚全掌、后脚前掌承重，胯下沉并略转正。 | 腰先稳住，胸随胯打开，肩放低；头朝前，下巴略收。 | 持剑肘把柄送离脸侧，腕开始扶横；另肘外开，手向对侧护位落。 |
| 150–400 ms · 成架 | 膝随胯下沉后接稳，脚趾留住支点，重量分到两脚。 | 腰、胸、持剑肩依次抬正，头略低于剑线，视线保持水平。 | 肩带上臂上举，肘腕最后将剑安在额前。另手落定身侧，轮廓与握柄手分开。**400 ms（第 8 刻）成架**，为视觉边界。 |
| 400–700 ms · 持守 | 轻吸时双膝略松，呼出时胯沉回；两脚支点固定。 | 胸廓小幅起落，腰、两肩随呼吸，头补偿俯仰。 | 持剑肘随胸吸收起落，腕稳住横线；另手随肩微动。区间首尾的剑尖、全身姿势与速度连续。 |

主手基础片 `yunxi_flash_parry`、副手 `yunxi_flash_parry_off` 拟用保持模式 `hold_on_last_frame`，`loop_region: [0.40, 0.70]`、`free_loop_region: true`。300 ms 内只作一次很浅的起伏；到期由宿主退出，循环接缝只回到横格基准。单独预览可跨两轮验接缝，真实施放遵守上限。保持优先级 15，淡入 0.05 s、淡出 0.08 s。[PA 横架先例](guard_weapon.md)

## 时间轴与退出

以下从**本次守段结束或收到实挡回执**重新计时，记为 R。真实挡中、守空、松开及耗尽由宿主决定。所有片段均无攻击 `hit` 标记；受击片名里的 `_hit` 表示守方反馈。

| 分支与相对时刻 | 双腿、支撑与胯 | 腰胸、肩与头 | 持剑侧与非持剑侧 |
| --- | --- | --- | --- |
| 实挡 R 至 R+100 ms · 受压 | 后膝加屈接重，胯短促后让，前脚仍贴地。 | 回震从剑传到肩和胸，头稍迟收下巴，腰把重量送往后脚。 | 剑先向额前短退，肘折回吸收冲量。横线仍清楚，另手向侧后张一点配平。 |
| 实挡 R+100 至 R+300 ms · 收稳 | 后脚支住，双膝、胯回到横格基准。 | 腰、胸先稳，肩稍后回位，头恢复平视。 | 肘把柄送回额角外，腕停在原剑向，另手回身侧。正常收势满 300 ms 才可受理还击。 |
| 松开或守空 R 至 R+150 ms · 撤架 | 两脚保持接地，膝先松开，胯开始回到前后错步。 | 腰胸转回半侧身，持剑肩先松，头看前方。 | 握柄手从额角外下撤，剑尖沿脸前外侧转回；另手从身侧向肩前回。 |
| 松开或守空 R+150 至 R+300 ms · 归架 | 双膝回到架势屈度，前脚全掌、后跟恢复架势高度。 | 胯、腰、两肩依次稳住，头回站姿角度。 | 肘收在本侧，剑回护位，双手及各指复位。末帧逐骨等于战斗站姿首帧。 |

- **实际格住且正常收势**拟用 `yunxi_flash_parry_hit` / `yunxi_flash_parry_hit_off`。同一回执只播一次，回震本身占用既有 300 ms 收势。以横格为首末姿，0.03 s 淡入；在 R+300 ms，若同手立即还击，斜劈从该手横格姿势接走；若继续等待，回震片从横格以 0.35 s 淡回当前站姿或步态。两种臂型的副手在最初拟定的 0.10 s 淡出中都会形成假挥击。淡出只决定显示权重。这样玩家可以在后续窗口内自由决定是否出剑。
- **松开、守空**拟用 `yunxi_flash_parry_lower` / `yunxi_flash_parry_lower_off`，从当前循环相位交叉淡入 0.05 s，300 ms 回架，淡出 0.05 s。若实挡耗尽，受压反馈走破防出口，交给受击恢复与当前底层，结束本次架势和还击资格。受击、退架优先级 16。两个出口互斥，尤其要核实同刻实挡和收势通知不会让普通退架盖掉第一拍回震。
- **外部打断**从当时的入架或持守帧冻结淡出，交给当下的普攻、格挡或受击。取 400、500、650 ms 三处的 STOP 看剑尖是否跳回起点，晚追踪按原施放时钟取当前循环相位。格剑持角与减伤按既有玩法，动画只取守方回执。[斜劈衔接](yunxi_cloud_cleaver.md) · [战斗站姿](stance_idle.md)

## 主副手、覆盖与零挥击验收

主手右后手握柄、剑尖朝左；副手左前手握柄、剑尖朝右。横向目标换边，肩、肘、腕按本侧实长重解；胯胸转动增量换向，脚位仍左前右后。副手独持时按游戏现有前臂承力规则结算，表现保留左手额前的剑位。各片的本手拇指及两组指骨都写握形；左惯用手由 PA 镜像。

六个片段均为 `mask: full`、`hand: main/off`、`upper_while_moving: true`、`fpv: false`，全身第一人称用默认躯干。静止检查马步，走动检查 0.4 移速下仍能从正面看清横剑，胯、腿逐帧跟随步态。classic、slim 分别核对额头净距、鞋底最低 ≥−0.25 px、支撑脚滑移 ≤0.5 px；检查实挡最深处的剑仍在头盒外，第一人称准星前方可见。

格剑各段 `phases: []`，目标均为零个 `swings`，无风痕、破风声或循环命中特效。另从战斗站姿按 60 Hz 检查两手别、两体型的**原始剑尖速度曲线**，连看入架、循环接缝、实挡回震及放下，依现有阈值切窗也应为零；若抬剑过快，回调运动行程及分时。[资产契约](../asset-contract.md) · [动画验收](../animation-acceptance.md)
