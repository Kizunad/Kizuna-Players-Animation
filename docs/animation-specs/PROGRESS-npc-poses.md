# NPC 日常姿态与烤火：总览

更新：2026-11-27。规格审过（六项决定见第 7 节），资源已生成并收进 `npc_poses` 分组，用户看过 GIF。接线在 PA-Mobs（`MobIdlePoses`：谁摆、何时换、怎样打断，见其 `docs/design.md`「日常姿态」）和剧情仓（演员的指定姿态与火边落座）。第二段与规格不同的地方见第 8 节。

用户 11-27 13:3x 要「坐下来烤火的动作，细节堆多一点」，14:2x 又补了日常站姿：「做点什么叉腰，交叉双臂站立，蹲坐等动画」。任务单见会话交接目录 `handoff/i5-c4-c8-work/CAMPFIRE-ANIM-TASK.md`。

本页放这批共用的东西：id、两套骨架、基准姿势、呼吸、层级与打断、门禁口径、制作方法和待审决定。各段的姿势和时间轴写在各自的规格里。

轴向与面板值约定见[共用约定](conventions.md)。文中「右手」指 `r_*` 骨。坐标单位是像素，脚底为原点，前方为 −Z，角色右侧为 −X。

## 2. 两套骨架为什么分轨

PA-Mobs 的村民几何 `geometry.mob.villager` 按 classic 的关节切口切分，24 根可见骨的名字、父子关系和枢轴都和玩家骨架一样。差别在体积上，见 PA-Mobs 的 `geo/mob_skeletons.geo.json`：

| 部位 | 玩家 classic / slim | 村民骨架 | 对动作的影响 |
| --- | --- | --- | --- |
| 袍子 | 无 | **挂在 `pelvis` 上的刚体盒**：8×12×6，从胯枢轴下 8 px 到上 4 px，原版另膨胀 0.5 px | 坐和蹲时袍子跟着胯走，会插进地里，见下面的实测 |
| 躯干厚度 | 4 px（外层 +0.25） | 6 px（膨胀 +0.5） | 胸前、背后贴身的手和前臂要外移约 1–1.5 px |
| 头 | 8×8×8 | 8×10×8，另有鼻子从脸前伸出 2 px（z −6，y 23–27） | 手凑到嘴边（呵气、叹气）要让开鼻子 |
| 手 | 手掌 1 px，三片手指各 2 px | 同样的分段，从原版手臂末端切出，没有单独的指头体积 | 手指开合看得见，但很粗；细节靠腕和整手 |
| 帽沿 | 无 | 头上一片 16×16×1，只在有职业帽时显示 | 抬头、歪头时不碰东西就行 |

**膨胀面**：村民服饰原版膨胀 0.5 px，门禁量距离不计膨胀。手贴身时贴的是膨胀后的表面，也就是离内盒 0.4–0.5 px，正好在相触门禁 0.5 px 的上限内。

流浪商人用的就是这份村民几何。女巫、灾厄村民、僵尸村民几何的胯、胸、头尺寸和村民完全相同，`_robed` 版也能用在它们身上，但这批只拿村民几何过门禁。

**实测**：规格期用 PA 门禁同一套正向运动学量过。脚本在会话交接目录的 `handoff/i5-c4-c8-work/campfire-spec/probe/`，用 `animation_analysis.AnimationSampler`，村民几何从 PA-Mobs 换算过来。门禁量最低点时不计膨胀，下面的数也不计。

| 情形 | 结果 |
| --- | --- |
| 胯后仰 0° / 30° / 60° / 75° / 85° / 90° | 袍子最低点在胯枢轴下 8.0 / 8.4 / 6.6 / 5.0 / 3.7 / 3.0 px |
| 现有 `meditate` 盘腿直接放到村民骨架上 | 袍子插地 **3.8 px** |
| 玩家盘腿，胯高 2.6 / 3.0 / 3.4 px | 全身最低点 +0.28 / −0.03 / +0.27 px，都不穿地；头顶 23.3–24.1 px |
| 村民盘腿，胯后仰 88° / 85° / 80°，胯高 3.3 / 3.6 / 4.4 px | 袍底 +0.02 / −0.09 / +0.06 px；腰枢轴落在胯后约 4 px；头顶 22.1–23.8 px |
| 玩家全脚掌蹲 | 胯高约 4.5 px，胯在踝后 4.5 px，小腿前倾 33°；躯干前倾 40° 时重心在支撑面内 |
| 村民全脚掌蹲 | 袍子后仰 65–80° 时胯高 6–7 px |
| 两种骨架撑 16 px 高的柜台 | 双臂几乎伸直、躯干前倾 ≥ 20° 时，掌心才到 z −9 |

结论：
- 村民要坐地，只能把胯后仰到 80–88°，让袍子平铺在腿上、袍底着地。腰再反向前屈，把躯干扶正。
- 这个胯角放到玩家身上，会在大腿后面横出一截 4 px 的胯块。反过来，玩家的正常坐姿放到村民身上，袍子会插地。

所以两边用同一份设计：关键姿势的意图、时间轴、小动作时刻表都相同，按各自骨架分别解。两版的差别逐段写在各规格的「骨架差异」里。

## 3. 共用基准

### 3.1 战斗站姿锚点

日常姿态的进入段从这里开始，退出段回到这里；坐下从这里开始，起身回到这里。锚点就是 [stance_idle](stance_idle.md) 首帧，逐骨相同，包括手指和脚趾：
- 胯下沉 1.8 px、右转 12°；
- 左脚在前全掌着地，踝在 (2.3, 1, −2.6)；
- 右脚在后提踵，踝在 (−1.7, 1.72, 3.2)；
- 双拳护在下巴前。

PA-Mobs 给村民的自动待机也是 `stance_idle`，所以同一锚点两套骨架都适用。`stance_idle` 是 2 s 循环，宿主从任意相位起播进入段时，由 `blend_in` 抹平残差。

### 3.2 呼吸

- 所有循环的周期都是 **4.0 s**：吸 1.7 s，呼 2.3 s，呼得比吸长。循环长度 8 s 或 12 s，正好容下整数个周期。
- 吸气时：
  - 胸后仰 1.0–1.4°，腰早 0.1 s 达峰；
  - 两肩上提 0.3 px，比胸晚 0.15 s；
  - 头反向低 0.5°，视线不动。
- 坐姿和蹲姿的呼吸更多落在肩上：肩提 0.4 px，胸只动 0.8°。
- 有意的深呼吸（呵气、叹气）直接替换当前这一周期，振幅放大 2–3 倍，不另起一套节拍。

### 3.3 小动作通则

- **每个小动作都有预备、峰值、跟随、回落**，并从近端往远端错开：重心和胯最先，然后腰胸、头、肩、肘、腕，手指最后。和 Yunxi 返工一样，在制作脚本里用每骨的提前量 `LEADS` 表实现。
- 同一循环里，两个小动作的起点不落在同一拍上，间隔不等。相邻两段可以按身体部位重叠，例如手在拨火时腿已经开始挪。
- 叠在上面的慢层（重心游移、头的漂移）周期取循环长度的约数：12 s 循环取 12 s、6 s、4 s，8 s 循环取 8 s、4 s。这样首尾无缝。
- **手指不能是一块板**：
  - 手放松时三片手指的屈度依次差 4–6°，拇指另外偏开；
  - 用力时（搓、撑、拍）先张后收，比腕晚 1–2 刻。
- 头上叠着 PA 的视线层 [head_follow](head_follow.md)。剪辑里头的转动尽量不超过 ±30°，叠加后不至于扭过头。

## 4. 层级、索引与打断

| 字段 | 取值 |
| --- | --- |
| `mask` | 全部 `full` |
| `hand` | 有单手小动作的段用 `main`：拨火、拍衣襟、翻货、划地、招呼，左撇子由运行时整段镜像。其余用 `none` |
| `priority` | 全部 **6**：高于 `stance_idle`（2）和睡眠（5），低于所有战斗动作（格挡 15 起、攻击 20、受击） |
| `blend_in` / `blend_out` | 进入段 0.15 / 0.12；循环 0.20 / 0.12；退出段 0.10 / 0.15。坐下 0.20 / 0.20，起身 0.30 / 0.25。收手入袖 0.30 / 0.20，抱袖循环 0.20 / 0.20 |
| `loop` | 循环段 `true`，其余一次性 |
| `fpv` | 全部 `false`。全身第一人称直接复用第三人称姿势 |
| `upper_while_moving` | 不写。日常姿态不在走动中播 |

**衔接**：
1. 宿主在进入段末 tick 起播循环。进入段的末帧逐骨等于循环首帧，两段之间看不出接缝。
2. 平常收姿时，宿主在循环任意时刻起播退出段，`blend_in` 0.10 s 从当前姿势淡入。
3. **立即打断**（被打、进入战斗）：宿主直接 STOP 当前片段。PA 冻住当刻采样，按 `blend_out` 0.12 s 淡出，露出底下的 `stance_idle`。被打时的受击片段优先级更高，直接盖上去。这条路不经过退出段。

坐姿两段循环被打断时，0.12 s 里胯要升 8–9 px，看起来像弹起来。建议宿主改播 `campfire_stand_up`。这一条列在下面的待审决定里。

PA 的实体字节入口不支持倍率（[资产契约](../asset-contract.md)「实体字节入口暂不支持倍率」），所以 0.5 倍速只在离线 GIF 里出。

## 5. 门禁口径

| 项 | 怎么验 |
| --- | --- |
| 玩家版 | 粗臂、细臂两套几何跑 `scripts/analyze_animation.py` 的完整门禁 |
| 村民骨架版 | PA 门禁目前只认玩家 `.bbmodel`。第二段在 MotionBricks 试验仓把 PA-Mobs 的村民几何换成 `.bbmodel` 形状（X 取反、盒照原尺寸、膨胀不计，和门禁读玩家几何的口径一致），带上 `_robed` 轨道，调同一个 `analyze_animation.report`，不改门禁的计算。正式门禁命令要不要加一个 `--robed` 参数，列在待审决定里 |
| 地面 | 沿用 PA 现有的「全身所有方块最低点 ≥ −0.25 px」，臀、袍子、大腿、小腿一并算在内 |
| 站立循环 | 一次性段已按站立门禁查：不穿地、支撑脚滑动 ≤ 0.5 px、重心投影在支撑脚 ±2 px 内。循环段默认不查。建议把五个站立和蹲的循环加进现有的 `STANDING_LOOP_IDS`，和 `stance_idle` 一样查 |
| 坐姿 | 坐着时重心在臀上，不在脚上。撑地起身时手也在承重。现有门禁只把脚算作支撑，坐着时会误判，见待审决定 2 |
| 循环接缝 | 首尾位置差 ≤ 0.05 px，速度差在现有阈值内 |
| 两手相触 | 搓手、叉腰、抱臂、抱袖、背手、呵气声明 `hand_contact_windows`：窗口内手和目标的间隙 ≤ 0.5 px，穿入 ≤ 0.25 px |
| 切入矩阵 | 从循环任意时刻淡入下一段的组合逐一合成检查：烤火 → 收手入袖、烤火 → 起身，以及各日常循环 → 退出段。取 0.25 s 一档，合成淡入期间的姿势，查最低点、手臂互穿、两手间隙。这是第二段的新检查，脚本放 MotionBricks 试验仓 |
| 发力链 | 坐下、起身、进入、退出出 60 Hz 逐骨峰值时刻表，查从近端到远端的顺序。用 Yunxi 返工的 `measure_yunxi_chain.py` 同一把尺 |
| 已有动画 | 一帧不改，用 Yunxi 的摘要探针法比对改前改后 |

## 6. 制作

- **生成**：MotionBricks 试验仓新增 `scripts/author_npc_poses_pa.py`。
  - 关键姿势写成数据：重心、胯高、胯角、脚、手、臀的接地目标和躯干朝向，按骨架分别解反向运动学。
  - 每骨按 `LEADS` 表错开时刻；小腿压地、袍子压地用二分抬胯夹紧，地面余量取 −0.20 px。
  - 循环段 = 呼吸和慢层的周期曲线 + 按时刻表放的小动作关键帧。
  - 坐下、起身、进入、退出在关键姿势之间用 MotionBricks 补中间帧，再按门禁做定点修正。
- **导入**：`scripts/import_npc_poses_pa.py` 按名把 40 段追加进新的 classic 分组 `models/player_skeleton_classic/npc_poses.bbmodel`，再跑 PA 导出器和 `--check`。导出 JSON 不手改。
  - `_robed` 轨道也存在这个分组里。在 Blockbench 里打开时，它显示在玩家网格上；审它看村民 GIF。
- **出片**：
  - 玩家用 `scripts/render_animation_gif.py`。
  - 村民用换算好的村民 `.bbmodel`，配原版村民贴图。贴图从本机 26.2 客户端 jar 里取，只用于预览，不入库。

## 7. 决定（主会话 11-27 14:4x 审定）

1. **分轨**：玩家版和 `_robed` 村民骨架版各解一条。
2. **坐姿支撑**：「触地即支撑」，只对 `campfire_*` 和 `idle_squat*` 生效（`analyze_animation.py` 的 `GROUND_SUPPORT_PREFIXES`）。
3. 日常姿态的五个循环进了 `STANDING_LOOP_IDS`。
4. 加了 `--robed` 门禁入口，村民门禁几何是 `models/robed_skeleton.bbmodel`。2、3、4 的改动不改变旧段结果：PA 旧 182 段（粗臂、细臂 364 份报告）、云溪 12 段（24 份）改前改后的 `--json` 报告逐字节相同。
5. **坐姿被打断**：起身要快。PA 的 `playback_rate` 只允许 (0, 1]（两个 proto 都一样），没法两倍速播，另出 `campfire_stand_up_quick`。时长是 **0.75 s**，不是两倍速的 0.50 s：坐着时两脚在胯前 6–9 px，左小腿先要屈 86° 收脚、再伸约 138° 蹬起，一次性段 720°/s 的上限下收脚 ≥ 0.22 s、蹬起 ≥ 0.31 s，加上撤步至少 0.66 s；再留出撤步时大腿的余量，定 0.75 s。
6. **拨火的枝**：原版木棍要靠 `item_states` 显隐，就得改写原版 `minecraft:stick` 的物品定义，那会影响所有木棍；PA 现在不支持只让原版物品在剪辑里显隐。所以按决定空手做拨的手势：伸手到右侧地上拿、往火里拨两下、放回，剪辑里没有 `item_states`。

## 8. 第二段：实现记录与和规格不同的地方

制作脚本在 MotionBricks 试验仓 `scripts/`：
- `npc_rig.py`：骨架、正向运动学、腿的最小二乘反解（踝点 + 脚掌朝向 + 膝的指向，小腿后角压地用软约束），臂的解析解；
- `npc_clips.py`：设计量与共用函数；
- `npc_idle.py`：五个日常姿态；
- `npc_campfire.py`：火边六段；
- `npc_keyed.py`：火边一次性段只在关键时刻反解，躯干、臂、手指在关键姿势之间按角度插值，腿逐帧反解；
- `author_npc_poses_pa.py`：逐帧采样、平滑抬胯、抽稀关键帧，写出 `.bbmodel`、导出 JSON 和索引条目；
- `import_npc_poses_pa.py`：按名收进 `npc_poses` 分组；
- `check_npc_entry_matrix.py`：切入矩阵；
- `render_npc_sequence.py`：按宿主接法连起几段出预览；
- `make_robed_skeleton.py`：生成村民门禁几何。

和规格不同的地方：

| 项 | 规格 | 实际 | 原因 |
| --- | --- | --- | --- |
| 索引 `hand` | 用单手的段 `main`，其余 `none` | 42 段全部 `main` | 每一族的首末帧都接 `stance_idle`，它是 `main`（左撇子整段镜像）；一族里有的镜像、有的不镜像，左撇子 NPC 接段时会跳 |
| 日常姿态退出段 | 0.30 s | **0.45 s** | 叉腰回护拳上臂要转 148°，单峰平滑曲线峰值约为平均的 1.5 倍，720°/s 的一次性上限下主动作至少 0.33 s |
| 进入段、退出段、坐下、收手入袖、起身 | 一次性 | **保持末帧**（`hold_on_last_frame`） | 末帧就是下一段的首帧（循环首帧或战斗站姿首帧），宿主接循环或 STOP 之前不会闪回 |
