> 状态：**规格已审**（2026-11-24）。PA 侧已按本页做出 MotionBricks 草稿、导入 `piglin_sword` 组并导出，过了 classic、slim 两套门禁；宿主接线和游戏内录像待 Human 开树。
> PA id 定为 `piglin_sword_spring_back`（副手 `piglin_sword_spring_back_off`），剑仓 `presentation.id` 由剑仓那边改成同名。左右按右主手角色自身说：持剑手是右手，也是架势后手。
> **审定两处**（剑仓那边改目录）：

## 1. 目的与触发

- **用意**：目录描述是「借着挡住剑锋的硬劲回身，剑刃从另一侧弹回」。设计稿 §4 写「剑身弹回来的劲从另一侧甩过去」「对面侧身能躲」，§7 写「反手甩」。动作是三拍，中间不停：
  1. **被挡**：前一剑被挡住（盾、前臂格挡、硬物），剑被震回来。
  2. **翻腕**：剑身弹回，手腕顺势旋前，把剑从持剑手这一侧翻到另一侧，横在身前，手背在前。
  3. **反手横斩**：从另一侧往持剑手这一侧横斩向前，打的是面前的人。
- **触发**：只能承接：前式是绕、抖或普通攻击，被 `SHIELD` / `GUARD` / `HARD_OBJECT` 挡下，在 600 ms 内施放。宿主收到 `meridian_piglin_sword:spring_back` 的 `START` 时起播。单手持剑，主手或副手都可以。
- **伤害几何**：剑仓改目录后是施放者正前方 ±30°（单体后备锥 60°）。`hit` 帧剑尖在身前中线上、约胸腰高，落在这个锥里。
- **起手要读得出「弹回」，和普通起手不一样**：
  - **方向**：剑先往身上回、剑身从竖着往另一侧倒，不是先往后蓄。
  - **速度曲线**：开头最快、往后减速，像被打回来。普通起手是慢起、加速、蓄满再出。
  - **身体是被推的**：胯往后脚坐、胸微后仰、头被带一下，是承受；接着躯干往另一侧拧，给反手横斩蓄劲。
  - 剑身本身弯不弯、颤不颤是剑仓特效，不做进关键帧。

## 3. 关键姿势

幅度是相对 [stance_idle](stance_idle.md) 首帧的增量；实际关键帧以 MotionBricks 试验仓 `scripts/author_piglin_sword_pa.py` 的 `SPRING_BACK` 为准。躯干各骨的转角是各自局部的，逐节叠加。坐标是 Blockbench 像素：`-z` 正前方，`-x` 角色右侧，`+x` 角色左侧。

- **起姿 P0（0.00）**：逐骨等于 `stance_idle` 首帧：剑竖在右颊侧前方，剑尖朝上偏右。实际画面是从前式（绕的回抽、抖的抬回、普攻的挥出）经 0.10 s 淡入接过来的，见第 6 节。
- **回弹 P1（0.06）**：
  - **身体被推**：胯往后脚坐 0.4 px，头被带着低一下（x −2°），这两条用「起步最快、往后减速」的插值。
  - **剑**：剑身从朝上偏右倒向朝上偏左（剑身方向 `[0.55, 0.8, −0.25]`），手留在右颊前（腕点 `(−3.9, 20.2, −6.2)`），不往脸前收。
- **翻腕蓄 P2（0.10–0.13）**：
  - **躯干**：往左拧给横斩蓄劲：胯左转 7°（0.10），腰 6°（0.11），胸 6°、后仰 3°（0.12），近端先到。头反向右转 16°，始终看着前面。
  - **腿和胯**：胯从后坐转成往前沉：沉 0.15 px、仍偏后 0.3 px（0.12）。两脚还平着。
  - **右臂**：手收到胸前中线（腕点 `(−2.6, 19.4, −6.2)`），前臂旋前，剑横到身体左侧、剑尖指向左（剑身方向 `[0.98, 0.05, 0.05]`），手背在前。
  - **左臂**：空手从肩往右下收到胸前（肘 115°），在剑路下面；按肩算，身子转过来时手不会扎进腰里。
- **斩到 P3（0.25，`hit`）**：
  - **腿**：横斩靠胯带：后脚跟抬起 10°，后脚掌跟着胯碾转 15°，前脚也碾 5°（都在 0.22 到位）。胯前送 0.6 px、沉 0.25 px。
  - **躯干**：胯先往右转到 +4°（0.22，从蓄劲算转了 11°），腰再 +3°（0.235），胸再 +2°、前倾 1.5°（0.25）。头反向往左转到 8°，抵消躯干右转，看着前面。
  - **右臂**：手从中线扫到右前（腕点 `(−8.5, 19.3, −5.0)`），手背领先；剑身从指左扫到指向前偏左（剑身方向 `[0.6, −0.05, −0.8]`），剑尖在身前中线、约 18.7 px 远、胸腰高。手指再握紧 4°。上臂比胸晚一帧、前臂再晚一帧到峰（上臂、前臂关键各晚 0.02 / 0.03 s）。
  - **左臂**：留在胸前。
- **跟随 P4（0.33–0.36）**：
  - 身子顺着斩的方向再转一点后刹住：胯 9°（0.34）、腰 7°、胸 6°（累计前倾 2.5°），胯前送到 0.7 px。头往左转到 19° 继续看前。后脚跟、两脚的碾转停在原处。
  - 手沿横斩方向再往右走：按肩算，肘留 20°，方向比斩到时从肩到腕的方向再往右转约 25°（0.35）。腕角保持斩到时的样子，手指松回 2°。跟随用肩算是因为身子右转后肩往后走了，给死的世界点会把臂拉直、肘朝向一下翻过去。
- **收回 P5（0.52–0.60）**：两脚 0.52 落平回正，胯、腰、胸 0.56–0.58 回到半侧身，右臂 0.60 回到 P0。

## 5. 遮罩、覆盖骨与持物

- `mask: full`、优先级 24、淡入 0.10、淡出 0.25；进 `FULL_BODY_IDS` 和 `GRIP_IDS`。两腿靠后坐、前送、髋转和两脚的碾转过有效运动阈值。
- **脚**：两脚原地不挪。后脚跟抬起、脚掌碾转，前脚掌碾一点，斩完落平回正。胯降一半时后小腿盒的角已经贴地，再深就穿地，所以胯只沉 0.25 px、后脚跟只抬 10°。门禁实测鞋底最低 −0.229 px（主手）/ −0.146 px（副手），支撑脚滑移 0.221 / 0.168 px（后脚掌碾转带的）。
- 走动中施放：`upper_while_moving: true`，规则同 [绕](piglin_sword_wind_around.md) 第 5 节。
- **握持**：右手全程握住；斩到时手指再收紧 4°，跟随时松回 2°，不张开。左手全程握拳。
- **剑在手里**：横斩用原版握法，剑和前臂约成 80°（`hit` 帧实测主手 54.5°、副手 48.3°），刃线自然在前，**不用 `item_rotation`**。前式是绕或抖、带着 `item_rotation` 时，挂点会在弹的 0.10 s 淡入里转回原版握法，这是资产契约里写的行为，不跳。
- **运动学：这一式声明 `impact_window: [0.00, 0.32]`**，照破门斩、千里腿、袖手拳的先例进白名单，阈值不动。普攻 `attack_main` 的 `[0.0, 0.2]` 也是从 0 开始。
  - 实测冲击段内最大角速度主手 1287°/s（右手旋前，0.10 s）、副手 1406°/s；最大角加加速度 2.9e6 / 1.3e6°/s³。段外 480 / 665°/s、2.8e5 / 7.1e5°/s³。
- **腕**：腕弯折最大主手 36.0°、副手 41.2°；旋前旋后最大主手 64.1°、副手 100.7°。翻腕主要靠前臂旋前，不靠屈腕。
- **重心**：脚不挪，重心在支撑面内，不声明 `unbalanced_windows`。
- **剑与身体净距**：判据同绕（≥ 1 px，或不比架势更近）。实测主手全程最近处就是架势（classic 0.774、slim 0.435 px）；副手最近 1.188 / 1.013 px，在 0.05 s 剑从脸前倒过去时。

## 6. 首末帧与衔接

- 首帧、末帧逐骨等于 `stance_idle` 首帧。弹总是接在别的动作后面，所以首帧的意义是：从哪里接过来都有同一个参照，交接靠 0.10 s 淡入。
- **从绕接**（最早在绕的 0.675 s）：右臂正沿刺线往回抽，回弹也往身上回，方向接得上。框架同一刻给绕发 `STOP`，绕淡出 0.25 s，弹淡入 0.10 s 盖上去。
- **从抖接**（最早在抖的 0.675 s）：剑正从低位抬回，回弹往身上带，接得上。
- **从普攻接**（被挡后 600 ms 内）：`attack_main` 在架势上只取上身，挥完往回。弹用全身遮罩、优先级 24 盖上去，腿从架势接过来。
- **从架势直接起**（普攻早就播完）：前面没有伸出去的手臂，回弹只能靠自己读出来，所以第 1 节的「被推」不能依赖前式的姿势。
- **被打断**：发 `STOP`，0.25 s 淡出回底层。
- **之后**：可以接普攻、格挡、受击，规则同绕。切换表见 [transitions](transitions.md)「流金剑」。

## 7. 副手、左主手、体型、第一人称、剑的种类

- **副手版 `_off`**：剑在左手（前手），躯干转动增量取反，腿保持左前右后的架势。结果是剑从左往右倒、翻到身体右侧，再从右往左反手横斩向前。和主手版不同的地方都写在生成脚本里：
  - 左肩在架势里比右肩靠前约 3.3 px，持剑腕点跟着前移（蓄 `(2.1, 19.3, −9.3)`、斩到 `(8.0, 19.1, −8.4)`），前臂朝向才和主手版一样、剑身横得过来。
  - 前手本来就在脸前，不需要主手版那个往前压剑的过渡剑向；回弹关键只给腕点。
  - 前手架势是拳眼朝上、前臂前平，翻到反手主要靠前臂旋前；求腕角时旋前旋后的代价放低（`OFF_TWIST_WEIGHT`），免得解成大幅屈腕。
  - 收回时剑从脸前竖回去，0.48 s 加一个往前留的腕点 `(7.0, 20.2, −8.8)`，剑过脸前时离头盒 ≥ 1 px。
  - 剑在前手、从左颊往右倒时正从脸前过：蓄劲时胯只往右拧 4.5°（`OFF_SPRING_COIL`），头只转 8°（`OFF_SPRING_HEAD`），剑倒过去时离头盒才 ≥ 1 px。
  - 上臂、前臂关键各晚 0.01 s（`OFF_SPRING_DELAYS`），不用主手版的 0.02 / 0.03：前臂晚得多了，回弹那一下剑离脸更近，收回也赶不及。
  - 空手（右、后手）横斩时收到胸前偏右、往前留出腰的厚度（0.12 `(−3.2, 16.8, −5.6)`、0.25 `(−2.6, 17.0, −5.8)`）：后手离胸近，照主手版按肩算会扎进腰里。
- **左主手玩家**：运行时整套镜像，不另做。
- **粗臂 / 细臂**：同一轨道，各自过门禁、出 GIF。
- **第一人称**：`fpv: false`。全身第一人称复用第三人称姿态，`fpv_torso` 用缺省；游戏内录像时看反手横斩的剑能不能从画面一侧扫过（待 Human 接线后做）。
- **金剑与别的剑**：一套轨道。回弹的剑身弯、颤是剑仓特效。

## 9. 审片要点

- 拍盾挡、前臂格挡、硬物挡各接一次弹。侧面和正面固定机位，施放者和挡的人都要在画面里。
  - 前 0.06 s 读得出「被弹回来」，和绕的主动拧身不一样；
  - 0.13 帧剑横在身体另一侧、手背在前；
  - 横斩看得出后脚跟抬起、脚掌碾转、胯先转，两脚不挪、不穿地；
  - 0.25 帧剑尖在身前中线，挡的人的受击反馈和这一帧对得上。
- 俯视：剑走「竖在持剑侧 → 倒到另一侧 → 反手扫过身前」一道连续的路，中间不停。
- 主手和副手、粗臂和细臂、铁剑和金剑，各出一组 GIF。另录绕 → 弹、抖 → 弹、普攻 → 弹三段连播，看衔接有没有跳。
