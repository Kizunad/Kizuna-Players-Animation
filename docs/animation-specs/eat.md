# eat：进食（送到嘴边，按进食音效节拍咀嚼）

> 状态：设计稿已审阅通过；2026-10-26 已录入 classic `.bbmodel`，主副手导出并接入 `VanillaAnimationScheduler`。双体型门禁通过（握持门禁已加入 `GRIP_IDS` 实测通过）；离线 GIF 在 `build/anim-review/2026-10-26/`，游戏内视觉验收尚未执行。
> 数值来自设计期原型轨道并经仓库门禁同算法核对（`scripts/analyze_animation.py`，粗臂/细臂）。

## 1. 动作目的与触发

- **用途**：`UseAction.EAT` 的持续使用（面包、牛排、金苹果、蜂蜜以外的食物等）。原版第三人称只套 `ArmPose.ITEM`
  （手臂前举 18°），身体和头不动。
- **触发**：`armPoseAction` 中 `EAT` 分支，主手 `eat`、副手 [eat_off](eat_off.md)。
- **原版进度来源**：
  - 普通食物使用时间 32 tick，零食（`FoodComponent.isSnack()`，如干海带、甜浆果）16 tick；吃完 `itemUseTimeLeft` 归零、
    使用结束。
  - `LivingEntity.shouldSpawnConsumptionEffects`：已使用 ≥ 7 tick（零食从 0 开始）且 `itemUseTimeLeft % 4 == 0` 时播放进食音效
    和碎屑粒子。32 tick 食物的节拍落在已使用 **8、12、16、20、24、28 tick**。
- **驱动**：`t = 已使用 tick / 20`；`t ≥ 0.80` 后在 `loop_region [0.40, 0.80]` 回绕（同 `spyglass` / `brush` 的
  `loopedSecondsProgress`）。剪辑 0.40 s 与 0.60 s 是两次“咬下”的姿势，正好对齐已使用 8、12 tick；回绕后每 0.2 s 一次，
  与之后的音效节拍一致。零食的节拍为 0、4、8、12 tick，前两次落在举起过程中，之后对齐。
- **结束**：吃完或松手，淡出 0.20 s 回到当前底层。

## 2. 时间轴

剪辑长度 **0.80 s**，`loop: "hold_on_last_frame"`，`loop_region: [0.40, 0.80]`，无时间线事件。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.08 | 胸腰后仰 1.2°～1.6°、右肩下沉，右臂下沉后撤 6°，头先抬 3° |
| 举起 | 0.08–0.33 | 胯左移承重，腰、胸前屈并右肩前送，右臂沿身前把食物送到嘴前；0.31 s 上臂过冲 4°、0.32 s 肘过冲 5° |
| 到位 | 0.33–0.40 | 回落到保持姿态，头低 8°、右转 4°、向右歪 3°，朝向食物 |
| 咀嚼循环 | 0.40–0.80 | 0.40 / 0.60 咬下：头点 3.5°、胸前点 0.8°、腰 0.4°，手腕把食物推近 0.5 px；0.50 / 0.70 回弹 |

## 3. 分阶段全身姿势

- **保持姿态（0.40 s）**：右上臂 (44.4, −30.7, −21.6)、肘 88.6°、腕 (−28, −20, −10)：`r_item` 在 (0.2, 23.0, −7.7)，
  比嘴（头局部 (0, 25.5, −4.6) 经身体前屈后在 (1.0, 24.0, −5.4)）前 2.4 px、低 1.0 px、偏右 0.8 px；食物平面朝向嘴。
  手指握持（拇指 50°、两组手指 78°～84°）。
- **躯干**：胯左移 0.4 px、下沉 0.15 px、后坐 0.2 px，Y −1°、向左侧屈 1.5°（重心落到左腿，右腿放松）；
  腰 (−3, −2, 0)、胸 (−4, −5, 1)：前屈并让右肩前送 5°。
- **头**：(−8, 4, 3)，低头看食物；咀嚼时在 −8° 与 −11.5° 之间点头。头轨道覆盖原版视线，依赖 [head_follow](head_follow.md)
  叠加视线偏航/俯仰（进食时低头幅度会和视线俯仰叠加，见第 8 节）。
- **左臂**：上臂 (12, 7, 5)、肘 48°，左手虚托在腹前，手指半握（−16°～−30°），比右手晚 0.05 s 到位。
- **双腿**：脚底锁定在零姿态踝位置，按胯姿态求解：右膝屈约 18°（放松腿），左膝约 25°（承重，含胯下沉）。右脚趾背伸 3°。
- **不动的部位**：`root` 无轨道；脚不离地。

## 4. 关键帧（面板值，度；胯位移为像素）

全部 Catmull-Rom；`l_*` 手指为负值屈曲（见共用约定）。见附表。

## 5. 重心与支撑

双脚全掌着地；重心 x 0.01～0.56 px（移向左脚）、z −0.48～−0.09 px，始终在支撑范围内。原型脚底最低 −0.012 px，
支撑脚滑动 ≤ 0.016 px。

## 6. 与其他状态的衔接

- 进入：`stand` / `walk` / `run` / `sneak` / `sneak_walk` / `crouch_work` / `ride` / `jump_air` → `eat`，淡入 0.10 s；
  有移动/支撑底层时只取 `upper`（`upperOverlay` 需加入 `eat`），双腿继续由底层负责。
- 退出：吃完或松手淡出 0.20 s；循环段中任意时刻淡出都从当时姿态平滑回底层。
- 游泳、攀爬、睡眠、鞘翅：原版仍可在水中进食，但本稿只允许站立/移动/潜行/骑乘/腾空叠加；游泳中进食保持原版姿态
  （`upper` 叠在横卧的泳姿上会把食物送到错误方向）。

## 7. 索引条目（提议）

`mask: full`、`priority: 15`、`blend_in: 0.10`、`blend_out: 0.20`、`hand: main`、`fpv: false`、`loop_region: [0.40, 0.80]`。

## 8. 接口缺口

1. `armPoseAction`：`EAT` 不再返回 `null`，改为 `eat` / `eat_off`；`DRINK` 同理（见 [drink](drink.md)）。
2. `armPoseProgress`：`eat` → `loopedSecondsProgress(used, 0.80f, 0.40f, 0.80f)`。
3. `PlayerAnimationAction` 加入 `EAT`、`EAT_OFF`（保持类，无自然时长）；`AnimationPlayer.upperOverlay` 加入 `eat`。
4. 分析器 `GRIP_IDS` 加入 `eat`、`eat_off`（当前握持门禁对新 ID 判为不适用）。
5. 头部视线：进食时原版头仍跟随视线；本资源的头轨道会覆盖它，需 [head_follow](head_follow.md) 的叠加层，否则进食时转头失效。
