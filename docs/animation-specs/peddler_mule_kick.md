## 1. 动作目的与触发

- **用途**：千里腿第六式，照卡波耶拉的双腿驴踢：
  - 俯身两拳撑地，低头从两腿之间看着身后；
  - 两腿先收到胸前，再一起往后上方蹬直，脚跟领先，像驴子、羊驼尥蹶子；
  - 落地正好落成架势的错步，推地起身；
  - 全套唯一用手撑地、唯一两腿同时离地踢、唯一往身后踢的一式。
- **与其他式的区别**：

  | 式 | 方向 | 支撑 | 腿 |
  | --- | --- | --- | --- |
  | 正蹬 | 前 | 后脚 | 单腿，脚掌 |
  | 飞踹 | 前，空中 | 无 | 单腿，脚刀 |
  | **尥蹶** | **后** | **两拳** | **双腿，脚跟** |

- **触发**：千里腿尥蹶起手时，宿主调用 `PlayerAnimationAction.PEDDLER_MULE_KICK`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。打击 1.45 s。
- **承接**：不作后式。作前式：扫堂从它的 0.40 s 起播。收势前半段 1.45–3.23 s 内双脚回架势踝位（左 1.85、右 1.95）。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势；撑地段被打断，俯身会在 0.20 s 内线性混回站姿，可接受。
- **时间线事件**：`1.45: hit`、`1.85: step_l`、`1.95: step_r`。拳着地、离地不发事件。

## 2. 时间轴

| 段 | 剪辑时间 (s) | 腿脚与重心 | 躯干与头 | 双臂 |
| --- | --- | --- | --- | --- |
| 预备 | 0.00–0.30 | 重心微后 | 胸后仰 +2° | — |
| **俯身撑地** | 0.30–1.00 | 双膝屈到 110–130°，胯降约 4.5 px；前脚半提踵、后脚提踵再高；重心前移 | 胯前倾 → 约 −60°，腰 −20°，胸 −15°：上身俯过水平；0.70 起低头，从两腿之间往后看 | 两手向身前地面按下，**0.85 两拳着地**；肘微屈 |
| **撑** | 1.00–1.30 | 重心移到两拳上；1.10–1.20 两脚蹬离地面；1.20 起双膝收到胸前（屈膝 120°、屈髋 100°） | 躯干绷紧 | 两臂撑直，肩在拳的正上方 |
| **蹶** | 1.30–1.50 | 两腿一起往后上方蹬直：**髋 1.32、膝 1.35、踝 1.40** 依次伸展，脚跟领先，蹬到对方腰高（**`hit` 1.45**） | 躯干被反作用顶得往前 0.5 px | 两臂吃住，肘再屈 5° |
| 落 | 1.50–2.10 | 两腿收回，**左脚 1.85、右脚 1.95** 先后落地（`step_l`、`step_r`），落成架势错步：左前全掌、右后提踵 | 胯降回 | 两拳仍撑地 |
| 起身 | 2.10–2.70 | 两脚踩实，双膝伸 | 胯、腰、胸依次抬起回直；头抬回正前方 | **2.30 两拳推地离开**，回到身前 |
| 收 | 2.70–5.00 | 不动 | 2.80–3.80 呼气 | 双拳回架势（3.30 到位） |

- **收势规则**：收势从 1.45 起，前半段到 3.23；左脚 1.85、右脚 1.95 已回架势踝位。
- **节奏**：俯身（慢，0.7 s）→ 收腿（中）→ **蹶（0.18 s 一瞬）** → 落（中）→ 推地起身（慢）→ 缓收。

## 3. 分阶段全身姿势

基准同 [peddler_snap_kick](peddler_snap_kick.md) 第 3 节（架势胯 `(0.15, −1.8, 0.6)` / `(−6, 12, 0)`，右踝 `(−1.7, 1.72, 3.2)`，左踝 `(2.3, 1.0, −2.6)`）。

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致。

### 预备（0.00–0.30 s）

胸 X −2° → +2°、胯后移 0.3 px；脚不动。

### 俯身撑地（0.30–1.00 s）

- **胯**：位置相对架势 → 约 `(−0.3, −4.5, −1.0)`，胯 X −6° → 约 −60°，胯 Y +12° → 0°（两拳要对称地落在身前）。
- **腰、胸**：腰 X −20°、胸 X −15°（腰 0.33、胸 0.36 起，各晚 0.03 s）；上身俯过水平约 5°。
- **头**：0.70–0.95 低头，颈 X → 约 −55°，从两腿之间往后看（视线层关掉时；不关时只到 −45° 到 −50°，见第 7 节第 3 条）；头 Y 回 0°。
- **腿**：
  - 双膝屈到 110–130°（左 110°、右 130°），胯降约 4.5 px；
  - 前脚半提踵：踝 1.00 → ≤ 1.45（C1）；后脚提踵再高：踝 1.72 → ≤ 2.17，脚趾压地；
  - 小腿前倾受 C2 限：全掌 ≤ 38°，所以前脚一定要抬跟；原型逐帧查小腿最低点。
- **双臂**：0.40–0.85 两手向身前地面按下，**0.85 两拳着地**：拳面朝下，拳的最低点 0–0.2 px，落点约 `(±3.0, 0, −7.0)`（左拳在 +X）；肩枢轴约 9 px（探针：肩要降到离地约 9 px 拳才够得着地）；肘 10–20°。
- 0.60 起重心越出两脚范围（往前压到拳上），失衡窗口从这里开始。

### 撑（1.00–1.30 s）

- 1.00–1.10 胯升约 1.5 px（「胯抬到腰高」），重心移到两拳上；两臂撑直（肘 5°），肩移到拳的正上方。
- 1.10–1.20 两脚蹬离地面（脚踝跖屈、膝微伸，峰值 ≤ 720°/s）。
- 1.20–1.30 双膝收到胸前：屈髋约 100°（相对胯）、屈膝 120°，两脚离地 2–3 px，脚背屈 +10°（脚跟领先的准备）。
- 躯干绷紧，腰、胸保持。

### 蹶（1.30–1.50 s，`hit` 1.45）

- **两腿同时**，近端先、远端后：
  - 髋 1.32–1.44 伸展：大腿屈髋 100° → 约 −10°（相对胯，加上胯 −60° 前倾，腿在世界里朝后上方约 20°）；
  - **膝 1.35–1.47** 伸展：120° → 10°（110° / 0.12 s，峰值约 1,700°/s）；
  - 踝 1.40–1.46 背屈 +10° → +20°，脚跟领先；
  - 1.45 脚跟到对方腰高（离地约 12–14 px，原型求解）。
- 躯干 1.38–1.48 被反作用顶得往前 0.5 px（胯 Z −0.5）；两肘再屈 5° 吃住。
- 两腿之间保持约 2 px 的间距，不并拢穿模。

### 落（1.50–2.10 s）

- 1.50–1.62 两膝回屈到约 90°（打击时段内，峰值 ≤ 1,800°/s），之后向下伸；
- 左脚 **1.85** 全掌落在架势踝位 `(2.3, 1.0, −2.6)`（`step_l`），右脚 **1.95** 提踵落在 `(−1.7, 1.72, 3.2)`（`step_r`）；落地前 0.1 s 只做竖直运动；
- 胯 1.60–2.05 降回约 `(−0.3, −4.0, −0.5)`；两拳仍撑地，两肘回 15°。

### 起身（2.10–2.70 s）

- 胯 2.10–2.50 升回架势高度和位置、X 回 −6°；腰 2.18、胸 2.26 起依次回直；头 2.30–2.60 抬回正前方。
- **2.30 两拳推地离开**，2.30–2.70 回到身前护位。

### 收（2.70–5.00 s）

腰、胸、头 3.00 回架势；2.80–3.80 呼气；双拳 3.30 回架势；3.80–5.00 静止。

### 不动的部位

0.85–2.30 两拳的世界位置不动（拳 IK 锁地）。

## 4. 重心与支撑

| 时段 | 支撑 | 重心（设计） |

| 0.85–1.10 | 双脚 + 两拳 | 分析器只认脚，按出界算 |

| 1.85–2.30 | 双脚 + 两拳 | 出两脚范围 |

## 7. 骨架与门禁带来的约束

1. **拳够得着地要俯得更深**：肩枢轴要降到约 9 px，胯降 4.5 px、胯前倾 −60°、膝 110–130°。全掌时小腿前倾 ≤ 38°（C2），所以前脚抬跟、后脚提踵再高（C1，同一次着地 ≤ 0.45 px）。
2. **两腿蹬直要打击时段**（C6）：110° / 0.12 s 峰值约 1,700°/s；拉到 0.3 s 以上才在 720°/s 内，尥蹶子的冲劲就没了。
3. **视线层会把拳和头带走**（C8）：偏航叠到腰 ±8°、胸 ±12°、上臂 ±4°，两拳离地或插地；俯仰叠到头 ±62°，颈 −55° 再低头就超 75°。建议整段关掉；不关就把颈只做到 −45° 到 −50°，接受转头时拳走位。
4. **撑地没有门禁**：分析器只认脚着地，拳不滑、不穿地靠原型自查；拳穿地本来就在全身最低点门禁里。
5. **手里的东西**：撑地的是手里的东西（PROGRESS 待决定第 14 条）。
6. **方向**：往身后踢（+Z），服务端取目标的方向要核对。

## 9. 门禁适用项

| 门禁 | 适用 | 说明 |
| --- | --- | --- |
| 有效运动骨骼 | 适用 | 目标 24 骨（不动 `root`） |
| 躯干链 / 头 | 适用 | 俯身过水平，颈 −55° |
| 双臂双腿（全身动作） | 适用 | 加入 `FULL_BODY_IDS` |
| 握持手指 | 适用 | 加入 `GRIP_IDS` |
| 预备 / 跟随 | 适用 | 默认链：预备胸后仰 +2°（与俯身相反）；起身时躯干越过竖直 2° 再回 |
| 主链峰值错开 | 适用 | `bend` 默认链、`kick` 腿链 |
| 曲线相关性 | 适用 | 每骨独立时刻；拳逐帧 IK，腿着地段逐帧 IK |
| 多轴 | 适用 | 胯（位置 + X、Y）、双大腿、双上臂、头 |
| 关节角度 | 适用 | 膝 ≤ 150°（130°），踝 ≤ 75°，腰 ≤ 45°（−20°），胸 ≤ 60°，颈 ≤ 75°（−55°） |
| 角速度 / 抽搐 | 适用 | 打击时段 1,800°/s；段外 720°/s（两脚蹬离、俯身、起身） |
| 手臂穿模 | 适用 | 两臂撑在两腿前，收腿到胸前时膝不碰上臂 |
| 着地 / 滑动 / 重心 | 适用 | 两脚各两次着地（0–1.10、1.85 / 1.95 以后）踝 X、Y ≤ 0.5 px；重心按失衡窗口 |
| 循环接缝 | 不适用 | 一次性动作 |

**自查（原型每次跑，不入门禁）**：
- 0.85–2.30 s 两拳最低点在 0–0.25 px、世界 X、Z 漂移 ≤ 0.3 px；
- 1.20–1.30 s 膝不穿上臂；
- 1.45 s 脚跟离地 12–14 px；
- 颈最大俯角；全身最低点 ≥ −0.25 px（重点看小腿、拳）。

**规模目标**：24 骨，约 1,300–1,600 个关键帧（5.0 s；0.30–2.70 拳、腿逐帧 IK，蹶段 1/60 s）。

**接触表**：18 个时刻：
- 起、俯身：0、0.30、0.60、0.85（拳着地）、1.00；
- 撑、蹶（独有段）：1.15（离地）、1.30（收腿）、1.38、1.45（击中）、1.55；
- 落、起身：1.85（左脚落）、1.95（右脚落）、2.30（拳离地）、2.70；
- 收：3.23、3.80、4.40、5.00。
