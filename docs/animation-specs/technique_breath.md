## 1. 动作目的与触发

- **用途**：基础功法“调息”（`meridian_basic_techniques:breath`）的表现：起手收气（双手托起、吸满停顿、翻掌下按，胸腹起伏），收势吐气还原到架势。
- **时长与驱动**：剪辑 **2.0 s**（`PlayerAnimationAction` 40 tick），`loop: false`。剪辑内 0–1.10 s 是起手（收气），1.10 s 为生效时刻，1.10–2.0 s 是收势（吐气还原）。
  默认按真实时间播放完整 2.0 s。宿主要与功法时序对齐时按分段映射：`t = 1.10 × 起手已过 / 起手时长`（起手内），`t = 1.10 + 0.90 × 收势已过 / 收势时长`（收势内）；
  按门禁（720°/s、1.5×10⁶°/s³）起手不宜短于 0.65 s、收势不宜短于 0.59 s。**功法时序已定（2026-10-27 用户确认）：起手 1.1 s、收势 0.9 s**，与 2.0 s 表现原速一致，上述映射比例为 1。
- **打断**：起手被伤害打断时淡出 0.15 s 回底层，不播收势。
- **层次**（审阅决定 Q13）：静止架势上 `full` 整段生效（剪辑里的胯只做 ±3° 前后倾、腿锁在架势踝位，与 `stance_idle` 无缝），底层是 `stance_walk_*` / `stance_run` 或闪避/轻步时只取上身。

## 3. 分阶段全身姿势

- **胯**：位移只有 +0.06 / −0.15 px，旋转 0 → +3°（0.50–0.80 s）→ −2.5°（1.05 s）→ −3°（1.42 s）→ 0，表现腹部起伏；腿锁定（在 `stance_idle` 底层上）。
- **腰 / 胸**：腰 −3°（0.12 s）→ +4°（0.45 s）→ +4.4°（0.75 s）→ −2°（1.0 s）→ −3.6°（1.38 s）→ +0.5°（1.72 s）→ 0；胸比腰晚 0.02～0.05 s，幅度 −3.5 → +7 → +7.6 → −1.5 → −4 → +0.6。
- **头**：−1°（0.16 s）→ +3°（0.56 s）→ +3.5°（0.82 s）→ −2°（1.08 s）→ −3°（1.45 s）→ +0.5°（1.80 s）；吸气抬、沉气低，幅度小于胸，视线基本不离前方。
- **双臂**：上臂 → 前臂 → 手依次晚 0.03 s（还原段 0.025 s）。托掌、按掌的手臂由挂点目标求解（带向前一关键姿势的正则，避免肩部换解）；左手比右手晚 0.01 s。
- **手与手指**：托掌掌心向上（右腕旋后 70°～72°、左腕 −70°～−72°），按掌掌心向下；手指 0.22 s 张开 55°、0.56–1.46 s 张开 60°～62°（掌形），1.78 s 起回握拳。
- **不动的部位**：`root`；腿只在 `stance_idle` 底层上随胯微动保持锁定，在移动底层上不取。

## 4. 重心与支撑

腿不动，重心随胸腹前后 ±0.3 px；脚底最低 -0.124 px，脚滑动 0。

## 5. 衔接

- 进入：架势底层上施放，淡入 0.10 s（起始帧就是架势基准）；退出：2.0 s 播完淡出 0.20 s。
- 调息期间移动：底层换步态，本动作只取 `upper`，双手托按照常进行。
- 与攻击叠加：攻击优先级更高，攻击会接管手臂；调息不打断，攻击结束后若仍在剪辑内，继续显示当前时刻姿态。
