## 1. 动作目的与触发

- **用途**：五脏诀炼元「心炼」，照六字诀呵字诀。屈膝，两掌向前下插出；收臂成捧掌（两掌小指一侧相靠、掌心朝上）托到胸前；两肘抬起、两掌内翻，掌背相靠、指尖朝下，缓缓下插到腹前，吐「呵」。一遍 5 s，练 6 遍。
- **触发**：五脏诀心炼开始时，宿主调用 `PlayerAnimationAction.EVOKER_REFINE_HEART`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **32.0 s**（640 tick），`loop: false`（待决定第 6 条）。没有 `cast`。
- **打断**：淡出 0.20 s 回架势，两脚在淡出里滑回架势位（E11）。
- **时间线事件**：`0.50: step_r`、`31.40: step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、32.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 进式（0.00–1.00 s）

- 腿、胯、腰、胸、头照 E2、E11（同 [肺炼](evoker_refine_lung.md) 第 3 节）。
- 两拳 0.05–0.30 松成掌；两臂 0.05–0.90 落下、内收、屈肘，两掌 0.85 内翻，0.90 掌背相靠在腹前：两腕 `(±0.5, 19, −4.5)` 附近，指尖朝下（约 y 16），肘近直（约 15°）。

### 一遍（τ 0.0–5.0）

- **插（0.0–1.0）**：两掌 0.0–0.10 分开 ≥ 0.5 px，然后向前下约 45° 插出：掌心 `(±3.5, 16.5, −5.8)` 附近，上臂前屈约 35°，肘屈约 35°，掌心相对、指尖朝前下。双膝 0.0–1.0 屈到 25°（胯 y −0.07 → −0.31）。
- **捧（1.0–2.0）**：屈肘收臂，前臂旋后，两掌转成掌心朝上，向里合拢：τ 1.85 两掌小指一侧相靠，掌心 `(±2, 16.5, −4.5)`，约与脐平；1.85–3.00 捧住不分开，手型捧掌（E3）。头 X 1.0–1.5 低到 −5°，看手；胸 0 → +1°（吸气）。
- **托（2.0–3.0）**：两掌捧着上托到胸前：掌心 `(±2, 21.5, −6)` 附近，2.4–3.0 掌心转朝内（朝脸），指尖约到下颏高（y 24）、离头盒 ≥ 0.5 px。小指一侧一直相靠。双膝伸回 5°（胯 y −0.07）；胸 +1° → +2°；头 2.0–2.6 回 0。
- **翻（3.0–3.5）**：两掌 3.00–3.05 分开，两肘抬到肩高、在肩前（肘约 `(∓4, 22, −3)`，上臂前屈约 100°、外展约 20°），两掌向内翻，3.45 掌背相靠，两腕 `(±0.5, 21.5, −5)` 附近，指尖朝下（约 y 18.5）。
- **下插（3.5–5.0）**：两掌掌背相靠，3.5–4.8 缓缓下插到腹前（两腕 `(±0.5, 19, −4.5)`），两肘随之落下；4.8–5.0 停住。胸 +2° → 0（呼气）；头 3.5–4.2 低到 −3°、4.2–5.0 回 0。
- 左臂每段晚 2 帧（E12）；相靠的几段两手要同时到位，左臂只在中段晚 2 帧、到位时追平。三片手指换手型时错开 1–2 帧（E3）。

### 收式（31.00–32.00 s）

- 照 E11：两掌 31.00–31.05 分开，31.00–31.40 落到体侧；31.00–31.10 胯左移；右脚 31.10 离地，31.40 以提踵落回 `(−1.7, 1.72, 3.2)`；左脚碾回外转 10°。
- 31.40–32.00 胯、腰、胸、头回架势；两掌握拳抬回护身位（全段最快，约 250°/s）。

## 8. 骨架与门禁带来的约束

1. **手够得到的范围**（E11）：页首第 1 条。翻掌那下肘在肩前，两腕离肩枢轴约 6.7 px。
2. **两手相触**（E9）：捧掌两掌小指一侧、下插两掌掌背，间隙 ≤ 0.5 px、穿入 ≤ 0.25 px。左臂晚 2 帧只放在每段中间，到位那几帧两手同步（原型把左手锁在右手上）。
3. **托到下颏**：指尖离头盒 ≥ 0.5 px（手臂穿模门禁查穿入 ≤ 0.25 px）。
4. **周期生成**：τ = 0 与 τ = 5.0 姿势、速度都相同（4.8–5.0 停住，0.0–0.1 分开）。
5. **转速**：一遍里最快的是翻掌：约 0.45 s 内手的朝向转约 180°，分给上臂抬肘内旋、前臂旋前、腕屈各约 60–90°，单骨峰值约 300°/s，可能快过收式（约 170–250°/s）。预备 / 跟随门禁按每根骨最快的一下判：翻掌前两肘先微沉约 3° 作反向，翻到位后过 2–3° 再回；实测还不过，就把翻掌拉长到 2.9–3.5。
