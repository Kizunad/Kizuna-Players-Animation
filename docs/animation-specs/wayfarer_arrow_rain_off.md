# wayfarer_arrow_rain_off：箭雨（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-11-01），实测与出入见文末「制作实测」。随主手页 [wayfarer_arrow_rain](wayfarer_arrow_rain.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9，射位见 C4 副手版。本页只写与主手版不同的地方。

## 做法

- **时间轴、事件、窗口**：与主手版相同（7.0 s；`0.85: step_r`、`2.80 / 3.20 / 3.60 / 4.00 / 4.40: release`、`5.40: step_r`；失衡、瞄准（`yaw`）、五段 `phases` 都不变），`hand: off`。
- **上身**（镜像主手版，C9）：侧身向右 40°（胯 +25°、腰 +8°、胸 +7°、头 −40°）；仰（腰 X +6°、胸 X +10°、头 X +30°）不变；第一拉胸后仰 2°、**右**转 3°；左手持弓举到仰角 50°，**右手**攥箭、勾弦、五抛。
- **腿**（C4 副手版的宽站）：
  - 左脚原地碾到脚尖右转 40°（0.50–0.90）；
  - 右脚 0.45 离地，**0.85 全掌落在约 `(−0.7, 1.0, 3.2)`**（`step_r`）：副手射位的右踝 `(0.2, 1.0, 1.4)` 沿两脚连线外推 2 px，两踝相距约 6.5 px，与主手版的宽站镜像。右脚只横移约 1 px，但要从提踵变全掌，照样抬脚再落（C2）；
  - 胯比副手射位再低约 0.5 px，位置取主手版宽站相对两踝中点的镜像，约 `(0.6, −1.4, 2.9)`；仰时前送 1 px（估算，未探针）；
  - 收势右脚 5.02 离地，**5.40 以提踵落回架势踝位**（`step_r`）。
- **物品**：`item_states` 与主手版相同，挂在副手。

## 与主手版不同的约束

- 宽站高度按主手版探针的镜像估（左小腿最低点约 −0.1 是主手版后腿的值；副手版后腿是右腿），未单独探针，原型核对全身最低点 ≥ −0.25。
- 仰射锚点的核对同主手页第 7 节第 2 条，换右手。

## 门禁

适用项同主手页第 9 节；握持查左手握弓、右手勾弦攥箭；错峰主链换右臂（C12），预备 / 跟随用左臂链；五次撒放的手指查右手。

改主手版后必须用同一原型重新生成本段，不允许只改一边。

## 制作实测（2026-11-01）

与主手版同一原型生成（`d_arrow_rain.py` 的副手分支），索引字段同主手页第 6 节，时间线同上文。门禁全部通过（粗、细臂相同）：关键帧 1,909；最快 647°/s（右手手指 4.50 s），抽搐最大 9.2×10⁵°/s³（右前臂 3.68 s）；最低点 −0.216 px（右小腿 0.83 s）；重心出界 0.67–0.78、5.10–5.32 s（都在失衡窗口内）；支撑脚滑动右 0.37、左 0.04 px；手臂穿模 0；预备 / 跟随 3/5 骨（腰、左手没过）。错峰：第一拉段右上臂 2.100 → 右前臂 2.267 → 右手 2.500 s（胸没判到）；后四段右上臂、右前臂同帧（如 3.067 s）、右手晚 3 帧，四段都过。自查：2.70 s 弦手离锚点 0.00 px，八五成 0.33–0.34 px（同主手版的出入）；撒放帧仰角 49.9–50.0°、偏航 −1.0…−1.1°；1.10–5.00 s 全身最低点 −0.207 px（4.98 s）；0.90 s 两脚朝向 +39.9°。

与主手版不同的地方：
- 宽站胯 `(0.6, −1.25, 2.9)`（上文估 `(0.6, −1.4, 2.9)`）；预备胯转到 +10°、腰胸跟转 −3.5°（架势胯 +12° 不镜像，预备方向与之后的右转相反）；收势胯先移到 `(1.4, −1.0, 1.2)`；
- **弦手 1.25 起伸到弦上**（主手版 1.40）：副手护颌位离中线近，上臂行程比主手版大（C9），提早起手；
- 其余出入（胸没下沉、搭箭转腕、八五成锚点 0.33 px 等）同主手页第 10 节。
