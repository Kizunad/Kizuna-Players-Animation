# herb_knife_cut：切药，刃口压在上沿往回拉（全身，1.0 s，可连切）

> 状态：**用户验收通过**（2026-11-10 夜），关键帧不再改；2026-11-11 接进游戏（未提交），截图见交接目录 `handoff/brewing-models-r2-20261110/README.md` 第十一节。用户 11-10 选方案甲（派单第八节）：刀在手里绕握点转平（索引 `item_rotation`），刃口压在药材上沿，往回、往下加腕掌屈拉切，药材横着拿。
> 原来写的「钩在药材远侧、刃口朝人」作废：刃口其实在刃弯外侧，见 [PROGRESS](PROGRESS-herb-knife.md) 第 7 节更正。
> 轴向、坐标和面板值约定见 [共用约定](conventions.md)；共用约束 K1–K8、刀刃接法、触发和决定见 [PROGRESS-herb-knife](PROGRESS-herb-knife.md)。
> 来源：设计稿 `22-Brewing-Addon.md` §4.3「主手拿药刀、副手拿药材，右键，切成片｜一刀 1 s，一个药材切出一份」，声音表 `knife.cut`；参考 Bong `herb_knife_slash`、`herb_harvest`（「吃的是拉不是砸」，首帧 = 末帧）。
>
> **资源 id**：`herb_knife_cut`；`mask: full`（移动中只取上身）、`hand: main`。
> **和 Bong 的不同**：Bong 的切是对着前方空气或地上的草，刀柄照原版握法立在手里。这里左手把药材横拿在胸腹前，刀在手里转平，刃口压在药材上沿往回拉，两只手一起干活。
> 所以首末帧是两手在胸腹前的「待切位」，不是持刀架势。

## 1. 动作目的与触发

- **用途**：主手药刀、副手药材（现在只有毒马铃薯）时按住右键，一秒切一份；按着不放就一直切，药材用完停下。
- **触发**（Brewing 服务端，[PROGRESS](PROGRESS-herb-knife.md) 第 3 节）：`HerbKnifeItem.use` 里 `startUsingItem` 并返回 `CONSUME`（不挥手），同时 `ServerPlayerAnimations.play(player, PlayerAnimationAction.HERB_KNIFE_CUT)`；
  `getUseDuration` 20、`getUseAnimation` `NONE`；中途松手 `releaseUsing` 里 `stop`。按住不放时原版下一 tick 重新开始使用，剪辑同 ID 重播从头开始，旧实例淡出。
- **结算**：`onUseTick` 剩余 9 tick（用了 11 tick，0.55 s）且在服务端时扣药材、刀耗损 1、给成品、放 `knife.cut`（`entity.sheep.shear`，0.5 / 1.2）；11 tick 前松手什么都不给。
  最后一份药材切完后剪辑照常走完，左手空着回位；下一次 `use` 因为没有药材直接返回 `PASS`。
- **时长**：**1.00 s**（20 tick），`loop: false`；和使用时长一致。
- **时间线事件**：无。结算时刻由服务端 tick 定，剪辑只对齐，不读事件。

## 3. 姿势

**刀在手里**：索引 `item_rotation` `[[0.0, [54, 0, 0]]]`，刀绕右手挂点 `r_item` 的 X 转 −54°，全程不变。
派单写的是「约 −40°」：I-5 用 −42° 时右腕要掌屈到 55° 才能把刀放平；多转 12° 换右腕各轴 ≤ 45°。

**待切位**（首帧 = 末帧，classic 实测）：
- **刀**：相对原版持物位在世界里绕 X 转 −33.7°、绕 Y 转 −39.9°。刀柄从拳往前左伸出，离水平 10–15°；刃挂在刀柄前端下方，刃口（刃弯外侧）朝下前。
  往左转 40° 是为了让右前臂从右后方来，不进胸和腰。刃口贴上沿的那一点在刃上的位置 2.47（0 = 转轴端，3 = 刃尖端），横向贴在上沿正中往里端（右手那边）1.37 px。
- **左手和药材**：药片中心 `(−0.55, 12.97, −5.31)`，上沿往前倾 49.6°、绕竖直转 −7.7°，长边横着；片面大致朝人。
  左上臂 `(25.5, 12.2, −9.0)`、左肘 34°、左手 `(−16.3, 97.6, 3.8)`。左手 y 约 98° 是手绕前臂轴转，把药片横过来，门禁每轴上限 120°。
- **右手**：右上臂 `(28.1, −24.5, 7.9)`、右肘 70.6°、右手 `(−39.7, −16.4, 18.5)`，挂点 `(−1.08, 17.04, −8.32)`。
- **躯干**：胯前屈 5°、后坐 0.6 px、下沉 0.43 px；腰前屈 8.07°、胸前屈 9.07°；头相对胸抬 3.14°，世界里低约 19°（拉割中约 34°）。腿用脚底锁定求，两膝微屈。
  多弯胸腰、头不跟着再低，是为了把肩和刀一起送低，又不让刀柄前端挡在脸前。
- **两手握拳**：右手架势拳，拉割时手指再收 5°（0.42 s 最紧）；左手握药材拳（拇指 Z −30、两组手指 −60、−64）。
- **高度**：拳在 y 14.8–17.6（slim 14.5–17.3），刀最高点 ≤ 21.15，正视时刀和右拳离头的轮廓 ≥ 0.51 px（slim 0.84），全程不挡脸。

**拉割的弧线**：刃口在刃弯外侧。刀转平后刃口压在药片上沿，右拳沿刃线往回、往下、往右拉，同时往药材里压、腕掌屈，让弧形刃口在上沿上滚着切进去。
0.20–0.40 切深增长最快，0.55 最深；0.63 以后先往上抬出，再从药材上方往前回位。

**两种体型**：共用同一套轨道（[验收](../animation-acceptance.md)「slim 使用同一动画轨道」）。slim 挂点低 0.5 px、内移 0.5 px，刃落得更深（0.55 s 1.78 对 classic 1.29），回位余量更小（0.27 对 0.42）。
求解时两副骨架一起算罚分，所以数值是两者的折中。
