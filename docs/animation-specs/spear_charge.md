# spear_charge / spear_charge_off：持矛与蓄力冲刺

状态：已实现并通过双体型门禁、客户端矩阵测试与 26.2 游戏内画面验收（2026-11-07）。
画面覆盖玩家主副手、左惯用手，以及僵尸、尸壳、僵尸猪灵和猪灵的持矛与实际使用状态。

本动作只覆盖持矛臂，主手模板为右臂，副手模板为左臂；左惯用手由运行时镜像。
首帧是持矛待机，能够叠在走路、潜行、骑乘和游泳之上。双手同时持矛时分别采样。
躯干、腿和另一只手由下层动作负责。优先级 15，淡入 0.10 秒、淡出 0.15 秒，第一人称交还原版双手。

剪辑长 9.15 秒，时间轴按下界合金矛标定；其他材质逐段映射各自 `KineticWeapon` 窗口，
不把下界合金的持续时间用于所有矛。窗口来自 26.2 `SpearAnimations.UseParams.fromKineticWeapon`：

| 标定时刻 | 原版时刻 | 姿态 |
| --- | --- | --- |
| 0 | 未使用 | 曲肘持矛，矛头斜上 |
| 0.20 / 0.32 / 0.40 秒 | delay × 0.5 / 0.8 / 1 | 肩先抬、肘前送、手腕转正 |
| 1.90–2.90 秒 | delay + dismount − 20 至 delay + dismount | 握持开始晃动 |
| 4.90–6.90 秒 | delay + knockback − 20 至 delay + knockback + 20 | 前臂逐渐放低 |
| 8.90–9.15 秒 | delay + damage − 5 至 delay + damage | 收回持矛姿态，继续使用则保持 |

三段击退相关边界并不按材质同比缩放：运行时分别读取条件窗口，缺少条件时采用原版的 0 tick。
手指保持包握，肩、肘、腕有独立关键帧；不写物品挂点轨道。持物手已由本动作接管时，
不再附加原版矛物品变换，防止转向和前伸叠加两次。

按单臂覆盖层验收：肩、肘、腕均有效运动，握持手三组手指非零，角度、速度、错峰、
穿模及曲线独立性门禁保留；腿部与躯干的运动要求由下层剪辑承担。
