# sleep：睡觉（仰卧呼吸循环）

> 审阅状态：**设计稿，待审阅**（2026-10-26）。尚未录入 `.bbmodel`，未跑原型门禁。轴向与坐标见 [共用约定](conventions.md)。

## 1. 动作目的与触发

- **用途**：`Pose.SLEEPING`。`LivingEntityRenderer.setupTransforms` 按床朝向转 Y、再绕 Z 转 90°（`getLyingAngle`）、再转 Y 270°，
  玩家仰面躺在床上；模型四肢不动。
- **本动作在身体空间制作**：骨架仍是站姿坐标，由原版矩阵放倒；仰卧时身体后方（+Z）朝下贴床。
- **触发**：`isSleeping()`。
- **原版进度来源**：无进度（睡满 100 tick 后夜晚跳过）；本动作是 4.0 s 自由时钟呼吸循环（15 次/分）。
- **结束**：醒来（原版立即站起），淡出 0.30 s。

## 2. 时间轴

剪辑长度 **4.0 s**，`loop: true`。

| 时间 | 内容 |
| --- | --- |
| 0.0–1.6 | 吸气：胸 X −1.5°（身体空间前屈 = 胸口向上抬起），腰 −0.8°，搭在腹部的右手随之上移 0.3 px |
| 1.6–4.0 | 呼气：缓慢回落；头随呼吸点 0.8°，晚 0.4 s |

## 3. 分阶段全身姿势（基准）

- **头**：(−6, 15, 6)：枕在枕头上微低、向右偏 15°、向右歪 6°，放松入睡的侧偏。
- **躯干**：胯 0、腰 (−1, 0, 0)、胸 (−1, 0, 0)；仰卧不扭转。
- **右臂（搭在腹部）**：上臂 (25, −10, −8)、肘 100°、手 (0, 0, −10)，前臂横放在腰前，手掌贴腹；手指松弛 10°～20°。
  前臂与腰盒间距 ≥ 0.3 px（阶段 2 用手臂穿模门禁核对）。
- **左臂（放在身侧）**：上臂 (−8, 0, 10)：外展 10°、略后伸（身体空间 −X = 世界里向下，贴床），肘 15°，手掌向下贴床，手指 15°。
- **右腿（屈膝外倒）**：大腿 (22, 15, −6)、膝 −40°、脚 (−20, 10, 0)：屈膝时膝向上（身体空间 −Z），脚跟沿床面回收，
  保持脚跟背面 z ≤ +2 px（床面），阶段 2 用 FK 锁定脚跟在床面。
- **左腿（伸直）**：大腿 (2, −5, 2)、膝 −5°、脚 (−30, 0, 0)：仰卧时脚背自然跖屈约 30°。
- **不动的部位**：`root`、胯（身体由原版矩阵放倒在床上）。

## 5. 重心与支撑

躺在床上，无站立支撑（门禁不适用：睡觉）。门禁仍检查关节角度、角速度、手臂穿模和循环接缝。

## 6. 衔接

- 进入：`stand` → `sleep`，淡入 0.30 s；原版在入睡瞬间放倒身体，淡入期间四肢从站姿平滑过渡到睡姿。
- 退出：醒来 → `stand`，淡出 0.30 s。
- 上层动作：睡眠中无法使用物品，所有上层动作必须先结束（切换表已规定）。
- 全身第一人称在睡眠时关闭（现有约定）。

## 7. 索引条目（提议）

`mask: full`、`priority: 5`、`blend_in: 0.30`、`blend_out: 0.30`、`hand: none`、`fpv: false`、`loop: true`。

## 8. 接口缺口

1. 调度新增 `scheduleSleep`（`isSleeping()` 边沿）；目录 `SLEEP`。
2. 分析器：全身动作、无地面支撑集合加入 `sleep`。按第 3 节“全身动作要求双臂双腿都有效运动”，睡眠呼吸幅度很小，
   右臂/右腿的 1° 起伏不足 3°。提议：睡眠属于静止姿势，门禁按“关节进入目标姿势”计有效运动（淡入时从站姿运动到睡姿），
   或审阅方确认对 `sleep` 按姿势类放宽“有效运动”判据。此项需要审阅决定。
3. `head_follow` 在睡眠时关闭（原版睡眠头部不跟视线）。

## 9. 规模预估

20 骨、约 80 关键帧（静止姿势为主；数量少于站立动作是因为呼吸是唯一运动）。
