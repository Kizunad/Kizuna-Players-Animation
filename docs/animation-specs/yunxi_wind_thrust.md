# yunxi_wind_thrust · 追风直刺

拟用表现 ID `meridian_story:yunxi_wind_thrust`，PA 主手 `yunxi_wind_thrust`、副手 `yunxi_wind_thrust_off`。以下左右以右主手模型为准，原速每刻 50 ms。

## 目的与触发

上卷 `meridian_story:wind_thrust` 受理时从 0 ms 起播。按 P0 选定的「B 侧身平刺」，侧视时，蓄势先把剑放平，随后剑尖沿同一高度向前伸至最远。俯视轨迹沿角色正前方，不绕盾沿。目录判定为 2.9 格、总角 24°、最多一人，距离只用来选靶。挥空也播完整个回收。

## 关键姿势与时间轴

从战斗站姿的左前脚、右后脚起步。侧视选三帧并看：预备末端的水平剑、250 ms 最远剑尖与弓起的前膝、550 ms 收回的两只脚。下表的发力区间是制作目标。

| 剪辑时刻 | 双腿、支撑与胯 | 腰胸、肩与头 | 持剑臂、剑与非持剑手 |
| --- | --- | --- | --- |
| 0–100 ms · 预备 | 前脚松重，后膝压低，后脚前掌接重。胯向后脚小幅坐转，前脚离开原支点。 | 腰胸随胯转成侧身，持剑肩略收，头反向补转，目光保持朝前。 | 后手屈肘，柄收至本侧胸前，腕与挂点把剑转向前。前手略送出配重。 |
| 100–250 ms · 平送 | 后脚前掌蹬伸，前脚向前落一小步并屈膝承重。胯先转向正面，再移到前脚上方。角色原点固定。 | 腰跟胯转，胸与持剑肩稍后向前送，头保持目标在画面中线。 | 上臂先送，前臂展开，腕收住。另手向后下让开轮廓。到 **250 ms（第 5 刻）**，肘接近伸直而保留余量，剑身水平，剑尖最远。 |
| 250–350 ms · 跟随 | 前膝继续吸收重量，后脚趾仍着地，胯减速。 | 腰胸晚于胯停下，肩顺势沉下，头保持平视。 | 肘开始回屈，柄沿原线回退，抵消肩的余势；剑尖不超过命中点。另手暂留后侧。 |
| 350–550 ms · 归架 | 后脚接回重量，前脚提起退回原位再落掌，后跟回到架势高度。 | 胯、腰、胸依次转回半侧身，两肩沉稳，头回架势角度。 | 肘带手回本侧护位，挂点恢复零旋转，剑再竖起。另手回肩前，两手恢复站姿握形。 |

`weapon_strike` 在 250 ms，`active_millis` 为 0。时间线仅有 `hit` 0.25 s，收势 300 ms，剪辑长 **550 ms（11 刻）**。拟定 `thrust` 发力段 0.10–0.25 s，从胯、腰、胸到施放侧上臂、前臂、手分别看角速度峰。以实际播放器 60 Hz 采样本手剑尖，只从发力段量一次 `swings`，淡入、放平和回剑排除，轻重随实测。

## 持物、主副手与覆盖

沿用流金剑「绕」的挂点做法。首末 `item_rotation` 为零，放平时平滑引入本手挂点局部 X 轴补角，发力末段保持对线，回收时平滑归零。可从「绕」的 58° 补角起试，按两手实际腕点调整。在 250 ms 检查剑身和前臂夹角 ≤20°，腕弯折相对架势 ≤40°；从柄到尖的连线同时要在侧视近水平。剑身与头、躯干及另一臂之间保留间隙。[流金剑持物先例](piglin_sword_wind_around.md)

主手由右后肩出剑。副手由左前肩出剑，剑尖横向目标换边，用左肩的位置重解肘腕；前手原已靠前，蓄势行程缩短。胯和胸转动增量换向，脚仍左前右后，右手向后下配重。左惯用手由 PA 镜像整套姿势。持剑侧拇指、两组指骨全程在剪辑中保持本侧握剑形。

两版都用 `mask: full`、`hand: main/off`、`upper_while_moving: true`。静止时看清提步、接重和退步，走动时胯腿跟步态，腰以上仍能看出平刺。`fpv: false`，全身第一人称沿用第三人称轨道，保留默认躯干。classic、slim 共用轨道，两体型分别检查支撑脚滑移 ≤0.5 px、鞋底最低 ≥−0.25 px、侧视剑尖和回收时的脸部净距。[资产契约](../asset-contract.md) · [动画验收](../animation-acceptance.md)

## 首末帧与衔接

一次性，优先级 24，淡入 0.10 s、淡出 0.25 s。首末帧含手指、脚趾均取战斗站姿首帧。从普攻、格挡或受击恢复进入时由当前姿势淡入；收势后可交还普攻或格挡。受伤中断从当前姿势冻结淡出，受击层接管；检查命中前中断时不会补播刺出。实机对帧时另看第 5 刻底层的通用挥手是否露出第二道剑路。[战斗站姿](stance_idle.md)
