# equip_leggings：弯腰把护腿放到膝高撑开，左右脚各穿进一条裤管，沿大腿提到腰并站直

> 审阅状态：待审阅（2026-10-22，第二批退回后重做）。轴向、坐标和数值来源见 [共用约定](conventions.md)。
> 数值已用设计期原型轨道做过正向运动学、三视角预览和门禁同算法检查。

## 1. 动作目的与触发

- **用途**：护腿槽从空变为有物品时，演出“弯腰把护腿下放到膝高、双手撑开腰口 → 抬右膝从腰口穿入、脚往下踩出裤管 → 换左脚 → 双手沿大腿把腰口往上提、身体随之站直 → 拉正腰部”。
- **触发与驱动**：`playArmorEquip` 检测到护腿槽空 → 非空时按世界时钟播放；原版没有穿戴进度。副手持盔甲时播 `equip_leggings_off`（本稿镜像）。
- **Minecraft 体型的限制**：手臂短，站直时手腕枢轴最低只到身前 y≈15。要把腰口放到膝高（手腕约 y=10、指尖约 y=8），上身必须前屈约 70°（腰 34°、胸 40°），并稍屈膝。

## 3. 分阶段全身姿势

腰比关键时刻早 0.01 s，胸晚 0.01 s，头晚 0.02 s；弯腰撑开、穿脚阶段双臂直接手摆为“从肩下垂、两手分开”的姿势，提腰和拉正阶段按腰侧目标点求解，
并约束前臂、手不进入头/胸/腰/胯包围盒。着地腿由胯的姿态做脚底锁定并补锁定帧；抬起的腿手摆，离地、穿出和落地各加一帧“脚底水平、垂直抬高”的 IK 帧。

- **预备（0.14 s）**：低头 14°，胸、腰前屈 7° / 6°；胯左移 0.8 px、下沉 0.4、后坐 0.8；双手前送（上臂前屈 30°、外展 12°，屈肘 22°）。
- **撑开（0.34 s）**：胯左移 1.2 px、下沉 0.9、后坐 2.0，前倾 6°，腰 28°、胸 32° 前屈，头抬 26° 看着双手；双臂前屈 100°、外展 22°、肘近直（4°），
  双手腕约在 `(−1.5, 12.6, −9.9)` / `(4.2, 11.9, −9.4)`，两手相距约 6 px。腰、胸前屈峰值 0.23 / 0.24 s，手臂 0.24 s 同步下放。
- **穿右脚（0.58 s）**：右腿屈髋 72°、屈膝 84°，膝盖抬到两手之间；胯左移 1.7 px、后坐 2.4 px、右侧提 4°，腰 34°、胸 40° 前屈，头抬 30°；双臂外展加大到 30°，腰口张得更开。
  右小腿离地屈膝峰值 0.43 s，大腿抬起峰值 0.52 s：先提脚、后抬膝。
- **踩出（0.74 / 0.92 s）**：右腿往下伸，0.74 s 脚底水平地停在原落点上方 1.6 px（脚从裤管里穿出来），0.84 s 降到 0.8 px，0.92 s 踩实；
  大腿放下峰值 0.68 s，小腿和脚 0.88 s 踩地时最快。胯回中、后坐 2.0 px，腰 32°、胸 38° 仍前屈，双手停在膝高。
- **穿左脚（1.10–1.72 s）**：右脚阶段的镜像，胯右移，左膝抬到两手之间，1.68 s 踩实。
- **提腰（1.88 / 2.02 s）**：1.88 s 双手腕滑到大腿外前侧 `(∓5.8, 14.2, −4.6)`，上身起到腰 20°、胸 22°；2.02 s 手腕到髋两侧 `(∓6.6, 15.4, −1.8)`，屈肘 66°、手腕背伸 24° 拽住腰口，
  腰、胸前屈只剩 8°，头低 4°。起身峰值：胸 1.90 s、腰 1.92 s、头 1.95 s，手臂上提 1.93 s 与之同步。
- **拉正（2.18 s）**：胯右转 5°，腰左转 3°、胸左转 2°，胸后仰 4°，头低 6° 左转 3°；转动峰值：腰 2.07 s、胯 2.09 s、胸 2.11 s。手扶腰侧 `(∓6.6, 15.8, −1.4)`。
- **收势（2.34 s）**：手指 2.22 / 2.24 s 松开，上臂后伸 3°、外展 8°，2.48 s 回零。
- **不动的部位**：`root`。脚趾随脚掌整体运动，离地、落地都是脚底水平进出。
