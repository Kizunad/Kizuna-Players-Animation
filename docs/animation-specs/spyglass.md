# spyglass：望远镜举到右眼，左手托住右前臂

2026-10-23 按用户要求把叉腰改为托臂。已制作关键帧和运行时俯仰联动；离线数值检查通过，视觉效果仍待审图和游戏内验收。轴向与坐标见 [共用约定](conventions.md)，完整关键帧以 classic `.bbmodel` 为准。

## 触发与时间轴

右键使用望远镜时，由 `VanillaAnimationScheduler` 按已使用 tick / 20 取样；主手选 `spyglass`，副手选 [spyglass_off](spyglass_off.md)。剪辑长 2.35 秒，保持末帧，观察阶段在 `loop_region: [0.35, 2.35]` 回绕，无时间线事件。

| 阶段 | 时间（秒） | 姿态 |
| --- | --- | --- |
| 预备 | 0–0.08 | 持镜手下沉，另一只手从身侧准备抬起 |
| 举镜与托臂 | 0.08–0.36 | 右手举镜到右眼前；左手经胸前向右前臂下方抬起，肘腕稍后跟随 |
| 定住 | 0.36–0.47 | 持镜臂收回过冲，左掌朝上托住右前臂内侧下方，手指微曲 |
| 观察 | 0.35–2.35 | 胸腰呼吸带动双臂，保持托掌与前臂的相对位置 |

## 支撑手与持镜手

右上臂保持角约 `(95, -11, 6)`、右肘 `27°`、右腕 `(25, -44, 25)`；沿用原有举镜和持镜轨道。左上臂保持角约 `(106.27, 48.77, 30.05)`、左肘 `14.56°`、左腕 `(-49.56, -110, 4.78)`，使掌面朝上、掌指连接处托住右前臂。平视时掌面法线与向上方向相差约 10.5°，接触参考点在前臂下方约 0.75 像素。以上均为 Blockbench 面板角度；掌面接触由实际骨架求解，避免只按挂点位置判断。

玩家改变视线俯仰时，先把 Minecraft 正值低头转换为模型空间负 X 旋转，双臂在胸部坐标空间绕共同肩线旋转，再恢复为各自局部姿态。不能分别给两个上臂的局部 X 欧拉角加同一个值，否则不同的 Y/Z 角会让托掌脱离前臂。头部继续跟随视线俯仰。

望远镜沿持镜手挂点渲染，不改变道具尺寸。与眼睛的精确对齐、极端俯仰下的身体碰撞仍需游戏内核验。

## 叠加与镜像

索引为 `mask: full`、`priority: 15`、`blend_in: 0.08`、`blend_out: 0.15`、`hand: main`、`fpv: false`。真实潜行或活动的移动/支撑底层存在时只取 `upper`；静止潜行观察可与 `crouch_work` 组合。停止使用时按索引淡出。

副手资源逐帧镜像为右手托左前臂；左主手由播放器再按既有规则镜像，不另写关键帧。粗臂与细臂共用轨道，分别按自己的骨架枢轴计算。

## 验证范围

主副手分别执行导出一致性与粗臂/细臂 60 Hz 门禁。Java 回归使用真实资源，覆盖主副手、左右主手、两种体型和 −89° 至 +89° 俯仰，检查托掌相对前臂的变换保持不变，以及低头时持镜手降低。离线组合预览额外覆盖 ±45° 连续俯仰，八种手侧/体型组合的前臂与躯干穿模检查通过；这些检查不替代游戏内视觉验收。
