## 1. 动作目的与触发

- **用途**：五脏诀强身第五式，照五禽戏虎扑。两拳提到肩前，向前划弧成虎爪，上身前俯、挺胸塌腰；屈膝下按，再伸膝送髋后仰，把身体像弓一样拉开；最后左脚上步成虚步，两爪向前下方扑下去。全书唯一上身前俯又后仰的一式。
- **触发**：五脏诀舒筋起手时，宿主调用 `PlayerAnimationAction.EVOKER_WOOD_SINEW`，按真实时间播放，`start_tick` 同步起点。
- **时长**：剪辑 **5.0 s**（100 tick），`loop: false`。效果 `cast` 2.80。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`0.35: step_r`、`2.50: step_l`、`2.80: cast`、`3.35: step_l`、`3.75: step_r`。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、5.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 开立（0.00–0.40 s）

- 照 E2，时间压缩同 [心火](evoker_fire_heart.md)。两拳 0.05–0.25 松成空拳（E3），两臂垂于体侧。

### 提拳（0.40–0.90 s）

- **腿**：双膝 0.40–0.70 伸到约 3°，胯升到 y 约 0。
- **躯干**：胸 X +3°，吸气。
- **双臂**：两拳沿体侧上提，0.85 到肩前上方 `(±4, 24, −3)` 附近：上臂前屈约 70°、外展 15°，肘屈约 140°，拳心朝后。左臂晚 2 帧。

### 前探（0.90–1.40 s）

- **腿**：胯 0.90–1.40 后移约 1.4 px（z −2.4 → −1.0），双膝约 5°（探针：前俯 −30°、两臂前上举时重心在踝前约 1.2 px，在 ±2 内）。
- **躯干**：胯 X −12°、腰 −10°、胸 −8°，前俯共 −30°；胸相对腰挺 +2°、腰塌（腰 X 比胯、胸的平均少 2°），侧视背是凹的。
- **头**：X +20°（相对胸），看前方。
- **双臂**：两手 0.95–1.35 向上、向前划弧：上臂前屈到约 150°（相对躯干），肘伸到 10°，手在头前上方；手型 1.00–1.30 由空拳变虎爪（E3：腕背伸 50°、拇指 `(35, 0, 35)`、两组手指 60° / 65°），掌心朝下。

### 下按后仰（1.40–2.00 s）

- **按**（1.40–1.65）：双膝屈到 30°（探针：胯降约 0.6 px），胯 X −15°、腰 −13°、胸 −12°（前俯 −40°，收腹含胸）；两手下划到大腿前侧，指尖约 y 9（第 8 节第 1 条）。
- **仰**（1.65–2.00）：双膝伸到 5°；胯前送约 1.8 px（z −1.0 → −2.8）、X 回 +4°，腰 +3°、胸 +3°，后仰共 +10°（腰先到、胸后到）；头 X 回 0。两手 1.65–1.75 握拳，1.70–2.00 沿体侧上提到胸侧 `(±4.5, 17, 1)` 附近：上臂后伸约 −30°、肘屈约 110°。
- 腰、胸、右上臂、右前臂、右手在 1.70–2.00 依次到峰值（第 4 节）。

### 扑（2.00–2.80 s）

- **腿**：
  - 胯 2.00–2.10 右移到右脚上方（x 约 −2.6）；
  - 左大腿 2.10–2.35 提到约 50°，左脚 2.35–2.50 向前落，2.50 脚跟着地于 `(2.3, 1.2, −5.6)` 附近，脚尖翘 ≤ 12°；
  - 右膝 2.10–2.60 屈到 40°（胯降约 0.9 px），重心留在右脚（虚步）。
- **躯干**：2.35–2.70 胯 X −10°、腰 −8°、胸 −7°（前倾 −25°）；头 X +15°。
- **双臂**：两拳 2.00–2.40 上举到头前（上臂前屈约 130°、肘 90°）；2.40–2.50 拳变虎爪；2.45–2.75 向前、向下扑：上臂前屈到约 60°、肘伸到 15°，两爪到膝前两侧 `(±3, 9, −8)` 附近，掌心朝下。

### 定（2.80–3.10 s）

- 虚步定住；头 X 再 +5°。

### 收（3.10–5.00 s）

- **左脚**：3.10–3.15 胯微升；左脚 3.15 离地，3.35 全掌落回 `(2.3, 1, −2.6)`、外转 10°（`step_l`）。
- **右脚**：胯 3.35–3.45 左移压左脚；右脚 3.45 离地，3.75 以提踵落回 `(−1.7, 1.72, 3.2)`（`step_r`）。
- **胯、上身**：躯干 3.10–3.80 回正，胯 3.75–4.30 降回架势、转回 `(−6, 12, 0)`；腰、胸、头回架势；呼气 3.40–4.20。
- **双臂**：虎爪 3.20–3.45 握拳，两拳 3.30–4.40 回护身位。
