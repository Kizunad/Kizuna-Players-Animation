# guard_weapon：横兵器抱架

> 原速抬手 200 ms，随后每 1.60 s 呼吸一轮。以下左右以右主手角色自身为准。

## 1. 目的与触发

玩家在战斗架势中持兵器起守。主手把兵器横到上胸与下颌前方，副手从下方托上来。正面一眼能看见一件兵器横跨身体中线，两只手分处握柄和承托的位置。宿主选择本段并给出起播时刻，角色守到收势或中断。

## 2. 关键姿势与支撑

- **起姿**逐骨取 `stance_idle` 首帧，包括握形和脚趾。左脚在前、全掌着地，右脚在后、前掌着地。主手一直握柄，副手从架势前拳打开。
- **横架基准**取 200 ms 抬完、吸气前的姿势。右手握柄在身体中线偏右、锁骨前下方，兵器朝左横过中线，远端可略高。左掌在中线另一侧靠近柄的一段托住兵器。双肘低于手，收在各自胸侧。正面看得清双眼、握柄手和兵器远端；从侧面看，兵器与下颌、上胸之间有空隙，够下一段受击往回一震。
- **剑和斧共用一双手的位置。** 主手物品只随 `r_item` 及物品自己的显示变换。副手掌根抵护手外、靠近剑根的剑身平面，手指微屈，刃线露在掌外。换铁斧时，同一掌根要贴到斧头下方的短柄，斧头和刃口留在手外。以两件物品的实际轮廓找这个托点；只在正面投影重合、侧面悬空的姿势需重做。
- **全身轮廓**保留架势里的前后脚差，膝微屈、胯略沉，下颌轻收，视线越过兵器。侧面要看得出兵器是由两臂送到身前，上背保留架势的自然斜度。三段共用整个人的横架基准，包括指形与后脚前掌。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 画面 |
| --- | --- |
| 0–50 ms | 双膝、胯先接住重量。右肩带握柄手略向身前送，为旋横腾出脸前的空间。左肘仍收着，左拳开始打开。 |
| 50–150 ms | 右肘带腕把兵器长轴转向左侧，剑尖或斧头始终沿身前的弧线走。左手从兵器下方迎上，胸口微转，头仍看前方。 |
| 150–200 ms | 两肩先稳，主手腕止住旋转，副手掌根贴实，肘仍低于兵器。到 200 ms 远端、托点与主手握位均清楚可见。 |
| 200–850 ms | 吸气，胸口微展，两肩、双手和整件兵器略起；两手间距与相对朝向保持稳定。 |
| 850–1800 ms | 呼气，重量经腰胯落回双脚，双手随胸回到横架基准。呼吸跨界时动作速度连续，脚底接点稳定。 |

## 4. 播放、覆盖与衔接

剪辑长 1.80 s，`loop: hold_on_last_frame`。索引声明 `loop_region: [0.20, 1.80]`、`free_loop_region: true`、`priority: 15`、淡入 0.05 s、淡出 0.08 s。200 ms 是视觉成架标记。仅呼吸区间回绕，循环两端逐骨同姿；持续动作由宿主停止，无自然结束 tick。三段均无玩法时间线事件。

三段索引均取 `mask: full`、`hand: main`、`fpv: false`。按既有架势覆盖规则，站定时全身联动，`root` 固定；走动时只取 `upper` 的腰、胸、头和两臂至手指，胯和两腿至脚趾由当前步态驱动。左主手由播放器镜像整段，左右手交换握、托职责。全身第一人称沿用同一骨架和持物挂点，平视时准星前方应清楚。

受击在呼吸上叠播，放下接宿主的收势。两段都引用这里的横架基准。[挡中受击](guard_weapon_hit.md) · [放下](guard_weapon_lower.md)

## 5. 审片与验收

草稿按粗臂铁剑、粗臂铁斧、细臂铁剑、细臂铁斧，用同一条轨道、相同机位出 20 fps GIF 与接触表。正面读横架与空手双前臂护面的轮廓差别，侧面看兵器到脸、胸的净距，四分之三视角看副手是否真托上、斧头是否压进手背。连续看起手、守两秒、受击两下、放下；单段另看两轮呼吸的托点。

接入 PA 后对自由播放取非端点姿势：0.60、2.20、3.80 s 应同相，且与 1.80 s 端点可区分；晚追踪按原起播 tick 赶到 3.80 s，应与从头播到这一刻同姿。实机再查镜像握托、行走时腿部步态和第一人称视野。
