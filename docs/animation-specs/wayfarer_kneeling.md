## 1. 动作目的与触发

- **用途**：行矢第六式，照兵马俑的跪射俑：右膝着地、左膝立起。弩横架在左腿上拉弦，举到脸边瞄准、射出，一共三次，一次比一次快。最后撑地站起来。全套唯一跪下的一式。
- **与其他弩式的区别**：连弩、横风都站着、用短行程推拉；**跪射跪着，每次把弩落回腿上用 `crossbow_charge` 的长行程拉弦**，三发之间有完整的「落 → 拉 → 举 → 瞄」。
- **触发**：行矢跪射起手时，宿主调用 `PlayerAnimationAction.WAYFARER_KNEELING`（弩在副手时 `_OFF`），按真实时间播放，`start_tick` 同步起点。跪下只是动画，碰撞箱不变（动作稿 §9）。
- **时长**：剪辑 **7.0 s**（140 tick），`loop: false`。撒放 2.60、3.70、4.80 s。
- **承接**：承接入口 0.40。作后式：五个弓式（天地同至除外）换兵接跪射，从 0.40 起播。作前式：满月 0.40、连珠 0.40、弓梢 0.30（换兵）。收势从 4.80 起，前半段到 5.90，右脚 5.85 已回架势踝位。
- **打断**：起手 0–2.60 s 被伤害打断时淡出 0.20 s（跪着被打断时在淡出里站起来，不另做）。
- **时间线事件**：`0.70: step_r`、`2.60 / 3.70 / 4.80: release`、`5.85: step_r`。

## 3. 分阶段全身姿势

「相对架势」是在 [stance_idle](stance_idle.md) 第 3 节基准上的增量（C1）。跪姿数值见 C10（探针，已按左脚不动平移）。

### 起点与终点（0.00 s、7.00 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 预备（0.00–0.40 s）

- 胸 X −2°，胯位置前送 0.2 px。0.40 s 全身速度为零（承接入口）。

### 下跪（0.40–1.30 s）

- **右脚后撤**：0.40 离地（架势提踵，脚尖先离地），向后摆 7.7 px；脚掌在空中转到竖直（世界俯仰约 −80°）、脚趾 0°；**0.70 脚尖点地落在终点**，踝 `(−1.7, 2.6, 10.9)`（探针），之后到起身前踝不动（C10）。
- **胯**：0.40–0.70 后移约 2 px、下降约 1 px（胯不后移右腿够不到：髋到终点踝要 12.8 px，腿长 11 px）；0.70–1.20 继续到 `(0.15, −4.0, 3.5)`，X −6° → 0°。
- **右膝**：0.70–1.20 绕固定的右踝落下，右膝屈到约 73°、右大腿 X 约 −18°；踝角 −11° → +16°（限 75°），脚尖一直着地（≤ 0.23 px，探针）。**1.20 右小腿近乎水平贴地**，最低点约 0.04 px（探针）。
- **左腿**：左脚全掌不动 `(2.3, 1.0, −2.6)`；左膝 0.70–1.20 屈到约 70°（动作稿「立起约 90°」：胯只降 2.2 px，左膝不用屈到 90°）。
- **上身**：胯 X 回 0、躯干竖直，胸 X 回 0；右手 0.80–1.25 把弩放低到右胯旁（弩口朝前下）。
- 1.20–1.30 静止一帧（着地）。

### 膝上装填一（1.30–1.95 s）

- **躯干**：1.30–1.45 前倾到 −8°（胯 X −3°、腰 −3°、胸 −2°）；拉弦时随用力回到 −2°（1.88）。
- **架弩**：1.30–1.40 右手把弩横过来，斜架在左大腿上：前端搭在左大腿中段上面（约 `(2.2, 9.5, 0)`），弩托抬向右胸，扳机在胸前中线附近（同 [crossbow_charge](crossbow_charge.md) 把弩压在左胸、前端斜指左胯的做法，只是前端落在大腿上）。
- **拉弦**：左手 1.40 在前端勾住弦，1.40–1.88 沿 `crossbow_charge` 的弦路径拉回扳机（约 7.5 px）；物品 1.40 `pulling` 开，`pull` 0 → 1（1.68 换 `_1`，1.88 换 `_2`）；1.92 `pulling` 关、`charged` 开。
- 动作稿「前端搭在左膝外侧」：跪姿里膝离肩约 11.4 px，左手够不到（第 7 节第 2 条）。

### 举、瞄一（1.95–2.60 s）

- **躯干**：1.95–2.25 回到竖直；胸 Y +12°（左肩前送，同 `crossbow_hold`）；头 Y −12° 回正前。
- **举弩**：1.95–2.25 右手把弩举到右颊前（照 `crossbow_hold` 的末帧在胸系里的位置，跪姿胯低 2.2 px，整体随之低）；左手托弩身，左肘尽量压低。
- **瞄**：2.25–2.55 屏气（胸不动），双前臂弱颤 ±0.5°（technique_charge 弱颤做法）。

### 射一（2.60 s）

- `release`；弩口上跳 3°（右前臂、腕，0.05 s 上、0.05 s 回）；胸 X +1° 后回；`charged` 关。

### 二（2.65–3.70 s）

- 2.65–2.82 弩落回左大腿（右上臂约 60°，0.17 s，峰值约 660°/s）；躯干前倾到 −5°。
- 2.82–3.05 左手拉弦（7.5 px，0.23 s，左肘峰值约 570°/s）；物品 2.82 `pulling` 开、`pull` 0 → 1（3.03 到 1）；3.06 `charged` 开。
- 3.06–3.35 举到右颊；3.35–3.65 瞄（弱颤）；**`release` 3.70**。

### 三（3.75–4.80 s）

- 3.75–3.92 落；3.92–4.14 拉弦（`pull` 4.13 到 1）；4.16 `charged` 开；4.15–4.45 举；4.45–4.75 瞄；**`release` 4.80**。

### 随（4.80–5.10 s）

- 弩仍在脸旁；4.85–5.10 呼气（胸 X −1°）。

### 起身（5.10–5.90 s）

- **蹬起**：5.10 左脚踩地发力、右脚尖蹬地（右踝仍不动）；躯干前倾到 −6°（5.25）；5.10–5.55 胯升回 `(0.45, −1.8, 0.6)`（架势高度、前移回原位、左移 0.3 px 让重心进左脚），右膝随之离地（约 5.25）、右腿伸。
- **右脚上前**：5.60 离地，向前摆 7.7 px，脚掌由竖直转回提踵 −35°；**5.85 落回 `(−1.7, 1.72, 3.2)`**；胯 5.85–5.95 右移回架势位置。
- **双臂**：5.10–5.60 弩由颊边放回右胯旁。
- 躯干 5.40–5.90 回直。

### 收（5.90–7.00 s）

- 胸、头回架势（6.40 到位），6.00–6.70 呼气；弩 6.50 回持物位，左手 6.60 回下巴前；6.70–7.00 静止。

## 5. 衔接

- 起止等于 `stance_idle` 首帧：`stance_idle → wayfarer_kneeling` 0.10 / 0.25，播完淡回 0.25 / 0.25。
- 作后式：弓式换兵接跪射，从 0.40 s 起播，前一式淡出 0.30 s。
- 作前式：满月 0.40、连珠 0.40、弓梢 0.30 s（换兵）；时窗在收势后半段（5.90–7.00），已站起。
- 打断：起手 0–2.60 淡出 0.20 s。跪着时被打断，0.20 s 内从跪姿淡回架势（胯升 2.2 px、右脚前移 7.7 px 都在淡出里），和其他式一样不另做。

## 7. 骨架与门禁带来的约束

1. **跪姿**（C10，探针）：胯再低右小腿就穿地；这副骨架的脚只有 1 px 高、脚趾枢轴在踝正下方，「脚趾背伸 60° 抵地」摆不出，做成脚竖直、脚尖点地，Minecraft 尺度上看起来就是脚趾扣地。右脚后撤 7.7 px 比一般后撤步长，是跪姿两脚前后跨度 13.5 px 决定的（左脚不动）；也可以左脚前移 2.9 px、右脚少撤，但动作稿只写右脚后撤，照它。
2. **左手够不到膝**：跪姿肩高约 18，左膝顶面约 y 8、z −2.6，左肩到膝外侧约 11.4 px，超过手臂 10.2 px；大腿中段上面约 8.7 px，够得着。弩前端搭在大腿中段，弩托抬向右胸，同 `crossbow_charge` 的斜架。
3. **左肘支不到膝**（动作稿 §9 待原型）：举弩时左手约在 y 20，肘到手约 7 px，肘最低到 y 13，离膝顶面约 5 px。左肘只能「尽量压低」。
4. **落弩速度**：动作稿第二、三次 0.10 s 把弩从颊边落回腿上，右上臂约 60°，峰值约 1,125°/s；放到 0.17 s（峰值约 660），拉弦相应缩到 0.22–0.23 s（左肘峰值约 570）。「一次比一次快」由拉、举、瞄合计 1.05 s 对第一次 1.30 s 体现。
