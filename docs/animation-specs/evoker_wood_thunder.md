## 1. 动作目的与触发

- **用途**：五脏诀附伤「惊雷」。起手「唤」后，两臂伸直向前上举过额，在额前上方一拍；然后两手分开，沿两侧往下拉到肩高，手臂发颤，像把雷从天上引下来。全书唯一击掌的一式。
- **触发**：五脏诀惊雷起手时，宿主调用 `PlayerAnimationAction.EVOKER_WOOD_THUNDER`，按真实时间播放，`start_tick` 同步起点。不开立。
- **时长**：剪辑 **3.5 s**（70 tick），`loop: false`。击掌 `clap` 1.40，效果 `cast` 2.00。
- **打断**：起手被伤害打断时淡出 0.20 s 回架势。
- **时间线事件**：`1.40: clap`、`2.00: cast`。两脚整段着地不离地。

## 3. 分阶段全身姿势

### 起点与终点（0.00 s、3.50 s）

与 `stance_idle` 首帧完全一致，首尾速度为零。

### 唤（0.00–0.70 s）

见 E5。

### 上举（0.70–1.30 s）

- **脚**：0.80–1.20 前脚提踵半程：踝 1.00 → 1.45、脚底约 −15°；后脚踝 1.72 → 2.10、脚底 −35° → 约 −45°；两脚趾前缘不动（E7）。胯随之升约 0.4 px。
- **躯干**：腰 X +2°、胸 X +5°（0.80–1.10），头 X +20°（0.85–1.20），看两手。
- **双臂**：由唤位向前上举：上臂前屈到约 150°、内收约 10°，肘伸到 5°；两手 1.25 在额前上方 `(±2.5, 27.5, −5.5)` 附近，掌心相对，相距约 1 px（内侧面之间）。手型掌。右臂先、左臂晚 2 帧。

### 击掌（1.30–1.45 s）

- **双臂**：两手 1.30–1.40 内收合拢，1.40 两掌内侧面相拍（间隙 ≤ 0.5 px、不穿），`clap`；1.40–1.45 贴住，1.45 起分开。两手离头盒 ≥ 0.5 px。

### 引雷（1.45–2.10 s）

- **脚**：1.45–1.55 两脚跟落回（前脚踝回 1.00、后脚回 1.72）；胯 1.50–1.80 降约 0.3 px（双膝各再屈约 15°）。
- **躯干**：胸 X +5° → 0、头 X +20° → 0（1.45–1.75）。
- **双臂**：两手 1.45–1.85 分开，沿两侧往下拉：上臂由前屈 150° 转到外展 90°（侧平举），肘 15°，两手在肩外 `(±13, 22, −2)` 附近，掌心朝下。1.65 起两上臂、前臂叠加 ±3° 颤（约 6 Hz，0.10 s 内渐强），上臂与前臂错 1/4 周期，左右反相；颤持续到 2.10。

### 收（2.10–3.50 s）

- 颤 2.10–2.20 渐弱停。两臂 2.10–3.00 落下、回护身位；两掌 2.30–2.60 握拳。
- 胯 2.10–2.80 回 `(0.15, −1.8, 0.6)`、旋转 `(−6, 12, 0)`；腰、胸、头回架势。

## 11. 制作实测（2026-11-01）

原型 `kpa-door-breaker-proto/evoker/d_wood_thunder.py` 求解（交接目录，不入库；共用的「唤」「收」在 `ev.py`，提踵沿用千里腿 `ped.py`），由 `install_ev.py` 装进 `player_skeleton_classic.bbmodel` 后导出。下列数值取自导出资源按粗、细臂两套几何跑的分析器报告（除相触一项外两套相同）和原型自查。

**索引实际值**：同第 7 节，`hand_contact_windows` `[[1.40, 1.45]]`，`phases` `[[0.70, 1.45], [1.45, 2.10]]`，时间线 `1.40 clap`、`2.00 cast`。

**门禁**：全部通过。
- 关键帧 1,010（目标 800–1,000，略超）。
- 全段最快 680°/s（右手 `fingers_b` 0.15 s，唤段松拳）；下拉时右上臂 X 427°/s（1.65 s，规格估 240）。抽搐最大 0.49×10⁶°/s³（右手 0.48 s，唤段）。
- 最低点 −0.168 px（右脚趾 1.48 s，落跟）；重心没出界。
- 半提踵：踝 Y 范围左 0.44、右 0.38 px（要求 ≤ 0.45），X ≤ 0.02 px。
- 手臂穿模 0（门禁按方块中心判）。
- 预备 / 跟随 4/5 骨。
- 错峰：
  - 上举到击掌 `[0.70, 1.45]`：腰 X 0.883 → 胸 X 0.933 → 右上臂 0.983（Z）→ 右前臂 1.033 → 右手 1.10；
  - 引雷 `[1.45, 2.10]`：胸 X 1.617 → 右上臂 1.717（Z）→ 右手 1.733 → 右前臂 1.75。前臂比手晚 1 帧，在门禁的 2 帧容差内。
- 曲线相关 1/253 对。
- 两手相触：窗口 4 帧，最大间隙粗臂 0.17 px、细臂 0.30 px，穿入 0。

**自查**：
- 1.40 击掌那帧两掌间隙 0.155 px；1.25–1.45 前臂和手离头盒最近 0.82 px（规格要两手 ≥ 0.5）。
- 实体探针 `ev.clip_clash`（标准见 PROGRESS「制作实测」）：
  - 手、前臂对头不超过 `stance_idle` 本身：右拇指 1.01 px（架势本身）；
  - 上臂肩角对头：左 1.03 px（1.82 s）、右 0.81 px（1.90 s），都在侧平举；击掌时上臂贴着头盒侧角约 0.03 px；
  - 前臂压进躯干前角：左前臂对胸 0.73 px（1.42 s，击掌时前臂斜过胸口上沿）；右前臂对腰 0.78 px（2.68 s，回护身位途中）。

**与规格的出入**：
- **击掌改在面前（下巴略上）**：左手掌心点 `(2.4, 24.5, −7.0)`、右手 `(−2.4, 24.5, −7.0)`（胸系），指尖朝上偏前 30°；头仍抬 20°。规格的额前上方 `(±2.5, 27.5, −5.5)` 时上臂、前臂沿头盒两角扫过，前臂和手压进头盒约 0.3 px（头抬 20°～30°、指尖朝上到朝前上 45° 都试过）；手再往前就超出臂长。两掌贴合时掌心点相距约 4.8 px（同[灼火](evoker_fire_burn.md)第 11 节）。
- 击掌时上臂欧拉角约 `(85, −27, −17)`、肘 29°（规格前屈约 150°、肘 5°）：手离肩约 7.9 px，在臂长内，肘伸不直。
- 上举：右臂 0.75–1.21、左臂晚 2 帧，前臂晚 0.04 s、手晚 0.08 s；到击掌前位（每只手外移 0.45 px，两掌内侧面相距约 1 px）。击掌 1.30–1.40 两手同时合拢（左臂不晚，两掌同帧相拍），目标轻拉向上举位的解：不拉时只移 0.45 px，上臂、前臂却各换 5°～9° 的解，合拢那一下上臂 Z 转速（72°/s）盖过上举（66°/s），上举段的上臂峰落到前臂后面（右上臂的主通道是侧平举的 Z）。
- **侧拉终点**：两手 `(±13.3, 21.5, −1.5)`（规格 `(±13, 22, −2)`），掌心朝下、指尖朝外，肘约 16°（规格 15°）。规格的点解出肘 31°，和击掌时差不多，下拉时前臂几乎不动，前臂峰值全由颤决定、落不进错峰顺序；外移 0.3 px、低 0.5 px、后 0.5 px 后前臂伸 13°，和颤一起出峰。
- **颤加初相 1.3 rad**：从 1.65 起渐强不变，前臂颤的回摆（伸肘方向）第一次满幅在 1.74 前后，和下拉的伸肘同向叠加，前臂峰落在右手峰 2 帧内。初相 0 时这一下在 1.78，前臂峰晚于手。规格说的「把颤往后挪」不管用：下拉本身前臂只有约 60°/s，低于颤的峰速 113°/s，往后挪了前臂峰就是后面某一下颤。
- 提踵：踝升左 0.42、右 0.36 px（规格 0.45、0.38，膝随动再多约 0.02，留出 E7 的 0.45），脚底俯仰左 −15°、右 −45°；脚趾前缘不动，按踝高反求脚趾俯仰。
- 躯干：腰 0.76–1.00 到 +2°、胸 0.80–1.04 到 +5°（规格都到 1.10）；胯 1.45–1.80 降到 y −1.6（规格 1.50 起）。

- 接触表时刻同第 10 节（19 个）。
