# idle_akimbo · 叉腰站

> 玩家版 `idle_akimbo_enter`、`idle_akimbo`、`idle_akimbo_exit`，村民骨架版各加 `_robed`。状态：2026-11-27 资源已生成并收进 `npc_poses` 分组，待用户看 GIF；第二段和本规格不同的地方见[总览第 8 节](PROGRESS-npc-poses.md#8-第二段实现记录与和规格不同的地方)。
> 共用约定见 [NPC 日常姿态总览](PROGRESS-npc-poses.md)。

## 1. 目的与触发

叉腰站：双手撑在腰胯两侧，挺胸。给书摊摊主、货郎这类站着等客、有点架子的 NPC，不再一直摆战斗站姿。

非战斗 NPC 静止时由宿主选中。走到位后先播进入段，再循环；平常收姿播退出段，被打或进入战斗时宿主立即 STOP，见总览第 4 节。

## 3. 关键姿势：叉腰基准

| 部位 | 玩家版 | 村民骨架版 |
| --- | --- | --- |
| 脚（日常站位，五个站姿共用） | 左脚稍前全掌，踝 (2.3, 1, −2.6)，不动；右脚全掌，踝 (−2.6, 1, 0.6)。前后错 3.2 px，左右宽 4.9 px，脚尖各外撇 8° | 同。袍子下只露出小腿下段和脚 |
| 重心 | 落在右腿上：胯右移 0.6 px、左侧低 3°，右膝几乎伸直（屈 3°），左膝放松屈 9° | 同。远看是袍子跟着胯斜一点 |
| 胯、腰、胸 | 胯升回站立高度，不再下沉。**挺胸**：胸后仰 4°、腰 2°，两肩后张 0.5 px | 同 |
| 头 | 抬下巴 3°，正视前方 | 同 |
| 双手 | 掌根压在髂嵴，即胯块上沿两侧 (∓4.5, 14.5, −0.3)。四指朝前下，拇指在后，掌面和身侧的间隙 ≤ 0.5 px | 手贴在膨胀后的袍面上：离内盒 0.4–0.5 px，x ±4.5。正好在门禁 0.5 px 的相触上限内 |
| 肘 | 两肘向外向后张开：上臂外展约 50°、后伸 10°，肘屈约 100° | 同。村民躯干厚，肘多往后 0.5 px |
| 手指 | 三片依次屈 10° / 14° / 20°，拇指往后包 25° | 同 |

## 4. 进入段（0.50 s）

| 时段 | 腿、胯 | 躯干、头 | 双臂 |
| --- | --- | --- | --- |
| 0.00–0.12 | 胯先回正、上升 1.8 px（站直），右后脚放下脚跟 | 胸、腰的右转（20°）跟着胯解开，各晚 1 刻。头的左转 19° 同步回正 | 拳往下一沉，手指松开 |
| 0.10–0.30 | 右脚离地 0.6 px，往前收 2.6 px，0.30 落地（`step_r`）。重心落到右腿上 | 胸开始挺，0.30 后仰到 2° | 两臂往外下摆，肘先往外走，比手早 1 刻 |
| 0.25–0.42 | 右膝伸直，左膝放松 | 胸挺到 4°，两肩后张，抬下巴 | 手往腰侧收，**0.42 掌根落在胯上沿**。手指晚 1 刻张开再贴住 |
| 0.42–0.50 | 稳住 | 吸一口气，肩提 0.3 px，作为叉稳的收尾 | 手稍压一下：肘再外张 2° 后回来，速度归零 |

## 5. 循环（12.0 s）

基础层：

| 层 | 周期 | 内容 |
| --- | --- | --- |
| 呼吸 | 4.0 s × 3 | 胸后仰 1.2°、肩提 0.3 px，叉着的两肘随肩起伏 |
| 身体摇 | 12 s | 胸偏航 ±1.5°，胯晚 0.5 s 反向 ±0.6° |
| 手指 | 12 s | 右手指在胯上点两下（1.2 s、1.5 s），左手不动 |

小动作：

| 段 | 时段 (s) | 内容 |
| --- | --- | --- |
| A1 换到左腿 | 2.60–3.60 | 胯向左移 1.2 px，左侧抬起、右侧低下 3°。左膝伸直，右膝放松，右脚跟抬起 0.2 px，脚掌不动。胸反向侧倾 1.5°，晚 2 刻，头保持水平。两脚全程不滑 |
| A2 往左看 | 4.30–5.60 | 头慢慢左转 28°，胸跟着转 6°，晚 2 刻。4.80–5.10 停住，看远处，再转回 |
| A3 拍衣襟 | 6.40–8.10 | 右肩先沉 0.4 px，6.55 右手离开胯，肘往里收，手掌平着拍到胸腹前的衣襟上，6.95 和 7.25 各一下。拍之前手指张开，拍后手腕弹回 12°。头低 10° 看一眼，晚 1 刻。7.45–8.10 手回到胯上叉好，8.00 贴住后压一下 |
| A4 换回右腿 | 8.80–9.80 | A1 的反向，速度稍快，0.9 s 完成，9.80 过冲 0.3 px 后收住 |
| A5 往右看 | 10.20–11.40 | 头右转 18°，比 A2 短、幅度小，转回时轻轻点一下头（下 2°） |
| 回到基准 | 11.40–12.00 | 只剩呼吸和摇 |

起点 2.6、4.3、6.4、8.8、10.2 s，间隔各不相同。A3 期间右手离胯，所以相触窗口在 6.40–8.10 s 断开。

## 6. 退出段（0.30 s）

| 时段 | 内容 |
| --- | --- |
| 0.00–0.06 | 手指先收，手离开胯。胸的后仰收回，胯开始下沉 |
| 0.04–0.22 | 右脚提起后撤 2.6 px，0.22 前掌落地、提踵（`step_r`）。胯沉 1.8 px、右转 12°，胸、腰右转 20°，各晚 1 刻 |
| 0.06–0.30 | 两臂由外张收到身前护拳：左拳先到下巴前（0.24），右拳后到（0.28）。手指握拳晚 1 刻。头左转 19°、收下巴。0.30 等于 `stance_idle` 首帧 |

## 7. 骨架差异（村民骨架版）

- 手贴膨胀后的袍面，离内盒 0.4–0.5 px。肘多往后 0.5 px，前臂不碰胸前的膨胀面。
- A3 拍衣襟拍在胸前膨胀面 z −3.5 上，玩家是 −2.25。
- 头更大，A2、A5 转头时帽沿不碰肩。叉腰时两肩后张，肩和帽沿之间的空隙够。

## 8. 验收

- 门禁：
  - 玩家版过粗臂、细臂，村民骨架版过换算的村民几何；
  - 进出两段和循环都按站立口径查：不穿地、支撑脚滑动 ≤ 0.5 px、重心在支撑脚 ±2 px 内（循环需要总览待审决定 3）；
  - 相触窗口内两手贴着胯；
  - 循环首尾连续。
- **切入矩阵**：循环每 0.25 s 一档淡入退出段，看 A3 拍到一半时切出去，手不穿身体。
- 60 Hz 峰值：进入看胯 → 胸 → 肩 → 肘 → 手，退出看手指 → 胯 → 腰胸 → 肩 → 拳。
