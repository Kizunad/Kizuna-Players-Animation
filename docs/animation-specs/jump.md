## 1. 动作目的与触发

- **用途**：玩家离地后的整段腾空表现，包括主动跳跃、走下台阶或被击飞后的下落，以及落地缓冲。
  [切换表](transitions.md) 中的 `jump_takeoff` / `jump_air` / `jump_land` 三个状态都由这一段剪辑的不同时间区间表现。
- **原版物理**（不由动画推动）：起跳时竖直速度 `vy0 = 0.42` 格/tick（跳跃提升每级 +0.1），每 tick `vy = (vy − 0.08) × 0.98`。
  平地起跳约第 6 tick 到顶点（高 1.25 格），约第 12 tick（0.60 s）落地，落地时 `vy ≈ −0.42`～`−0.45`。
- **结束**：落地缓冲播完（剪辑 0.90 s）后淡回当前底层；落地后立刻再跳则直接重新开始。

## 2. 时间轴与驱动

剪辑长度 **0.90 s**，`loop: false`。腾空段按竖直速度取样，落地段按真实时间播放：

| 段 | 剪辑时间 | 驱动 | 内容 |
| --- | --- | --- | --- |
| 起跳 | 0.00–0.12 | 竖直速度 | 下蹲姿态蹬伸：髋膝伸直、踝跖屈、脚趾蹬地，双臂由后向前上摆 |
| 上升 | 0.12–0.27 | 竖直速度 | 开始收腿，双臂继续上抬外展 |
| 顶点 | 0.27–0.33 | 竖直速度 | 收腿最深（右膝 80°、左膝 72°），双臂前平外展 |
| 下落 | 0.33–0.60 | 竖直速度 | 双腿向下伸展找地面，双臂张开保持平衡，低头看落点 |
| 落地缓冲 | 0.60–0.90 | 落地沿起的真实时间 | 0.60 触地，0.72 缓冲最深（胯下沉 1.9 px、膝 65°），0.80 回弹，0.90 站直 |

驱动（运行时需求，见 `/tmp/players-animation-redo-notes.md` 的「分工」节第 6 条，本稿修订为按 vy0 归一化）：

- **腾空**：`t = clamp(0.30 × (1 − vy / vy0), 0, 0.60)`。`vy` 取被渲染实体每 tick 的 y 差值（格/tick，带 tickDelta 插值），
  这样远端玩家也可靠；`vy0` 取离地沿那一 tick 的 vy。
  - 平地跳：`vy = vy0` 时 t = 0；第 2 tick（vy = 0.248）t = 0.12，起跳段刚好结束；顶点 vy = 0 时 t = 0.30；
    落地前 vy ≈ −0.42 时 t = 0.60。剪辑时间与真实时间基本一致，GIF 的节奏就是游戏里的节奏。
  - 跳跃提升：vy0 变大，同一公式自动把顶点放在 vy = 0，只是整体变慢。
  - 走下台阶、被击飞后下落等没有起跳冲量的离地（离地沿 vy0 ≤ 0.2）：按 `vy0 = 0.42` 计算。
    第一 tick vy ≈ −0.08，对应 t ≈ 0.36，直接从顶点后的下落姿态开始，不会演出不存在的蹬地。
  - 长时间下落：t 停在 0.60，保持“伸腿找地面”的姿势。
- **落地**：`onGround` 由假变真时，从 t = 0.60 起按真实时间播到 0.90。若落地时 t 还没到 0.60（跳上一格高的方块，
  约 vy = −0.15、t ≈ 0.41），用 0.05 s 交叉淡入从当前腾空姿态接到 0.60。
- **连跳**：落地段中再次离地，用 0.05 s 交叉淡入回到 t = 0。缓冲下蹲和起跳下蹲姿势接近，连跳不会弹回站姿。
- 现有 `VanillaAnimationScheduler` 在落地沿发 `stop`，需改为“落地沿进入落地段，播完自然结束”。

## 3. 分阶段全身姿势

### 起跳（0.00–0.12 s）

剪辑从离地那一刻开始，原版此时已经起跳，没有离地前的预备时间。因此把预备的下蹲放在首帧（淡入 0.05 s），
再用 0.12 s 蹬伸，观感是“蹲—蹬”，而不是先离地再下蹲。

- **胯**：0.00 s 下沉 0.9 px、后坐 0.3 px、前倾 8°（屈髋），0.06 s 回到 −0.3 px，0.12 s 上抬到 +1.0 px、后仰 2°。
  上抬的 1 px 是蹬伸的“拉长”，让脚尖绷直时不穿过模型地面；实体本身已在上升，不会造成脚底悬空的错觉。
- **腿**：首帧屈髋 31°、屈膝 47°、踝背屈 24°，双脚全掌着地（0.00–0.06 s 由胯姿态锁定求得）。
  0.07 s 髋、膝角速度到峰值，0.10 s 踝跖屈到峰值，0.12 s 腿几乎伸直（膝 5°、踝 −12°）；脚趾 0.06–0.12 s 背伸到 22° / 19°，表现最后的蹬离。
- **躯干**：腰从前屈 8° 打开到 0.13 s 后仰 3°，胸 0.14 s 后仰 4°，整条躯干在蹬伸后段伸展。
- **头**：首帧抬头 11°，抵消身体前倾，保持平视；0.18 s 回到 2°。
- **双臂**：首帧后摆（右上臂后伸 22°、外展 8°，左侧对称略小），0.06 s 角速度峰值、比髋膝略早；0.10 s 已前摆到 22° / 18°；肘微屈 16°～22°。
- **手**：首帧手腕背伸、手指松开，蹬伸时手指自然半握到 22°～26°。

### 上升与顶点（0.12–0.33 s）

- **腿**：0.20 s 起收腿，右腿先收（大腿屈髋角速度峰值 0.17 s），左腿晚约 0.07 s，避免左右同步的机械感。
  0.30 s 顶点：右腿屈髋 46°、屈膝 80°，左腿屈髋 40°、屈膝 72°；大腿各外旋 3°～5°、外展 2°～3°，膝向外分开；踝从绷直回到 −6° / −8°。
- **胯**：+1.0 px 回落到 +0.6 px，前倾 4°，配合收腿的团身。
- **躯干**：腰前屈 5°、胸前屈 3°，稍微团身；胸带一点左旋 1°、右侧屈 1°，跟随右腿先收。
- **双臂**：0.20 s 上臂前举 52° / 48°，0.30 s 到 60° / 56°，同时外展 30° / 26°，前臂屈 38° / 34°，双手在胸前外侧平衡，右手约 21 px 高、身前 8 px。
- **头**：0.32 s 低头 4°，略向右转 2°。

### 下落（0.33–0.60 s）

- **腿**：0.45 s 伸到屈髋 24°、屈膝 38°，0.53 s 屈髋 12°、屈膝 20°，脚踝回到背屈 8°，准备全掌着地；
  脚底离模型地面 0.5 px 以上，直到 0.60 s 才落到地面。
- **胯**：0.53 s 后坐 0.3 px，0.60 s 下沉到 −0.2 px、后坐 0.6 px，触地前先把重心放到脚跟上方。
- **双臂**：外展加大到 36° / 34°、前举降到 18° / 16°，张开平衡。
- **头**：0.50 s 低头 8°，看落点。

### 落地缓冲（0.60–0.90 s）

- **触地 0.60 s**：双脚全掌着地，膝屈 21°、髋屈 16°，踝背屈 8°。
- **缓冲 0.60–0.72 s**：胯沿设计曲线下沉 −0.9 / −1.6 / −1.9 px（0.64 / 0.68 / 0.72 s），同时后坐 1.1 / 1.6 / 1.9 px，前倾 6° / 10° / 12°；
  腿由脚底锁定求得，0.72 s 屈髋 53°、屈膝 65°、踝背屈 24°。膝角速度峰值 0.62 s（约 700°/s），之后减速。
  腰前屈 6°、胸前屈 5° 跟着身体前倾，头抬起 12° 保持平视。双臂外展 30° / 28°、前举 16° / 14°，肘屈到 34° / 32°。
  脚趾在 0.66 s 轻微背伸 4° / 1°，表现重量压到前脚掌再回落。
- **回弹 0.72–0.85 s**：胯回升到 −0.9 px（0.80 s）、−0.3 px（0.85 s），膝从 65° 伸到 27°，双臂收回身侧，头回到 2°。
- **站直 0.90 s**：全身回零，速度为零。

### 不动的部位

`root` 不动：实体的上升和下落由原版物理负责，动作只在 `pelvis` 上做 ±2 px 以内的下蹲和拉伸。

收腿时右腿屈髋峰值 0.174 s、左腿 0.241 s；落地缓冲时屈膝峰值 0.623 s，比胯的前倾峰值（0.656 s）和头的抬起（0.673 s）早。

预备与跟随：蹬伸前有下蹲（屈髋屈膝、踝背屈）和双臂后摆的反向预备；蹬伸后双臂继续上抬到 0.30 s、脚尖继续绷到 0.20 s，
再进入团身；落地后有下蹲缓冲和回弹。

## 6. 重心与支撑

只有 0.00–0.06 s 和 0.60–0.90 s 双脚着地。0.08–0.55 s 脚底离模型地面 0.32 px 以上（0.20 s 左脚最低）；
0.06–0.08 s 是刚离地、0.55–0.60 s 是落向地面，这几帧脚底在 0.25 px 以内，门禁按着地计入滑动，实测脚踝位移仍只有 0.21 px。

## 7. 道具

不涉及道具。手持物品随 `r_item` / `l_item` 跟手，起跳前摆和缓冲张臂时不与身体相交（手与躯干、头包围盒最近 0.5 px，静止站姿时贴身侧）。

## 8. 索引条目与叠加

提议：`mask: full`、`priority: 16`、`blend_in: 0.05`、`blend_out: 0.15`、`hand: none`、`fpv: false`。

- 底层 `walk` / `run` / `sneak`：跳跃是全身动作，腾空和落地期间下身、上身都由本动作接管；落地段结束后淡回当时的移动底层。
- 跳跃中攻击：攻击按自身规则只取 `upper` 叠在本动作上，双腿保持跳跃姿态（[切换表](transitions.md) 的 `jump_air + attack`）。
- 腾空中进入水或鞘翅：按切换表转到 `swim` / `elytra`，本动作淡出 0.08 s。

## 9. 与其他状态的衔接

- 进入：`stand`、`walk`、`run`、`sneak` 离地沿；淡入 0.05 s 正好覆盖首帧下蹲，脚底不跳。
- 落地后：淡回 `stand` / `walk` / `run` / `sneak`。落地段 0.90 s 的末帧是站姿零位，淡回移动底层不会再塌一次。
- 连跳：从缓冲姿态交叉淡入回起跳下蹲，两者都是屈膝约 50°～65°，不经过站直。

## 10. 门禁预期（原型实测，classic 骨架）

| 门禁 | 适用 | 原型结果 |
| --- | --- | --- |
| 有效运动骨骼 | 是 | 26 根（只有 root 不动） |
| 躯干链 / 头 | 是 | 胯、腰、胸、头都参与 |
| 双臂双腿（全身动作） | 是 | 通过 |
| 握持手指 | 否 | 非持物动作 |
| 关节角度 | 是 | 最大：腰 8°、胸 5°、颈 12°、肘 38°、腕 10°、膝 80°、踝 24°，全部在上限内 |
| 角速度 / 抽搐 | 是 | 60 Hz：最大 685°/s（小腿 0.633 s）、1.23×10⁶°/s³；120 Hz 复核最大 699°/s，没有超过 720°/s 的时刻 |
| 预备 / 跟随 | 是 | 设计上满足（第 5 节）；现有分析器判定无法通过，原因同 [attack_main](attack_main.md) 第 10 节 |
| 错峰 | 是 | 手臂 → 髋膝 → 脚趾 → 躯干 → 踝 |

## 11. 待审事项

- 用竖直速度驱动腾空、落地沿进入落地段，而不是现在的“离地 play / 落地 stop”，需要运行时配合。
- 首帧下蹲是对“原版没有离地前时间”的折中：起跳头 0.06 s 演出蹲—蹬。如果审阅方希望完全不要下蹲，可以把首帧改成半伸展，代价是起跳不够有力。
- 落地缓冲深度固定，不随下落速度变化。高处落下想更深地蹲，需要运行时按落地速度给落地段加权，本稿不包含。
