# bow_draw：拉弓（随原版拉弓进度拉满，松手撒放）

> 审阅状态：**设计稿，待审阅**（2026-10-26）。尚未录入 `.bbmodel`。轴向与坐标见 [共用约定](conventions.md)。
> 本稿关键姿势已用正向运动学核对（弓手朝向、锚点可达性）；首版原型轨道**未通过**手臂穿模与角速度门禁（第 9 节），
> 原因已定位，阶段 2 按本稿第 3 节的修订姿势重做后再跑门禁。

## 1. 动作目的与触发

- **用途**：`UseAction.BOW` 持续使用。原版 `ArmPose.BOW_AND_ARROW`（主手右手持弓）：右臂 `yaw = −0.1 + headYaw`、
  左臂 `yaw = 0.5 + headYaw`，两臂 `pitch = −90° + headPitch`，即双臂平举指向视线，左手并不后拉。
- **触发**：`armPoseAction` 的 `BOW` 分支；弓在主手 `bow_draw`，副手 [bow_draw_off](bow_draw_off.md)。
- **原版进度来源**：`BowItem.getPullProgress(useTicks)`：`f = t / 20`，`pull = min((f² + 2f) / 3, 1)`，**20 tick 满弓**；
  松手时 `pull < 0.1` 不发射。弓最大使用时间 72000 tick。
- **驱动**（scrub）：
  - 拉弦：`clip = 1.0 × pull`（`pull < 1`）。2 tick 时 pull 0.07、4 tick 0.15：前 0.15 s 剪辑（举弓、搭箭）约在 4 tick 内完成。
  - 满弓保持：`pull = 1` 后 `clip = 1.0 + ((used − 20) / 20 mod 0.6)`，在 `loop_region [1.0, 1.6]` 回绕（持弓微颤与呼吸）。
  - 撒放：停止使用且 `pull ≥ 0.1`（原版确实射出）时，调度按真实时间把剪辑从 1.6 推进到 1.9（6 tick），再淡出；
    机制同 `attack` 收势尾段（`attackTailProgress`）。从未满弓或保持段中间进入撒放时用 0.08 s 交叉淡入。`pull < 0.1` 松手直接淡出。
- **结束**：撒放段末或未发射松手，淡出 0.15 s。

## 2. 时间轴

剪辑长度 **1.9 s**，`loop: "hold_on_last_frame"`，`loop_region: [1.0, 1.6]`。建议在 1.6 s 加时间线事件 `release`（白名单已有）。

| 段 | 剪辑时间（拉弓进度） | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.04 | 胯回转 +1.5°、右臂下沉后撤 5°，胸腰微后仰 |
| 举弓搭箭 | 0.04–0.15 | 躯干左转成侧身（胯 −8°、腰 −6°、胸 −9°），头右转 28° 看向前方；右臂平举、弓手朝向对齐原版；左手到弓把旁勾弦 |
| 拉弦 | 0.15–1.00 | 侧身加深到 65°（胯 −22°、腰 −18°、胸 −25°），左手沿箭杆后拉到右下颌旁锚点，左肘抬起向后；胸后仰 2°、肩胛内收 |
| 满弓保持 | 1.00–1.60 | 持弓臂每 0.3 s 一次 1.2° 微颤，弦手 1.5° 后拉蓄力，胯 0.03 px 下沉 |
| 撒放 | 1.60–1.90 | 弦手向后上弹开 12°、手指张开；持弓臂前送 6° 后回 3°；腰胸回转 3°～5°，头回 2°～3° |

## 3. 分阶段全身姿势（修订后目标）

- **弓手朝向**：满弓时右手世界朝向与原版持弓右臂 `(90, −5.7, 0)` 相同，保证 `bow_pulling_*` 模型方向与原版一致。
  躯干左转 65° 时，右上臂面板值约 (88, 59.3, 0)（在胸部空间向外 59°，世界里正指前方），肘只屈 6°、腕 (−6, 0, 0) 补偿。
  `r_item` 约 (−2.1, 23.9, −14.3)。
- **为什么要侧身 65°**：Steve 两肩相距 10 px、肩到挂点约 10.6 px。正身或侧身 35° 时，左手要把弦拉到右肩前方，
  距左肩 11.9 px，超出臂长（原型 IK 误差 2.4–3.4 px，肘被拉直、手臂横穿头部，即首版失败原因）。侧身 65° 后左肩转到身后，
  锚点放在右下颌旁 `(−1.3, 24.4, −3.2)`，距左肩约 9.8 px，原型 IK 解误差 0.19 px、肘屈约 43°。
- **拉距**：从 0.15 s 弓把旁 (`r_item` + (1.2, 0.6, 1.0)) 拉到锚点，约 11 px。原版 `bow_pulling_2` 模型里的箭尾位置固定，
  手与模型箭尾可能相差 2–4 px，需要 `calib_item` 游戏内对照后微调锚点。
- **躯干与头**：胯 Y −22°、腰 −18°、胸 −25°（各在腰 45°、胸 60° 上限内），胸后仰 2°；头 (−2, 62, 6)，颈 62° < 75°，脸朝前、
  向右歪 6° 让脸颊靠近弦。
- **双腿**：踝锁定在零姿态；胯左转时大腿 Y 反向补偿 22° 保持脚尖朝前（髋外旋），膝屈约 30°，下沉 0.4 px。
- **左手指**：勾弦 0.18 s 起屈到 −62°～−66°，满弓 −70°～−74°，撒放 1.67 s 张开到 −8°～−10°。右手握弓 50°～86°。
- **视线**：原版持弓双臂跟随视线俯仰与偏航。资源按平视制作，运行时需像 `spyglass` 一样绕两肩共同轴线刚性旋转双臂
  （保持弦手与弓的相对位置），见第 8 节。

## 5. 重心与支撑

侧身转动只改变上身朝向，胯在脚间；原型（首版）重心 x −0.08～+0.01 px、z −0.38～−0.23 px，脚底最低 −0.019 px，滑动 0.024 px。

## 6. 衔接

- 进入：站立/步态/潜行/`crouch_work`/骑乘/腾空 → `bow_draw`，淡入 0.08 s；移动底层时只取 `upper`。
  `upper` 遮罩不含胯，叠在步态上时胯的 −22° 不生效，侧身只剩 43°，锚点会再次够不到。提议：不做第二套资源，
  阶段 2 把扭转改由腰（−25°）和胸（−37°）承担，胯只保留 −3°，使 `full` 与 `upper` 两种叠加的上身朝向一致
  （腰、胸仍在 45° / 60° 上限内）。此项需要审阅决定（见第 10 节）。
- 退出：撒放尾段后淡出 0.15 s；未发射直接淡出。

## 7. 索引条目（提议）

`mask: full`、`priority: 15`、`blend_in: 0.08`、`blend_out: 0.15`、`hand: main`、`fpv: false`、`loop_region: [1.0, 1.6]`、
`phases: [[0, 1.0], [1.6, 1.9]]`。

## 8. 接口缺口

1. `armPoseAction` 的 `BOW` → `bow_draw` / `bow_draw_off`；`armPoseProgress` 用 `BowItem.getPullProgress(used)` 与保持回绕。
2. 撒放尾段：调度需要记住“上一 tick 在用弓且 pull ≥ 0.1”，停止使用后按真实时间推进 1.6→1.9（新增状态，复用 `AttackState` 风格）。
3. 视线：`PlayerMeshRenderer.applyArmPosePitch` 加入 `bow_draw` / `bow_draw_off`，按 `spyglass` 的共同肩线刚性旋转；
   原版双臂还跟随 `headYaw`，需同时绕胸部竖直轴补偿剩余偏航（与 [head_follow](head_follow.md) 的分配配合）。
4. 分析器：错峰主链应为拉弦臂（主手持弓时是左臂），参照 `crossbow_charge` 的特例；`GRIP_IDS` 加入两者。
5. 目录 `BOW_DRAW`、`BOW_DRAW_OFF`；`upperOverlay` 加入 `bow_draw`。

## 9. 门禁预期

首版原型（侧身 35°、拉距 6.5 px）实测：有效骨骼 25、相关性 0.063、着地通过；**失败**：手臂穿模 4.7 px（左前臂横穿头部，
IK 被拉直）、左上臂角速度 1,690°/s（举弓段 Euler 大幅翻转）。修订：侧身 65°、锚点下颌旁、左臂按可达 IK 解并在
Blockbench 中检查欧拉分量连续性，举弓段不跨越 ±180° 分支。阶段 2 必须重跑全部门禁，不沿用首版数值。

规模预估：23–25 骨、约 180 关键帧（含撒放段）。
