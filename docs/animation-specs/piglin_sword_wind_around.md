## 1. 目的与触发

- **用意**：目录描述是「剑尖不与盾面争力，顺着缝隙绕进去」，设计稿 §7 写「刺出、腕子外翻」。动作是**一剑刺出**，出手末段腕子外旋画一个圈，剑尖先偏出盾沿外侧，再往里勾到盾后。身子侧着送进去。**不是劈砍**，剑刃不画竖弧也不画横弧。
- **触发**：宿主收到表现 `meridian_piglin_sword:wind_around` 的 `START` 时起播，`start_millis 0`；收势结束时宿主发 `STOP`。施放者单手持剑，主手或副手都可以（上卷规则），手里可以是金剑，也可以是别的剑。
- **一眼要读出的**：刺的轨迹是直的，剑尖在最后一小段走一个向外凸的钩。身体由半侧身（左肩在前）拧成右肩在前。打完收回架势。

## 2. 时间来源（目录 → 剪辑）

目录取自 `wt-sword-p2` 的 `technique_catalog.txtpb`。P2 已审过待合，主线 `55bf786` 里这一式的时间与它相同。

| 目录 | 值 | 剪辑里 |
| --- | --- | --- |
| `warmup_millis` | 350 | 0.00–0.35 起手 |
| `active_millis` | 0 | 无生效段 |
| `recovery_millis` | 650 | 0.35–1.00 跟随与回收 |
| `weapon_strike` `at_millis` | 350（单体、3 m、60° 锥、`facing_offset 0`、×1.0） | **`hit` 0.35**，剑尖到盾后、手臂最长 |
| `presentation` | `at_millis 0`、`UNTIL_RECOVERY_END`、`start_millis 0` | 剪辑 0 = 施放 0；`STOP` 在 1.00 到，和剪辑末帧同时 |

剪辑长 **1.00 s，20 tick**。这和袖手拳崩拳是同一个约定：目录 1000 + 2000 ms 对应 3.0 s 剪辑，`hit` 在 1.00。时间按 tick 对齐：0.35 s 正好是第 7 tick。宿主慢放时按 `HumanTechniqueAnimations.playback` 给的 rate 拉长，`hit` 跟着伤害时刻一起移动。

## 3. 关键姿势

数值是相对 [stance_idle](stance_idle.md) 首帧的增量；实际关键帧以 MotionBricks 试验仓 `scripts/author_piglin_sword_pa.py` 的 `WIND_AROUND` 为准。躯干各骨的转角是各自局部的，逐节叠加。2026-11-24 用户看过 GIF 后要求「加一点身体的协调以及腿部的动作」，本节是返工后的姿势。

- **起姿 P0（0.00）**：逐骨等于 `stance_idle` 首帧，握形和脚趾也一样。剑在右拳里，竖在右下颌侧前方，剑尖朝上、略向前。左拳在左肩前、下巴高。左脚在前全掌着地，右脚在后提踵。胯右转 12°，躯干累计右转 20°，是半侧身。
- **蓄 P1（0.06–0.16）**：
  - **腿和胯**：胯往后脚坐 0.5 px、沉 0.15 px，重心压到后腿上。
  - **躯干**：胯再右拧 3°（0.06），腰 4°（0.08）、胸 4°（0.10）依次跟上，胸微后仰。头反向左转 5°，一直看着目标。
  - **右臂**：手往后下收到腕点 `(−6.4, 17.6, −7.0)`（0.16），前臂旋前、腕往里扣，剑从竖着放平，剑尖指向对方胸口一线。手往后下走，不往脸前收：这一点让剑离头盒和架势一样远。
  - **左臂**：拳往前顶到 `(4.8, 20.3, −7.6)`（0.12），和右手的后收对拉。
- **刺到 P2（0.35，`hit`）**：
  - **腿**：后脚蹬，胯往前脚送 2.0 px、沉 0.6 px（0.24），成弓步：前膝弓出（前小腿实测多屈 18.9°），后膝蹬直（后小腿伸 9.4°），后脚跟再抬 8°。两脚原地不挪，前脚全掌、后脚前掌接地点不动。
  - **躯干**：胯先左转 16°（0.24），腰再左转 12°、前倾 2.5°（0.27），胸再左转 10°、前倾 6°（0.30），共左拧约 38°，从半侧身拧成右肩在前。
  - **头**：反向右转到 34°（0.31），抵消躯干的拧转，一直看着目标，下巴微收。
  - **右臂**：前伸到肩高略低，肘留 12° 不锁死，手指再握紧 4°。剑身与前臂大致对线（第 5 节），前臂比 P1 外旋，剑尖走完外凸弧、勾在中线内侧。
  - **左臂**：往后下展开（从肩往后下、肘留 25°），给前刺配重。
- **跟随 P3（0.43–0.47）**：胯、腰、胸各再左转 1°，胯再前送 0.1 px，然后整体刹住。头转到 37°。右肘伸到 10°，腕再外旋几度把钩走完。左臂停在后下。
- **收回 P4（0.80–1.00）**：后脚跟 0.80 落回架势，胯和躯干 0.82–0.85 回到半侧身，右臂 0.85 收回架势，剑竖回右颊旁。末帧逐骨等于首帧。

## 5. 遮罩、覆盖骨与持物

- **遮罩**：`mask: full`、优先级 24、淡入 0.10、淡出 0.25，和破门斩、袖手拳等功法剪辑同一套；25 根骨全部写轨道，`root` 不写。
- **走动中施放**：索引写 `upper_while_moving: true`。静止架势上整段生效；移动底层（走、跑、潜行、闪避、跃步）上只取上身，腿听底层，规则同格挡（[资产契约](../asset-contract.md)「索引条目」）。剑三式施放时不减速，这样走动中出剑脚不滑。
- **全身门禁**：这一式进 `FULL_BODY_IDS`，两臂、两腿、躯干链和头都要过有效运动阈值。左臂的配重和两腿的弓步都超过 3°。
- **脚**：两脚原地不挪（六式都不带冲刺），前脚全掌、后脚前掌的接地点不动。门禁实测鞋底最低 −0.228 px（主手）/ −0.224 px（副手），支撑脚滑移 0.087 px。
- **握持**：进 `GRIP_IDS`。右手拇指和两组手指全程握住，形状沿用架势的握拳，刺出时可以再收紧几度，不允许张开。左手全程握拳。
- **剑身与前臂对线**：本骨架的剑从拇指侧出来，和前臂约成 80°。刺要把夹角压到 ≤ 20°。做法：
  - 腕的弯折相对架势 ≤ 40°（同破门斩的腕约束）；
  - 剩下的角度交给索引 `item_rotation`，绕持剑挂点转剑，先例是药刀的 `[[0.0, [54, 0, 0]]]`。审定只在刺出段用：`[[0.0, [0,0,0]], [0.12, [0,0,0]], [0.33, [58,0,0]], [0.47, [58,0,0]], [0.64, [0,0,0]]]`，0.64 转回 0。
  - 门禁会把 `item_rotation` 当作挂点轨道一起查角速度和角加加速度。
  - 实测（classic、slim 相同）：`hit` 0.35 帧剑身与前臂夹角主手 4.1°、副手 1.1°；腕弯折最大主手 23.9°、副手 35.8°，旋前旋后最大主手 30.0°、副手 4.3°。
- **剑与身体的间隙**：`analyze_animation.py` 没有剑的几何。MotionBricks 生成脚本按 `render_animation_gif.py` 的剑几何逐帧算剑身到头、躯干、两腿和空手上臂的最小净距，算法同破门斩斧头。
  - 架势首帧本身剑离头盒就不到 1 px（classic 0.774、slim 0.435；副手版 2.688 / 2.311），所以判据是「≥ 1 px，或不比架势更近」。
  - 实测：主手全程最近处就是首末帧的架势；副手最近 2.442 / 2.118 px，在 0.07 s 蓄劲时。

## 6. 首末帧与衔接

- 首帧、末帧逐骨等于 `stance_idle` 首帧。从架势、普攻淡出、格挡放下或受击之后起播，都不跳。
- 起播在非架势底层（例如 `stand`）上时，两脚在 0.10 s 淡入里滑到架势踝位，淡出时再滑回。这和袖手拳、破门斩的已知行为一样。
- **接「弹」**：目录允许绕收势过半（0.675 s）后接「弹」。此时右臂正在沿刺线往回抽，弹的回弹方向也是往身上回，两者方向一致。弹用 0.10 s 淡入顶掉绕，见 [弹](piglin_sword_spring_back.md) 第 6 节。
- **被打断**：施放可以被伤害打断（`interruptible_by_damage: true`），框架会对已起播的表现发 `STOP`。剪辑用 0.25 s 淡出回当前底层，受击反应盖在上面。
- **接普攻**：收势结束后普攻 `attack_main`（优先级 20）起播。绕还在 0.25 s 淡出里时，普攻在它下面，淡出完就露出来。
- 切换表见 [transitions](transitions.md)「流金剑」。

## 7. 副手、左主手、体型、第一人称、剑的种类

- **副手版 `_off`**：剑在左手，也就是架势的前手。照 [door_breaker_knock_off](door_breaker_knock_off.md) 的做法，不整段镜像：
  - 持剑臂的剑尖和挂点目标 x 取反，对左臂重新求解。腕约束相对架势左腕计算。
  - 腿保持左前右后的架势，发力仍是后脚蹬、胯送前脚。
  - 躯干转动增量相对架势取反：右拧，左肩在前侧身，头反向转着看目标，颈 ≤ 75°。
  - **胯转 ×0.7、前送 ×0.8、不下沉**（`OFF_THRUST_HIP_TURN`、`OFF_THRUST_HIP_SHIFT`）：盒子模型里胯往右拧时后腿折得更厉害，照主手版的幅度后小腿盒的角会低于地面（−0.41 px）。弓步因此浅一些：前送 1.7 px，前小腿多屈 7.8°。
  - 蓄劲时前手（持剑手）按肘角 80° 从肩往前上放平剑（`OFF_WINDUP_ELBOW`），不用主手版的世界腕点：前手离目标近，照抄会让上臂、前臂在蓄劲里先伸后屈、超速。
  - 主手版 0.29 s 的腕翻关键不抄（`skip_blades`）：左手照抄这一下会把腕甩过头，超速。
  - 右拳（空手、后手）刺出时直接往后下展开配重，不先护在脸前。
  - 前手到目标近，伸展幅度比主手版小。`hit`、`phases` 和索引都同主手版，只把 `hand` 改成 `off`，主链改查左臂。
- **左主手玩家**：运行时按 `hand` 把整套资源（含 `stance_idle`）镜像，不另做。
- **粗臂 / 细臂**：同一条 classic 轨道，两种体型分别过门禁、分别出 GIF。细臂要特别看两处：后手回收时拳到头盒的间隙，以及挂点位置变化后剑到脸的间隙。
- **第一人称**：`fpv: false`，照现有规则。独立第一人称手臂不播这段；全身第一人称复用第三人称姿态，`fpv_torso` 用缺省 `true`。游戏内录像时要在全身第一人称里截图，看刺出的剑能不能进画面、手和剑有没有戳进镜头（待 Human 接线后做）。
- **金剑与别的剑**：一套轨道。剑只跟着 `r_item` / `l_item` 和物品自己的显示变换走。金剑剑身弯是剑仓的特效，不做进关键帧，也不分物品出剪辑。

- `timeline`：`0.35: hit`。副手版只改 `id`、`file`、`hand: off`，`phases` 的链换成 `l_upper_arm`、`l_forearm`、`l_hand`。
- `swings` 不手写：由 SwingWindowsContractTest 实测，再用 `scripts/apply_swing_windows.py` 写回。只量 `phases` 声明的发力段，淡入期间不量（asset-contract「索引条目」swings）：破风声落在刺上，起手淡入和收势的 `item_rotation` 转回都不算挥击。实测（返工后）：主手 0.12–0.33 重（剑尖最快 14.2 格/s），副手 0.12–0.32 重（12.5 格/s）。0.12 起剑尖已经随胯转往前、往外绕，往回带的那一下在淡入里（0.05–0.10）。

  - 腕外旋圈要放在 ≥ 0.12 s 里走完；外旋 50° 压到 0.12 s 以内就会超限。
  - 实测最大角速度主手 584°/s、副手 618°/s，最大角加加速度 5.9e5 / 4.7e5°/s³，都在普通限值内。

## 9. 审片要点

- 侧面：刺是直线，不带上下劈弧；侧身从左肩在前换到右肩在前，看得出后脚蹬、前膝弓出、胯先走，两脚不挪、不穿地。

- 0.35 帧单独截一张：剑尖在最前、手臂最长，和伤害时刻对齐。
