# door_breaker_knock_off：叩门（副手出手）

> 状态：**已录入 `models/player_skeleton_classic.bbmodel` 并导出**（2026-10-29，斧刃版），随 [door_breaker_knock](door_breaker_knock.md) 一起审阅通过、一起制作。门禁实测见主手页第 11 节；游戏内验收与触发接线尚未进行。

> **起手压缩（I7a，2026-11-02）**：与主手版同一套钉点和发力段平移，现长、时间线和打击时段相同，见 [主手页](door_breaker_knock.md) 页首说明；起手段逐帧速率按副手版自己的门禁另算，中间时刻与主手版相差不超过 0.04 s。现行索引与主手版相同。

## 为什么不整段镜像

叩门在静止的 `stance_idle` 上整段全身生效，首末帧必须等于 `stance_idle` 首帧（右手为主手时左脚在前、右脚提踵）。
`attack_off` 那样的整段镜像会把脚换成右前左后，淡入淡出时双脚会滑着换位。所以副手版只镜像手臂，腿保持架势。这条做法 2026-10-28 已经审阅方确认，本次不变。

## 做法（同一个原型 `d_knock.py`，`spec(off=True)`）

- **时间轴、事件、索引**：与主手版相同（3.0 s，`1.7: hit`，`impact_window [1.55, 1.75]`，`phases [[0.76, 0.90], [1.11, 1.25], [1.50, 1.75]]`），只把 `hand` 改为 `off`。服务端按钝击结算，同主手版。
- **持物臂（左）**：主手版拳的目标位置左右镜像（x 取反）。
  - 拳在左腹前；斧头中心每下举到最高时约在左肩顶高度（≤ y 23.5）；三下刃口点落在身前同一片（镜像后 x ≈ +5～+6，z −13.5、−14.0、−15.0）。
  - 柄线方向取「世界镜像」与「胸部局部镜像」的加权（0.4 / 0.6），沿用柄尾版：只按世界镜像时左腕会顶到限位，只按胸部镜像时斧刃会偏向右前方。
  - 腕约束同主手版：弯折 ≤ 40°，扭转保持架势左腕的值 ± 12°（不翻腕）。
  - 左手是前手、头又朝它偏。斧子在 0.30–2.80 s 离头盒不足 1 px 时，在竖起的几帧（举、蓄）把拳向左外移 ≤ 1.5 px。
- **空手臂（右）**：右手是后手，够不到身前按门的位置，所以在右胸前方掌心朝前（腕增量 `(0, 0, −40)`，挂点约 `(−3.0, 21.5, −8.5)`）。蓄时收回护位；实叩时肘贴右肋回拉（上臂约 `(8, −12, −4)`、肘约 100°），不做镜像的外展。
- **躯干**：胯、腰、胸的转动增量（Y、Z）相对架势取反：预备右转 2°，对门左转 4°，两下轻叩右转，蓄时左拧共 20°，实叩右转发力。头仍按躯干转动的总和反向转，盯住门。
- **腿**：踝位保持左前右后的架势位置，重新求解。发力改为**前脚**：
  - 蓄时胯前移，压到前脚（相对架势约 `(0.25, −0.12, −0.3)`）；
  - 实叩时左脚蹬地，把身体送向后脚（约 `(−0.25, −0.6, 0.5)`），**后膝 1.70 撑住**；
  - 后脚全程保持架势提踵，前脚趾的抓地与主手版相同。
- **左主手玩家**：运行时按 `hand` 把整套资源（含 `stance_idle`）镜像，主手版和副手版都不用另做。

## 首尾帧的头盒问题（第 2 项已改架势，2026-10-29）

- 首尾帧就是共用架势的左护手位。按真实斧子几何，副手持斧时斧头本来就会插进头盒（柄尾版实测 0–0.33 s、2.80–3.0 s 都在头里，最深约 1.5 px）。
- 斧刃版在 0.30–2.80 s 把斧子放到肩高，这段能让开。首尾帧要等第 2 项改架势左手护脸位后才能解决。
- 第 2 项完成后，主手版和本段都按新架势基准重新生成，并重跑门禁。
- **第 2 项已完成**（[战斗架势总览](PROGRESS-combat-stance.md) 第 6 节）：新护手位下副手斧子离头盒 2.6 px（`stance_idle` 全段最小 2.57 px）。本段已在新架势上重新求解，全段斧子离头盒最小 2.54 px。

## 制作结果（2026-10-29）

与上文做法的出入：
- **持物臂目标**：取主手同一时刻“拳相对右肩”的位置，世界镜像后接到副手当时的左肩上；柄线方向取世界镜像与胸部局部镜像 0.7 / 0.3 的混合。
  - 原因：架势里左肩比右肩的镜像位置靠前约 3.4 px，只按世界镜像时，举和蓄够不到（手臂被甩到身后）；按胸部局部镜像时，落点被转到身体右侧、斧刃偏 66°～71°。
  - 结果：本段落点比主手版靠前约 3.5 px（刃口点 z −17.4 / −17.7 / −18.3），斧刃朝向与 −Z 夹角 45.0° / 48.7° / 48.9°。
- 没有用柄尾版的“拳外移”修正：斧子放到肩高后已离开头盒。
- **腿**：
  - 胯的实叩位移同样拆成先退后沉：1.53–1.62 s 高度不变送向后脚，前膝伸约 5.5°；1.62–1.68 s 下沉，后膝 1.725 s 停止屈曲。
  - 实测：前膝伸 1.537 s → 胯 1.587 s → 腰 1.613 s → 胸 1.629 s → 上臂 1.637 s → 肘 1.654 s → 腕 1.671 s。
- **规模**：24 骨 / 634 关键帧。

自查：
- 举到最高时斧头中心 y 22.86 / 23.10 / 22.72；
- 斧子到头盒全段 ≥ 2.54 px，到右手 ≥ 4.03 px；
- 刃口领先手臂 1.45～1.47 px；
- 左腕弯折最大 26.6°，扭转偏离架势最大 11.1°；
- 柄线过拳心偏差最大 0.17 px。

门禁：粗臂、细臂全部适用项通过，实测值见主手页第 11 节表格右列。改主手版后必须用同一原型重新生成本段，不允许只改一边。
