# wayfarer_gale_off：横风（副手版）

> 状态：**已实现，门禁通过，待游戏内验收**（2026-11-01），实测与出入见文末「制作实测」；扇面方向的服务端同步还没做（待决定第 13 条）。随主手页 [wayfarer_gale](wayfarer_gale.md) 一起审阅、一起制作；做法见 [PROGRESS-wayfarer](PROGRESS-wayfarer.md) C9。本页只写与主手版不同的地方。

## 做法

- **时间轴、事件、窗口**：与主手版相同（6.0 s；`0.75: step_r`、`2.20 / 2.55 / 2.90 / 3.25 / 3.60 / 3.95: release`、`4.90: step_r`；失衡、瞄准、六段 `phases` 都不变），`hand: off`。
- **扇面反过来**（待决定第 13 条）：先转到**左** 45°，再由左往右扫；六发依次朝视线左 45°、左 27°、左 9°、右 9°、右 27°、右 45°。服务端行矢 §4 没分主副手，**要那边同步镜像**，否则副手版的六发方向和动画相反。
- **上身**（镜像主手版，C9）：
  - 预备胯 Y +2°；抵腰：弩托顶**左**胯侧、弩身斜过腹前（弩口偏右约 15°），躯干前倾约 15°，胸相对胯**左**扭约 20°；左手（`l_item`）握弩，右手托在扳机前、推拉，右肘外张；
  - 转到左：整体左转，弩口到世界 −45°；回扫整体右转 −45° → +45°，胯领先，腰晚 0.03 s、胸晚 0.05 s；随：余势再转 7°，到 +52° 停住。
- **腿**：脚位与脚步照搬主手版（后脚 0.45 离地、向右后撤 1.5 px、0.75 以提踵落，`step_r`；4.50 离地、4.90 落回架势踝位，`step_r`），双膝屈 30°；回扫时两脚碾的方向与主手版相反（后脚脚跟内转、前脚脚尖外转）；重心从前脚移到后脚（主手版从后到前）。
- **物品**：`item_states` 与主手版相同，挂在副手。

## 与主手版不同的约束

- 抵腰摆法够得着同主手版一样是估算（主手页第 7 节），镜像后弩托顶的是前脚一侧的胯，左胯前送、右手要从身体右侧绕到腹前左边的扳机，原型核对；不够就把胸的左扭加到 25°。
- 回扫结束时身体朝右后方，收势转回正前的方向与主手版相反。

## 门禁

适用项同主手页第 9 节；握持查左手握弩、右手推拉；错峰主链换右臂（推拉臂，C12），预备 / 跟随用左臂链。

改主手版后必须用同一原型重新生成本段，不允许只改一边。

## 制作实测（2026-11-01）

与主手版同一原型生成（`d_gale.py` 的副手分支），索引字段、时间线同主手页第 10 节。扇面照本页反过来：先转到左 45°，六发依次朝 −45 … +45°，随到 +52° 停住。

门禁全部通过（粗、细臂相同）：关键帧 1,870；最快 652°/s（右前臂 2.67 s），抽搐最大 0.84×10⁶°/s³（同一处）；最低点 −0.21 px（左小腿 4.27 s）；重心出界 0.53–0.68 s、4.58–4.80 s（两次右脚迈步，都在失衡窗口内）；支撑脚滑动右 0.34、左 0.04 px；手臂穿模 0；预备 / 跟随 4/5 骨（胸反向只有 1.5°）。错峰门禁判到 2.20、2.55 两段（右上臂 → 右前臂 → 右手），其余四段右上臂在整段主轴 Z 上动不到 3° 没判到；探针按段内主轴另查，这四段也是右上臂 → 右前臂 → 右手。

自查：撒放帧弩口偏航与扇面差 ≤ 0.38°；头与弩口偏航差 ≤ 0.6°；弩口俯仰在后坐外 −1.4 … +1.2°；1.40–4.40 s 弩托离抵腰点最大 0.22 px（1.63 s）；托手转到左时离弩身最多 0.62 px（1.65 s），第一拉起都在弩身上；推、拉到底托手位置五次差 0.019 / 0.046 px。

与主手版不同的地方：
- **扭转按绝对值镜像**：抵腰时腰、胸面板 Y 取 −12 / −16°（主手版 +12 / +16°）。架势的腰、胸本来各右扭 4°，只镜像增量时胸相对胯只左扭约 12°，托手差 1.7 px 够不到、弩托偏 1.2 px；
- **重心路径另列**：转到左时胯前移 0.7 px、左移 0.5 px，回扫向右时后移 1.4 px 压到后脚（规格写的「从前脚移到后脚」），随时停在后脚；照搬主手版的路径扫到右端时右腿伸不到；
- 弩手 IK 的先验权重转身时 0.015、1.85–2.15 平滑升到 0.03（两版同一原型）：全程 0.03 时副手版弩托偏 0.53 px，全程 0.015 时托手超速；
- 本页「与主手版不同的约束」第 1 条的「把胸的左扭加到 25°」没用上，绝对值镜像后左扭 28°（腰 + 胸面板值）已经够得着。
