# guard_arms：双前臂抱架

> 空手护面规格。以下时间是原速下的剪辑时间。骨骼名称、左右与镜像沿用[共用约定](conventions.md)。

## 1. 目的与触发

玩家在战斗架势中起守，双前臂从架势拳位抬到头、胸前。宿主从起手时刻播放一次，400 ms 抬完，此后一直守到宿主停止。主手持剑或斧时使用持兵器横架。举盾时的准入由宿主处理。

## 2. 关键姿势与支撑

- **战斗架势**取 [stance_idle 首帧](stance_idle.md)。右主手时左脚在前、全掌着地，右脚在后、提踵以前掌承重。左拳在肩前，右拳在下颌侧。这个姿势也是放下的终点。
- **抱架基准**取抬完、第一次吸气前的姿势。正面看，两拳约在额头高度，两前臂并排竖在脸、颈前，中间只留一道向前看的窄缝。肘尖向下，收在上胸前方。侧面看，前臂与脸之间留有受击后让的空间。腕和肘各在自己一侧，两臂不交叉。
- 胯比战斗架势略沉，腰胸基本直立，下颌微收，视线仍向前。双膝随胯加深屈曲，重心投影始终在原有两脚之间。手指保持握拳或握柄，剑刃随主手腕从同侧向外上方露出。以空手能看清两条前臂、持剑时脸和另一只手都避开剑刃为准。
- 抱架基准由三段共用，包含胯、腿、腕和手指。[受击](guard_arms_hit.md)从这里起、回到这里，[放下](guard_arms_lower.md)从这里起。

## 3. 分阶段全身动作与标记

| 剪辑时间 | 步骤 | 从画面上要能读到的动作 |
| --- | --- | --- |
| 0–100 ms | 起手 | 先屈膝、微沉胯，腰胸立起，下颌跟进。肘在原拳位下方往里收，双手始终在身前。 |
| 100–300 ms | 抬臂 | 上臂把肘送到上胸前方，两侧拳同时向额前聚拢。正面能看见前臂逐步遮住脸颈。胯的下沉先收住，脚位固定。 |
| 300–400 ms | 成架 | 胸与头先稳住，肘、腕依次减速，手指收稳。到 400 ms 两臂已完整护住头胸，可以直接连接放下或受击。 |
| 400–1050 ms | 吸气 | 胸口微展，腰、肩跟随，双臂随胸略起伏。拳仍在额前，肘仍在胸前，脚底接地点不移。 |
| 1050–2000 ms | 呼气 | 胸口徐徐回落，重量经胯、膝落稳，两肩和手略晚回到抱架基准。下一次吸气接上时位置与速度都连续。 |

剪辑长 **2.00 s**，只回绕 **[0.40, 2.00] s**，每次呼吸 **1.60 s**。循环两端逐骨同姿，呼吸幅度以侧面可读、任意相位切受击或放下都不跳手为准。
400 ms 是视觉到位和循环入口。三段的阶段均只用于制作和检查，不向 `timeline` 发出格挡生效、命中或脚步事件。

## 4. 覆盖、持物与视角

三段沿用 PA 的架势覆盖规则。索引均为 `mask: full`，同归 `AnimationPlayer.stanceOverlay`。静止架势取胯、腰、胸、头、两条完整手臂（至手指）和双腿（髋至脚趾）的姿态。双脚只吸收重心变化，`root` 固定。
在 `stance_walk_*` 等现有移动底层上，`effectiveMask` 取 `upper`，只覆盖腰、胸、头和双臂。胯、腿、踝和脚趾继续走当前步态；起步、停步以及受击、放下都沿用同一条规则。守中四成移速由宿主控制。

三段都取 `hand: main`，以右主手制作，左主手由播放器整段镜像。物品跟随本手现有挂点，手指保持握形，手背和剑柄在粗臂、细臂上都要与脸留出间隙。
沿用格挡的 `fpv: false`。全身第一人称复用第三人称姿势，独立第一人称手臂沿用原有表现。实际全身第一人称须能从双拳之间看清准星前方。

## 5. 播放与衔接

- 建议 `priority: 15`，淡入 0.05 s、淡出 0.08 s，`loop: hold_on_last_frame`，索引 `loop_region: [0.40, 2.00]`。目录中作为持续动作登记，不设自然结束 tick。
- 宿主用 `playFrom`，按起播 tick 和倍率取剪辑时间。索引的 `free_loop_region: true` 让自由播放也按上述区间回绕。例：剪辑已经过 2.20 s，应显示 0.60 s 的呼吸姿态；晚进入视野的观察者也从该相位接上。
- 受击叠在保持之上，保持仍走原来的时钟。收到真实收势通知才换放下；按下不足 400 ms 就松开时，正常收势仍从抬完的位置开始。中断、死亡的显式停止交还当前底层。下次守从战斗架势重新抬手。

制作验收看两种体型的正、侧与四分之三视角，特别检查呼吸第二圈、吸气顶点转受击、走动中停步。全身联动、握持、穿模、脚滑及循环位置与速度按 [PA 验收规则](../animation-acceptance.md)核对。
