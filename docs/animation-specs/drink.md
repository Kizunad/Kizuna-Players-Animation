# drink：饮用（举瓶到嘴边，随饮用仰头）

> 审阅状态：**设计稿，待审阅**（2026-10-26）。尚未录入 `.bbmodel`。轴向与坐标见 [共用约定](conventions.md)，
> 数值来自设计期原型轨道并经仓库门禁同算法核对。

## 1. 动作目的与触发

- **用途**：`UseAction.DRINK`：药水、牛奶桶、蜂蜜瓶。原版第三人称只套 `ArmPose.ITEM`。
- **触发**：`armPoseAction` 中 `DRINK` 分支，主手 `drink`、副手 [drink_off](drink_off.md)。
- **原版进度来源**：药水、牛奶桶 32 tick，蜂蜜瓶 40 tick。`spawnConsumptionEffects` 对 DRINK 只播放饮用音效，节拍同进食：
  已使用 8、12、…、28 tick（32 tick 物品）。
- **驱动**：`t = min(已使用 tick / 20, 1.60)`，保持末帧。剪辑 0.40 + 0.2k s 是吞咽点，对齐已使用 8、12…28 tick 的音效；
  1.60 s（32 tick）仰头最大。蜂蜜瓶多出的 8 tick 停在仰头姿态（音效 32、36 tick 时不再额外吞咽，见第 9 节待审项）。
- **结束**：喝完或松手淡出 0.20 s。

## 2. 时间轴

剪辑长度 **1.60 s**，`loop: "hold_on_last_frame"`，无事件。

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 预备 | 0.00–0.08 | 同 [eat](eat.md)：胸腰后仰、右臂下沉后撤、头先抬 2.5° |
| 举瓶 | 0.08–0.33 | 右臂把瓶口送到嘴边，瓶身前倾；0.31 s 上臂过冲 2°，0.32 s 肘先少屈 5° 让瓶子离脸（避免穿过头），再回到 0.40 s |
| 饮用 | 0.40–1.60 | 头从 −2° 逐渐仰到 22°，胸 −3° → +5°、腰 −2° → +2.5°、胯 0° → +1.5°（后仰由下往上分担）；右上臂抬 53° → 80°、腕把瓶底抬高（X −48° → −70°）；每 0.2 s 一次吞咽：头先收 1.6° 再回到仰头曲线 |
| 保持 | 1.60 | 仰头末姿，直到使用结束 |

## 3. 分阶段全身姿势

- **到嘴（0.40 s）**：右上臂 (53.1, −32.9, −29.2)、肘 102°、腕 (−48, −24, −6)：`r_item` (0.25, 24.4, −6.7)，瓶口在嘴前 1.6 px。
- **仰头（1.60 s）**：右上臂 (80.3, −31.6, −31.9)、肘 101.9°、腕 (−70, −24, −4)：`r_item` (−0.04, 27.7, −3.7)，
  在仰起的嘴（(0.56, 27.5, −2.3)）前 1.4 px、略高，瓶身接近水平。
- **头**：(−2, 3, 2) → (22, 3, 2)。颈 22° 后仰，胸腰后仰 7.5° 分担，避免只靠脖子仰。
- **左臂**：从身侧逐渐抬到胸前保持平衡：上臂 (6, 3, 8) → (14, 5, 16)，肘 24° → 40°，手掌半开（−12°～−25°）。
- **躯干与腿**：胯左移 0.3 px 承重，后坐 0.18 → −0.15 px（仰头时胯前送以保持重心）；脚底锁定，左膝屈约 20°、右膝 13°。
- **不动的部位**：`root`；脚不离地。

## 4. 关键帧

全部 Catmull-Rom。见附表。

## 5. 重心与支撑

重心 x 0.01～0.51 px、z −0.34～+0.03 px；仰头时胯前送把重心留在脚掌上方。原型脚底最低 −0.010 px，滑动 ≤ 0.016 px。

## 6. 衔接

同 [eat](eat.md) 第 6 节（底层集合相同，`upper` 叠加，淡入 0.10 s、淡出 0.20 s）。

## 7. 索引条目（提议）

`mask: full`、`priority: 15`、`blend_in: 0.10`、`blend_out: 0.20`、`hand: main`、`fpv: false`。

## 8. 接口缺口

1. `armPoseAction` 的 `DRINK` → `drink` / `drink_off`；`armPoseProgress`：`clipSecondsProgress(min(used / 20, 1.60), 1.60)`。
2. 目录 `DRINK`、`DRINK_OFF`；`upperOverlay` 加入 `drink`；`GRIP_IDS` 加入 `drink`、`drink_off`。
3. 视线：同 eat。仰头末姿与原版视线俯仰叠加时，玩家抬头看天会更仰；`head_follow_pitch` 对 `drink` 需要按 50% 权重叠加
   （第 [head_follow](head_follow.md) 第 6 节列出例外表）。
